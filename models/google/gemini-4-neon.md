# Gemini 4 Neon

Google recommends Neon for complex software engineering, knowledge work and science when time to finish the whole task matters. Google's guide places it between Hydrogen and Carbon for those workloads [L: api-guide]. Google lists `gemini-4-neon` as a stable text-output model with multimodal input [L: api-model].

## How to instruct it

### Setting up the prompt

Google's model guide shows requests with task instructions in the input and generation controls in a separate configuration. It gives no model-specific system prompt template [L: api-guide].

### Reasoning and effort

Set `thinking_level` to low, medium, high, xhigh. The default is `high`. Google recommends low for simple work and xhigh for the hardest tasks. Leave room for the final answer because thinking consumes part of `max_output_tokens` [L: api-guide].

### Output: format, length, tone

The Gemini API guide gives 65,536 output tokens for a normal synchronous response. For more, use long decode with background execution in the Interactions API or client-side continuation. Join the text from each `model_output` step if the Interactions API returns multiple steps [L: api-model, api-guide].

### Tools and agents

Google lists function calling, code execution, computer use, file search, Search and Maps grounding, and URL context. The Interactions API also offers tool retrieval in preview [L: api-model].

### Coding

Google recommends Neon for multi-file engineering work and describes using it to direct Hydrogen subagents in Google Antigravity [L: launch].

### Long context and retrieval

The 1,048,576-token window is shared by input, thinking and output. The input reduces the maximum available output with long decode. The Gemini API guide gives 4,096 tokens as the implicit-cache minimum and a 95 percent input discount on hits. It lists implicit caching only [L: api-model, api-guide].

### Structured output

The Gemini API lists structured outputs as supported. The model guide gives no model-specific schema rules [L: api-model, api-guide].

### Images, audio, other inputs

The Gemini API specification lists text, image, video, audio and PDF input and text output. Agentic video understanding defaults to static processing [L: api-model].

### Sampling and API parameters

Google says the Gemini API ignores in-range values for temperature, top_p and top_k and returns HTTP 400 for values outside the valid range. [L: api-guide]

### Migrating from the previous generation

Google recommends Neon as an upgrade from 3.1 Pro Preview and advises testing medium and high on existing workloads. Argon and Carbon default to medium, so specify the thinking level when migrating an application that relied on that default [L: api-guide, model-choice]. When moving from a model that supports explicit caching, Google says to remove the cache creation call and cached-content field [L: api-guide].

## What the system card reports

Google adapted Neon from Carbon. Its material capability change assessment found a gain over Argon below the threshold for a full new evaluation. Google carried over the Argon determinations: it could not rule out the biological and cybersecurity critical capability levels or the stealth and situational awareness tracked capability level. Google describes training and output filtering, usage monitoring, and control and model-security mitigations [L: model-card].

## Behaviour observed in practice

Artificial Analysis measures how Intelligence Index scores change by effort. The scores below apply to its benchmark tasks and settings [M: aa-model].

## Benchmarks

- Artificial Analysis measured 63.6 percent at xhigh on Terminal-Bench 4.0 with mini-swe-agent. Its method averages pass@1 over three runs of each of the 66 tasks [M: aa-terminal].
- Artificial Analysis Intelligence Index v5.0.1 by thinking level gives 44 (low), 55 (medium), 60 (high), 61 (xhigh) [M: aa-model].
- Artificial Analysis Coding Agent Index v2.1 gives 58.6 at xhigh in Antigravity CLI. Its Terminal-Bench 4.1 component is 65.2 percent [M: aa-coding].
- The Terminal-Bench 4.1 public board gives 61.2 percent at xhigh in Antigravity CLI, with a 95 percent confidence interval of ±2.8 percentage points [M: terminal-board].
