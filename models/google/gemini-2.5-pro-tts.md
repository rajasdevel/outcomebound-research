# Gemini 2.5 Pro TTS

Gemini 2.5 Pro TTS is the speech synthesis model of the Gemini Pro TTS class, and the only model in that class: Google shipped no later Pro TTS. It reads a transcript aloud and takes direction for delivery from a style prompt and from bracket tags in the text, so it is a voice actor model in this library's sense. Google Cloud released it as generally available on 2025-09-30. The Gemini API keeps it under the preview id `gemini-2.5-pro-preview-tts`, with access limited to accounts that used it before. Google names the 3.8 TTS models as its replacements on the deprecations page. Family-wide rules are in the [Google README](README.md).

## How to instruct it

### Setting up the prompt

The model is served by the Google Cloud Text-to-Speech API and the Vertex AI API. The Cloud API has a `prompt` field for the style and a `text` field for the words. Our own example of the shape:

```json
{
  "input": {
    "prompt": "You are a bedtime storyteller. Say the following slowly and softly.",
    "text": "The little fox curled up under the old oak. [short pause] Goodnight, he whispered."
  },
  "voice": {"languageCode": "en-us", "name": "Achernar", "modelName": "gemini-2.5-pro-tts"},
  "audioConfig": {"audioEncoding": "LINEAR16"}
}
```

- **The Cloud page's examples.** Google's examples for this class of model give a role and a manner in the prompt: a casual chat with a friend, said in a friendly and amused way, over a text with emphasis in capitals and a laugh [g-cloud-tts].
- **Tags and the three levers.** The Cloud page's prompting tips, with the three levers (style prompt, text content, markup tags) and the four tag modes, are in [the 3.1 file](gemini-3.1-flash-tts-preview.md#setting-up-the-prompt). The page lists them for its Gemini-TTS models as a group and names no model for each tag. The tags carry a Preview mark on that page [g-cloud-tts].
- **The Gemini API form.** The guide of the 3.1 and 2.5 era took the instruction inside the text: a short order before the words, such as a request for a spooky whisper, and for two speakers a labelled line per speaker with a separate direction for each. It added a structured prompt (Audio Profile, Scene, Director's Notes) and free-form square-bracket tags. [The 3.1 file](gemini-3.1-flash-tts-preview.md#setting-up-the-prompt) describes it in full [g-archive-guide].
- **Voice choice.** 30 prebuilt voices, each with a gender on the Cloud page and a trait label in the Gemini API guide. The guide advises a voice whose trait fits the wanted emotion [g-cloud-tts] [g-archive-guide].

### Reasoning and effort

None. The model page lists thinking, function calling and the Live API as not supported [g-model-25-pro-page].

### Output: format, length, tone

The Cloud Text-to-Speech API chooses the format in `audioConfig`: LINEAR16 (the unary default), ALAW, MULAW, MP3, OGG_OPUS or PCM; streaming defaults to PCM. The Vertex AI API returns 16-bit 24 kHz PCM without a WAV header. The text and prompt fields are at most 4,000 bytes each and 8,000 bytes together. Output past about 655 seconds is truncated. Vertex AI Media Studio shows speed and volume gain settings, and the page does not say whether the API takes the same fields for this model [g-cloud-tts].

### Tools and agents

Not a tool-calling model. Google describes the model as the high-control choice for podcast generation, audiobooks and customer support. The Gemini API page calls it the premium engine for long-form content and professional narration [g-cloud-tts] [g-model-25-pro-page].

### Coding

The Cloud route is `texttospeech.googleapis.com` (regions global, us and eu) with a Cloud client library; the Vertex AI route is generateContent. The Gemini API id is `gemini-2.5-pro-preview-tts` [g-cloud-tts] [g-models].

### Long context and retrieval

Input is capped at 8,192 tokens. The Gemini API model page says caching is not supported [g-model-25-pro-page].

### Structured output

Not supported [g-model-25-pro-page].

### Images, audio, other inputs

Text only [g-cloud-tts].

### Voice: turn-taking, interruption and speech style

The model is not a conversation model. It has no turn detection and no barge-in. Turn-taking does not apply.

**How to direct delivery.** A natural-language `prompt` and bracket tags, as in the 3.1 file. Google's Cloud page says the style prompt is the main driver of tone, and that text fitting the style gives more reliable results [g-cloud-tts].

**How strongly it works.** A vendor paper with human raters put the preview id first of 31 configurations for Reliability (3.89 on a five-point scale) and in the top five for Acting / Role-Fit and Expressiveness. The authors work at a speech vendor [hume-rwveq]. Artificial Analysis rates the model low in its arena, below the 3.1 and 3.8 models [aa-pv].

**Multi-speaker dialogue.** The Cloud page lists single and multi-speaker output. A request lists turns with speaker aliases made of letters and digits, and the dialogue is capped at 4,000 bytes [g-cloud-tts].

**Voice design and cloning.** Not offered. The Gemini API guide's table shows voice design and voice replication for the 3.8 models only [g-tts-guide].

**Long-form consistency.** The 4,000-byte field caps and the 655-second output cap force chunks on the Cloud route. Google's model page calls it a premium engine that is best for long-form content and professional narration, and gives no measure of long-form stability [g-cloud-tts] [g-model-25-pro-page].

**Pronunciation and text normalisation.** The Cloud page says the Cloud Text-to-Speech API applies text normalisation by default, and it names dates and money values as the case where this helps. The Vertex AI API route does not mention it [g-cloud-tts].

**Safety.** The Cloud API takes safety thresholds for four harm categories in `advancedVoiceOptions` [g-cloud-tts].

### Sampling and API parameters

The pages read list no temperature or seed for the model [g-cloud-tts].

### Migrating from the previous generation

There is no previous generation of the class. Google's deprecations page names `gemini-3.8-flash-tts` or `gemini-3.8-flash-lite-tts` as the replacement for the two 2.5 preview ids. The step to the 3.8 models changes the direction method: direction moves into a `speech_metadata` style and angle-bracket tags, and a designed voice replaces long persona text. See [the 3.8 Flash TTS file](gemini-3.8-flash-tts.md#migrating-from-the-previous-generation) [g-deprecations].

## What the system card reports

No model card for the 2.5 TTS models was found. The Gemini API changelog of 2025-12-10 says Google launched enhancements to the 2.5 TTS previews for expressivity, pacing and dialogue, and the changelog of 2026-09-18 says access to the 2.5 models is limited to accounts that used them before, without deprecation [g-changelog].

## Behaviour observed in practice

- **Arena rank (M).** Artificial Analysis lists it as Gemini 2.5 Pro (Dec 2025) at 1033, rank 70 of 93 with a range of 63 to 74, on 2,417 votes and 4 voices [aa-pv].
- **Reliability (M, vendor paper).** First of 31 configurations for Reliability, 3.89 [hume-rwveq].

## Benchmarks

Independent: Artificial Analysis Elo 1033. A vendor paper: Reliability 3.89 [aa-pv] [hume-rwveq]. No maker benchmark was found.

## Open questions

- Whether the Cloud model `gemini-2.5-pro-tts` and the Gemini API id `gemini-2.5-pro-preview-tts` are the same model. The pages do not say.
- Whether Google will keep the model after the 3.8 release. The Gemini API says it is not deprecated, and the Cloud page lists it as generally available.
- Which tags work on this model.
