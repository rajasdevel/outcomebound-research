# Gemini 2.5 Flash-Lite Preview TTS

Gemini 2.5 Flash-Lite Preview TTS is the generation before [Gemini 3.8 Flash-Lite TTS](gemini-3.8-flash-lite-tts.md) in the Gemini Flash-Lite TTS class. Google Cloud serves it as a preview model through the Cloud Text-to-Speech API and the Vertex AI API. The Gemini API does not list it. It is a single-speaker model for low-cost, low-latency speech, and it takes a natural-language style prompt and bracket tags, so it is a voice actor model in this library's sense. This file says what differs from the other Cloud-served Gemini-TTS models. The tag modes and the prompting tips are in [the 3.1 file](gemini-3.1-flash-tts-preview.md#setting-up-the-prompt). Family-wide rules are in the [Google README](README.md).

## How to instruct it

### Setting up the prompt

The Cloud API takes a `prompt` field for the style and a `text` field for the words. Google's own example for this model is a short prompt that asks for an elated delivery, over a one-line congratulation [g-cloud-tts]. Our own example:

```json
{
  "input": {
    "prompt": "Say the following in a warm, upbeat way.",
    "text": "Your order is on its way. [short pause] Thank you for waiting."
  },
  "voice": {"languageCode": "en-us", "name": "Aoede", "modelName": "gemini-2.5-flash-lite-preview-tts"},
  "audioConfig": {"audioEncoding": "LINEAR16"}
}
```

The three levers, the four tag modes and the advice to test each tag are in [the 3.1 file](gemini-3.1-flash-tts-preview.md#setting-up-the-prompt). The Cloud page gives them for its Gemini-TTS models as a group [g-cloud-tts].

### Reasoning and effort

None.

### Output: format, length, tone

The same as the other Cloud-served Gemini-TTS models: LINEAR16 by default for a unary request, and ALAW, MULAW, MP3, OGG_OPUS or PCM on request. The text and prompt fields are at most 4,000 bytes each, and output past about 655 seconds is truncated [g-cloud-tts].

### Tools and agents

Not a tool-calling model. Google describes it as the model for low latency, controllable, single-speaker audio for cost-efficient everyday applications [g-cloud-tts].

### Coding

Reached through `texttospeech.googleapis.com` in the global, us, eu and northamerica-northeast1 regions, or through the Vertex AI API. A Google Cloud release note of 2025-12-11 added the regions [g-cloud-tts] [g-cloud-rn].

### Long context and retrieval

Input is limited to 8,192 tokens, and the text field to 4,000 bytes [g-cloud-tts].

### Structured output

Not applicable.

### Images, audio, other inputs

Text only [g-cloud-tts].

### Voice: turn-taking, interruption and speech style

The model is not a conversation model. It has no turn detection and no barge-in. Turn-taking does not apply.

**How to direct delivery.** A natural-language prompt and bracket tags, as in the other Cloud models. Google's page gives no measure of how strongly the prompt acts on this model [g-cloud-tts].

**How strongly it works.** No test of style control was found. Artificial Analysis rates the model 1083 in its arena (listed as Gemini 2.5 Flash Lite TTS), rank 43 of 93 with a range of 40 to 48, ahead of 2.5 Pro and below the 3.1 and 3.8 models [aa-pv].

**Multi-speaker dialogue.** Not offered. The page lists single-speaker output only [g-cloud-tts].

**Voices.** 30 prebuilt voices, with a gender for each. No voice design or replication is documented [g-cloud-tts].

**Pronunciation.** The page documents no tag or lexicon. The Cloud Text-to-Speech API applies text normalisation by default [g-cloud-tts].

### Sampling and API parameters

None documented [g-cloud-tts].

### Migrating from the previous generation

There is no earlier model in the class. The 3.8 Flash-Lite TTS file describes the step to the current model [Gemini 3.8 Flash-Lite TTS file](gemini-3.8-flash-lite-tts.md#migrating-from-the-previous-generation).
