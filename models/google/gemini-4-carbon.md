# Gemini 4 Carbon

Google announced Carbon on 2026-10-28 and released the stable Gemini API model on 2026-11-10. Google recommends it for its most difficult reasoning, architecture and debugging workloads [L: launch, api-release, api-guide]. Google lists `gemini-4-carbon` as a stable text-output model with multimodal input [L: api-model].

## How to instruct it

### Setting up the prompt

Google's model guide shows requests with task instructions in the input and generation controls in a separate configuration. It gives no model-specific system prompt template [L: api-guide].

### Reasoning and effort

Set `thinking_level` to low, medium, high. The default is `medium`. Google recommends low for simple work and high for the hardest tasks. Leave room for the final answer because thinking consumes part of `max_output_tokens` [L: api-guide].

### Output: format, length, tone

The Gemini API guide gives 65,536 output tokens for a normal synchronous response. For more, use long decode with background execution in the Interactions API or client-side continuation. Join the text from each `model_output` step if the Interactions API returns multiple steps [L: api-model, api-guide]. On Agent Platform, the Carbon model page gives 65,536 for a streaming foreground segment and 32,768 for a non-streaming foreground segment [L: cloud-model].

### Tools and agents

Google lists function calling, code execution, computer use, file search, Search and Maps grounding, and URL context. The Interactions API also offers tool retrieval in preview [L: api-model].

### Coding

Google recommends Carbon for architecture and root-cause debugging. In Gemini Managed Agents the Antigravity agent accepts Carbon through `agent_config.model` [L: api-guide].

### Long context and retrieval

The 1,048,576-token window is shared by input, thinking and output. The input reduces the maximum available output with long decode. The Gemini API guide gives 4,096 tokens as the implicit-cache minimum and a 95 percent input discount on hits. It lists implicit caching only [L: api-model, api-guide].

### Structured output

The Gemini API lists structured outputs as supported. The model guide gives no model-specific schema rules [L: api-model, api-guide].

### Images, audio, other inputs

The Gemini API specification lists text, image, video, audio and PDF input and text output. Agentic video understanding defaults to static processing [L: api-model].

### Sampling and API parameters

Google says the Gemini API ignores custom values for temperature, top_p and top_k. [L: api-guide]

### Migrating from the previous generation

Google says Carbon can spend more thinking tokens per difficult turn than Argon. It recommends starting at medium and allowing for longer reasoning when setting client timeouts and output caps [L: api-guide]. When moving from a model that supports explicit caching, Google says to remove the cache creation call and cached-content field [L: api-guide].

## What the system card reports

Google based Carbon on Argon. Its model card describes filtering training data, post-training alignment, product-level filtering and usage monitoring. It points to a separate Safety and Security Report for the frontier safety assessment [L: model-card].

## Behaviour observed in practice

Artificial Analysis measures how Intelligence Index scores change by effort. The scores below apply to its benchmark tasks and settings [M: aa-model].

## Benchmarks

- Artificial Analysis measured 65.2 percent at high on Terminal-Bench 4.0 with mini-swe-agent. Its method averages pass@1 over three runs of each of the 66 tasks [M: aa-terminal].
- Artificial Analysis Intelligence Index v5.0.1 by thinking level gives 54 (low), 58 (medium), 60 (high) [M: aa-model].
- Artificial Analysis Coding Agent Index v2.1 gives 55.5 at high in Antigravity CLI. Its Terminal-Bench 4.1 component is 64.6 percent [M: aa-coding].
- The Terminal-Bench 4.1 public board gives 64.5 percent at high in Antigravity CLI, with a 95 percent confidence interval of ±3.2 percentage points [M: terminal-board].
