# Gemini 3.8 Flash-Lite TTS

Gemini 3.8 Flash-Lite TTS is the speech synthesis model of the Gemini Flash-Lite TTS class, generation 3.8. It uses the same request schema, the same style string and the same inline tags as [Gemini 3.8 Flash TTS](gemini-3.8-flash-tts.md), so it is a voice actor model in the same way. Google released it on 2026-09-22 as the fast, low-cost tier, and names it as the replacement for the 3.1 Flash TTS preview. The earlier model of this class is [Gemini 2.5 Flash-Lite Preview TTS](gemini-2.5-flash-lite-preview-tts.md), which Google Cloud serves. This file says what differs from Flash TTS. The syntax and the advice for directing delivery are in the Flash TTS file. Family-wide rules are in the [Google README](README.md).

## How to instruct it

### Setting up the prompt

The prompt is the same as for Flash TTS. Google says both 3.8 models share the exact same API schema and prompting format, and that you can switch between them by changing one parameter [g-model-lite-page] [g-tts-guide]. The transcript is verbatim. A `speech_metadata` annotation holds the `style` and the `speaker`. Inline angle-bracket tags such as `<laugh>` and `<short pause>` mark single events. See [the Flash TTS file](gemini-3.8-flash-tts.md#setting-up-the-prompt) for the full syntax and for what fails.

Google ties the two models to different work. It lists heavy vocal-burst tags, difficult pronunciations, regional or minority dialects and complex multi-speaker dialogue under Flash. It lists bulk production, voice agent cascades, read-aloud features, reliable voice replication and everyday single-speaker speech under Flash-Lite. The wording suggests that tag-heavy acting is the weaker use of Flash-Lite, but Google states no measured gap [g-tts-guide] [g-model-lite-page].

The guide says overlapping speech through pipe segments works best with Flash TTS. The guide gives no test of that feature on Flash-Lite [g-tts-guide].

### Reasoning and effort

None. The model page lists thinking as not supported [g-model-lite-page].

### Output: format, length, tone

The formats are the same as for Flash TTS: WAV by default on a unary request, raw 24 kHz PCM on a stream, and mu-law or A-law on request. Limits are 8,192 input tokens and 16,384 output tokens on the model page [g-model-lite-page] [g-tts-guide].

### Tools and agents

Not a tool-calling model. Google names voice agent cascades as a main use. Its advice for agents is the same as for Flash: one call per turn, a constant short style string or none, and shorter turns in place of stronger style text [g-tts-guide].

### Coding

The same as Flash TTS: the Interactions API or generateContent, `google-genai` 2.25.0 or later or `@google/genai` 2.24.0 or later [g-tts-guide].

### Long context and retrieval

Input is capped at 8,192 tokens. Google makes no long-form claim for Flash-Lite. For Flash it names long narration that needs steady voice and room tone [g-tts-guide] [g-model-lite-page].

### Structured output

Not supported [g-model-lite-page].

### Images, audio, other inputs

Text only. Voice replication and voice design work on this model, with the same limits as for Flash: 200 stored voices per project, a replication clip of 10 to 30 seconds and a consent clip [g-voice-repl] [g-voice-design].

### Voice: turn-taking, interruption and speech style

The model is not a conversation model. It has no turn detection and no barge-in. Turn-taking does not apply.

**How to direct delivery.** The same as Flash TTS: a `style` string for the turn, tags for single events, capitals and punctuation, and pipe segments in a dialogue. Google says to start with an empty style and to keep the style string short and constant [g-tts-guide].

**Differences that matter.** Language count is 101 against 130+ for Flash. Throughput is higher: a median of 57.7 characters a second against 48.8. The price of audio output is two thirds of Flash [aa-g38l] [g-pricing].

**Voice design and replication.** Both work on this model. Google's guide lists reliable voice replication among the uses Flash-Lite is optimised for, and its model page lists voice replication as a best use [g-voice-design] [g-voice-repl] [g-tts-guide] [g-model-lite-page].

**Multi-speaker dialogue and long-form.** Up to two prebuilt voices per request, as for Flash. Google makes no separate claim for dialogue or long-form on Flash-Lite [g-tts-guide].

**Pronunciation.** The guide documents no phoneme tag or lexicon. See the Flash file for the pronunciation test that a measurer ran on the 3.8 family.

### Sampling and API parameters

The pages read list no sampling parameters [g-model-lite-page].

### Migrating from the previous generation

The earlier model of this class is [Gemini 2.5 Flash-Lite Preview TTS](gemini-2.5-flash-lite-preview-tts.md), a single-speaker model on the Google Cloud route. Google names this model as the replacement for the 3.1 Flash TTS preview for high-volume work. The migration steps are the same as for Flash. In those steps, direction moves into `speech_metadata`, tags change from square brackets to angle brackets, every turn names its speaker, a designed voice replaces Audio Profile text, and a unary request returns WAV [g-model-lite-page] [g-tts-guide].

## What the system card reports

The card is the one shared with the other 3.8 audio models. It lists Google AI Studio, the Gemini API, Google Vids and Gemini Enterprise Agent Platform as channels for this model, text input up to 8K and audio output of 64K tokens. See the [Flash TTS file](gemini-3.8-flash-tts.md#what-the-system-card-reports) for the rest [g-card-38].

## Behaviour observed in practice

- **Arena rank (M).** Artificial Analysis rates it 1241.71 on the provider-voice arena, eighth of 93, with a rank range of 6 to 9 at 95 percent confidence [aa-g38l] [aa-pv].
- **Controlled voices (M).** On the board that uses the same eight cloned voices for every model, it scores 1059, rank 10, nine points above Flash TTS. The intervals overlap, so the order is not firm [aa-cv].
- **Throughput (M).** A median of 57.7 characters a second [aa-g38l].

## Benchmarks

Independent: provider-voice Elo 1241.71, controlled-voice Elo 1059 and a median of 57.74 characters a second [aa-g38l] [aa-cv]. Google reports second place for Flash-Lite on Hume AI's Overall Quality Index. No number was published and the pages with the results were not read [g-blog-38].

## Open questions

- How much weaker Flash-Lite is than Flash at tag-heavy acting and difficult dialects. Google gives no measured gap.
- Whether overlapping speech through pipe segments works on Flash-Lite.
- A time-to-first-audio figure. Google gives none.
- Whether the 16,384-token output cap or the 64K cap on the card applies.
