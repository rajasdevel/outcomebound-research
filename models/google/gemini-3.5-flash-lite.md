# Gemini 3.5 Flash-Lite

Gemini 3.5 Flash-Lite is the current generation of Google's Flash-Lite class (generation 3.5), generally available since 2026-07-21. It is built on Gemini 3.1 Flash-Lite and aimed at high-volume, latency-sensitive work such as translation, classification, document parsing and simple data processing, and at acting as a low-cost subagent. It replaces 3.1 Flash-Lite, which Google's deprecations page names it as the successor to [L: gemini-3-5-flash-lite-card, gemini-spec-gemini-3.5-flash-lite, gemini-deprecations].

Evidence tags: L is Google's own text, M is an independent measurement, A is one practitioner's or outlet's account. Family-wide guidance lives in [the Google README](README.md); this file says what is specific to 3.5 Flash-Lite.

## How to instruct it

### Setting up the prompt

Google publishes no prompting guide for the Flash-Lite models beyond the family pages; [README.md](README.md#setting-up-the-prompt) applies. Google's Cloud page for this model says it is suited to simple coding tasks, precise document understanding and lightweight agent work, and that it is a suitable replacement for Gemini 2.5 Flash and for less complex Gemini 3 Flash workloads [L: gemini-cloud-3-5-lite]. For tasks where the model should only return the transformed text, Google's page for the previous Flash-Lite model shows a system instruction that says to output only the result, with a response schema when the output is structured [L: gemini-spec-gemini-3.1-flash-lite]. The knowledge cutoff in the model card is March 2026 for some domains and January 2025 for others [L: gemini-3-5-flash-lite-card].

### Reasoning and effort

This model accepts four levels, minimal, low, medium and high, and defaults to minimal (3.8 and 3.7 Flash default to medium) [L: gemini-thinking, gemini-cloud-3-5-lite]. Google's guidance for this model:

- Minimal: for latency-sensitive classification, routing and JSON extraction, where speed and cost matter most.
- Medium or high: when the model works as an autonomous subagent that writes code, runs terminal commands or calls external APIs. Google says minimal can end tool use early ("premature tool termination") on multi-step tasks [L: gemini-cloud-3-5-lite].

Artificial Analysis ran its index on the reasoning version of the model without stating the effort; its score appears in the observed-behaviour section [M: aa-gemini-3-5-flash-lite]. Thought summaries, the effect of the output cap on thinking tokens and the other mechanics are in [README.md](README.md#reasoning-and-effort).

### Output: format, length, tone

Family defaults apply. Artificial Analysis rates the model as fairly concise, with 59 million output tokens to run its index against a median of 100 million for comparable models [M: aa-gemini-3-5-flash-lite]. Requests may not end on a model turn (an error on both the Interactions API and generateContent), so format control comes from the system instruction or a schema [L: gemini-cloud-3-5-lite].

### Tools and agents

Function calling follows the family rules in [README.md](README.md#tools-and-agents). The model supports computer use (a preview) and built-in tools, and the Antigravity managed agent lets callers choose 3.5 Flash-Lite as the underlying model to favour speed and cost over reasoning depth [L: gemini-computer-use, gemini-antigravity-agent]. Google's card reports OSWorld-Verified at 74.0 percent (3.1 Flash-Lite 54.3; GPT-5.4 mini 72.1; Claude Haiku 4.5 50.7) and GDPVal-AA v2 at 1140 Elo (3.1 Flash-Lite 642) [L: gemini-3-5-flash-lite-card]. No independent agent benchmark was found: the model has no Terminal-Bench 4.0 row, no SWE-Bench Pro V2 row and no METR measurement.

### Coding

Google's card reports SWE-Bench Pro (public set) at 54.2 percent, in line with GPT-5.4 mini at 54.4 and above Claude Haiku 4.5 at 39.5, and Terminal-Bench 2.1 at 54.0 percent under the Terminus-2 harness (GPT-5.4 mini 59.2, Haiku 4.5 44.2) [L: gemini-3-5-flash-lite-card]. Google's methodology PDF says all of its 3.5 Flash-Lite runs used high thinking, and that it computed SWE-Bench Pro itself on the full public set with an internal version of its Antigravity harness, so the figure is not a run on a public harness [L: gemini-3-5-flash-lite-eval]. Google's Cloud page calls the model suitable for simple coding tasks; Google's own advice for coding subagents is medium or high effort [L: gemini-cloud-3-5-lite].

### Long context and retrieval

Input is 1,048,576 tokens and output up to 65,536 [L: gemini-spec-gemini-3.5-flash-lite]. Google's card reports an eight-needle retrieval test at 128,000 tokens at 72.2 percent (3.1 Flash-Lite 60.1) and at 1 million tokens, pointwise, at 21.3 percent (12.3 for 3.1 Flash-Lite) [L: gemini-3-5-flash-lite-card]. The second figure shows how far retrieval of several facts falls at full length. Caching is supported and billed at $0.03 per million cached tokens, with storage at $1.00 per million tokens an hour; the minimum cache size for Flash-Lite models is not stated on Google's caching page [L: gemini-pricing, gemini-caching].

### Structured output

Supported, with the schema subset and validation advice in [README.md](README.md#structured-output). Google names JSON extraction as a minimal-effort use of this model [L: gemini-cloud-3-5-lite].

### Images, audio, other inputs

Input is text, images, video, audio and PDF; output is text. Agentic video understanding is available on the Gemini API for this model [L: gemini-video-understanding]. Audio input costs the same as text on this model ($0.30 per million tokens), unlike 3.1 Flash-Lite where audio costs double [L: gemini-pricing]. Google's card reports CharXiv Reasoning at 74.5 percent without tools and 76.5 with tools [L: gemini-3-5-flash-lite-card]. Limits and token counts are in [README.md](README.md#images-audio-video-documents).

### Sampling and API parameters

temperature, top_p and top_k are ignored and the Cloud page shows them fixed; frequency and presence penalties are errors; a request that ends on a model turn is an error [L: gemini-cloud-3-5-lite, gemini-latest-model-archive].

### Migrating from the previous generation

From 3.1 Flash-Lite: the default level (minimal) is unchanged, but Google now says to raise it for subagents. Google's checklist removes sampling parameters and prefilled model turns; its July 2026 notice applies those rules from this model on, and the 3.1 models still list temperature as adjustable on Cloud. Prices rise from $0.25 input and $1.50 output to $0.30 and $2.50 per million tokens [L: gemini-pricing]. Google's card shows large gains over 3.1 Flash-Lite on its own tests (3.5 Flash-Lite at high thinking): SWE-Bench Pro 54.2 against 38.3, Terminal-Bench 2.1 54.0 against 31.0, MLE-Bench 39.2 against 22.0, OSWorld-Verified 74.0 against 54.3 [L: gemini-3-5-flash-lite-card]. The safety deltas moved toward more refusals (below). Computer use and agentic video understanding, absent from 3.1 Flash-Lite, are available.

## What the system card reports

The card (July 2026) names 3.1 Flash-Lite as the base model and defers to its card and to the 3.1 Pro card for architecture, training, policies and risks. It adds a benchmark table (compared with 3.1 Flash-Lite, GPT-5.4 mini and Claude Haiku 4.5), safety deltas, a red-teaming statement and a frontier-safety summary [L: gemini-3-5-flash-lite-card].

Safety evaluations against 3.1 Flash-Lite (automated; lower is better except tone): text-to-text safety minus 8.14 points, multilingual safety minus 0.92, image-to-text unchanged, tone plus 3.04, and unjustified refusals plus 5.32. Google says the model outperforms 3.1 Flash-Lite on safety and tone, and that the slight regression in refusals arises because the model is more likely to decline sensitive topics to stay safe. Manual review of flagged losses found them overwhelmingly false positives or not egregious [L: gemini-3-5-flash-lite-card].

Red teaming: child-safety launch thresholds were met; content-safety results were similar to or better than 3.1 Flash-Lite; the wider scope, compared with 3.1 Pro, found no egregious concerns [L: gemini-3-5-flash-lite-card].

Frontier safety: the card rests its conclusion on Google's assessment of 3.1 Pro, which did not reach any critical capability level, and says that 3.5 Flash-Lite, which excels at agents and coding, has no meaningful new capability over 3.1 Pro [L: gemini-3-5-flash-lite-card]. The 3.1 Pro and 3 Pro findings (cyber alert threshold reached, evaluation-awareness transcripts, layered prompt-injection defences) are in [README.md](README.md#findings-that-carry-across-the-family) and [the 3.1 Pro file](gemini-3.1-pro-preview.md#what-the-system-card-reports). Not reported for this model: prompt-injection or agentic-safety figures, sycophancy and reward-hacking findings.

## Behaviour observed in practice

- Artificial Analysis (index v4.3.2, reasoning version): score 22 against a median of 13 for comparable models; $0.12 per index task; 59 million output tokens; about 346 output tokens a second. It calls the per-token price above the median for its price range [M: aa-gemini-3-5-flash-lite].
- No practitioner account of agent or subagent use was found beyond vendor and aggregator pages that repeat Google's numbers.

## Benchmarks

Independent: Artificial Analysis Intelligence Index v4.3.2, 22 (reasoning version, effort not stated) [M: aa-gemini-3-5-flash-lite].

Maker-reported (Google's card; high thinking per the methodology PDF): SWE-Bench Pro public 54.2 (internal Antigravity harness); Terminal-Bench 2.1 54.0 (Terminus-2); MLE-Bench 39.2 (30-problem subset, average position score); GDPVal-AA v2 1140 Elo; OSWorld-Verified 74.0 (average of five runs, 100-step limit); CharXiv Reasoning 74.5 (no tools) and 76.5 (tools); GDM-MRCR v2 eight-needle 72.2 at 128,000 tokens and 21.3 at 1 million [L: gemini-3-5-flash-lite-card, gemini-3-5-flash-lite-eval].

No Terminal-Bench 4.0 row, no SWE-Bench Pro V2 row, no Coding Agent Index value and no METR measurement was found.
