# Chatterbox-Nano

Chatterbox-Nano is an open-weight speech synthesis model of Resemble AI, class Chatterbox Turbo, with 110M parameters and English only. It shares the architecture of [Chatterbox-Turbo](chatterbox-turbo.md) in a smaller package aimed at on-device and CPU use: it runs about 3 times faster than real time on 8 CPU cores, by the maker's figure. It takes the same square-bracket tags. Its tag list was not read from its own tokenizer; the list for Turbo is used (inferred). It was released on 2026-04-14 under the MIT licence. Maker-wide facts are in the [Resemble AI README](README.md).

## How to instruct it

### Setting up the prompt

- **Paralinguistic tags in square brackets.** The Nano model card says tags are native to both Nano and Turbo. It names laugh, cough and chuckle and says there are more. The tokenizer of the Nano weights defines the same 19 bracket tokens as the Turbo weights: advertisement, angry, chuckle, clear throat, cough, crying, dramatic, fear, gasp, groan, happy, laugh, narration, sarcastic, shush, sigh, sniff, surprised and whispering. The README names only three, so the others are the tokenizer's set and are not documented as a tag list (inferred) [hf-cb-nano] [hf-cb-nano-tokens] [hf-cb-turbo-tokens].
- **Placement.** The README example puts a chuckle in the middle of a sentence of a phone call. The model has no instruction field, so tags in the text are the whole direction [gh-cb].
- **Reference clip.** Cloning needs a reference clip; the README's example uses a clip of about 10 seconds. The README tips, written for the original and multilingual models, say the output can take the accent and the pace of the reference clip [gh-cb].
- **No exaggeration or guidance knobs documented for Turbo and Nano.** The original Chatterbox model has two settings: an exaggeration value (0.5 by default) and a guidance weight (0.5 by default). The README's tips apply to that original model [gh-cb].

### Coding

The package `chatterbox-tts` installs with pip. The model loads with `ChatterboxTurboTTS.from_pretrained` and `nano=True`, and `generate(text, audio_prompt_path=...)` makes the audio. The repository was last changed on 2026-07-21 [gh-cb].

### Voice: turn-taking, interruption and speech style

Turn-taking does not apply. The maker built the model for low-latency voice agents, and the client handles turns and interruptions.

**How to direct delivery.** Tags in the text are the direction. The set covers sounds (laugh, chuckle, cough, sigh, gasp, groan, sniff, clear throat, shush), emotions (angry, fear, happy, sarcastic, surprised, crying) and manners (dramatic, narration, advertisement, whispering) as far as the tokenizer shows [hf-cb-turbo-tokens].

**Strength.** The maker publishes no measure of tag control on the pages read. Its README shows a listener-study chart without numbers in text [gh-cb].

**What fails.** Not documented.

**Voice design and cloning.** Cloning only. No voice design.

**Multi-speaker dialogue, long-form consistency, pronunciation.** Not documented.

**Speed.** Runs 3 times faster than real time on 8 CPU cores, by the maker. [gh-cb]

### Sampling and API parameters

The Turbo example passes only the text and the reference clip path. The `exaggeration` and `cfg_weight` settings belong to the original Chatterbox model [gh-cb].

### Migrating from the previous generation

The original Chatterbox (500M, English, 2025-04-24) and Chatterbox Multilingual V3 (23 languages, 2026-06-10) steer expression with an exaggeration value and a guidance weight only. They take no tags. They are not voice actor models by this library's definition, so they have no file. Turbo and Nano add native tags and a one-step decoder [gh-cb] [hf-resemble-list].
