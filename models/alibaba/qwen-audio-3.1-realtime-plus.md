# Qwen-Audio-3.1-Realtime-Plus

Qwen-Audio-3.1-Realtime-Plus is Alibaba's realtime speech model of the Qwen Audio line, generation 3.1, Plus tier. It takes streaming audio and text. It gives back speech and text. Alibaba calls it a full-duplex model and names speech reasoning, multi-turn instruction following, empathy and role play as its gains over 3.0. QwenCloud's changelog dates it 2026-09-20. It follows [Qwen-Audio-3.0-Realtime-Plus](qwen-audio-3.0-realtime-plus.md). Alibaba names it as the recommended model for realtime conversation and as its replacement for closed-source realtime models. Family-wide rules are in the [Alibaba README](README.md) [qwencloud-changelog] [qwencloud-s2s-models] [qwencloud-page-audio31].

## How to instruct it

### Setting up the prompt

The `instructions` field of `session.update` sets the role, the style and the behaviour for the whole session. Alibaba's guide gives six pieces of advice [qwencloud-audio-guide]:

- Give the model a clear role, and optionally a name or a gender.
- Set the tone and the phrasing. Say that a natural tone must not cut content: details, numbers and recommendations still go in.
- Tell the model to use every constraint from the conversation: budget, preferences, limits and earlier agreements.
- Say what the output must look like. Unless the user asks, no emoji, no special characters and no Markdown, so that speech playback sounds natural.
- Set a reply strategy. Keep greetings and casual talk short. For reasoning, multi-condition questions, lists and safety advice, put completeness first, with no preamble, repetition or filler.
- Set a follow-up rule. Answer the current question first. Then ask one question at the end. Do not ask several questions in a row or confirm again and again.

The guide gives a default prompt that follows these rules (a named assistant with a warm and friendly style). It also gives persona prompts. A persona prompt states the name, age or setting, the speech style (short sentences, interjections, a quiet and sharp tone) and a limit, for example that the persona may tease but never attacks a real wound and drops the act when the user is in pain [qwencloud-audio-guide]. Persona and style go into this one field. There is no other prompt field.

### Reasoning and effort

Alibaba documents no switch for reasoning on this model. The model page lists a 2K maximum reasoning figure and a thinking limit for input and output. The guide has no thinking parameter. Alibaba's table says the Qwen-Audio realtime models do not support thinking mode [qwencloud-page-audio31] [qwencloud-s2s-models].

### Output: format, length, tone

`modalities` takes `["audio", "text"]` (default) or `["text"]`. The text-only setting suits debugging and logging. A single `response.create` can override it with `response.modalities` [qwencloud-audio-guide]. `enable_speech_emotion` (default `true`) makes the voice vary its emotion more [qwencloud-audio-events]. `session.output_audio.language` sets the target language of the speech. The model tries to speak that language but this is not guaranteed, and the language of the text does not change. To change the text language, write the reply language into `instructions` [qwencloud-audio-events].

### Tools and agents

Function tools are registered with `session.tools`. Return a result with a `conversation.item.create` item of type `function_call_output`, then send `response.create`. Web search works through `enable_search`. It cannot run at the same time as tools [qwencloud-audio-guide] [qwencloud-audio-events]. The client can also insert, fetch or delete items in the conversation to add history or remove items that do not belong. An item with an `item.id` that already exists causes an error [qwencloud-audio-guide].

### Coding

Alibaba gives no coding guidance or score for this model.

### Long context and retrieval

The model page gives a 262K context, with up to 245K input and 16K output [qwencloud-page-audio31]. The session keeps at most 50 audio turns or 300 seconds of audio. `max_history_turns` (1 to 50, default 20) sets how many earlier turns the model reads. The guide advises 5 to 10 for short question-and-answer calls, to cut latency, and 30 to 50 for long customer-service calls [qwencloud-audio-guide].

### Structured output

The model page lists structured outputs as a feature. The guide gives no rules for them [qwencloud-page-audio31].

### Images, audio, other inputs

Input is PCM, 16-bit, mono, 16 kHz. Output is PCM, 24 kHz. The guide advises about 100 ms of audio per chunk (3,200 bytes) [qwencloud-audio-guide]. The model takes no image or video input. Conversation languages are German, English, Spanish, French, Indonesian, Italian, Japanese, Korean, Portuguese, Russian and Chinese, plus 21 Chinese varieties. `session.input_audio_transcription.language` takes one of 30 source-language codes [qwencloud-audio-guide] [qwencloud-audio-events]. The guide says these models need a Singapore-region API key [qwencloud-audio-guide].

### Voice: turn-taking, interruption and speech style

**Three modes.** `turn_detection.type` selects the mode. It can change only before the first audio is sent. A new mode needs a new connection [qwencloud-audio-ws] [qwencloud-audio-guide].

- `server_vad` finds speech by acoustic features. `threshold` runs from -1.0 to 1.0 (default 0.5). `silence_duration_ms` runs from 200 to 6000 (default 800). The guide advises 400 to 800 ms for conversation. Lower values reply faster and may fire on short pauses. These two settings have no effect in `smart_turn` mode.
- `smart_turn` joins acoustic and semantic signals. A filler such as "uh" or "hmm" does not start a turn and does not interrupt playback. The server may also retract a turn it first judged valid. It then sends `input_audio_buffer.speech_stopped` with `reason=turn_invalid` and starts no response. The client can send `response.create` while it waits for the next input.
- `turn_detection: null` is push-to-talk. The client sends `input_audio_buffer.commit`, then `response.create`.

**Ambient speech and speaker lock.** In `smart_turn` mode, the server sends speech that is not a valid turn as `conversation.item.ambient_audio_transcription` events. It does not write that speech into the conversation. Up to five reference recordings (16 kHz PCM or WAV, public URLs in `turn_detection.voiceprint_audio_urls`, first `session.update` only) let the model lock onto one speaker and ignore other voices. A failed registration does not stop the call [qwencloud-audio-guide].

**Interruption.** In `server_vad` and `smart_turn` modes, new user speech cancels the running response. The server sends `response.done` with status `cancelled`. When `input_audio_buffer.speech_started` arrives, clear the local playback buffer at once. Otherwise old audio overlaps with the new reply. Alibaba lists the same rule under fault tolerance and under latency [qwencloud-audio-guide] [qwencloud-audio-ws].

**Voice.** The default voice is `longanqian_v3.1`. 3.1 keeps the five voices of 3.0 and adds eight. Cloned voices work after you create one with `target_model` set to this model. The voice can be set in the first `session.update` only. Later changes are ignored [qwencloud-audio-guide] [qwencloud-audio-events].

**Latency and delivery.** The guide advises to start playback when the first `response.audio.delta` arrives. It says not to wait for `response.done`. Alibaba recommends AOQ for mobile clients that need stable latency, weak-network resilience and built-in echo cancellation. A raw WebSocket has no echo cancellation [qwencloud-audio-guide] [qwencloud-rt-overview].

**Fault handling.** The guide advises reconnection with exponential back-off (1, 2 and 4 seconds are its example). A client error (`invalid_request_error`) leaves the session open. A server error (`server_error`) ends it [qwencloud-audio-guide].

### Sampling and API parameters

The rate limit is 100K tokens and 60 requests per minute [qwencloud-page-audio31]. Alibaba lists no temperature or top_p setting for the Qwen-Audio realtime session.

### Migrating from the previous generation

The WebSocket event protocol is unchanged from 3.0. To move, change the `model` value in the URL and choose a voice from the 3.1 list. The context grows from 65K to 262K tokens, the output limit from 8K to 16K, and the voice list from 5 to 13. The 3.1 model adds the two language parameters and a safer refusal behaviour that Alibaba describes in words only [qwencloud-audio-guide] [qwencloud-page-audio31] [qwencloud-page-audio30plus].
