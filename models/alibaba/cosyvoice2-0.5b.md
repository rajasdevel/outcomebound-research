# CosyVoice2-0.5B

CosyVoice2-0.5B is an open-weight speech synthesis model of Alibaba's FunAudioLLM team, class CosyVoice, generation 2, released in December 2024. It clones a voice and takes a short instruction and inline tags. It is the generation before [Fun-CosyVoice3](fun-cosyvoice3-0.5b-2512.md), which the maker now recommends. Its instruction support is thinner in the pages read than that of version 3: the pages show a dialect instruction and laughter tags, and give no list of emotions. Maker-wide facts are in the [Alibaba README](README.md).

## How to instruct it

### Setting up the prompt

- **Instruction.** `inference_instruct2` takes the text, an instruction ending in `<|endofprompt|>`, and a reference clip. The maker's example script asks for a Sichuan-dialect reading with a short Chinese phrase [cosy-example].
- **Fine-grained tags.** The version 2 tokenizer defines `[breath]`, `[quick_breath]`, `[laughter]`, `[cough]`, `[sigh]`, `[noise]`, `[vocalized-noise]`, `[lipsmack]`, `[hissing]`, `[clucking]`, `[accent]`, `[mn]`, `<strong>` and `<laughter>`. The example script puts laughter tags in a Chinese sentence and points to the tokenizer for the supported tags [cosy-tokenizer] [cosy-example].
- **No list of instructions.** The pages read give no supported-instruction list for version 2. The list in the code is for version 3 [cosy-common].

### Reasoning and effort

None.

### Output: format, length, tone

- **Tone.** Instruction and tags only; no other tone control is documented.
- **Streaming.** Supported, in text-in and audio-out modes [cosy-example].

Python, vLLM, TensorRT-LLM, FastAPI and gRPC are covered by the repository README [cosy-gh].

### Long context and retrieval

Not applicable.

### Structured output

Not applicable.

### Images, audio, other inputs

Text and a reference clip.

### Voice: turn-taking, interruption and speech style

Turn-taking does not apply.

**How to direct delivery.** An instruction phrase in instruct mode, or tags in the text, direct delivery. The example script for version 2 shows one dialect instruction and laughter tags. For wider emotion instructions, version 3 is the documented model [cosy-example] [cosy-common].

**Strength, failures, voice design, dialogue, long-form.** The pages read give no figures or advice for version 2 on these points.

**Pronunciation.** The example script says the maker's demo results were made with the text front end turned off (`text_frontend=False`), so the front end runs by default. The README lists pinyin and CMU phoneme inpainting as a feature of version 3 [cosy-example] [cosy-gh].

### Sampling and API parameters

The inference scripts expose a `stream` flag; the README names no other sampling settings [cosy-example].

### Migrating from the previous generation

Version 1 models (CosyVoice-300M, an SFT model and an Instruct model) take an instruct string in a different call, `inference_instruct`, with a voice name. Version 2 moved the instruction to `inference_instruct2` with a reference clip. They are older than two generations and have no file here [cosy-example].
