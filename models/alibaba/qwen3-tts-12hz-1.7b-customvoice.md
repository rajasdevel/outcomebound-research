# Qwen3-TTS-12Hz-1.7B-CustomVoice

Qwen3-TTS-12Hz-1.7B-CustomVoice is an open-weight speech synthesis model of Alibaba's Qwen team, class Qwen TTS, generation 3. It speaks with one of nine fixed voices and takes a plain-language style instruction on top, for example a very angry tone or very happy. It is a voice actor model for the delivery of a chosen voice. The smaller 0.6B CustomVoice model has the same voices and takes no instruction, so it is not a voice actor model and has no file here. For a new voice from a description, see [VoiceDesign 1.7B](qwen3-tts-12hz-1.7b-voicedesign.md). Maker-wide facts are in the [Alibaba README](README.md).

## How to instruct it

### Setting up the prompt

- **Three inputs.** The call takes `text`, a `speaker` and an optional `instruct`. Without `instruct`, delivery is the default. The package offers `get_supported_speakers()` and `get_supported_languages()` for the lists [qwen3tts-gh].
- **Instruction wording.** The README examples are short: a Chinese phrase meaning say it in a very angry tone, and the English phrase Very happy. The README states no length limit and gives no list of supported styles [qwen3tts-gh].
- **Voices.** Vivian (bright, slightly edgy young woman, Chinese), Serena (warm and gentle, Chinese), Uncle_Fu (low, mellow older man, Chinese), Dylan (Beijing dialect), Eric (Chengdu dialect), Ryan (dynamic man, English), Aiden (sunny American man, English), Ono_Anna (playful Japanese woman) and Sohee (warm Korean woman). Alibaba advises each speaker's native language for the best quality [qwen3tts-gh].
- **Hosted counterpart.** The hosted Qwen3-TTS-Instruct-Flash models take instructions in an `instructions` field, up to 1,600 tokens, in Chinese or English only [ali-doc-tts].

### Reasoning and effort

None.

### Output: format, length, tone

- **Tone.** The instruction and the meaning of the text set tone, speed and emotion, per the README [qwen3tts-gh].
- **Length.** Alibaba's long-text table gives word error rates for long inputs. The 12 Hz model scores 2.4 (Chinese) and 2.8 (English). The 25 Hz model scores 1.5 and 1.2 [qwen3tts-gh].
- **Formats.** The package returns arrays; saving is up to the caller.

### Tools and agents

Not applicable.

### Coding

The package exposes `generate_custom_voice` with single and batch calls. vLLM-Omni offers offline inference [qwen3tts-gh].

### Long context and retrieval

Not applicable. See the long-text figures above.

### Structured output

Not applicable.

### Images, audio, other inputs

Text, a speaker name and an instruction. No reference audio; cloning is in the Base models [qwen3tts-gh].

### Voice: turn-taking, interruption and speech style

Turn-taking does not apply.

**How to direct delivery.** A plain-language instruction in `instruct` directs delivery. The model reads it and also the text itself. Alibaba's table marks this 1.7B model as taking instructions and the 0.6B CustomVoice model as not taking them [qwen3tts-gh].

**Strength.** On InstructTTSEval for target speakers, Alibaba reports attribute scores of 83.0 (Chinese) and 77.3 (English) for this model. GPT-4o-mini-tts scores 54.9 and 76.4 in the same table. Gemini entries in that table score higher, at 87.6 to 92.3 [qwen3tts-gh].

**What fails.** The README lists no failure cases.

**Voice design and cloning.** Not in this model. The VoiceDesign model makes a new voice, and the Base models clone one.

**Multi-speaker dialogue.** The README documents none.

**Long-form consistency.** The fixed voices stay the same across calls; only the instruction and text change.

**Pronunciation and normalisation.** No phoneme or lexicon control is documented. The README says the series is robust to noisy text [qwen3tts-gh].

### Sampling and API parameters

Defaults come from the checkpoint's `generate_config.json`. Alibaba's tests used bfloat16 and `max_new_tokens` 2048 [qwen3tts-gh].

### Migrating from the previous generation

There is no earlier open Qwen3-TTS release.

## Behaviour observed in practice

No independent or practitioner report was read for this model. The OpenBMB README and BreezeBlue's benchmark list other Qwen3-TTS models, not this one [voxcpm-gh] [breeze-blog2].

## Benchmarks

Maker (Alibaba, InstructTTSEval, target speaker): Chinese APS 83.0, DSD 77.8, RP 61.2; English APS 77.3, DSD 77.1, RP 63.7 [qwen3tts-gh]. No independent result was found.
