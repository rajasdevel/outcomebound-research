# Qwen3.8-Flash

Qwen3.8-Flash is the hosted, production build of Alibaba's Flash-size 3.8 model, in the Qwen Flash class at generation
3.8, released on QwenCloud on 2026-08-26. Alibaba calls it the official version of the open-weight
[Qwen3.8-Flash-Next](qwen3.8-flash-next.md) with a 1M-token context by default and built-in tools, and
positions it as the fast, low-cost model of the 3.8 line [hf-flash-next] [qwencloud-page-flash]. It follows
Qwen3.7-Flash in the class. Family-wide rules are in the [Alibaba README](README.md); the open weights, their
sampling advice and their technical report are on the Flash-Next file, which this file does not repeat.

## How to instruct it

### Setting up the prompt

Alibaba gives no model-specific guidance on system prompts, roles, structure, examples or document placement for
hosted Flash; QwenCloud's general prompt-design page is summarised in the README [qwencloud-prompting]. The launch
post says the model suits high-volume applications, tool-driven workflows and coding and office assistants
[blog-flash-next]. QwenCloud's model-selection page places Flash in its lightweight and low-cost group, mapped
against small models from other labs, and suggests it for office tasks where cost matters [qwencloud-models].
QwenCloud's own page for the model describes it as a preview of the Qwen 4 architecture with 125B total and 6B
active parameters, the same build as the open Flash-Next weights [qwencloud-latest-flash].

### Reasoning and effort

Thinking is on by default. QwenCloud's Flash page documents `reasoning_effort` with three levels: `xhigh` (the
default; it names maths proofs, architecture design and complex coding), `medium` (everyday development and
document writing) and `low` (simple questions and information extraction); `max` and `high` are mapped to `xhigh`,
and `enable_thinking` false turns thinking off so no `reasoning_content` comes back [qwencloud-latest-flash]. The API
reference adds that the levels stand for reasoning budgets of 4,096, 16,384 and 262,144 tokens and cannot be
combined with `thinking_budget` [qwencloud-api-chat]. On preserved thinking the pages differ: the Flash page says
`preserve_thinking` is on by default for this model, while the API reference lists it as supported without marking
it on by default [qwencloud-latest-flash] [qwencloud-api-chat]. In a tool loop both pages say to send the earlier
`reasoning_content` back with the tool results [qwencloud-latest-flash] [qwencloud-thinking]. The model page gives
262K reasoning tokens, 983K input with thinking and 131K output [qwencloud-page-flash]. The open cards' caution (lower
effort may not shorten a multi-turn agent task) is stated for the weights [hf-flash-next]. Artificial Analysis has no
entry for the hosted endpoint; its figures for the open build are 240M output tokens against a median of 140M
[aa-qwen3-8-flash-next].

### Output: format, length, tone

No formatting or tone guidance. The output limit is 131,072 tokens (QwenCloud's model table says 128k); use
`max_completion_tokens` to cap reasoning plus reply [qwencloud-latest-flash] [qwencloud-models] [qwencloud-thinking].
Prefix completion (partial mode) is listed as a feature [qwencloud-page-flash].

### Tools and agents

The page lists function calling and these built-in tools: code interpreter, web search and web extractor, text and image
search, PDF parsing and web fetch; Model Studio says web search is available only in its Beijing and Singapore regions
for this model [qwencloud-page-flash] [aliyun-flash]. The `agent` web-search strategy is not available for Flash on
Chat Completions, only through the Responses API, and in thinking mode `tool_choice` accepts only `auto` or `none`
[qwencloud-search] [qwencloud-fn-calling]. The service is described as compatible with both the OpenAI and the
Anthropic protocols, so it can be driven from Claude Code and Codex [qwencloud-changelog] [blog-flash-next]. Alibaba
publishes no subagent or computer-use guidance for hosted Flash.

### Coding

Alibaba reports no separate run for the hosted build. QwenCloud's Flash page repeats the open Flash-Next card's
figures (Claude Code unless stated: SWE-bench Pro 62.5 on a refined set, DeepSWE 1.1 58.7, SWE-bench Multilingual
81.0) and adds, without numbers, that the model can complete real multi-day projects [qwencloud-latest-flash]
[hf-flash-next].
The only independent coding figure is for the open weights: 25.3% on Artificial Analysis's Terminal-Bench 4.0 run
[aa-qwen3-8-flash-next].

### Long context and retrieval

1M context; up to 991,808 input tokens (983,616 with thinking) [qwencloud-latest-flash]. No retrieval benchmark is
published for the hosted build; the technical report's long-context table for the open architecture shows
multi-needle recall falling sharply past 256K (see the Flash-Next file) [tech-report-flash-next]. Implicit cache hits
cost US$0.016 per million tokens, explicit creation US$0.20 and explicit reads US$0.016, and the Flash page also lists
session cache for the Responses API [qwencloud-page-flash] [qwencloud-latest-flash]. QwenCloud notes that Flash's
explicit-cache hit price is its own rate, not the usual 10% of input [qwencloud-cache].

### Structured output

Flash is on QwenCloud's list for JSON Schema mode (strict) as well as JSON Object mode, and is not among the models
whose JSON mode is limited to non-thinking use; a multimodal input falls back to JSON Object [qwencloud-structured].

### Images, audio, other inputs

QwenCloud's model page, its Flash page and Model Studio list text, image and video input and text output; none of
them lists audio [qwencloud-page-flash] [qwencloud-latest-flash] [aliyun-flash]. Images go in as `image_url` parts and
are compressed by default; `vl_high_resolution_images` and `max_pixels` raise the visual token budget, and `fps` sets
the video sampling rate [qwencloud-latest-flash] [qwencloud-vision]. Model Studio gives up to 2,048 images per
request and videos up to 2 hours or 2 GB [aliyun-vision].

### Sampling and API parameters

QwenCloud's Flash page says that in thinking mode `temperature` defaults to 0.6 and lower values are raised to 0.6
[qwencloud-latest-flash]. The API reference gives a default presence_penalty of 1.5 in non-thinking mode
[qwencloud-api-chat]. The open card's values (thinking: temperature 1.0, top_p 0.95, top_k 20; non-thinking: 0.7,
0.80, 20 with presence_penalty 1.5) belong to the open weights [hf-flash-next]. Rate limits on the page: 2M tokens and
15K requests per minute [qwencloud-page-flash].

### Migrating from the previous generation

Alibaba publishes no Flash-to-Flash comparison with Qwen3.7-Flash. Differences from the pages: the 3.8 build has a
131K output limit where QwenCloud's table lists 64k for 3.7-Flash, it adds `reasoning_effort` levels, and the
3.7-Flash list price is US$0.03 input and US$0.13 output up to 32K tokens against US$0.15 and US$0.47 here
[qwencloud-page-flash] [qwencloud-models] [qwencloud-page-37flash] [qwencloud-api-chat]. QwenCloud says the 3.8 Flash
cost less than a ninth as much as Qwen3.7-Plus to train [qwencloud-latest-flash].

## What the system card reports

Alibaba has published no system card or model card for hosted Flash; the launch post carries no safety content
[blog-flash-next]. QwenCloud states that it moderates all requests and responses [qwencloud-security]. There is no
published refusal, sycophancy, deception, injection or cyber and biology finding for this model.

## Behaviour observed in practice

No independent evaluation of the hosted endpoint was found. A news report gave the launch price as US$0.16 input
and US$0.47 output, as did the launch post; the model page now shows US$0.15 for input, and Model Studio shows
US$0.113 input and US$0.382 output outside Singapore [runtimewire-flash] [blog-flash-next] [qwencloud-page-flash]
[aliyun-flash].

## Benchmarks

None for the hosted endpoint from an independent source; Scale SWE-Bench Pro V2 and METR list no Qwen3.8-Flash
entry, and Artificial Analysis has no page for it [scale-swe-pro-v2] [metr-horizons]. The open build scores 40 on
the Artificial Analysis Intelligence Index v4.3.2 and 25.3% on its Terminal-Bench 4.0 run [aa-qwen3-8-flash-next].
Maker figures repeated for the hosted model: SWE-bench Pro 62.5, DeepSWE 1.1 58.7, SWE-bench Multilingual 81.0,
CoWorkBench 73.9, JobBench 55.7, Toolathlon 73.5, AndroidWorld 84.5, MathVision 95.7, LVBench 76.6
[qwencloud-latest-flash].
