# Qwen3.8-2.4T-A95B

Qwen3.8-2.4T-A95B is the open-weight release of Alibaba's Qwen3.8 flagship: a text-only mixture-of-experts model
with 2.4 trillion parameters and 95 billion active per token, in the Qwen open-weights class at generation 3.8.
It is the first Max-scale Qwen model whose weights are public, and it is the base of the hosted Qwen3.8-Max, which
adds image and video input, a non-thinking mode, 1M context by default and built-in tools [hf-qwen3-8-2-4t].
Earlier open Qwen releases were smaller; the largest one read in the sources is Qwen3.5-397B-A17B. Family-wide rules are in the
[Alibaba README](README.md); the hosted sibling is [Qwen3.8-Max](qwen3.8-max.md).

## How to instruct it

### Setting up the prompt

Alibaba gives no model-specific guidance on system prompts, roles, structure, examples or document placement for
this model; the model card's "Best Practices" covers sampling and output length only [hf-qwen3-8-2-4t], and
QwenCloud's general prompt-design page is summarised in the README [qwencloud-prompting]. Mechanics that matter,
from the model's own chat template: the system message must come first, tool calls are written as an XML-like
block, and effort is written into the system turn as a sentence for `xhigh` and `low` and as nothing for
`medium`, so effort-like wording in a shared system prompt can collide with it [hf-24t-template].

### Reasoning and effort

Thinking cannot be switched off. The card states that the model requires thinking mode for all interactions and
that every reply begins with a reasoning block, and the template raises an error if `enable_thinking` is set to
false [hf-qwen3-8-2-4t] [hf-24t-template]. Depth is set with `reasoning_effort` (`xhigh` by default, `medium`,
`low`); `preserve_thinking` is on by default and keeps earlier reasoning in the history [hf-qwen3-8-2-4t]. On
QwenCloud the model is listed as thinking-only and requires streaming, and the API reference maps the effort levels
to reasoning budgets of 4,096, 16,384 and 262,144 tokens (with 131,072 when neither is set) [qwencloud-thinking]
[qwencloud-api-chat]. Budgets: the card suggests up to 262,144 reasoning tokens and 131,072 reply tokens where an
engine takes separate limits, inside a 1M window; the hosted model page lists 131K maximum reasoning and QwenCloud's
model table a 128k thinking budget, so the hosted limit is half the card's figure [hf-qwen3-8-2-4t]
[qwencloud-page-2-4t] [qwencloud-models]. Alibaba's caution that lower effort does not always shorten agent tasks
appears on the sibling cards rather than this one [hf-qwen3-8-27b]. On the independent index the open checkpoint
used 170M output tokens against a median of 140M, effort not stated [aa-qwen3-8-2-4t].

### Output: format, length, tone

No formatting, verbosity or tone guidance is published. For endless repetition the card says the presence
penalty can be raised between 0 and 2, at the cost of occasional language mixing and slightly lower quality
[hf-qwen3-8-2-4t]. Output limit on the hosted build: 131K [qwencloud-page-2-4t].

### Tools and agents

The card says the model has stronger autonomous planning and handling of environment feedback, and wider support
for popular harnesses [hf-qwen3-8-2-4t]. A self-hosted SGLang server uses the `qwen3` reasoning parser and the
`qwen3_coder` tool-call parser [sglang-qwen38]. Hosted function calling and the code-interpreter, web-extractor and
web-search tools follow the README's rules; the hosted model page lists those three built-in tools
[qwencloud-page-2-4t]. QwenCloud accepts only `auto` or `none` for `tool_choice` in thinking mode, so on this
thinking-only model a call to one named function cannot be forced (an inference from the two pages)
[qwencloud-fn-calling] [qwencloud-thinking]. On a tool loop QwenCloud says to send the earlier `reasoning_content`
back with the tool results [qwencloud-thinking]. Alibaba gives no subagent, context-management or computer-use
guidance for this text-only model.

### Coding

The card's table (Claude Code harness, temperature 1.0, top_p 0.95, 256K context) gives Terminal-Bench 2.1 86.6
(average of 10, 5-hour timeout, max_tokens 131,072), SWE-bench Pro 67.7 on a refined set, DeepSWE 1.1 56.6 and
NL2Repo-Bench 55.9; the column heading is the hosted Max build of 2026-08-03, and the table has no column for this
checkpoint [hf-qwen3-8-2-4t]. For the repository-generation test the evaluators disabled shell commands that fetch
the target repository, as a guard against reward hacking. Independent: Artificial Analysis's own-harness chart data
gives this checkpoint 82.0% on Terminal-Bench 2.1 and 11.1% on Terminal-Bench 4.0, well below the hosted Max
(0902) on both [aa-qwen3-8-2-4t].

### Long context and retrieval

Native context is 262,144 tokens, extensible to about 1,010,000 tokens; the card gives no YaRN recipe for this model
(the 27B and Flash-Next cards do), while the hosted build serves 1M with 991K maximum input
[hf-qwen3-8-2-4t] [qwencloud-page-2-4t]. The maker's table gives MRCR v2 256K (8-needle) 92.9 and LongBench v2
66.3, under the Max column. Artificial Analysis lists a 262K window for the open checkpoint [aa-qwen3-8-2-4t].
Explicit-cache hits on QwenCloud are priced at the model's own rate (US$0.17), not the usual 10% of input
[qwencloud-cache]. No placement or degradation guidance is published.

### Structured output

QwenCloud lists this model for JSON Object mode without the non-thinking restriction it puts on older models, and
its JSON Schema (strict) list names Max, Flash and the 3.7 models, not this one [qwencloud-structured]. The card
says nothing about constrained decoding; a self-hosted engine's own guided-decoding options apply.

### Images, audio, other inputs

None. The card says multimodal inputs are not supported; the hosted Max and the open 27B take images and video
[hf-qwen3-8-2-4t]. QwenCloud's page for this model quotes figures that need image input (OSWorld 86.1,
BabyVision 82.0) in its description; they most likely describe Max, and the page does not say
[qwencloud-page-2-4t].

### Sampling and API parameters

Card values: temperature 1.0, top_p 0.95, top_k 20, min_p 0.0, presence_penalty 0.0, repetition_penalty 1.0, with
the note that engines differ in which sampling parameters they support [hf-qwen3-8-2-4t]. On QwenCloud
`enable_thinking` and `preserve_thinking` go at the top level of the request instead of inside
`chat_template_kwargs` [hf-qwen3-8-2-4t]. Serving engines named: SGLang, vLLM and TokenSpeed, latest versions
advised because throughput differs widely by engine; an FP8 copy of the weights is also published
[hf-qwen3-8-2-4t]. Hosted rate limits: 5M tokens and 5K requests per minute [qwencloud-page-2-4t].

### Migrating from the previous generation

Earlier open Qwen models let thinking be switched off. Against them: thinking cannot be turned off here; effort is a
three-level setting; earlier thinking is kept by default (Qwen3 and 3.5 advised leaving it out; Qwen3.6 made it
optional); the thinking temperature is 1.0 where 0.6 had been used; the licence is the custom Qwen3.8-Max licence,
not Apache-2.0 [qwen-f7] [qwen-f6] [qwen-f23] [hf-max-license]. The hosted limits differ from the open ones (1M
context against 262,144 native, and 131K reasoning against the card's 262,144) [qwencloud-page-2-4t].

## What the system card reports

Alibaba has published no system card for this model. The model card holds benchmarks and best practices and no
safety evaluation; the footnote about disabling repository-fetching commands is the only safeguard it names
[hf-qwen3-8-2-4t]. No refusal, over-refusal, sycophancy, deception, prompt-injection or cyber and biology
findings are published. Open weights can be fine-tuned, so deployed behaviour depends on the deployer.

## Behaviour observed in practice

- **Verbosity and speed (M).** 170M output tokens on Artificial Analysis's index against a median of 140M, 38.7
  output tokens per second, 2.78 s to first token, and a cost of US$2.16 per index task at US$2 in and US$6 out
  [aa-qwen3-8-2-4t].
- **Standing (M).** Artificial Analysis's v4.3 article names GLM-5.3 and Kimi K3 as the leading open-weights
  models and GLM-5.3 Flash (42) as third, followed by this model at 40 [aa-index-v4-3].
- Independent agent measurements beyond Artificial Analysis's terminal runs: none found.

## Benchmarks

[aa-qwen3-8-2-4t]. Scale SWE-Bench Pro V2 and METR list no entry [scale-swe-pro-v2] [metr-horizons]. Maker-run, each

AndroidBench 75.1, CoWorkBench 74.8 and WorkSpaceBench 67.7 (in-house), JobBench 53.4, SkillsBench 70.2, Toolathlon
Verified 72.5, WideSearch 81.9, HLE with tools 56.2, GPQA Diamond 92.6, HLE 43.6, IFBench 82.8, HealthBench 60.2,
PLawBench 73.2, MRCR v2 256K 92.9, LongBench v2 66.3 [hf-qwen3-8-2-4t].
