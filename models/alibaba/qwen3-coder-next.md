# Qwen3-Coder-Next

Qwen3-Coder-Next is an open-weight coding model from Alibaba: 80 billion parameters in total and 3 billion active per token,
Apache-2.0, released on 2026-02-03. It belongs to the Qwen Coder class (generation 3), which Alibaba built for coding
agents and local development, and it never thinks: it has a single, non-thinking mode [hf-coder-next]. QwenCloud's
page for the hosted endpoint carries a notice that the endpoint will be retired on 2026-10-10; the open weights are not
covered by that notice [qwencloud-page-coder]. Alibaba's model-selection page now recommends qwen3.7-plus and
qwen3.8-max for coding harnesses and files Coder-Next under Legacy in its full table [qwencloud-models]. Family-wide rules are in
the [Alibaba README](README.md).

## How to instruct it

### Setting up the prompt

Alibaba gives no model-specific guidance on system prompts, roles, structure, examples or document placement for
Coder-Next. The card says
the model is adapted to several scaffold templates (Claude Code, Qwen Code, Qoder, Kilo, Trae, Cline), so the scaffold's own
prompt is the intended instruction channel [hf-coder-next]. The model does not generate thinking blocks, and the card says
specifying `enable_thinking=False` is no longer needed [hf-coder-next].

### Reasoning and effort

None. The model supports only non-thinking mode; there is no effort, budget or toggle control [hf-coder-next]. QwenCloud's
table lists no thinking budget for it [qwencloud-models]. Reasoning that a task needs has to be elicited in the output
itself; Alibaba gives no advice on whether to ask for it. Artificial Analysis lists it as a non-reasoning model that used
34M output tokens on its index against a median of 26M [aa-qwen3-coder-next].

### Output: format, length, tone

No formatting or tone guidance. The card's example sets `max_new_tokens` to 65,536 and QwenCloud lists a 65K output limit; neither is
stated as a model limit by the card [hf-coder-next] [qwencloud-page-coder]. Prefix completion (partial mode) is listed as a
hosted feature [qwencloud-page-coder].

### Tools and agents

The card says the model is strong at tool use and recovery from execution failures, and shows the OpenAI `tools` API with a
self-hosted server started with `--tool-call-parser qwen3_coder` (SGLang 0.5.8 or later, vLLM 0.15.0 or later)
[hf-coder-next]. Because the model never thinks, the thinking-mode limit on `tool_choice` does not apply, though Qwen
models still do not support `required` [qwencloud-fn-calling]. Hosted function calling is listed on the model page;
the README's rules apply [qwencloud-page-coder]. No
subagent, context-management or computer-use guidance is published.

### Coding

The model's purpose. Figures relayed by a secondary article from the Qwen team (not readable as text on the card, which
carries them as images): SWE-bench Verified 70.6 and SWE-bench Multilingual 62.8 and SWE-bench Pro 44.3, all with the
SWE-Agent scaffold, Terminal-Bench 2.0 36.2 (Terminus-2 JSON) and Aider 66.2 [analyticsvidhya-coder-next]. Verified is a
retired set on leading boards; the Pro figure is not on the Scale V2 set. Independent index score: 9 on v4.3.2
[aa-qwen3-coder-next].

### Long context and retrieval

Native context 262,144 tokens; Artificial Analysis lists 256k [hf-coder-next] [aa-qwen3-coder-next]. The card warns that
a full-length context can run out of memory and suggests lowering the setting to 32,768 [hf-coder-next]. QwenCloud's page
lists 262K context, 204K maximum input and 65K maximum output [qwencloud-page-coder]. No retrieval benchmark is published.

### Structured output

QwenCloud's page lists structured outputs; its guide lists the Qwen3-Coder series for JSON Object mode and not for
JSON Schema mode, so JSON Object mode is the documented route [qwencloud-page-coder] [qwencloud-structured]. The card
does not discuss it.

### Images, audio, other inputs

None; text only [hf-coder-next].

### Sampling and API parameters

Card values: temperature 1.0, top_p 0.95, top_k 40 [hf-coder-next]. Hosted price shown for input up to 32K tokens: US$0.30
input and US$1.50 output per million tokens; Amazon Bedrock also lists the model, at prices it sets itself
[qwencloud-page-coder] [aws-bedrock-qwen]. Rate limits on the hosted page: 1M tokens and 600 requests per minute.

### Migrating from the previous generation

Qwen3-Coder (July 2025) was also non-thinking and trained against a specially designed function-call format; Coder-Next
keeps the single mode and the `qwen3_coder` parser, and uses a hybrid Gated DeltaNet and attention design with 512
experts [qwen-g3] [hf-coder-next]. Alibaba publishes no Coder-to-Coder
comparison. For hosted use the retirement notice means a move to another endpoint; QwenCloud's page does not name a
replacement [qwencloud-page-coder]. Where a general Qwen model replaces it, that model thinks by default, which changes
latency, output tokens and cost [qwencloud-thinking].

## What the system card reports

Alibaba has published no system card for Coder-Next. The card describes training for long-horizon reasoning, complex tool use and
recovery from failures, and reports no safety evaluation [hf-coder-next]. No refusal, sycophancy, deception, injection or cyber
and biology finding is published. The weights are Apache-2.0 and so can be fine-tuned without restriction.

## Behaviour observed in practice

- **Index, verbosity and speed (M).** Artificial Analysis v4.3.2: 9, 34M output tokens against a median of 26M, 83.5
  output tokens per second, 1.29 s to first token, $0.35 input and $1.20 output per million tokens, cost $0.55 per index
  task [aa-qwen3-coder-next].
- **Terminal tasks (M).** Artificial Analysis's chart data gives 38.2% on Terminal-Bench 2.1 and 0% on the harder
  Terminal-Bench 4.0 [aa-qwen3-coder-next].

## Benchmarks

Independent: Artificial Analysis Intelligence Index v4.3.2, 9 (non-reasoning) [aa-qwen3-coder-next]; Terminal-Bench 4.0
0% and Terminal-Bench 2.1 38.2% on Artificial Analysis's own harness, read from chart data [aa-qwen3-coder-next]. Scale
SWE-Bench Pro V2 and METR list no entry [scale-swe-pro-v2] [metr-horizons]. Maker figures as relayed:
those above, from a February 2026 article [analyticsvidhya-coder-next].
