# Qwen-Audio-3.0-Realtime-Plus

Qwen-Audio-3.0-Realtime-Plus is the Plus tier of generation 3.0 of Alibaba's Qwen Audio realtime line. It takes streaming audio and text and gives back speech and text. Alibaba calls it a full-duplex model that favours depth over speed. QwenCloud's changelog dates it 2026-08-10, together with the Flash tier. The 3.1 Plus model replaced it as the recommended choice. This file says what differs from [Qwen-Audio-3.1-Realtime-Plus](qwen-audio-3.1-realtime-plus.md), which holds the full guide. Family-wide rules are in the [Alibaba README](README.md) [qwencloud-changelog] [qwencloud-page-audio30plus] [qwencloud-s2s-models].

## How to instruct it

### Setting up the prompt

Alibaba's guide for the Qwen-Audio realtime models applies. The guide says to put the role, style and behaviour in `instructions`. It also advises plain text with no emoji and no Markdown, one follow-up question per turn, and short greetings [qwencloud-audio-guide]. See the 3.1 file for the six rules and the persona examples.

### Reasoning and effort

No reasoning switch exists. The model page lists no reasoning budget for this model. Alibaba's table shows no thinking support for the Qwen-Audio realtime models [qwencloud-page-audio30plus] [qwencloud-s2s-models].

### Output: format, length, tone

`modalities` takes `["audio", "text"]` (default) or `["text"]`. `enable_speech_emotion` (default `true`) makes the voice vary its emotion more. The two language parameters of 3.1 (`session.input_audio_transcription.language`, `session.output_audio.language`) apply to 3.1 only [qwencloud-audio-guide] [qwencloud-audio-events].

### Tools and agents

Function calling and web search (`enable_search`) are available. They cannot run together [qwencloud-audio-guide] [qwencloud-audio-events] [qwencloud-s2s-models].

### Coding

Alibaba gives no coding guidance or score for this model.

### Long context and retrieval

The context is 65K tokens, with 57K input and 8K output. The model keeps at most 50 audio turns or 300 seconds of audio. `max_history_turns` runs from 1 to 50 and defaults to 20 [qwencloud-page-audio30plus] [qwencloud-audio-guide].

### Structured output

The model page lists structured outputs as a feature. The guide gives no rules for them [qwencloud-page-audio30plus].

### Images, audio, other inputs

Input is PCM, 16-bit, mono, 16 kHz. Output is PCM, 24 kHz. The model takes no image or video input. Conversation languages are German, English, Spanish, French, Indonesian, Italian, Japanese, Korean, Portuguese, Russian and Chinese, plus 21 Chinese varieties. The guide says these models need a Singapore-region API key [qwencloud-audio-guide].

### Voice: turn-taking, interruption and speech style

The three modes, `server_vad`, `smart_turn` and push-to-talk, work as in 3.1. `server_vad` has `threshold` (default 0.5) and `silence_duration_ms` (200 to 6000, default 800, 400 to 800 advised for conversation). The mode can change only before the first audio is sent. In `smart_turn` mode, fillers do not start a turn or interrupt playback. Speaker lock with reference recordings is available in that mode [qwencloud-audio-ws] [qwencloud-audio-guide].

In VAD modes, new user speech cancels the running response (`response.done` with status `cancelled`). The guide advises to clear the local playback buffer on `input_audio_buffer.speech_started`. It advises about 100 ms of audio per chunk. It advises to start playback on the first audio delta [qwencloud-audio-guide].

The model has five system voices. The default is `longanqian`. Cloned voices are also available. The voice can be set in the first `session.update` only [qwencloud-audio-guide].

### Sampling and API parameters

The rate limit is 100K tokens and 60 requests per minute [qwencloud-page-audio30plus].

### Migrating from the previous generation

This is the first generation of the Qwen Audio realtime line in this library. Alibaba's earlier realtime speech models were the Qwen3-Omni and Qwen3.5-Omni realtime models. Alibaba's migration table points users of closed-source realtime models to the 3.1 Plus model, and users of cost-sensitive models to the 3.0 Flash model [qwencloud-s2s-models].

## Behaviour observed in practice

Artificial Analysis measured the model on its Speech to Speech page (read 2026-10-03) [aa-s2s]:

- Speech reasoning (Big Bench Audio): 99.2%.
- Conversational dynamics (a subset of Full Duplex Bench v1 and v1.5): 98.4%. The parts are pause handling 97.8, turn-taking 98.3, interruption handling 97.5 and backchannel handling 100.
- Agentic performance (tau-Voice, full-duplex models only): 54.6%. The parts are airline 61.3, retail 49.0 and telecom 53.5.
- Time to first audio: 1.54 seconds on average.
- Arena preference Elo: 775. Task success rate: 77.8%, as the page labels it.

Alibaba's model page says the model ranks first overall in the speech-to-speech category on Artificial Analysis. That claim does not match what the page showed on 2026-10-03, where other models have a higher displayed index. The page does not say why. The page also holds two different values of its composite index for this model (66.8 in its table and 84.1 in its embedded data), so this file records neither [qwencloud-page-audio30plus] [aa-s2s]. Artificial Analysis lists US$0.03 per hour of input audio and US$0.18 per hour of output audio. The QwenCloud price per token gives a different amount. The pages do not explain the difference [aa-s2s].
