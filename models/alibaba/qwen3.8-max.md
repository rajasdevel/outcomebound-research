# Qwen3.8-Max

Qwen3.8-Max is Alibaba's hosted flagship, the 3.8 generation of the Qwen Max class. It is a mixture-of-experts
model with 2.4 trillion parameters and about 95 billion active per token, released on 2026-08-03 as the
successor to Qwen3.7-Max, and aimed at long-running coding and office-style agent work. The open-weight
Qwen3.8-2.4T-A95B is its base; Alibaba calls Max the official version with image and video input, a
non-thinking mode, 1M context and built-in tools added [hf-qwen3-8-2-4t] [blog-qwen3-8-max]. The bare id
`qwen3.8-max` has pointed at the `qwen3.8-max-0902` snapshot since 2026-09-05. Family-wide rules (API
parameters, caching, tools, licences, how the guidance moved) are in the [Alibaba README](README.md); this file
covers what is specific to Max.

## How to instruct it

### Setting up the prompt

Alibaba publishes no Max-specific guidance on system prompts, roles, structure, examples or where to put long
documents. QwenCloud's general prompt-design page (context, objective, style, tone, audience and response
sections, delimiters, few-shot examples) applies to all its models and is summarised in the README's "Prompting
guides" [qwencloud-prompting]. What Alibaba says about Max bears on instruction style indirectly. Reinforcement
learning ran across several agent harnesses (QwenWork, Claude Code, Codex, OpenClaw and Hermes), and the launch
post gives set-up steps for Claude Code, Codex, Qoder CLI, Qwen Code and OpenClaw, which suggests (an inference,
not an Alibaba statement) that each harness's own prompts and tool formats are the intended route rather than a
Qwen-specific format [blog-qwen3-8-max]. The post's showcase runs (an autonomous coding project that reached 265
commits after about 16 days, a chip-design run of about 500 turns and 71 evaluations, a 24-hour programming
contest) are capability claims, not prompting advice [blog-qwen3-8-max]. On instruction following, the maker's
table gives IFBench 82.8 (maker-run, harness not stated) [hf-qwen3-8-2-4t]. The cross-model study in the README
(fully compliant replies falling to zero by 80 simultaneous instructions) did not name the models it tested
[arxiv-2607-19257].

### Reasoning and effort

- **Control.** `reasoning_effort` takes `low`, `medium` or `xhigh`; `xhigh` is the default. QwenCloud maps the
  OpenAI values (`max` and `high` to `xhigh`, `minimal` to `low`, `none` to thinking off) and rejects others
  [qwencloud-api-chat]. Thinking is on by default and `enable_thinking` false turns it off; the open 2.4T model
  cannot do this, and hosted Max adds the non-thinking mode [qwencloud-thinking] [hf-qwen3-8-2-4t]. On the
  Anthropic endpoint the same levels go in `output_config.effort` [qwencloud-anthropic].
- **Levels.** Alibaba's descriptions: `xhigh` for complex tasks that need thorough analysis, `medium` to
  balance accuracy and speed, `low` for speed and cost [hf-qwen3-8-2-4t]. The 27B and Flash-Next cards add that in
  multi-turn agent work a lower effort does not always shorten the task, because faster turns can bring more
  failures and retries [hf-qwen3-8-27b]. Alibaba publishes no per-level measurement for Max.
- **Budgets.** `reasoning_effort` and `thinking_budget` cannot be sent together. When only the effort is set it
  stands for a reasoning budget of 4,096 (`low`), 16,384 (`medium`) or 262,144 (`xhigh`) tokens; with neither set
  the defaults are `xhigh` and 131,072 tokens [qwencloud-api-chat]. The model page lists up to 262,144 reasoning
  tokens, 983K input tokens with thinking on and 131K output tokens [qwencloud-page-max]. `max_completion_tokens`
  bounds reasoning plus reply; `max_tokens` is capped at 32,768 in thinking mode and counts only the reply
  [qwencloud-thinking].
- **Thinking visibility and history.** Reasoning streams as `reasoning_content` before `content`. QwenCloud's API
  reference marks `preserve_thinking` on by default for `qwen3.8-max` and `qwen3.8-max-0902`, asks that all earlier
  reasoning be sent back in the `reasoning_content` field, and says pasting it into `content` may degrade results;
  the preserved reasoning is billed as input [qwencloud-api-chat]. The thinking guide adds that tool-call loops must
  return `reasoning_content` with the tool results, since leaving it out lowers accuracy [qwencloud-thinking].
- **What not to do.** Beyond the `content` rule above and not combining effort with a budget, Alibaba says nothing
  about step-by-step prompts on Max. The 3.7-Max post recommended a system sentence stating the effort level
  [blog-qwen3-7]; on 3.8 the parameter replaced it, and whether the hosted endpoint adds that sentence itself is
  not stated.
- **Cost of the default.** Artificial Analysis measured 190M output tokens on its index against a median of
  81M and called the model very verbose; effort was not stated [aa-qwen3-8-max]. In launch week the same firm's
  cost per index task was reported as US$1.14 against US$0.53 for the predecessor, with 64 turns per task against
  14 [nyu-rits].

### Output: format, length, tone

Alibaba gives no verbosity, formatting or tone controls for Max. The output limit is 131,072 tokens (model page)
or "128k" (QwenCloud's model table), reasoning included when `max_completion_tokens` is used
[qwencloud-page-max] [qwencloud-models]. Prefix completion (partial mode) is listed as a feature of Max; its
behaviour with thinking on is not documented in the pages read [qwencloud-page-max]. Alibaba gives no
stop-sequence guidance.

### Tools and agents

- **Function calling** uses the OpenAI `tools` format. Qwen models do not support `tool_choice: "required"`, and
  QwenCloud names `qwen3.8-max` as a model whose default thinking mode accepts only `auto` or `none`, so forcing a
  named function means turning thinking off. `parallel_tool_calls` enables several calls in one turn; streamed
  arguments must be joined before parsing; QwenCloud advises passing no more than 20 tools [qwencloud-fn-calling].
- **Built-in tools** on Max: code interpreter, web extractor, web search, text-to-image search,
  image-to-image search, PDF parsing and web fetch [qwencloud-page-max]. Chat Completions returns no search
  sources and does not support the `agent` search strategy for Qwen3.8; the Responses API does
  [qwencloud-search]. Model Studio says web search for Max works only in its Beijing and Singapore regions
  [aliyun-max].
- **Harness routes.** The Anthropic Messages endpoint serves Claude Code; the Responses protocol serves Codex;
  Qwen Code, Qoder CLI and OpenClaw are also named [blog-qwen3-8-max] [qwencloud-anthropic].
- **Long-horizon behaviour.** Alibaba reports an autonomous coding project that reached 265 commits, 127 pull
  requests and 151 issues after about 16 days; its Codex set-up example declares a 1M window with
  `effective_context_window_percent` set to 95 [blog-qwen3-8-max]. Both are the maker's own material. Independent
  data points to heavy tool use: 64 turns per task on Artificial Analysis's launch-week index run [nyu-rits], and
  about 110 steps and US$3.48 per task, with a 95% cache-hit rate, in its Claude Code coding-agent runs
  [aa-coding-agents].
- **Computer use.** The maker reports OSWorld-Verified 86.1 (relayed by a secondary article; not in the open
  card's table) and describes "hybrid agent" use that mixes coding with GUI actions [nyu-rits] [blog-qwen3-8-max].
- Alibaba gives no subagent or context-management guidance for Max beyond the caching rules in the README.

### Coding

Alibaba's own table (Claude Code harness, temperature 1.0, top_p 0.95, 256K context) gives Terminal-Bench 2.1
86.6 (average of 10, 5-hour timeout, max_tokens 131,072), SWE-bench Pro 67.7 on a refined task set (so not the
Scale V2 set) and DeepSWE 1.1 56.6 (Max did best on Claude Code) [hf-qwen3-8-2-4t]. The other models in that table
are scored on different harnesses, so the rows do not compare like for like. Independent figures: Artificial
Analysis's Coding Agent Index (Claude Code) puts Max at 43.3, with DeepSWE v1.1 51.0, Terminal-Bench 4.0 16.7 and
SWE-Atlas-QnA 62.1 [aa-coding-agents]; its own-harness chart data gives the 0902 snapshot 88.8% on Terminal-Bench 2.1
and 38.9% on Terminal-Bench 4.0 [aa-qwen3-8-max]. A launch-week review reports 81.3 on Artificial Analysis's
Terminus 2 harness and 67.4 from Vals AI against Alibaba's 86.6 (class A) [codersera-max]. The 0902 snapshot is
described as stronger on engineering-scale projects and long-running agent tasks, with no new scores
[qwencloud-max-update] [datanorth-0902]. For repository-generation tests Alibaba disabled shell commands that
fetch the target repository, as a guard against reward hacking [hf-qwen3-8-2-4t].

### Long context and retrieval

- **Limits.** 1M context; up to 991K input (983K with thinking); 131K output; 262K reasoning
  [qwencloud-page-max]. Artificial Analysis lists 984K [aa-qwen3-8-max].
- **Retrieval measurements.** The maker's table gives MRCR v2 256K (8-needle) 92.9 and LongBench v2 66.3, both
  maker-run [hf-qwen3-8-2-4t]. Artificial Analysis's long-context reasoning score (AA-LCR) fell two points
  against the 3.7-Max generation in a launch-week report (class A) [nyu-rits].
- **Price and caching.** One price row, with no long-input surcharge shown: US$2 input, US$6 output; implicit
  cache US$0.25; explicit cache creation US$2.50 and read US$0.17 per million tokens [qwencloud-page-max]. QwenCloud
  notes that Max's explicit-cache hit price is its own rate, not the usual 10% of input [qwencloud-cache]. Alibaba
  publishes no placement or degradation guidance specific to Max.

### Structured output

Max is on QwenCloud's list for JSON Schema mode (strict), as well as JSON Object mode, and is not among the models
whose JSON mode is limited to non-thinking use. The guide says a multimodal request falls back to JSON Object, not
to set `max_tokens`, and to validate output before using it [qwencloud-structured]. On the Anthropic endpoint
`output_config.format` gives schema-strict output for the Qwen3.8 models [qwencloud-anthropic].

### Images, audio, other inputs

Input is text, image and video; output is text. Model Studio gives up to 2,048 images per request (QwenCloud's
vision guide says 256 by URL), up to 16 million pixels each, and videos up to 2 hours or 2 GB, up to 64 per
request; image tokens are height times width divided by 1,024, plus 2 [aliyun-vision] [qwencloud-vision]. Alibaba
says Max handles documents above 200 pages and videos above 100 hours [blog-qwen3-8-max]. The 0902 snapshot is said
to improve chart reasoning, document parsing and perception, with no scores [qwencloud-max-update]. No audio input
is listed for Max [qwencloud-page-max].

### Sampling and API parameters

The hosted guide gives no sampling values for Max; the API reference gives a default presence_penalty of 1.5 in
non-thinking mode [qwencloud-api-chat]. The open-weight card suggests temperature 1.0, top_p 0.95, top_k 20, min_p
0, presence_penalty 0 for thinking [hf-qwen3-8-2-4t]; the maker's evaluations used 1.0 and 0.95
[hf-qwen3-8-2-4t]; MathArena's run through OpenRouter also used 1.0 and 0.95 [matharena-max]. Through the
Anthropic endpoint temperature may be set from 0 up to but not including 2 [qwencloud-anthropic].

### Migrating from the previous generation

Compared with Qwen3.7-Max: QwenCloud's 3.7-Max page lists text input only (its 2026-06-08 snapshot added image
understanding), so image and video input are new for most callers; `reasoning_effort` (three levels) and
default-on `preserve_thinking` replace the system-sentence approach and opt-in setting of 3.7 [qwencloud-page-37max]
[qwencloud-changelog] [blog-qwen3-7] [blog-qwen3-8-max]; list price falls from US$2.50 input and US$7.50 output to
US$2 and US$6 [qwencloud-page-37max] [qwencloud-page-max]. On the maker's own table 3.7-Max scores 74.5 on
Terminal-Bench 2.1, 60.6 on SWE-bench Pro, 21.6 on DeepSWE 1.1 and 79.1 on IFBench against Max's 86.6, 67.7, 56.6
and 82.8 [hf-qwen3-8-2-4t]; on Artificial Analysis's index the score rose from 29 to 45 while tokens used rose from
120M to 190M [qwen-trend] [aa-qwen3-8-max]. The bare id moved to the 0902 snapshot on 2026-09-05, so a prompt
written against the launch build may behave differently under the same id; a dated id fixes that
[qwencloud-max-update]. QwenCloud's model table gives 3.7-Max a 64k output limit and no structured-output support,
while its model page lists 131K and its structured-output guide names 3.7-Max for JSON Schema mode; the pages
disagree [qwencloud-models] [qwencloud-page-37max] [qwencloud-structured].

## What the system card reports

Alibaba has published no system card for Qwen3.8-Max (see the README's "System-card practice"). The launch post
reports capability showcases only. The related 3.7-Max post reports reward-hacking monitoring during
reinforcement learning (1,618 cases flagged over 80-plus hours, 13 new heuristic rules) [blog-qwen3-7]; the 3.8
table notes that shell commands fetching the target repository were disabled for one benchmark
[hf-qwen3-8-2-4t]. The nearest independent data: in Artificial Analysis's Claude Code runs Max refused none of 909
attempts, and the judge model it uses for reward hacking flagged none of the 33 passing Terminal-Bench 4.0 attempts
it reviewed [aa-coding-agents]. There is no published measurement of over-refusal, sycophancy, deception,
prompt-injection resistance or cyber and biology classifiers for this model. QwenCloud states that it moderates
all requests and responses [qwencloud-security]. One unreplicated claim on a security-tools vendor's blog (class A) says a persona prompt bypassed the
earlier `qwen3.8-max-preview` build [penligent-jailbreak].

## Behaviour observed in practice

- **Verbosity and speed (M).** 190M output tokens on Artificial Analysis's index (v4.3.2) against a median of 81M;
  37.8 output tokens per second (rank 177 of 224) and 2.66 s to first token for the 0902 snapshot; cost per
  index task US$5.41 [aa-qwen3-8-max].
- **Coding-agent runs (M).** In Claude Code, about 110 steps, 63 minutes of agent time and US$3.48 per task on
  average, with a 95% cache-hit rate [aa-coding-agents].
- **Hallucination (class A, relayed from Artificial Analysis).** In launch-week figures, AA-Omniscience fell 10
  points with the hallucination rate rising from 23% to 40% against the previous generation [nyu-rits].

  cycles lifted Max's Artificial Analysis score from 40 to 45 (the 0902 build) [versely-apsara] [qwen-next].
