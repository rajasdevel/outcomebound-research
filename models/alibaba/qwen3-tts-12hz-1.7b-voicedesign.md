# Qwen3-TTS-12Hz-1.7B-VoiceDesign

Qwen3-TTS-12Hz-1.7B-VoiceDesign is an open-weight speech synthesis model of Alibaba's Qwen team, class Qwen TTS, generation 3. It creates a new voice from a written description, and the same description can set tone, speed and emotion. It is a voice actor model: you direct the performance in plain language. Alibaba released the Qwen3-TTS series on 2026-01-22. The sibling [CustomVoice 1.7B](qwen3-tts-12hz-1.7b-customvoice.md) keeps nine fixed voices and takes style instructions on top. Maker-wide facts are in the [Alibaba README](README.md). The closed Qwen-Audio TTS models, hosted only, are outside this file.

## How to instruct it

### Setting up the prompt

- **The prompt is a description.** The model has no system prompt. You pass the text to speak and a description in `instruct`. The README examples include one English sentence: an incredulous tone with panic starting to creep in. They also include a longer Chinese description of a cute, clingy girl's voice with a high, varied pitch [qwen3tts-gh].
- **What to put in the description.** The README gives no writing guide. Alibaba Cloud's voice design page for the hosted models does, and it is the nearest guide from the maker. It gives these rules. A description is specific, with words such as deep, crisp or fast-paced and not nice or normal. It covers several dimensions, such as gender, age, pitch, speed, emotion, voice character and use case. It describes the voice and not a named person. It avoids repeated synonyms. The hosted limit is 2,048 characters, in Chinese or English only [ali-doc-vd].
- **Dimensions listed by Alibaba.** Gender; age bands from child to senior; pitch; speed; emotion (cheerful, calm, gentle, serious, lively, composed, soothing); voice character (resonant, crisp, husky, mellow, sweet, deep, powerful); and use case (news, advertising, audiobook, animation character, voice assistant, documentary) [ali-doc-vd].
- **Language of the description.** The README examples pair a Chinese description with Chinese text and an English description with English text [qwen3tts-gh].
- **The `language` field.** It takes the language of the text, or `Auto`. The README says to set it when the language is known [qwen3tts-gh].

### Reasoning and effort

None. The model has no reasoning or effort control.

### Output: format, length, tone

- **Tone and pace.** The description sets them. The README says the model also reads the text itself and adjusts tone, rhythm and emotion from its meaning [qwen3tts-gh].
- **Length.** Alibaba's own tests used a limit of 2,048 new tokens per generation. The model card gives no maximum text length [qwen3tts-gh].
- **Consistency.** The same description can give a slightly different voice on each run. For a stable character, Alibaba's README suggests this workflow. Design the voice and keep a short clip of it. Build a reusable clone prompt from that clip with the Base model. The prompt then serves later lines [qwen3tts-gh]. The README does not say how much a design varies between runs. The FAQ of Alibaba Cloud's hosted voice design page says that voice design has randomness, so one description can give slightly different voices each time, and it suggests making several and choosing one. The same variation is likely for the open model (inferred) [ali-doc-vd].

### Tools and agents

Not applicable. The model does not call tools.

### Coding

Alibaba gives no coding guidance. The `qwen-tts` package exposes `generate_voice_design` with single and batch calls. vLLM-Omni offers offline inference; the README said online serving would follow [qwen3tts-gh].

### Long context and retrieval

Not applicable. A long text is split by the caller. The README gives no length advice for this model; its long-text table covers the CustomVoice model [qwen3tts-gh].

### Structured output

Not applicable.

### Images, audio, other inputs

Text and a description only. Reference audio goes to the Base models, which clone a voice from a short clip and do not take instructions [qwen3tts-gh].

### Voice: turn-taking, interruption and speech style

Turn-taking does not apply. The model renders one text at a time.

**How to direct delivery.** The `instruct` field holds the direction. Alibaba's table marks instruction control as supported for this model and for the 1.7B CustomVoice model only. The 0.6B CustomVoice model and the Base models take no instruction [qwen3tts-gh]. Examples in our words: an incredulous voice with a hint of panic, in one line of English. A Chinese description of a cute, clingy voice with high, wavering pitch is another [qwen3tts-gh].

**Strength.** On InstructTTSEval, Alibaba reports attribute perception scores of 85.2 (Chinese) and 82.9 (English), and response precision of 65.1 and 68.4. The same table lists Gemini and GPT-4o-mini-tts rows for target-speaker models, and Hume and several research models for voice design [qwen3tts-gh]. A competitor's benchmark ranks the model sixth of seven on role fit [breeze-blog2].

**What fails.** The README gives no list. Alibaba Cloud's hosted page says its voice design does not imitate named people, such as celebrities or actors. Its FAQ says that one description can give slightly different voices on each run [ali-doc-vd].

**Voice design and cloning.** This model is the design model. To reuse a designed voice, design then clone. The Base models clone from about three seconds of audio [qwen3tts-gh].

**Multi-speaker dialogue.** The README documents none for the open models.

**Long-form consistency.** Design then clone, as above, keeps a voice stable. The README has a long-text table. In it, the 25 Hz and 12 Hz CustomVoice models score word error rates of 1.2 to 2.8 percent on long Chinese and English text. The table has no VoiceDesign row [qwen3tts-gh].

**Pronunciation and normalisation.** The README says the series is robust to noisy input text. It documents no phoneme or lexicon control [qwen3tts-gh].

**Hosted counterparts.** Alibaba Cloud serves Qwen3-TTS-VD models, and the Instruct-Flash models take an `instructions` field of up to 1,600 tokens in Chinese or English [ali-doc-tts].

### Sampling and API parameters

The package reads default sampling values from the `generate_config.json` of the checkpoint. Alibaba ran its tests in bfloat16 with `max_new_tokens` 2048 [qwen3tts-gh].

### Migrating from the previous generation

There is no earlier open Qwen3-TTS release. Alibaba's earlier hosted speech models (`qwen-tts`, `qwen3-tts-flash`) are separate closed models with fixed system voices [ali-doc-tts].

Alibaba publishes no system card for the model. The README names no safety test. The model card repeats the series description and the evaluation tables [qwen3tts-gh] [hf-q3tts-vd].

## Behaviour observed in practice

- **Comparison by a competing maker (L, third-party vendor).** BreezeBlue ranks a model listed as Qwen3-TTS-VD sixth of seven on its voice design benchmark. The role fit is 58.48 and the model makes 83 distinct voices. The page does not say whether it tested the open weights or the hosted model [breeze-blog2].
- **Comparison table in another model's README (L).** OpenBMB's table repeats Alibaba's InstructTTSEval row. It puts its own VoxCPM2 level with that row on the Chinese attribute score (85.2) and ahead on the English one (84.2 against 82.9) [voxcpm-gh].
- No practitioner report was read.

## Benchmarks

Maker (Alibaba, InstructTTSEval): Chinese APS 85.2, DSD 81.1, RP 65.1; English APS 82.9, DSD 82.4, RP 68.4. Third-party vendor: BreezeBlue role fit 58.48 [qwen3tts-gh] [breeze-blog2]. No independent measurer lists this open model.
