# Qwen3.7-Plus

Qwen3.7-Plus is Alibaba's mid-range hosted model, the 3.7 generation of the Qwen Plus class, released on QwenCloud
on 2026-06-01. It is closed, takes text, images and video, has a 1M-token context, and is described as the
cost-effective Qwen3.7 model with upgraded vision-language and "multimodal interactive hybrid agent" abilities
[qwencloud-page-plus] [qwencloud-changelog]. QwenCloud's model-selection page recommends it as the balanced
choice for coding in Claude Code or OpenClaw and for office tasks. QwenCloud's changelog lists no Qwen3.8-Plus up to
2026-10-02, so it is still the newest Plus model [qwencloud-changelog] [qwencloud-models]. Family-wide rules are in the
[Alibaba README](README.md).

## How to instruct it

### Setting up the prompt

Alibaba gives no model-specific guidance on system prompts, roles, structure, examples or document placement for
Plus; QwenCloud's general prompt-design page, whose worked example is an assistant on an earlier Flash model, is
summarised in the README [qwencloud-prompting]. QwenCloud's
model-selection page maps it to mid-range models from other labs (for migrations away from those models) and
recommends it for document drafting, email and meeting notes, and for coding harnesses that need full tool support and
a 1M window [qwencloud-models]. A host (Fireworks) paraphrases the Qwen team as calling it an agent model rather than a
chat model (class A) [fireworks-37plus].

### Reasoning and effort

- **Control.** Thinking is on by default and can be switched off with `enable_thinking`; `thinking_budget` caps
  reasoning tokens (the API reference's default is the model's maximum; the console's setting runs from 1 to
  32,768); `preserve_thinking` is supported and off by default. QwenCloud's API reference documents
  `reasoning_effort` levels for the Qwen3.8 models and not for Qwen3.7, so none is documented for Plus; the effort
  sentence recommended in the 3.7-Max post is the nearest guidance [qwencloud-thinking] [qwencloud-api-chat]
  [blog-qwen3-7].
- **Cost of thinking.** QwenCloud measured that reasoning makes up more than 60% of Plus's output tokens and that turning
  thinking off cuts total latency by 60 to 75%; generation speed is about 52 to 54 tokens per second, so the delay
  comes from the volume of reasoning [qwencloud-thinking]. For long prompts that time out the same page suggests
  turning thinking off, streaming, or a client timeout of 180 s or more, and it says thinking pays off for
  multi-step tool orchestration more than for simple single-tool calls [qwencloud-thinking].
- **Budgets.** The page lists 262K maximum reasoning tokens and 983K input with thinking [qwencloud-page-plus]. Use
  `max_completion_tokens` for a combined cap [qwencloud-thinking].
- Artificial Analysis lists it as a reasoning model, effort not stated, with 130M output tokens against a median of
  100M [aa-qwen3-7-plus]. A Fireworks write-up says thinking and non-thinking modes are selectable per request there
  [fireworks-37plus].

### Output: format, length, tone

No formatting or tone guidance. Output limit: the model page says 131K tokens (also for thinking) while QwenCloud's model
table says 64k; the larger figure is on the card and the two pages disagree [qwencloud-page-plus] [qwencloud-models]. Prefix
completion (partial mode) is listed as a feature. Non-streaming calls are accepted [qwencloud-thinking].

### Tools and agents

Function calling is supported, along with built-in code interpreter, web search, web extractor and text- and
image-search tools [qwencloud-page-plus]. The 3.7-Max post says that model works across Claude Code, OpenClaw and Qwen Code; it does not say this of
Plus [blog-qwen3-7]. In thinking mode `tool_choice` accepts only `auto` or `none` [qwencloud-fn-calling]; the README covers streaming
arguments and returning `reasoning_content`.
For "hybrid agent" use the page lists scene perception, screen reading, GUI interaction, code from visual references
and mobile app navigation as strengths [qwencloud-page-plus]. The maker's later tables give OSWorld-Verified 73.3 and AndroidWorld 81.0
(comparison column, maker-run) [hf-qwen3-8-27b] [hf-flash-next]. No subagent or context-management guidance is published.

### Coding

The only vendor coding numbers are comparison columns on the 27B and Flash-Next cards (maker-run, Claude Code):
SWE-bench Pro 57.6 on the 27B card and 55.8 on the Flash-Next card (the two cards disagree), Terminal-Bench 2.1
(Terminus) 64.0, DeepSWE 1.1 14.2 or 16.5, NL2Repo-Bench 41.1, LiveCodeBench v6 89.6 [hf-qwen3-8-27b] [hf-flash-next]. The
Flash-Next card's table lists the model as 397B total and 17B active; no Plus page states this, and Artificial Analysis
lists the size as undisclosed [hf-flash-next] [aa-qwen3-7-plus].

### Long context and retrieval

1M context; up to 991K input, 983K with thinking [qwencloud-page-plus]. Fireworks serves it with a 262k-token window,
so a host can cap it below the maker's figure [fireworks-37plus]. The price shown is for inputs up to 256K tokens; a
rate for longer inputs was not on the page read. Implicit cache hits cost US$0.08 per million tokens
[qwencloud-page-plus]. No retrieval benchmark is published.

### Structured output

Plus is on QwenCloud's list for JSON Schema mode (strict) and for JSON Object mode without the non-thinking
restriction it puts on 3.6-Plus and older Plus models; a multimodal input falls back to JSON Object
[qwencloud-structured].

### Images, audio, other inputs

Text, image and video in, text out. Up to 2,048 images per request, videos up to 2 hours or 2 GB, up to 64 videos, per
Model Studio; QwenCloud's vision guide gives up to 256 images per request by URL [aliyun-vision] [qwencloud-vision].
No audio input.

### Sampling and API parameters

No sampling values are published for Plus; the API reference gives a default presence_penalty of 1.5 in non-thinking
mode for the Qwen3.7 models [qwencloud-api-chat]. Rate limits on the page: 5M tokens and 15K requests per minute
[qwencloud-page-plus].

### Migrating from the previous generation

Alibaba publishes no Plus-to-Plus comparison. The 3.6 generation added `preserve_thinking` as an opt-in setting, noted as
recommended for agent work; the 3.7 post kept that recommendation and the 3.8 models turned it on by default
[qwen-g8] [blog-qwen3-7] [qwen-f6]. A Fireworks write-up claims 3.55 times the throughput of Qwen3.6-Plus there
(class A) [fireworks-37plus].

## What the system card reports

Alibaba has published no system card or model card for Qwen3.7-Plus. The 3.7-Max post, which covers the other
3.7 model with a post, reports reward-hacking monitoring (1,618 cases over 80-plus hours of experiments, 13 new
heuristic rules); it does not cover Plus [blog-qwen3-7]. No refusal, sycophancy, deception, injection or cyber and
biology finding is published for Plus. QwenCloud moderates all requests and responses [qwencloud-security].

## Behaviour observed in practice

- **Index, verbosity and speed (M).** Artificial Analysis v4.3.2: 25, 130M output tokens against a median of 100M,
  55.9 output tokens per second (rank 113 of 176) and 2.21 s to first token, cost $0.22 per index task
  [aa-qwen3-7-plus].
- **Position (M).** Below Qwen3.8-27B (34 at `xhigh`) and the Flash-Next weights (40) on the same index
  [aa-qwen3-8-27b] [aa-qwen3-8-flash-next].
- **Terminal tasks (M).** Artificial Analysis's chart data gives 61.0% on Terminal-Bench 2.1 and 1.0% on the harder
  Terminal-Bench 4.0 [aa-qwen3-7-plus].

## Benchmarks

Independent: Artificial Analysis Intelligence Index v4.3.2, 25 [aa-qwen3-7-plus]; Terminal-Bench 4.0 1.0% and
Terminal-Bench 2.1 61.0% on Artificial Analysis's own harness, read from chart data [aa-qwen3-7-plus]. Scale SWE-Bench
Pro V2 and METR list no entry [scale-swe-pro-v2] [metr-horizons]. Maker-run comparison columns on
later cards are in the card; Alibaba has not published a Plus table of its own.
