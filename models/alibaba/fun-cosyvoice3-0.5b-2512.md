# Fun-CosyVoice3-0.5B-2512

Fun-CosyVoice3-0.5B-2512 is an open-weight speech synthesis model of Alibaba's FunAudioLLM team (Tongyi), class CosyVoice, generation 3. It clones a voice from a short clip and takes spoken-language instructions and inline tags for delivery. It is a voice actor model with a fixed instruction list and a fixed tag list. Alibaba released it in December 2025, with a base checkpoint and a reinforcement-learning checkpoint. It follows [CosyVoice 2](cosyvoice2-0.5b.md). Maker-wide facts are in the [Alibaba README](README.md).

## How to instruct it

### Setting up the prompt

- **Instruction prefix.** The instruct mode (`inference_instruct2`) takes the text, a reference clip and an instruction string. The string starts with the line You are a helpful assistant, then the instruction, then the end-of-prompt token `<|endofprompt|>` [cosy-example].
- **Supported instructions.** The code lists 26 strings. They cover 17 Chinese dialects, for example Cantonese, Sichuan, Shanghai, Dongbei and Minnan. They cover loud and very soft volume, slowest and fastest speed, and very happy, very sad and very angry. Two more ask for a role style: a cartoon character and a robot. The README says the instructions cover languages, dialects, emotions, speed and volume [cosy-common] [cosy-gh].
- **Instruction language.** The listed strings are Chinese, except the loud and soft ones, which are English [cosy-common].
- **Inline tags.** They go in the text. The tokenizer defines these: `[breath]`, `[quick_breath]`, `[laughter]`, `[cough]`, `[sigh]`, `[noise]`, `[vocalized-noise]`, `[lipsmack]`, `[hissing]`, `[clucking]`, `[accent]`, `[mn]`, `<strong>...</strong>` for stress and `<laughter>...</laughter>` for laughing while speaking. Pinyin and English CMU phoneme markers also exist as tokens [cosy-tokenizer].
- **Prompt text in other modes.** Zero-shot cloning also starts the prompt text with the same helper line and the end-of-prompt token. For tags in cross-lingual mode, put the helper line, then the token, then the text with tags [cosy-example].
- **Example in our words.** The maker's examples include a Cantonese instruction on a Cantonese line. Another example asks for very fast speech on a Chinese line about a birthday gift [cosy-example].

### Reasoning and effort

None.

### Output: format, length, tone

- **Tone.** Instructions and tags set tone, as above. The README adds that the model reads numbers and symbols without a separate text front end [cosy-gh].
- **Streaming.** Both text-in and audio-out streaming are supported, with latency as low as 150 ms [cosy-gh].
- **Japanese.** The example says Japanese text must be written in katakana [cosy-example].

### Coding

The repository gives Python examples, vLLM support (0.9.0 and 0.11 or later) and TensorRT-LLM, plus FastAPI and gRPC servers [cosy-gh].

### Long context and retrieval

Not applicable. The README gives no length limit. A caller should split long text into sentences, as the README's streaming example does with its own sentence splitting note [cosy-example].

### Structured output

Not applicable.

### Images, audio, other inputs

Text and a reference clip. The instruct and zero-shot modes both need the clip, so the instruction directs a cloned voice and is not a separate voice design [cosy-example].

### Voice: turn-taking, interruption and speech style

Turn-taking does not apply.

**How to direct delivery.** Delivery is directed by an instruct-mode call with one of the listed instruction strings, or by tags in the text. The set is closed in practice: the code shows 26 strings, and the maker's example script points to that list for the supported controls. The README names the kinds only: languages, dialects, emotions, speed and volume [cosy-common] [cosy-example] [cosy-gh].

**Strength.** Alibaba's README tables report content accuracy only, not instruction following. A competing maker's card reports that CosyVoice3-Base scores 40 percent on the neutral-emotion sets of its emotion control test. The card does not say which CosyVoice 3 checkpoint it ran [ming-note].

**What fails.** The README lists none. Japanese needs katakana input [cosy-example].

**Voice design and cloning.** The model clones from a reference clip. Alibaba Cloud's hosted voice design for CosyVoice uses a different model, FunAudioGen-VD, and is not in these weights [ali-doc-vd2].

**Multi-speaker dialogue.** Not documented.

**Long-form consistency.** Not documented.

**Pronunciation and normalisation.** Pinyin and English CMU phoneme markers can replace words. This controls pronunciation. A hotfix example in the code shows a pinyin mark inside Chinese text. The model also reads numbers and symbols without a separate text front end [cosy-gh] [cosy-example].

### Sampling and API parameters

Inference scripts expose a `stream` flag; the README names no other sampling settings for this model [cosy-example].

### Migrating from the previous generation

CosyVoice 2 used the same instruct call. Its instruction was a short phrase, such as a Sichuan dialect request. Version 3 adds the helper prefix line before every instruction and prompt text. Version 3 covers 9 languages and 18 or more Chinese dialects, adds a reinforcement-learning checkpoint, and states lower error rates than version 2 in Alibaba's table [cosy-example] [cosy-gh] [arxiv-cosy3].

## What the system card reports

Alibaba publishes a paper (arXiv 2505.17589) and a README. It publishes no system card with safety findings [arxiv-cosy3].

## Behaviour observed in practice

- **Emotion control (L, inside a competing maker's card).** The Ming-omni-tts card reports 40 percent for CosyVoice 3 base on its neutral-emotion test of emotion control. It reports 46.7 percent for Ming-omni-tts [ming-note].
- No practitioner report was read.

## Benchmarks

Maker (Alibaba): test-zh character error rate 1.21 (base) and 0.81 (RL); test-en word error rate 2.24 and 1.68; hard set 6.71 and 5.44. These measure content accuracy [cosy-gh]. No independent measurer lists this model.
