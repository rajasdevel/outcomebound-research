# Qwen-Audio-3.1-Realtime-Flash

Qwen-Audio-3.1-Realtime-Flash is the Flash tier of generation 3.1 of Alibaba's Qwen Audio realtime line. It takes streaming audio and text and gives back speech and text, and Alibaba calls it a full-duplex model. QwenCloud's changelog dates it 2026-10-27, five weeks after the 3.1 Plus tier. Alibaba's speech-to-speech table now names it the choice for cost-sensitive conversation, the role that [Qwen-Audio-3.0-Realtime-Flash](qwen-audio-3.0-realtime-flash.md) had. This file says what differs from [Qwen-Audio-3.1-Realtime-Plus](qwen-audio-3.1-realtime-plus.md), which holds the full guide. Family-wide rules are in the [Alibaba README](README.md) [qwencloud-changelog] [qwencloud-page-audio31flash] [qwencloud-s2s-models].

## How to instruct it

### Setting up the prompt

The guide for the Qwen-Audio realtime models applies, and the 3.1 Plus file gives it in full. The guide says to put the role, style and behaviour in `instructions`. It advises plain text with no emoji, special characters or Markdown unless the user asks, and one follow-up question at the end of a turn, after the answer [qwencloud-audio-guide].

### Reasoning and effort

No reasoning switch exists. Alibaba says the Qwen-Audio realtime models do not support thinking mode. The model page still lists thinking limits and a reasoning figure, which no guide explains [qwencloud-s2s-models] [qwencloud-page-audio31flash].

### Output: format, length, tone

`modalities` takes `["audio", "text"]` (default) or `["text"]`. `enable_speech_emotion` defaults to `true` and makes the voice vary its emotion more. `speech_rate` runs from 0.5 to 2.0 (default 1.0). `session.output_audio.language` sets the target language of the speech. The model tries to speak that language, without a guarantee, and the text language does not change [qwencloud-audio-events].

### Tools and agents

Function tools go in `session.tools`, and web search is `enable_search`. This is the one Qwen-Audio realtime model on which both can run together. On 3.1 Plus and on both 3.0 tiers they cannot [qwencloud-audio-events] [qwencloud-s2s-models]. No independent test of its tool use exists yet. On the 3.0 generation, Artificial Analysis found a large gap between the Flash and Plus tiers on multi-step tool tasks (see the 3.0 Flash file).

### Coding

Alibaba gives no coding guidance or score for this model.

### Long context and retrieval

The model page gives a 262K context, with up to 245K input and 16K output, four times the 65K context of 3.0 Flash. The session keeps at most 50 audio turns or 300 seconds of audio. `max_history_turns` runs from 1 to 50 and defaults to 20 [qwencloud-page-audio31flash] [qwencloud-audio-guide] [qwencloud-audio-events].

### Structured output

The model page lists structured outputs among its features. The realtime guide gives no rules for them [qwencloud-page-audio31flash].

### Images, audio, other inputs

Input is PCM, 16-bit, mono, 16 kHz. Output is PCM, 24 kHz. The model takes no image or video input. Conversation languages are the 14 of 3.1 Plus (3.0 had 11; 3.1 adds Thai, Vietnamese and Arabic), plus 21 Chinese varieties. The guide lists two regions for the model, Singapore and China North 2 (Beijing), each with an API key of that region [qwencloud-audio-guide].

### Voice: turn-taking, interruption and speech style

**Modes.** `server_vad`, `smart_turn`, `smart_turn_v2` and push-to-talk work as for 3.1 Plus. The guide now recommends `smart_turn_v2`, which builds on `smart_turn` and is better at ignoring bystanders and unrelated interjections. `threshold` (default 0.5) applies to all three detection modes. `silence_duration_ms` (200 to 6000, default 800, 400 to 800 advised) applies only to `server_vad`. The mode can change only before the first audio is sent [qwencloud-audio-events] [qwencloud-audio-ws] [qwencloud-audio-guide].

**Interruption.** In the detection modes, new user speech cancels the running response. The guide advises to clear the local playback buffer on `input_audio_buffer.speech_started`, and to start playback at the first audio delta. In the smart-turn modes, up to five reference recordings in `turn_detection.voiceprint_audio_urls` (first `session.update` only) let the model lock onto one speaker [qwencloud-audio-guide] [qwencloud-audio-events].

**Voice.** The default is `longanqian_v3.1`. The 3.1 realtime models take the union of the system voices of the 3.1 TTS Plus and 3.1 TTS Flash models, and cloned voices made with `target_model` set to this model. Voice cloning for the realtime models is offered only in China North 2 (Beijing). The voice can be set in the first `session.update` only [qwencloud-audio-guide] [qwencloud-audio-events] [qwencloud-voice-cloning].

### Sampling and API parameters

The rate limit is 100,000 tokens and 60 requests per minute [qwencloud-page-audio31flash]. Alibaba lists no temperature or top_p setting for the session.

### Migrating from the previous generation

The WebSocket event protocol is the same as for 3.0 Flash. Change the `model` value in the URL and pick a 3.1 voice; the 3.0 default `longanqian` becomes `longanqian_v3.1`. The price per token is the same as on the 3.0 Flash page. The context grows from 65K to 262K tokens, the output from 8K to 16K, and the conversation languages from 11 to 14. 3.1 adds the two language parameters and lets tools and web search run together [qwencloud-audio-guide] [qwencloud-page-audio31flash] [qwencloud-audio-events].

## What the system card reports

Alibaba has published no system card. The model page says this generation has stronger safeguards for refusing unsafe requests and keeping safety limits. It gives no test or number [qwencloud-page-audio31flash].
