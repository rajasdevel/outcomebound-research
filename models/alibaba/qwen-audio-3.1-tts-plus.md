# Qwen-Audio-3.1-TTS-Plus

Qwen-Audio-3.1-TTS-Plus is the Plus tier of generation 3.1 of Alibaba's hosted Qwen-Audio speech synthesis line. It takes the same free-text instruction and inline tags as the Flash tier, so it is a voice actor model. QwenCloud's changelog dates it 2026-10-21. Alibaba names it for audio quality: audiobooks, film and television dubbing, brand voices and character performance. Its speech synthesis overview makes it the default recommendation for built-in voices and for cloning. The generation before it, `qwen-audio-3.0-tts-plus`, is still sold and has no file. This file says what differs from [Qwen-Audio-3.1-TTS-Flash](qwen-audio-3.1-tts-flash.md), which holds the full guide. Family-wide rules are in the [Alibaba README](README.md) [qwencloud-changelog] [qwencloud-page-tts31plus] [qwencloud-tts-models].

## How to instruct it

### Setting up the prompt

As for the Flash tier: the text, one `instruction` for the whole task and a voice. Name the synthesis language and the effect in the instruction, in the language of the text [qwencloud-tts-guide].

### Reasoning and effort

None.

### Output: format, length, tone

The same output settings as the Flash tier: four formats, six sample rates, volume, rate, pitch, seed, word timestamps and the optional AIGC watermark [qwencloud-tts-events].

### Tools and agents

Not applicable.

### Coding

Alibaba gives no coding guidance for this model.

### Long context and retrieval

The same task limits as the Flash tier: 20,000 characters per message and 200,000 per task, with a 23-second limit between messages [qwencloud-tts-events].

### Structured output

Not applicable.

### Images, audio, other inputs

Text only. The cloning rules are the same as for the Flash tier. The voice-cloning guide uses this model in its example [qwencloud-voice-cloning].

### Voice: turn-taking, interruption and speech style

Turn-taking and interruption do not apply: the model does not listen [qwencloud-tts-guide].

**Direction.** The `instruction` field and the two tag sets (23 control tags and 7 nonverbal tags) are the same as on the Flash tier and on the 3.0 models. The Flash file lists them [qwencloud-tts-guide]. The model page adds "synthesis style" to the attributes that the instruction and tags can set, and it stresses authentic dialect pronunciation. The pages give no separate syntax for either [qwencloud-page-tts31plus].

**Voices.** The voice list for this model has four flagship system voices: `longanlingxin_v3.1`, `xunanchuan_v3.1`, `longanhuan_v3.1` and `longanfengyue_v3.1`. Each one lists SSML, instruction control and timestamps as supported. Most voice choice therefore comes from cloning or voice design, which are both supported [qwencloud-tts-voices] [qwencloud-tts-models].

**Languages.** The overview's language list for the 3.1 and 3.0 models applies: Mandarin and English for system voices, and 16 languages plus 20 Chinese dialects for cloned voices. The longer list of extra languages is for the Flash tier only [qwencloud-tts-models].

### Sampling and API parameters

`seed` only. The model page gives a rate limit of 180 requests per minute [qwencloud-tts-events] [qwencloud-page-tts31plus].

### Migrating from the previous generation

From `qwen-audio-3.0-tts-plus`: change the model name, pick a 3.1 voice and make cloned voices again for the new target model. Tags and `instruction` do not change. 3.1 adds voice design and HTTP access. The price rises from US$0.20 to US$0.30 per 10,000 characters on the international price list [qwencloud-tts-models] [qwencloud-prices]. Alibaba's notes say 3.1 is more robust to noise and reverberation in a cloning clip, with better quality, clarity and resolution [qwencloud-changelog] [qwencloud-page-tts31plus].

## What the system card reports

Alibaba has published no system card or model card. See the Flash file for the watermark option and the cloning rules.

## Behaviour observed in practice

Artificial Analysis's Provider Voice Arena leaderboard (read 2026-10-31), with accent and category set to All, ranks this model third: Elo 1305 (95% interval 1290 to 1320) from 2,281 blind listener votes on 8 of its voices, after Eleven v4 Turbo (1336) and Eleven v4 (1334). Its per-accent and per-category boards give other values, and its data dates the model to September 2026, before the changelog date (M) [aa-tts-board]. No practitioner report was found.

## Benchmarks

Independent: Artificial Analysis Speech Arena Elo 1305 on the provider voice board, rank 3, as above [aa-tts-board]. Maker: none; Alibaba's pages give no scores.

## Open questions
