# Qwen3.7-Flash

Qwen3.7-Flash is Alibaba's closed, low-price hosted model of the Qwen Flash class, generation 3.7. QwenCloud's changelog
lists it on 2026-07-25 with a dated snapshot of 2026-07-15. It takes text, images and video, outputs text, and has a 1M-token
context. Alibaba describes it as a native vision-language model with upgrades over 3.6-Flash in multimodal understanding,
search-agent and CI-agent work, and multimodal coding [qwencloud-page-37flash] [qwencloud-changelog]. It replaced
Qwen3.6-Flash, and Qwen3.8-Flash (2026-08-26) followed it. Alibaba published no launch post, model card or benchmark table
for it. Family-wide rules are in the [Alibaba README](README.md).

## How to instruct it

### Setting up the prompt

Alibaba gives no model-specific guidance on system prompts, roles, structure, examples or placement of long documents. The
README summarises QwenCloud's general prompt-design page [qwencloud-prompting]. QwenCloud's model-selection page does not
list the model among its recommended models. It appears in the full table and in the list of models with built-in tools
[qwencloud-models]. OpenRouter describes the model as a vision-language reasoning model for multimodal agents, visual
coding, search and computer interaction (class A) [openrouter-models].

### Reasoning and effort

- **Control.** The API reference lists Qwen3.7 among the hybrid models that take `enable_thinking`, and
  `thinking_budget` applies to the Qwen3.7 series. QwenCloud's model table gives a thinking budget of 256k
  [qwencloud-api-chat] [qwencloud-thinking] [qwencloud-models]. QwenCloud's pages do not state the default. Alibaba Cloud
  Model Studio's thinking guide lists the Qwen3.7 Flash series as hybrid with thinking on by default [aliyun-thinking].
- **Preserved thinking.** The thinking guide and the API reference list `qwen3.7-flash` and its 2026-07-15 snapshot as
  supporting `preserve_thinking`, which is off unless set. QwenCloud says to send the earlier `reasoning_content` back in
  tool loops and says that leaving it out lowers accuracy [qwencloud-thinking] [qwencloud-api-chat].
- **No effort levels.** `reasoning_effort` is documented for the Qwen3.8 models only [qwencloud-api-chat].
- **Calls.** The thinking guide's list of models that accept non-streaming calls names Qwen3.7 Max and Plus and does not
  name Qwen3.7 Flash. Streaming is advised for every model. Thinking tokens are billed as output
  [qwencloud-thinking].

### Output: format, length, tone

No formatting, length or tone guidance exists for this model. The output limit is 131K on the model page (also with
thinking), 64k in QwenCloud's model table and 65,536 on OpenRouter, so sources disagree [qwencloud-page-37flash]
[qwencloud-models] [openrouter-models]. Prefix completion is listed as a feature [qwencloud-page-37flash].

### Tools and agents

Function calling is supported. In thinking mode `tool_choice` accepts `auto` or `none` only [qwencloud-fn-calling]. The model
page lists the code interpreter, web extractor, web search, text-to-image search and image-to-image search, all through the
Responses API, and QwenCloud's model table marks built-in tools as supported [qwencloud-page-37flash] [qwencloud-models].
The API reference's list of models for the `agent` search strategy does not name this model [qwencloud-api-chat]. The page
describes strengths in search-agent and CI-agent tasks and "more stable end-to-end task execution", with no number to
support it. No guidance on subagents, context management or computer use is published [qwencloud-page-37flash].

### Coding

Alibaba published no coding numbers for this model. The page says only that multimodal coding was optimised for a smoother
"vibe coding" experience. No independent run exists on Scale's SWE-Bench Pro V2, on Artificial Analysis's coding-agent
board or on Terminal-Bench 4.0 [qwencloud-page-37flash] [scale-swe-pro-v2] [aa-coding-agents].

### Long context and retrieval

The context window is 1M tokens, with up to 991K input, or 983K with thinking. Rate limits on the page are 5M tokens and
15K requests per minute. The price shown is for inputs up to 32K tokens: implicit cache hits cost US$0.006 per million
tokens, explicit cache creation US$0.038 and an explicit hit US$0.003. The page shows no tier for longer inputs
[qwencloud-page-37flash]. The README describes the cache rules [qwencloud-cache]. No retrieval benchmark is published.

### Structured output

The structured-output guide lists the Qwen3.7-Flash series for JSON Object mode without the thinking-mode restriction that
it puts on older Flash models, and for JSON Schema mode (strict). A multimodal input falls back to JSON Object mode
[qwencloud-structured].

### Images, audio, other inputs

Text, image and video in; text out. The vision guide gives up to 256 images per request for the Qwen3.7-Flash model
(it gives 2,048 for the Qwen3.7-Plus series), 32 by 32 pixels per image token, and the pixel and frame-rate settings
that the README describes. No audio input is listed [qwencloud-vision] [qwencloud-page-37flash].

### Sampling and API parameters

Alibaba gives no sampling values for this model. The API reference gives a default `presence_penalty` of 1.5 for Qwen3.7 in
non-thinking mode and a default `top_k` of 20 for models it does not list. The temperature range runs from 0 up to but not
including 2. The reference says to set one of `temperature` and `top_p`, not both [qwencloud-api-chat].

### Migrating from the previous generation

The previous Flash model is Qwen3.6-Flash (2026-04-16). QwenCloud's table gives both models a 1M context and a 64k output
limit, and a thinking budget of 80k for 3.6-Flash against 256k for 3.7-Flash. Built-in tools are supported by both. QwenCloud
lists 3.6-Flash for JSON Object mode in non-thinking mode only and 3.7-Flash for JSON Object and JSON Schema without that limit
[qwencloud-models] [qwencloud-structured]. Prices fell: a QwenCloud retirement notice quotes US$0.25 input and US$1.50
output per million tokens for 3.6-Flash up to 256K input, against US$0.03 and US$0.13 for 3.7-Flash up to 32K input
[qwencloud-snapshot-notice] [qwencloud-page-37flash]. The page names the gains as better object recognition and spatial
perception, better search-agent and CI-agent tasks, and better multimodal coding, with no measured comparison
[qwencloud-page-37flash]. `preserve_thinking` was added as an opt-in in the 3.6 generation and is supported here.

## What the system card reports

Alibaba has published no system card, model card or launch post for Qwen3.7-Flash, so no safety or alignment finding is
available. QwenCloud moderates requests and responses, as the README says.

## Behaviour observed in practice

- **Capability index (M).** Epoch AI gives an Epoch Capabilities Index of 145, rank 84 of 253 tracked models on
  2026-10-03 and rank 67 of 236 at release. It places the model close to Qwen3.5 Flash (144) and Qwen3.6-27B (146)
  [epoch-qwen3-7-flash].
- **Individual tests (M).** Epoch AI measured GPQA Diamond 82%, OTIS Mock AIME 87%, FrontierMath Tiers 1-3 19%, chess puzzles
  23% and mystery-game puzzles 15%, all rounded to whole percent [epoch-qwen3-7-flash].
- No practitioner report was found.

## Benchmarks

Independent: Epoch AI's capability index 145 and the five tests above [epoch-qwen3-7-flash]. Artificial Analysis has no page
for this model, and Scale's SWE-Bench Pro V2 page, METR and Artificial Analysis's coding-agent board hold no entry that
this file could find [scale-swe-pro-v2] [metr-horizons] [aa-coding-agents]. Alibaba published no table for it.
