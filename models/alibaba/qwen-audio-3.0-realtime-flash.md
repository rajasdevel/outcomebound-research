# Qwen-Audio-3.0-Realtime-Flash

Qwen-Audio-3.0-Realtime-Flash is the Flash tier of generation 3.0 of Alibaba's Qwen Audio realtime line. It takes streaming audio and text and gives back speech and text. Alibaba calls it a full-duplex model that favours speed. QwenCloud's changelog dates it 2026-08-10, with the Plus tier. Alibaba's table names it the choice for cost-sensitive conversation. This file says what differs from [Qwen-Audio-3.1-Realtime-Plus](qwen-audio-3.1-realtime-plus.md), which holds the full guide. Family-wide rules are in the [Alibaba README](README.md) [qwencloud-changelog] [qwencloud-page-audio30flash] [qwencloud-s2s-models].

## How to instruct it

### Setting up the prompt

The guide for the Qwen-Audio realtime models applies. The guide says to put the role, style and behaviour in `instructions`. It advises plain text with no emoji and no Markdown. It advises one follow-up question per turn [qwencloud-audio-guide]. See the 3.1 file for the full list of rules.

### Reasoning and effort

No reasoning switch exists. Alibaba's table shows no thinking support for the Qwen-Audio realtime models [qwencloud-s2s-models].

### Output: format, length, tone

`modalities` takes `["audio", "text"]` (default) or `["text"]`. `enable_speech_emotion` defaults to `true` [qwencloud-audio-guide] [qwencloud-audio-events].

### Tools and agents

Function calling and web search (`enable_search`) are available. They cannot run together [qwencloud-audio-guide] [qwencloud-audio-events] [qwencloud-s2s-models]. Independent tests show a large gap to the Plus tier on multi-step tool tasks. See below.

### Coding

Alibaba gives no coding guidance or score for this model.

### Long context and retrieval

The context is 65K tokens, with 57K input and 8K output. The model keeps at most 50 audio turns or 300 seconds of audio. `max_history_turns` runs from 1 to 50 and defaults to 20 [qwencloud-page-audio30flash] [qwencloud-audio-guide].

### Structured output

The model page lists structured outputs as a feature. The guide gives no rules for them [qwencloud-page-audio30flash].

### Images, audio, other inputs

Input is PCM, 16-bit, mono, 16 kHz. Output is PCM, 24 kHz. The model takes no image or video input. The conversation languages are the same as for the Plus tier. The guide says these models need a Singapore-region API key [qwencloud-audio-guide].

### Voice: turn-taking, interruption and speech style

The three modes, `server_vad`, `smart_turn` and push-to-talk, work as in 3.1. `server_vad` has `threshold` (default 0.5) and `silence_duration_ms` (200 to 6000, default 800, 400 to 800 advised). The mode can change only before the first audio is sent [qwencloud-audio-ws] [qwencloud-audio-guide]. The model page says this tier "places greater emphasis on ultra-fast responsiveness" [qwencloud-page-audio30flash]. On the Artificial Analysis test the two tiers took about the same average time to first audio: 1.54 seconds for Plus and 1.55 seconds for Flash [aa-s2s].

In VAD modes, new user speech cancels the running response. The guide advises to clear the local playback buffer on `input_audio_buffer.speech_started`. It advises about 100 ms of audio per chunk and playback from the first audio delta [qwencloud-audio-guide]. The model has five system voices. The default is `longanqian`. Cloned voices are available. The voice can be set in the first `session.update` only [qwencloud-audio-guide].

### Sampling and API parameters

The rate limit is 100K tokens and 60 requests per minute [qwencloud-page-audio30flash].

### Migrating from the previous generation

This is the first generation of the Qwen Audio realtime line in this library. Alibaba's table points cost-sensitive users of closed-source realtime models to this tier [qwencloud-s2s-models].

## Behaviour observed in practice

Artificial Analysis measured the model on its Speech to Speech page (read 2026-10-03) [aa-s2s]:

- Speech reasoning (Big Bench Audio): 96.1%.
- Conversational dynamics: 96.9%. The parts are pause handling 92.0, turn-taking 98.3, interruption handling 97.5 and backchannel handling 100.
- Agentic performance (tau-Voice): 35.9%. The parts are airline 54.0, retail 29.2 and telecom 24.6.
- Time to first audio: 1.55 seconds on average.
- Arena preference Elo: 850. Task success rate: 81.7%, as the page labels it.

The Plus tier scored 54.6% on tau-Voice, so the Flash tier resolved fewer customer-service scenarios. The Flash tier has the higher task success rate and Elo in the page's arena columns [aa-s2s]. The page does not explain the difference between those measures.
