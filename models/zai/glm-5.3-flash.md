# GLM-5.3-Flash

GLM-5.3-Flash is a low-cost, natively multimodal model in Z.ai's GLM Flash class (generation 5.3), released on
2026-08-26 under the MIT licence. Unlike GLM-5.3 it is a newly trained base model, with 320B parameters (18B active)
and a hybrid of sparse and linear attention, and it takes image, video and file input. It is aimed at coding,
visual work such as interface and document building, and office and research tasks, at about a tenth of GLM-5.3's
price. The previous Flash-class generation is GLM-4.7-Flash, a free text-only model with 200K context. Family-wide
rules are in the [Z.ai README](README.md); this file says what is specific to Flash.

## How to instruct it

Z.ai publishes no prompting guide written for Flash. Its docs page lists recommended settings and eight worked
use cases; the general guides are in the [README](README.md#prompting-guides). Flash shares GLM-5.3's text
parameter set, so everything in the [GLM-5.3 file](glm-5.3.md) about thinking, tools and sampling applies unless
stated below.

### Setting up the prompt

- **Z.ai's recommended settings.** `temperature: 1`, `top_p: 0.95`, `reasoning_effort: max`, `thinking.type: enabled`
  (the only accepted value), `thinking.clear_thinking: false`, and for streamed requests both `stream: true` and
  `tool_stream: true` (L). [zai-flash-docs]
- **Task shape from the use cases.** Each example prompt on the page states the deliverable, the audience and format
  (page count, style, framework), the inputs available in the working directory, a rule not to invent data ("do not
  fabricate any business data; cite the source"), a build-then-inspect loop, and a final report of what was verified
  and what risks remain. Interface work: give screenshots, ask for analysis of the design system and interaction
  states first, build, then launch and compare screenshots page by page. Documents and slides: render and inspect each
  page for overflow, overlap and misalignment. Finance: separate disclosed facts, assumptions and the model's own
  conclusions, keep the evidence for each conclusion, and check that the three statements reconcile. 3D and CAD:
  render from fixed cameras, compare with references over several rounds. Computer use: use the goal mode and compare
  the original application with the rebuilt one (L). [zai-flash-docs]
- **Instruction files, structure, examples.** As for GLM-5.3; Z.ai gives nothing specific to Flash.

### Reasoning and effort

`reasoning_effort` takes `low`, `high` or `max`; the default is `max`, and thinking cannot be disabled (the Z.ai API
returns an error; the Coding Plan maps a disable request to low) (L). [zai-deep-thinking, zai-switch-models] Z.ai's
agent guide gives per-level advice for GLM-5.3 only (see that file). [zcode-agents] On Z.ai's private Code Bench (Claude Code
2.1.207), Flash scored about 21.5% at low, about 28% at high and 29.0% at max (the first two read from Z.ai's chart),
and the chart puts the max run at roughly 139K output tokens a task, against about 75K for GLM-5.3 at 34.5% (L).
So at max Flash spends about twice GLM-5.3's tokens for a lower score. [zai-flash-docs, zai-flash-blog] Artificial
Analysis measured max only: 69k output tokens a task, 1,014 seconds a task, about 51 output tokens a second, 3.3
seconds to the first token (M). [aa-flash-vs-53] Preserved thinking (`clear_thinking: false`) is recommended; the Hugging Face
template defaults to false and asks chat users to pass true. [hf-glm53-flash]

### Output: format, length, tone

As for GLM-5.3: no documented verbosity, formatting, tone or prefill controls; 131072 tokens maximum output. For file
deliverables Z.ai's examples name PPTX, PDF, DOCX and XLSX outputs produced through tools, with a render-and-inspect
step. [zai-flash-docs]

### Tools and agents

Function tools are supported (up to 128); `tool_choice` accepts only `auto` (L). [zai-chat-api] Z.ai trained the model
on a loop in which it renders its own output, inspects it and revises, and ships it in ZCode with browser use and
computer use that click through pages and operate desktop applications (L). [zai-flash-blog] Z.ai says it tested
Flash before release under the name ox-alpha on OpenCode and OpenRouter. Independent agent data: Flash has no row on
Artificial Analysis's Coding Agent Index or on the tbench.ai Terminal-Bench 4.0 board; Artificial Analysis's own
Terminal-Bench 4.0 run scored 32.8, against 41.9 for GLM-5.3 (M). [aa-coding-agent, aa-flash-vs-53]

### Coding

Z.ai reports Terminal-Bench 2.1 84.3 (Claude Code 2.1.207) and DeepSWE v1.1 63.4 (mini-swe-agent) against 81.0 and 46.2
for GLM-5.2, and says Flash approaches Claude Opus 4.8 overall (L). On Terminal-Bench 2.1, Artificial Analysis's own run
agrees (84.3 for Flash, 83.9 for GLM-5.3), but on the newer Terminal-Bench 4.0 Flash trails GLM-5.3 by about nine points
(32.8 against 41.9) (M); the two benchmark versions give different pictures, so the version belongs with every figure.
Scale lists no Flash row. [hf-glm53-flash, aa-flash-vs-53, scale-swe-pro-v2]

### Long context and retrieval

1M tokens of context and 131072 of output. The hybrid attention cuts attention compute by about 3.0 times and
key-value cache by about 4.4 times against GLM-5.3 (L); Z.ai notes its cache is still slightly larger than two named
open models. Artificial Analysis's AA-LCR is 80.0% against 79.7% for GLM-5.3 (M). Fireworks lists a 1,040K-token context.
Placement advice is not published. Cached input costs US$0.03 per million tokens. [zai-flash-docs, aa-flash-vs-53,
fireworks-flash]

### Structured output

Z.ai's capability list says structured output is supported, but the chat-completion reference lists `response_format`
only for text models and omits it from the request type that carries Flash. OpenRouter lists `response_format` and
structured outputs for the model (A). JSON mode is therefore documented for GLM-5.3 but not confirmed for Flash on
Z.ai's own API. [zai-flash-docs, zai-chat-api, openrouter-models]

### Images, audio, other inputs

Z.ai's page lists image, video, text and file input and text output. Images go in `image_url` content blocks (a URL is
recommended; a Base64 data URL also works), several per message; the reference's examples also show `video_url` and
`file` blocks. The reference's limits: an image under 5 MB and at most 6000 by 6000 pixels, in JPG or PNG; a video
under 200 MB, in MP4, MKV or MOV; a file up to 50 MB, by `file_id` (an upload, Flash only), `file_url` (PDF, TXT,
Word, JSONL, XLSX, PPTX) or Base64 `file_data`, and a `file` block cannot be combined with image or video blocks in
the same request. The per-request counts of images and videos are stated for other Z.ai vision models but not for
Flash, and no video length limit is given. Artificial Analysis lists image input only, OpenRouter image and video,
Fireworks image. Z.ai positions it for screenshots,
page images, screen recordings, charts, documents and video understanding (L). Audio input is not offered. [zai-flash-docs,
zai-chat-api, openrouter-models, fireworks-flash]

### Sampling and API parameters

Defaults temperature 1.0 (range 0 to 1) and top_p 0.95; the same recommended settings as above. The Hugging Face note says
`reasoning_effort` falls back to max for any other value, while the Z.ai API returns an error. [zai-chat-api, hf-glm53-flash]

### Migrating from the previous generation

From GLM-4.7-Flash (free tier, 200K context, text only): context rises to 1M; image, video and file input arrive;
thinking is forced on and effort is a field; the price moves from free to US$0.15 in and US$0.50 out per million tokens.
On the Coding Plan, GLM-4.7 requests are routed to GLM-5.3-Flash. Against GLM-5.2, Z.ai's table has Flash ahead on its six
benchmarks at about a tenth of the list price, with the caveats above on token use. [zai-pricing, zai-coding-plan,
zai-flash-docs]

## What the system card reports

Z.ai publishes no system card or safety report for Flash. The release post and docs page report capabilities (see
Benchmarks) and an engineering account of the model and its serving on Chinese AI chips; they report no refusal,
over-refusal, sycophancy, prompt-injection or classifier results, and no cyber evaluation (GLM-5.3's cyber numbers
are not given for Flash). The MIT licence has no use restrictions. The API's generic `sensitive` finish reason and
error 1301 apply. [zai-flash-blog, zai-errors]

## Behaviour observed in practice

- **Speed and cost (M, Artificial Analysis).** About 51 tokens a second against about 71 for GLM-5.3; US$0.25 a task
  against US$2.01; 1,014 seconds a task against about 769; the index's blended price per million tokens US$0.098 against US$0.902.
  [aa-flash-vs-53]
- **Gap to GLM-5.3 by evaluation (M).** Intelligence Index 41.8 against 44.8; SciCode 51.6 against 59.0; Humanity's Last
  Exam 39.9 against 42.3; CritPt 15.4 against 19.1; AA-Omniscience 7.5 against 14.3 (hallucination rate 27.6% against
  29.6%); GDPval-AA 1647 against 1653; Terminal-Bench 2.1 84.3 against 83.9. [aa-flash-vs-53, aa-glm-5-3]
- **Index version (L).** Z.ai quotes an Artificial Analysis score of 57 on index v4.1.1 at about US$0.045 a task
  (discounted); Artificial Analysis's current pages use v4.3.2, where the score is 41.8. Versions are not comparable.
  [zai-flash-blog]
- **Usage campaign.** Z.ai ran a time-limited Coding Plan promotion for Flash from 2026-09-03 to 2026-10-07.
  [zai-coding-plan]
