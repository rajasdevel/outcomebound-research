# GLM-4.7-Flash

GLM-4.7-Flash is the small model of Z.ai's GLM-4.7 line: a 30B-A3B mixture-of-experts model (31.2B parameters in total, about 3B active per token), text only, with a 200K-token window and open weights under the MIT licence. It belongs to the class GLM Flash, generation 4.7, the generation before [GLM-5.3-Flash](glm-5.3-flash.md). Z.ai launched it on 2026-01-19 as the free-tier version of GLM-4.7, for coding, reasoning and general generation with low latency. What Z.ai's models share (endpoints, parameters, thinking rules, guides) is on the [Z.ai page](README.md); this file says what is specific to GLM-4.7-Flash.

## How to instruct it

Z.ai publishes no prompt-writing guide for GLM-4.7-Flash. It publishes a GLM-4.7 series overview that covers the Flash and FlashX models, a thinking-mode guide and a model card. The [prompting-guides section of the maker page](README.md#prompting-guides) lists the general guides (coding-agent practice, memory files, function calling), which are advice for any model [zai-glm47-docs] [zai-thinking-mode] [hf-glm47-flash].

### Setting up the prompt

- **System prompt, roles, structure.** The card's examples use a single user message. Z.ai gives no GLM-4.7-Flash advice on roles, tags, examples or document placement. Its general coding-agent guidance frames a task as goal, context, constraints and a "done when" condition [zai-glm47-docs].
- **Instruction following.** No instruction-following score is published for this model. The overview says GLM-4.7 keeps context and constraints better across turns than earlier GLM models and answers simple queries more directly; it makes the claim for the series, with no figure [zai-glm47-docs] (class L).
- **Document placement.** No guidance.

### Reasoning and effort

- **The control.** `thinking.type` is `enabled` or `disabled`; there is no effort field (effort starts with GLM-5.2). The reference says GLM-4.7 models think compulsorily when thinking is enabled, where several earlier GLM models decide for themselves whether to think; the default is enabled [zai-chat-api] [zai-thinking-mode].
- **Turn-level switch.** Each request in one session can switch thinking on or off, a capability Z.ai introduced with GLM-4.7. Z.ai suggests turning it off for light turns such as a fact lookup or a wording tweak and on for planning, multi-constraint reasoning and debugging [zai-thinking-mode].
- **Interleaved thinking.** On by default: the model thinks between tool calls and after tool results, and the thinking blocks should be returned with the tool results [zai-thinking-mode].
- **Preserved thinking.** Off by default on the standard API (`thinking.clear_thinking` true, which removes earlier-turn reasoning) and on by default on Z.ai's Coding Plan endpoint. Setting `clear_thinking: false` keeps it, and the complete, unedited, correctly ordered earlier `reasoning_content` must come back, or performance and cache hits may suffer. The model card says to turn preserved thinking on for multi-turn agentic tasks (tau2-Bench and Terminal Bench) [zai-thinking-mode] [zai-chat-api] [hf-glm47-flash].
- **Output budget.** `max_tokens` up to 128K for the GLM-4.7 series; reasoning counts toward it. The card's default evaluation setting used 131,072 new tokens [zai-chat-api] [hf-glm47-flash].
- **Step-by-step prompting.** No advice.

### Output: format, length, tone

- **Length.** No verbosity control. Output is bounded by `max_tokens` and by one stop word at most [zai-chat-api].
- **Style.** Z.ai's overview says GLM-4.7 produces more natural conversation and better front-end styling than earlier models; it publishes no tone or formatting defaults for the Flash model [zai-glm47-docs].
- **Prefill.** Not documented.

### Tools and agents

- **Function calling.** Supported; the reference lists functions as the only tool type and allows up to 128 [zai-chat-api] [zai-glm47-docs]. `tool_choice` takes `auto` only. Streaming of tool-call arguments (`tool_stream`) is supported by the GLM-4.7 series [zai-chat-api].
- **Self-hosting.** The card starts vLLM with `--tool-call-parser glm47` and `--reasoning-parser glm45`, and SGLang with the same pair, both with multi-token-prediction or EAGLE speculative decoding [hf-glm47-flash].
- **Agent results.** Maker-reported tau2-Bench 79.5 and BrowseComp 42.8, with SWE-bench Verified 59.2 (Benchmarks). Z.ai's GLM-4.7 page says the series works with a think-before-acting mechanism inside Claude Code, Kilo Code, TRAE, Cline and Roo Code (a series claim, not a Flash measurement) [hf-glm47-flash] [zai-glm47-docs].
- **Computer use.** Not offered: text only.

### Coding

- **Maker table.** SWE-bench Verified 59.2 (Qwen3-30B-A3B-Thinking-2507 22.0, GPT-OSS-20B 34.0), LiveCodeBench v6 64.0 (66.0; 61.0). The SWE-bench and Terminal Bench runs used temperature 0.7, top-p 1.0 and 16,384 new tokens; the card does not name the scaffold [hf-glm47-flash] (class L).
- **Independent.** No independent agentic-coding result was found. Artificial Analysis's index (below) is the only outside number [aa-glm47-flash].
- **Harness notes.** On Z.ai's Coding Plan, requests for GLM-4.7 are routed to GLM-5.3-Flash (see the [Z.ai page](README.md)).

### Long context and retrieval

- **Limits.** 200K tokens of context and 128K of output [zai-glm47-docs].
- **Quality.** No long-context retrieval score is published for this model.
- **Caching.** Z.ai documents implicit context caching for the GLM-4.7 series; Flash shows cached input as free on the price list [zai-glm47-docs] [zai-pricing].

### Structured output

JSON mode through `response_format: {"type": "json_object"}`; the reference restricts the field to text models. No schema-constrained mode is documented [zai-chat-api] [zai-glm47-docs].

### Images, audio, other inputs

Text only [zai-glm47-docs]. Image, video and file input arrive with GLM-5.3-Flash.

### Sampling and API parameters

- API defaults for the GLM-4.7 series: `temperature` 1.0 (range 0.0 to 1.0) and `top_p` 0.95 (0.01 to 1.0) [zai-chat-api].
- The card's evaluation settings: temperature 1.0 and top-p 0.95 for most tasks; 0.7 and 1.0 for Terminal Bench and SWE-bench Verified; temperature 0 for tau2-Bench [hf-glm47-flash].

### Migrating from the previous generation

- **To GLM-5.3-Flash.** Z.ai's own pages (see the [GLM-5.3-Flash file](glm-5.3-flash.md#migrating-from-the-previous-generation)): context 1M against 200K, image, video and file input, thinking forced on with an effort field, and a price of $0.15 input and $0.50 output per million tokens against free here.
- **From GLM-4.6 (hybrid thinking).** GLM-4.7 made thinking the default and the model think compulsorily when enabled; preserved thinking and turn-level switching are new in the 4.7 series [zai-thinking-mode] [zai-chat-api].

## Behaviour observed in practice

- **Standing and speed (class M).** Artificial Analysis scores the reasoning variant 15 on its Intelligence Index v4.3.2 against a comparable-model median of 8, at about 67 output tokens a second (its average is 91), and marks the model deprecated for its own benchmarking [aa-glm47-flash].
- **Maker claim of size-class standing (class L).** Z.ai says the model achieves the best open-source scores among models of similar size on SWE-bench Verified and tau2-Bench; its card table compares it with two models only [zai-glm47-docs] [hf-glm47-flash].
- No practitioner review of this model was read.
