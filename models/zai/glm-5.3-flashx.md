# GLM-5.3-FlashX

GLM-5.3-FlashX is a faster serving tier of GLM-5.3-Flash, in the GLM FlashX class (generation 5.3), listed on
2026-09-18. Z.ai's page describes it only as inference at about 200 tokens a second, on the same docs page and with
the same parameters as Flash, at about 2.5 times Flash's price. Z.ai publishes no benchmark, weights or model page
of its own for it, so this file rests on the shared Flash page, the API reference and reseller listings. The
previous FlashX-class generation is GLM-4.7-FlashX. Read the [Flash file](glm-5.3-flash.md) for how to instruct the
model and the [Z.ai README](README.md) for family rules.

## How to instruct it

Z.ai states that FlashX uses the same text parameters as GLM-5.3 and the same recommended settings as Flash, and gives it
no advice of its own. Everything in the [Flash file](glm-5.3-flash.md#how-to-instruct-it) applies unless stated here.

### Setting up the prompt

As for Flash: the recommended settings are temperature 1, top_p 0.95, `reasoning_effort: max`, `thinking.type: enabled`
and `clear_thinking: false`, with `stream` and `tool_stream` both true when streaming (L). The use cases on the shared
page are written for Flash. [zai-flash-docs]

### Reasoning and effort

Thinking is forced on. Z.ai's Deep Thinking page names Flash, not FlashX, when it lists `low`, `high` and `max`; the shared
Flash/FlashX page says the text parameters are consistent with GLM-5.3, and OpenRouter lists `max`, `high` and `low` for
FlashX (A). No measurement of FlashX at any effort exists. [zai-deep-thinking, zai-flash-docs, openrouter-models]

### Output: format, length, tone

As for Flash. Z.ai's pitch for FlashX is speed, about 200 tokens a second (L, a vendor figure); the only speed measurement
found for the Flash line is Artificial Analysis's figure for Flash at max, about 51 tokens a second when read (M). A
reseller blog attributes 98 tokens a second for Flash to Artificial Analysis, a figure the page did not show on the
read date, and suggests measuring one's own workload before paying more (A). [zai-flash-docs, aa-glm-5-3-flash,
orcarouter-flashx]

### Tools and agents

As for Flash: function tools, `tool_choice` only `auto`, streamed tool arguments with `tool_stream`. On the read date
FlashX was not on the GLM Coding Plan, while Flash was (L). [zai-chat-api, zai-flash-docs]

### Coding

No coding result exists for FlashX from Z.ai, Scale, tbench.ai, Artificial Analysis or METR. Z.ai's Flash numbers belong to
Flash; a reseller blog says FlashX has the same weights and so inherits them, a reading Z.ai's page does not state (A).
[orcarouter-flashx, scale-swe-pro-v2, tbench-4, aa-coding-agent]

### Long context and retrieval

1M tokens of context (L) and 131072 of output; OpenRouter lists 1,048,576. Cached input is US$0.075 per million tokens
(OpenRouter lists 0.09). No long-context measurement exists. [zai-flash-docs, zai-pricing, openrouter-models]

### Structured output

Same uncertainty as Flash: the capability list says structured output is supported, the API reference omits JSON mode from
the request type that carries the Flash models, and OpenRouter lists `response_format` for FlashX. [zai-chat-api,
openrouter-models]

### Images, audio, other inputs

Z.ai's shared page lists image, video, text and file input. The API reference's image and video examples use
`glm-5.3-flashx` as the model id. OpenRouter lists image and video, not file. [zai-flash-docs, zai-chat-api, openrouter-models]

### Sampling and API parameters

As for Flash: temperature 1.0 and top_p 0.95 by default. [zai-chat-api]

### Migrating from the previous generation

From GLM-4.7-FlashX (text only, 200K context, US$0.07 in and US$0.40 out per million tokens): context rises to 1M, input
adds image, video and file, thinking becomes forced with an effort field, and the price rises to US$0.37 in and US$1.25 out.
From Flash: the id changes to `glm-5.3-flashx`, the price is about 2.5 times higher, and Z.ai promises speed, not extra
quality. [zai-pricing]

## What the system card reports

Z.ai publishes no system card, model card or safety report for FlashX, and no page of its own. Nothing is reported on
refusals, over-refusal, sycophancy, prompt injection or classifiers; the generic `sensitive` finish reason and error 1301
apply. [zai-flash-docs, zai-errors]

## Behaviour observed in practice

No independent or practitioner observation of FlashX was found beyond a reseller's launch blog. That blog says Z.ai
announced it on 2026-09-18 without benchmarks, as a hosted tier on the Flash backbone with no weights of its own; Z.ai's
own page says neither, so this is the reseller's reading. Artificial Analysis has no page for FlashX (404 on the read
date). [orcarouter-flashx, aa-glm-5-3-flash]

## Benchmarks

None for FlashX: not on Scale's SWE-Bench Pro V2 page, the tbench.ai Terminal-Bench 4.0 board, Artificial Analysis's
Intelligence Index or Coding Agent Index, or METR's page, and Z.ai publishes none. Flash's figures (Intelligence Index 41.8,
Terminal-Bench 4.0 32.8, both Artificial Analysis at max) are an assumption for FlashX, not a measurement. [scale-swe-pro-v2,
tbench-4, aa-coding-agent, metr-time-horizons]

## Open questions

- Whether FlashX is Flash's weights served faster or a different model.
- Its quality, token use and real speed.
- Whether it will reach the Coding Plan.
