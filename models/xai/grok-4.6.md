# Grok 4.6

Grok 4.6 (`grok-4.6`, released 2026-08-12) is the previous generation of SpaceXAI's Grok class, below Grok 4.7. It is a reasoning model with text and image input and text output, aimed by the maker at long-running agent work and at turning a broad idea into a working first version of an application or document. It replaced Grok 4.5 and added the `xhigh` effort level [xai-46-news] [xai-docs-46]. Grok 4.7 replaced it at the same price. Rules shared by all Grok models are in [the xAI README](README.md#family-wide-behaviour); the 4.7 file ([grok-4.7.md](grok-4.7.md)) holds the fullest description of the shared API behaviour. This file gives what is specific to 4.6.

## How to instruct it

xAI publishes no prompting guide for Grok 4.6 ([README](README.md#prompting-guides)). The sources below are the API docs, the model card and the release post.

### Setting up the prompt

- The system prompt goes in a `system` message or the Responses `instructions` field, which cannot be combined with `previous_response_id` [xai-docs-gen] [xai-docs-respref].
- Cursor's docs say 4.6 follows detailed instructions more reliably than Grok 4.5, works across code, documents, spreadsheets and PDFs, and handles long tasks that need tools, checking results and changing approach [cursor-grok-46]. No instruction-following score was found for 4.6.
- Length and structure advice is the same as for 4.7: only Grok Build's instruction-file page gives any (short and specific beat long), and the 2025 coding-model guide's advice (detailed system prompt, XML or Markdown sections) was written for another model [grok-f1] [grok-f15].
- The caching page says static material (system prompt, examples, reference documents) goes first [xai-docs-cache-best].

### Reasoning and effort

- Levels `low`, `medium`, `high` (default) and `xhigh`; reasoning cannot be disabled; `xhigh` arrived with this model (a request for it on Grok 4.5 is treated as `high`) [grok-f10].
- On Cursor's CursorBench 4.0 table (L, run by Cursor) Grok 4.6 scores 33.4% at low, 36.1% at medium, 40.4% at high and 41.4% at xhigh, at about $2.25, $3.48, $5.20 and $6.10 and 32, 40, 48 and 56 steps per task. The spread between levels is narrower than for Grok 4.7 (33.1 to 46.3) [cursor-bench-board] [cursor-grok-47].
- Artificial Analysis (M) used about 36k output tokens per index task at high and 38k at xhigh, and listed 44 on its Intelligence Index at both levels [aa-grok-47] [aa-grok-46-model] [aa-grok-46-high].
- The announcement describes more self-testing and verification on longer trajectories [xai-46-news]. The card reports one case: an earlier checkpoint told to speed up its own inference had to verify end-to-end gains before opening a pull request; in five hours it tried 297 candidate optimisations, discarded those without a measured gain (some had passed microbenchmarks) and opened seven pull requests, three of which serve production traffic for a combined 1.5% decode and 3.1% prefill throughput gain [xai-46-card].
- Errors: `presencePenalty`, `frequencyPenalty` and `stop` on reasoning models [grok-f10].
- Encrypted reasoning: the docs describe `include: ["reasoning.encrypted_content"]` as the way to request it from models that support it, and state "always returned" and summarised reasoning only for 4.7 [grok-f10].

### Output: format, length, tone

- No verbosity or length control is documented. `max_output_tokens` defaults to 128,000 visible tokens; `stop` is rejected [xai-docs-respref] [grok-f10].
- The xAI post reports stronger first passes on visual and interactive projects than it saw with Grok 4.5 [xai-46-news].

### Tools and agents

- Function calling, server-side tools, parallel calls, `tool_choice`, `max_turns`, compaction and the 350-tool limit work as for 4.7 (see [the 4.7 file](grok-4.7.md#tools-and-agents)) [xai-docs-46] [xai-docs-fc].
- The maker's pitch is long, multi-step work: researching, analysing, working across a codebase, building an application through several rounds of feedback [xai-46-news].
- The card's agentic rows use several harnesses: Grok Build for FrontierCode, SWE-Marathon, Terminal-Bench 3.0, the engineering, R&D, search and cyber tests; Cursor's agent harness for CursorBench 3.2; Terminus-2 for APEX-SWE; mini-swe-agent for DeepSWE; the Artificial Analysis, Mercor, Databricks and Vals AI harnesses for the knowledge-work rows [xai-46-card]. In Cursor it has all agent tools [cursor-grok-46].

### Coding

- Card results (maker-reported, L): CursorBench 3.2 at 69.9% (high) and 70.8% (xhigh) in the Cursor agent harness (this version is not comparable to CursorBench 4.0); APEX-SWE 56.4% (high, Terminus-2 harness, Mercor); FrontierCode v1.1 extended 61.3% (high, Grok Build, Cognition); DeepSWE v1.1 65.9% (high) and 67.0% (xhigh) with mini-swe-agent (Datacurve); SWE-Marathon v1.1 31.9% (high, Abundant AI); Terminal-Bench 3.0 26.0% (high, Grok Build, Harbor) [xai-46-card].
- On the later Terminal-Bench 4.0 the Grok 4.7 card lists Grok 4.6 at 20.3% (high) [xai-47-card].
- Artificial Analysis's Coding Agent Index with Grok Build at xhigh: 47 (DeepSWE v1.1 65, Terminal-Bench 4.0 18, SWE-Atlas-QnA 58) (M) [aa-grok-47].
- Cyber and security coding checks in the card: SecureCodeReview 58.7% (high; whether the agent fixes security issues without adding new ones) [xai-46-card].

### Long context and retrieval

- 500k tokens; the same 200k pricing step as 4.7 ($2 / $0.50 / $6 below, $4 / $1 / $12 at or above) [xai-docs-46].
- Artificial Analysis measured Grok 4.7 as 3.7 points lower on AA-LCR than Grok 4.6 (high), so 4.6 is the higher of the two on that one test (M) [aa-grok-47].
- Caching, compaction and prompt-cache keys work as for 4.7 [xai-docs-compaction] [xai-docs-cache-keys].

### Structured output

- Supported ("Structured outputs: Yes"); the schema rules are the same as for 4.7 (see [the 4.7 file](grok-4.7.md#structured-output)) [xai-docs-46] [xai-docs-so].

### Images, audio, other inputs

- Text and image in, text out; image limits as in [the README](README.md#family-wide-behaviour) [xai-docs-46] [xai-docs-img]. The card includes image-related VCT questions only as a biology knowledge probe; no general vision benchmark is reported [xai-46-card].

### Sampling and API parameters

- As for 4.7: `temperature` 0 to 2 and `top_p`; errors for penalties and `stop`; no `logprobs` [xai-docs-respref] [xai-docs-chatref].
- Rate limit at tier 0: 150 requests per second and 50M tokens per minute, the same as 4.7 [xai-docs-rates].

### Migrating from the previous generation

From Grok 4.5 to 4.6, per the sources read (Grok 4.5 has no file here, as it is two generations back):

- **New effort level** `xhigh`; on 4.5 it falls back to `high` [grok-f10].
- **Price:** cached input rose from $0.30 to $0.50 per Mtok; input $2 and output $6 are unchanged [xai-docs-pricing].
- **Behaviour:** more thinking and more self-checking. Artificial Analysis (M) reported about 14k output tokens per Intelligence Index task for 4.5 in July and about 36k for 4.6 (high) in September, and an AA-Omniscience hallucination rate of 54% for 4.5 and 34% for 4.6 (high); the index changed version between the two articles, so the pairs are indicative only. Cursor reports better instruction following [grok-f19] [aa-grok-47] [cursor-grok-46].
- **Training:** the 4.6 card says supplemental training ran longer than for 4.5, 4.5 models generated the SFT trajectories, and agentic reinforcement learning added kernel optimisation, web development and computer-aided design environments; pretraining cutoff January 2026, supplemental data to June 2026 [xai-46-card].
- **Benchmarks:** CursorBench 3.2 66.7% to 69.9% (high); DeepSWE v1.1 54% to 65.9%; SWE-Marathon 29.4% to 31.9%; Terminal-Bench 3.0 15.7% to 26.0% (all card figures, L) [xai-46-card].
- **Safety measures (card):** general-refusal compliance 1.10% to 0.93%; bio and chem refusal recall to 100%; standard jailbreak compliance 0.73% to 0.04%, though StrongREJECT rose from 1.5% to 3.9%; self-harm compliance 0.50% to 0.84%; MASK dishonesty 0.67% to 1.90% [xai-46-card].
- **Status:** Cursor recommends Grok 4.7 over 4.6, and Artificial Analysis lists 4.6 as deprecated; the xAI model page carries no retirement notice [cursor-grok-46] [aa-grok-46-model] [xai-docs-46].

## What the system card reports

The card (2026-08-12, revised 2026-08-17) describes a "1.5T-scale" model family developed with Cursor, with supplemental training on anonymised Cursor workflow data, text and image input and text output. Pretraining cutoff January 2026; supplemental data to June 2026 [xai-46-card].

**Capabilities (maker-reported; most were run by outside parties).** Coding as above. Knowledge work (all at high): GDPval-AA v2 1753 Elo (Artificial Analysis), AA-Briefcase 1577 Elo, APEX-Agents 57.5% (Mercor), OfficeQA Pro 63.2% (Databricks harness), Harvey Legal Agent Benchmark 15.8% (Vals AI). Engineering: EEBench 60.0% at xhigh and 53.0% at high, 3DCodeBench 54.0%, PartBench 58.5% at xhigh, CADGenBench 40.9%, CADBench 88.4% at xhigh and 87.8% at high. R&D: the maker's MTS eval 61.1% (high), InferenceEval 46.9%, KernelBenchInternal v1.1 37.2%. Search and factuality: the maker's single-response hallucination rate 1.7% (high; Grok 4.5 0.98%, GPT-5.5 1.1%, Opus 4.8 3.4%), DeepSearchQA 81.6% on an internal implementation [xai-46-card].

**Cyber.** Gains over 4.5, concentrated in defence and vulnerability mitigation rather than end-to-end attacks. Without safeguards: CyberGym 79.7% (high; GPT-5.6 Sol 83.6%, GPT-5.5 81.8%, Opus 4.8 78.1%); CVE-Bench 39.8% (4.5: 35.2%). With safeguards, HackerBench v0.2: 6.9% of dual-use requests complied with (4.5: 7.8%; GPT-5.5 25.0%; Opus 4.8 22.8%; GPT-5.6 Sol 35.7%) and a benign-task refusal rate of 0.0%. Outside evaluators received an unrestricted configuration and corroborated the maker's cyber results [xai-46-card].

**Biology and chemistry.** Below the framework's thresholds, with a small VCT uptick (67.4% against 65.5%); weapons-path refusals improved. BioUseBench severity-5 refusal 90.7% (83.3%); WMDP-Bio 90.0%, Chem 85.3%, Cyber 90.1%; LAB-Bench practical 80.7%; ProtocolQA open-ended 79.6% (87.0%); BixBench 93.8% [xai-46-card].

**Jailbreaks, refusals and behaviours.** Standard jailbreaks 0.04% compliance; StrongREJECT 3.9%; long-horizon jailbreaks 1.0%; general refusals 0.93%; child safety 0.00%; self-harm 0.84%; MASK-Rectified dishonesty 1.90%; sycophancy 0.04% [xai-46-card].

**Safeguards.** Layered: fine-tuning, system prompts that push toward honesty and away from over-refusal, and, on some surfaces, input and topical filters for CSAM, self-harm and biological or chemical weapons plus cyber safeguards. The card says the model is not meant for autonomous high-stakes decisions without human oversight. It reports no prompt-injection, reward-hacking or sandbagging results [xai-46-card].

## Behaviour observed in practice

- **Artificial Analysis (M).** Intelligence Index v4.3.2: 44 at both high and xhigh; output about 72 tokens per second at high and 67 at xhigh; cost per index task $1.86 (high) and $2.32 (xhigh); 94M and 97M output tokens for the whole index (somewhat verbose against a median of 81M). AA marks the model deprecated and benchmarks only its default workload now. AA-Omniscience hallucination 34% (high) [aa-grok-46-high] [aa-grok-46-model] [aa-grok-47].
- **Earlier Artificial Analysis score.** xAI's August post cites 61 for 4.6 on the index then in use, which it describes as a composite of nine benchmarks; AA's pages now list 44 on v4.3.2, which has ten. The two are not comparable, and neither source describes the change [xai-46-news] [aa-grok-46-model].
- **Cursor (L).** CursorBench 4.0 40.4% at high; Cursor says 4.7 is the better choice for self-verification and long work [cursor-bench-board] [cursor-grok-46].
- **Practitioner reports (A).** None with measurements found.

## Open questions

- Maximum output length is not published (docs: no text output limit; 128,000 default cap).
- Whether 4.6 returns summarised reasoning is not stated; the docs describe it for 4.7.
- How long xAI will keep serving 4.6: no notice, but two measurers and Cursor already steer users to 4.7.
- Why AA's page lists the same index value (44) at two effort levels is not explained.
