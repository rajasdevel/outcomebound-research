# Grok 4.7 Fast

Grok 4.7 Fast is the Grok 4.7 model served on faster infrastructure at twice the token price, offered only inside Cursor and Grok Build and not on the public xAI API. SpaceXAI states that it is the same model as Grok 4.7; the distinction is speed and billing [xai-docs-47-overview] [xai-release-notes]. The library keeps a separate file because the price, the places it is available and the billing rules differ from the standard model, and because the generation before it is also a Fast tier (Cursor lists a Grok 4.6 Fast). Everything about how to instruct the model is in [the Grok 4.7 file](grok-4.7.md); this file lists only what differs.

## How to instruct it

xAI publishes no prompting guide for Grok 4.7 or its Fast tier. The maker calls Fast the same model, so the instructions in [the Grok 4.7 file](grok-4.7.md#how-to-instruct-it) apply [xai-docs-47-overview]. No source compares the two tiers' answers; no independent measurer lists a Fast entry.

### Setting up the prompt

- Same as Grok 4.7. Because Fast runs only in Cursor and Grok Build, the system prompt is the harness's own prompt, and user instructions arrive as project rules or instruction files: `.cursor/rules` (`.mdc` files; a plain `.md` file in that folder is ignored) and `AGENTS.md` in Cursor, and `AGENTS.md`, `CLAUDE.md` and `.grok/rules/` (with `.claude/rules/` and `.cursor/rules/` read for compatibility) in Grok Build [cursor-harness-doc] [grok-f1].
- Cursor's rules guidance: keep rules under 500 lines, split large ones, point to files instead of pasting them, avoid copying whole style guides or listing commands the agent already knows, and add a rule when the same mistake repeats. Rules affect the agent, not Cursor Tab, and user rules do not apply to inline edit [cursor-harness-doc].

### Reasoning and effort

- Cursor's Grok 4.7 page lists four levels (low, medium, high as default, xhigh), treats Fast as a separate speed choice, and describes a wider gap between levels than on Grok 4.6 [cursor-grok-47].
- Speed and effort are separate choices in the Cursor picker. Fast is the default speed tier on Pro and higher plans; on the India-only Start plan, Grok models run at standard speed with effort fixed at medium and cannot be changed [cursor-grok-47] [cursor-pricing].
- The xAI sources state no per-level behaviour for Fast. For levels see the Grok 4.7 file [xai-docs-47-overview].

### Output: format, length, tone

- No Fast-specific output control is documented. xAI says Fast has twice the output speed of standard [xai-47-news].

### Tools and agents

- Fast has the same tools as Grok 4.7 in each harness: all Cursor agent tools in Cursor; Grok Build's plan mode, permissions and subagents in Grok Build [cursor-grok-47] [xai-build-plan] [xai-build-subagents].
- Fast is billed through the plan in Cursor or Grok Build, not by the token on an xAI key. It is excluded from Grok Build's free tier [xai-docs-47-overview] [xai-docs-pricing].

### Coding

- No coding result exists for Fast alone. The Grok 4.7 results (card, Artificial Analysis, Cursor) were measured on the standard tier or do not say which tier ran; Cursor's CursorBench 4.0 table lists Grok 4.7 by effort level only [xai-47-card] [aa-grok-47] [cursor-bench-board].

### Long context and retrieval

- xAI gives 500k tokens for Grok 4.7. Cursor shows a 256k standard window with a 500k long-context tier, billed at 2x the standard rates for standard speed and 3x the standard rates for Fast above 256k input tokens; billing uses input length only [cursor-grok-47] [cursor-pricing].
- xAI's own pricing page for Fast uses a 200k threshold: $4 input, $1 cached and $12 output per Mtok below 200k prompt tokens and $6, $1.50 and $18 above [xai-docs-pricing].

### Structured output

- xAI says Fast is not offered on the public API, so the API's schema rules have no documented Fast use. Structured output in Cursor or Grok Build follows those products' own tools. The API references do list a `service_tier` value `fast` (described as the model's fast deployment where one is configured, otherwise priority scheduling); no page connects it to Grok 4.7 Fast [xai-docs-47-overview] [xai-docs-chatref].

### Images, audio, other inputs

- Cursor lets a prompt carry pasted or dropped images; its docs do not say which models read them. Grok 4.7 takes image input per xAI [cursor-docs-prompting] [xai-docs-47].

### Sampling and API parameters

- None are exposed for Fast: it is not on the API, and neither Cursor nor Grok Build documents sampling controls in the pages read.

### Migrating from the previous generation

- Grok 4.6 also has a Fast tier in Cursor at the same $4 / $1 / $12 price. The Fast tier of Grok 4.5 was $4 / $1 / $18 in Cursor's table [cursor-pricing].
- For Grok 4.7 changes against 4.6 (token use, encrypted reasoning, effort separation) see [the 4.7 migration section](grok-4.7.md#migrating-from-the-previous-generation).

## What the system card reports

No separate card exists for Fast. The Grok 4.7 model card does not name a Fast tier in its text; xAI states Fast is the same model [xai-47-card] [xai-docs-47-overview]. The card's results for Grok 4.7 are in [the 4.7 file](grok-4.7.md#what-the-system-card-reports). Whether the Fast tier applies the same safeguards is not stated.

## Behaviour observed in practice

- No independent measurement of Fast alone was found; Artificial Analysis lists no Fast entry (M) [aa-grok-47-model].
- For comparison only: Cursor's Composer 2.5 also has a Fast tier, which Artificial Analysis measured about 30% faster per task at about six times the cost per task; nothing equivalent exists for Grok Fast [aa-composer-25].
- Practitioner reports (A): none found.

## Benchmarks

None run on Fast alone by the maker or an independent measurer, as of 2026-10-03. Scale's SWE-Bench Pro (public V2) has no Grok entry; METR has no measurement; Artificial Analysis lists no Fast entry [scale-swe-pro-v2] [metr-time-horizons] [aa-grok-47-model]. Grok 4.7's own figures are in [its file](grok-4.7.md#benchmarks).

## Open questions

- Whether Fast and standard give equal quality at equal effort: xAI says yes; no published test was found on 2026-10-03.
- Cursor's 256k and 500k context tiers against xAI's single 500k figure and 200k price step.
- Whether Fast will reach the public API: the docs say it is not available there and give no plan. What `service_tier: "fast"` does for `grok-4.7` on the API is not stated.
