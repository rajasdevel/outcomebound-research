# Hume EVI 3

EVI 3 is the earlier of the two supported versions of Hume's Empathic Voice Interface. It is the version that a chat uses when the config names no version. Hume's changelog says EVI 3 became available in the API on 2025-07-18. It runs on two native speech-language models, `hume-evi-3` and `hume-evi-3-websearch`, and can use a supplemental language model. EVI 1 and EVI 2 ended support on 2025-08-30. Hume has announced that the EVI and TTS APIs end on 2026-11-13. This file says what differs from [Hume EVI 4-mini](evi-4-mini.md), which holds the full guide. Maker-wide facts are in the [Hume README](README.md) [hume-evi-version] [hume-changelog] [hume-overview].

## How to instruct it

### Setting up the prompt

The prompting guide of EVI 4-mini applies. It covers specific instructions, few-shot examples, sections, voice-only formatting, expressive prompting, dynamic variables and short, stable prompts [hume-prompting]. With EVI 3 the guide's examples name `hume-evi-3` and `hume-evi-3-websearch` as the native speech-language models. Hume says these models give fast replies, and that a supplemental model suits reasoning, long system prompts and tool use [hume-prompting].

### Reasoning and effort

EVI has no reasoning setting. A supplemental language model is optional with EVI 3 and required with 4-mini [hume-evi-version].

### Output: format, length, tone

Output is audio and text. EVI 3 sends the assistant's prosody scores later, in a separate `assistant_prosody` message that shares an `id` with the `assistant_message`. This lowers delay during synthesis. Quick responses are available with EVI 3 and not with 4-mini [hume-evi-version].

### Tools and agents

The same as EVI 4-mini: tool use and webhooks, and tool use through Anthropic, OpenAI and Google supplemental models [hume-faq].

### Coding

Hume gives no coding guidance.

### Long context and retrieval

Hume states no context size. The model in use sets it [hume-language-model].

### Structured output

Not supported with supplemental models, according to the FAQ [hume-faq].

### Images, audio, other inputs

Audio input and output formats are the same as for 4-mini. The language support is unclear: the overview and version pages say English, and the FAQ says English and Spanish [hume-overview] [hume-faq].

### Voice: turn-taking, interruption and speech style

The settings are the same as for 4-mini: `end_of_turn_silence_ms` (500 to 3000, default 800), `speech_detection_threshold` (default 0.5), `prefix_padding_ms` (default 300) and `interruption.min_interruption_ms` (50 to 2000, default 800). Timeouts and the interruption rules are the same. As for 4-mini, the client stops playback and clears the queue on `user_interruption`. Hume's fix for interruption delay is `verbose_transcription=true` [hume-turn-detection] [hume-interruption] [hume-timeouts] [hume-audio-guide].

EVI 3 uses a voice system that the older versions do not share. A voice is required in every config, because there is no default voice. Voices come from the Voice Library (more than 100) or from voices you design or clone. Hume's library has EVI 3 versions of the older Ito and Kora voices [hume-evi-version] [hume-voice].

### Sampling and API parameters

Temperature is available for all supplemental models [hume-faq].

### Migrating from the previous generation

The class in this library holds EVI 3 and EVI 4-mini. EVI 3 is the earlier one. To move up, set `evi_version` to `"4-mini"`, make a supplemental model available, and create voices again with a prompt in the language you want [hume-evi-version]. To move from EVI 1 or 2 to EVI 3, Hume's guide lists three breaking changes: a new voice system, a required voice and separate prosody messages [hume-evi-version].
