# SoulX-Podcast-1.7B

SoulX-Podcast-1.7B is an open-weight multi-speaker speech model of Soul AI Lab, with about 1.7B parameters, built for podcast-style dialogue in Mandarin and English. It clones a voice for each speaker and takes paralinguistic tags such as laughter, sighs and coughs inside the script. It is a weak voice actor model, because the documented tags are few; the tokenizer defines far more. The group released it on 2025-10-27 under Apache-2.0, with a separate [dialect checkpoint](soulx-podcast-1.7b-dialect.md). Maker-specific facts are in this file.

## How to instruct it

### Setting up the prompt

- **A script of turns.** The input is a JSON file with a speaker table (a reference clip and its transcript for each speaker) and a list of turns. Each turn names the speaker and holds the text [gh-soulx].
- **Paralinguistic tags in the text.** The repository README lists five tags in the form `<|laughter|>`: laughter, sigh, breathing, coughing and throat_clearing. The model cards name laughter and sighs only. The maker's example script puts a laughter tag and a sigh tag inside Mandarin lines [gh-soulx] [hf-soulx].
- **What the tokenizer defines.** The tokenizer lists many more special tags than the README documents: vocal events (for example laughing, sighing, breathing, coughing, throat clearing, crying, gasping, whispering, shouting, singing, sniffing, sneezing, yawning), a long list of emotion words, and numbered levels for speed, pitch, volume and pause time. The README documents none of these beyond its five tags, so they are not documented controls (inferred from the token list) [hf-soulx-tokens] [gh-soulx].
- **Dialects.** Dialect control is in the separate dialect checkpoint [hf-soulx].

### Output: format, length, tone

- **Length.** The paper reports more than 90 minutes of continuous conversation with stable timbre [arxiv-soulx].
- **Tone.** Tags and the speaker clips; the paper says speakers show context-adaptive prosody as a dialogue goes on [arxiv-soulx].

The repository has a command-line script that reads a JSON script, a web UI, and a Docker setup with vLLM support. Streaming inference was still on the to-do list [hf-soulx] [gh-soulx].

### Long context and retrieval

Not applicable. See the 90-minute figure.

### Structured output

The script is a JSON file with speakers and turns [gh-soulx].

### Images, audio, other inputs

Text and a reference clip with transcript for each speaker.

### Voice: turn-taking, interruption and speech style

Turn-taking does not apply to a live conversation. The model renders a written multi-speaker script.

**How to direct delivery.** Paralinguistic tags in the turn text, and the voice of each speaker clip. The documented tags are the five in the README: laughter, sigh, breathing, coughing and throat clearing. The tokenizer defines more [gh-soulx] [hf-soulx-tokens].

**Strength.** The paper reports results above its comparison models in the maker's own tests and stable timbre over 90 minutes. It gives no per-tag score on the pages read [arxiv-soulx].

**What fails.** Not documented.

**Voice design and cloning.** Cloning per speaker, also across dialects. No voice design.

**Multi-speaker dialogue.** The main feature: speaker tables and turns, with smooth transitions according to the maker [hf-soulx] [arxiv-soulx].

**Long-form consistency.** Stable over more than 90 minutes by the maker's report [arxiv-soulx].

**Pronunciation and normalisation.** Not documented.

### Sampling and API parameters

The command-line script takes a `--seed`; no other setting is named on the pages read [gh-soulx].

### Migrating from the previous generation

No earlier SoulX-Podcast model was found. The same group also released a singing model, a duplex model and a transcriber, which are outside this file [hf-soulx].
