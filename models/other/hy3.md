# Tencent Hy3

Hy3 is Tencent's Hy-team model released in July 2026: a mixture-of-experts model with 295B parameters in total and 21B active per token, a 256K-token window and text input only, under the Apache 2.0 licence. It belongs to the class Tencent Hy, generation 3, the generation before [Hy4 preview](hy4-preview.md). It replaced Hy3 preview (April 2026), which Tencent retrained with feedback from more than 50 of its products and a larger post-training run. Tencent presents it for coding, office work, search and agent tasks, with a stress on reliable tool calls and fewer hallucinations. What the Other-makers folder says in general is on the [folder page](README.md); this file covers Hy3.

## How to instruct it

Tencent publishes a Hugging Face model card for Hy3 and no prompt-writing guide. This section says what the card, its serving notes and independent measurements say; where nothing is published it says so [hf-hy3].

### Setting up the prompt

- **System prompt, roles, structure.** The card gives a plain user-message example with no system prompt and no advice on roles, tags, Markdown, examples or document placement.
- **Instruction following.** No score is published. The card says that the retrained model improved on coreference resolution, ellipsis recovery and inheriting constraints across turns, and that its internal multi-turn test showed an issue rate falling from 17.4% to 7.9% (class L, maker-run, internal test, no public method) [hf-hy3].
- **Concision.** Tencent says outputs are more concise while complex intents do not drift over long dialogues [hf-hy3].

### Reasoning and effort

- **The control.** `reasoning_effort` goes in `chat_template_kwargs` on an OpenAI-compatible server: `no_think` (the default, direct answers), `low` or `high` (deep chain of thought). Tencent says to use `high` for maths, coding and reasoning tasks and `no_think` for direct responses [hf-hy3].
- **What `low` is for.** The code comment lists `low` and the prose does not describe it; no guidance on when to pick it.
- **Evaluation setting.** Tencent's benchmark notes say every result, its own and the comparison models', used the highest effort tier [hf-hy3].
- **Default differs from the successor.** Hy4 preview makes thinking the default; Hy3 and Hy3 preview default to direct answers [hf-hy3] [hf-hy4].
- **Reasoning output.** The serving commands attach a reasoning parser (`hy_v3` in vLLM, `hunyuan` in SGLang), which splits reasoning text from the answer [hf-hy3].
- **Step-by-step prompting.** No advice.

### Output: format, length, tone

- **Length.** No verbosity setting; no maximum output is published.
- **Tone and formatting.** Nothing published beyond the concision claim.
- **Prefill.** Not documented.

### Tools and agents

- **Reliability work.** Tencent says it fixed baseline reliability problems in tool calls and output formats, improved error recovery, and measured accuracy variance on SWE-Bench Verified within 4% across the CodeBuddy, Cline and KiloCode scaffolds (class L, maker-run) [hf-hy3].
- **Serving.** For self-hosted tool use start the server with a tool-call parser (`hy_v3` in vLLM with `--enable-auto-tool-choice`, `hunyuan` in SGLang) [hf-hy3].
- **Long runs.** A news summary says Tencent validated stable agent runs of up to 495 steps in production traffic; the card itself does not say this (class A, relayed) [nyu-hy3].
- **Agent benchmarks.** BrowseComp 84.2 (self-summary context management), WideSearch 76.4, MCP-Atlas public 79.1, Toolathlon 48.5, ClawEval pass^3 68.5, all at the highest effort and mostly in Tencent's own harnesses (Benchmarks) [hf-hy3].
- **Computer use.** Not offered: text input only.

### Coding

- **Maker table.** Highest effort: SWE-bench Pro 57.9, Verified 78.0, Multilingual 75.8 in the SWE-agent scaffold; Terminal-Bench 2.1 71.7 in Terminus-2 (xml parser, 4-hour timeout, 500 episodes at most); NL2Repo 45.6 in Claude Code with extra anti-hacking constraints; DeepSWE 28.0 in mini-swe-agent. Tencent's table rates Claude Opus 4.8 above Hy3 on most coding rows (SWE-bench Pro 69.2, Terminal-Bench 2.1 85.0 or 85.4, NL2Repo 69.7) [hf-hy3] (class L).
- **Independent.** Scale's SWE-Bench Pro V2 table has no Hy3 row, and no coding-agent index entry was read [scale-swe-pro-v2].
- **Blind evaluation.** Tencent says 270 experts scored Hy3 2.67 out of 4 on tasks from their own work, against 2.51 for GLM-5.1, with the widest gaps in frontend development, data and storage, and CI/CD; the card gives no further method (class L, maker-run) [hf-hy3].

### Long context and retrieval

- **Limits.** 256K tokens of context [hf-hy3].
- **Quality.** Tencent's own AA-LCR run scored 73.4 (Hy3 preview 66.3) and the card says MRCR improved markedly, without a number [hf-hy3].
- **Caching and cost.** No caching terms were read.

### Structured output

Nothing is published for JSON mode or schema-constrained output; the parsers above cover tool calls only [hf-hy3].

### Images, audio, other inputs

Text only [hf-hy3].

### Sampling and API parameters

- Recommended `temperature=0.9` and `top_p=1.0`; the card gives one setting and does not split it by reasoning mode [hf-hy3].
- Self-hosting: serve on 8 GPUs with larger memory (Tencent names H20-3e); both example commands enable multi-token-prediction speculative decoding with two speculative tokens (SGLang: EAGLE with three draft tokens). The FP8 build is separate [hf-hy3].

### Migrating from the previous generation

- **From Hy3 preview.** Same architecture and size (295B, 21B active, 256K). The licence changed from the Tencent Hy Community licence to Apache 2.0; the request interface and recommended sampling are the same. Tencent's table shows large gains: SWE-bench Pro 46.0 to 57.9, Terminal-Bench 2.1 58.0 to 71.7, BrowseComp 67.1 to 84.2, DeepSWE 0.9 to 28.0, MathArena Apex 12.6 to 38.7 [hf-hy3] [hf-hy3-preview] [hf-hy3-license].
- **Reliability figures (maker, internal).** Hallucination rate 12.5% to 5.4%, commonsense error rate 25.4% to 12.7% [hf-hy3].
- **To Hy4 preview.** Hy4 preview has 770B total and 49B active parameters, a 1M-token window and thinking by default with the effort values `high` and `no_think`; see the [Hy4 preview file](hy4-preview.md#migrating-from-the-previous-generation).

## What the system card reports

Tencent publishes no system card for Hy3. The model card holds benchmarks, serving notes and internal reliability figures; it has no refusal, jailbreak, prompt-injection, bias or biology and cyber evaluation, and no named safeguards. The anti-hallucination work is described in outline: fine-grained data cleaning and training constraints aimed at answering when grounded and saying when evidence is missing [hf-hy3]. No independent safety assessment of Hy3 was found.

## Behaviour observed in practice

- **Standing, speed and cost (class M).** Artificial Analysis scores Hy3 25 on its Intelligence Index v4.3.2 (rank 27 of 118; its median for comparable models is 19), notes 170M output tokens for the index run against a 140M median, about 87 output tokens a second, and $0.07 per index task [aa-hy3].
- **Harness sensitivity.** Tencent's footnotes say that its NL2Repo runs added anti-hacking prompt constraints and tool-call monitoring for all models, and that scores in the table came from several different harnesses (SWE-agent, Terminus-2, Claude Code, mini-swe-agent, OpenClaw and internal ones) [hf-hy3].
- No practitioner review of Hy3 was read.
