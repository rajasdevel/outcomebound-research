# Dia 1.6B (0626)

Dia 1.6B (0626) is an open-weight dialogue speech model of Nari Labs, class Dia, generation 1, with 1.6B parameters. It speaks English from a script with two speaker tags and adds 21 non-verbal sounds through inline tags such as laughs and coughs. Emotion and tone come from an audio prompt, not from a written instruction. This makes it a weak voice actor model: it directs non-verbal sounds by tag and delivery only by example audio. It is in this folder because Nari Labs' Dia is a widely used open model and the sounds fall inside the definition. The newer Dia2 (November 2025) documents no tags and no delivery control, so it has no file; it streams and limits output to 2 minutes [gh-dia2]. Maker-specific facts are in this file.

## How to instruct it

### Setting up the prompt

- **Speaker tags.** The text begins with `[S1]` and alternates `[S1]` and `[S2]`. The README says two turns by the same tag in a row are not good [gh-dia].
- **Non-verbal tags.** Parenthesis tags: laughs, clears throat, sighs, gasps, coughs, singing, sings, mumbles, beep, groans, sniffs, claps, screams, inhales, exhales, applause, burps, humming, sneezes, chuckle and whistles. The README says these listed tags are recognised but may still give unexpected output. It says to use tags sparingly and only from the list, because overused or unlisted tags may cause artifacts [gh-dia].
- **Emotion and tone.** Condition on an audio prompt. The README says audio conditioning gives emotion and tone control [gh-dia].
- **Audio prompt rules.** An audio prompt needs the transcript of the clip before the script, marked with the speaker tags. The README advises a clip of 5 to 10 seconds (about 86 tokens per second). It also advises ending the prompt text with the second-to-last speaker's tag, which improves the end of the audio [gh-dia].
- **Length.** The README advises input that gives 5 to 20 seconds of audio [gh-dia].

### Coding

Dia loads in Hugging Face Transformers, through `pip` from the repository, through uv, a Gradio app, or a command-line tool. It was tested on GPUs only, with CUDA 12.6 and PyTorch 2 or later at the time of the README [gh-dia].

### Long context and retrieval

Not applicable. See the length guidance.

### Structured output

Not applicable.

### Images, audio, other inputs

A script, and optionally an audio prompt with its transcript. The model was not fine-tuned on one voice, so a fixed seed or an audio prompt keeps a voice [gh-dia].

### Voice: turn-taking, interruption and speech style

Turn-taking does not apply to a live conversation. The two speaker tags only mark turns in a script.

**How to direct delivery.** Non-verbal sounds by the 21 tags. Emotion and tone by an audio prompt. No written instruction [gh-dia].

**Strength and failures.** The README warns that overusing tags or using unlisted ones causes artifacts, that very short input sounds unnatural and that long input speeds up. It gives no score [gh-dia].

**Voice design and cloning.** No design. Cloning through the audio prompt.

**Multi-speaker dialogue.** The main feature: `[S1]` and `[S2]`.

**Long-form consistency.** Voices change on every run unless an audio prompt or seed is used [gh-dia].

**Pronunciation and normalisation.** Not documented.

### Sampling and API parameters

Example: `guidance_scale` 3.0, `temperature` 1.8, `top_p` 0.90, `top_k` 45, `max_new_tokens` 3072 [gh-dia].

### Migrating from the previous generation

The original Dia-1.6B (2025-04-20) is the earlier revision of the same model. Dia2 (1B and 2B, 2025-11-19) is a streaming model that conditions on audio. It limits output to 2 minutes. The pages read document `[S1]` and `[S2]` tags and no non-verbal tags [gh-dia2].
