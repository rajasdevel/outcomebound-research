# Ming-omni-tts 16.8B-A3B

Ming-omni-tts 16.8B-A3B is an open-weight unified audio generation model of Ant Group's inclusionAI team (a mixture-of-experts model named 16.8B with about 3B active parameters). It speaks, and can also generate environmental sound and music in the same stream. It takes instructions for speech rate, pitch, volume, emotion and dialect, and it designs voices from a natural-language description. It is a voice actor model whose instructions are structured fields, not free text. The team released both sizes on 2026-02-11 under Apache-2.0. The sibling [Ming-omni-tts 0.5B](ming-omni-tts-0.5b.md) has its own file. Maker-specific facts are in this file.

## How to instruct it

### Setting up the prompt

- **Instruction as fields.** The cookbook builds the instruction as a JSON object. The field names are in Chinese. They are speaker, background music (BGM), emotion, dialect, style, speaking rate, base frequency (pitch), volume and a field named IP. The cookbook does not describe the IP field. Each field takes a value or stays empty. The example in the cookbook sets the emotion field to the word for happy and pairs it with a speaker reference clip [ming-test].
- **What the fields do.** The maker says the model controls speech rate, pitch, volume, emotion and dialect through simple commands. Its summary claims 93 percent accuracy for Cantonese dialect control. Its tables give this 16.8B-A3B model instruction success rates of 96.33 percent for speech rate, 97.00 for volume and 83.67 for pitch [gh-ming].
- **Voice design.** The maker says the model designs a voice from a natural-language description. On InstructTTSEval-ZH its table gives this 16.8B-A3B model an average of 76.20 over the three scores (APS 87.30). Qwen3-TTS-12Hz-1.7B-VD averages 77.13 in the same table, and the maker calls the 76.20 of its larger model on par with it [gh-ming].
- **Prompt line.** The cookbook calls the model with a fixed English sentence, Please generate speech based on the following description, then the text. For sound and music it uses sibling sentences [ming-test].
- **Podcast dialogue.** Speaker-labelled lines with speaker reference clips and a prompt transcript give two-speaker dialogue [ming-test].

### Reasoning and effort

None.

### Output: format, length, tone

- **Output.** The cookbook writes wav files with `max_decode_steps` set to 200 in its examples [ming-test].
- **Text normalisation.** The cookbook says the text normalisation feature is not supported for the mixture-of-experts models, so this size does not have it. The maker's normalisation figure (1.97 percent in normalised regions) is for the 0.5B model [ming-test] [gh-ming].
- **Tone.** Fields and description.

### Coding

Installation uses the repository's requirements or a Docker image. The cookbook script and a notebook show speech, sound, music and podcast calls. vLLM inference and a technical report were still on the maker's to-do list [gh-ming].

### Long context and retrieval

Not applicable. The maker says the patch-by-patch scheme enables podcast-style generation [gh-ming].

### Structured output

The instruction is a JSON object with fixed field names [ming-test].

### Images, audio, other inputs

Text, an instruction object, and optional reference clips with transcripts. Music and sound generation use the same model [gh-ming].

### Voice: turn-taking, interruption and speech style

Turn-taking does not apply.

**How to direct delivery.** Fill the instruction fields: emotion, dialect, style, rate, pitch, volume. Or describe a voice in words. The English values for the fields are not listed on the pages read; the cookbook uses Chinese values [ming-test].

**Strength.** The maker's tables give this 16.8B-A3B model 76.7 percent emotion accuracy on the CV3-Eval emotional test sets and 45.0 percent on the neutral test sets. CosyVoice3-0.5B scores 66.3 and 40.0 in the same tables. The summary text claims 46.7 percent on the neutral sets, which does not match the table value of 45.0 for the larger model. These are the maker's runs [gh-ming].

**What fails.** The pages read name no failure cases.

**Voice design and cloning.** Both. The model also has 100 or more built-in voices [gh-ming].

**Multi-speaker dialogue.** Supported through speaker labels in the cookbook [ming-test].

**Long-form consistency.** Not documented beyond the podcast claim.

**Pronunciation and normalisation.** Normalisation of formulas is a stated strength [gh-ming].

### Sampling and API parameters

## Benchmarks

Maker only, for this 16.8B-A3B model: InstructTTSEval-ZH average 76.20; CV3-Eval emotion accuracy 76.7 (emotional sets) and 45.0 (neutral sets); attribute instruction success 92.33 percent on average; dialect accuracy 96.30 percent on WSYue-TTS-eval (base set) and 83.48 and 88.44 percent on the easy and hard WSC-Eval-TTS sets; Seed-TTS-eval Chinese word error rate 0.83 [gh-ming].
