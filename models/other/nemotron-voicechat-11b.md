# NVIDIA NemotronLabs VoiceChat 11B

NemotronLabs VoiceChat is NVIDIA's open full-duplex speech-to-speech model with tool calling. It has 11 billion parameters. It joins a Fast Conformer speech encoder, the Nemotron Nano v2 9B text model as its backbone, an NVIDIA speech decoder and codec, and a separate output channel for tool calls. NVIDIA dates the release 2026-08-03. The weights are under the OpenMDW-1.1 licence. NVIDIA claims that no earlier open full-duplex model supported tool calling. Maker-wide facts for NVIDIA are in the [README of this folder](README.md) [nvidia-card-voicechat] [nvidia-paper-voicechat].

## How to instruct it

### Setting up the prompt

The model takes a system prompt. The card says the default template adds the list of available tools and the tool-call protocol to the system message. It gives a rendered example, which reads in short sections [nvidia-card-voicechat]:

- The name and job: a helpful and harmless voice assistant, with a warm and friendly tone, clear and direct on yes-or-no questions, and short answers unless the user asks for detail.
- A rule not to interrupt the user, and to let the user finish the turn.
- A decision process in three steps. First, if the request matches an available tool, call that tool and never answer from memory. Second, if it is a general-knowledge question, answer directly and call no tool. Third, if it needs an outside action that no tool covers, say politely that the agent cannot do it.
- A rule to call a tool only when the request matches a tool in the list, never to invent a tool name, to use only argument values that the user spoke, to ask when a required value is missing, and not to retry a failed call but to tell the user the API has a problem.

System prompts and tool responses must contain ASCII only. The card lists em dashes, en dashes, degree signs and emoji as symbols to avoid. Turn tool responses into short ASCII sentences that suit speech before you pass them to the model [nvidia-card-voicechat].

### Reasoning and effort

The model has no reasoning mode or effort control. It reaches 27.0% on the speech-reasoning test of Artificial Analysis. See Behaviour below [aa-s2s].

### Output: format, length, tone

Output is audio at 22.05 kHz, the agent's text, and a transcript of the user. The default prompt asks for short answers. For each tool you can define an "on-hold" message. The agent says it as soon as the model writes the text that triggers the call [nvidia-card-voicechat].

### Tools and agents

A separate output channel carries tool calls while the voice conversation goes on. The call format is `<TOOLCALL>[{"name": "tool_name", "arguments": {...}}]</TOOLCALL>`. The client runs the tool and returns `<TOOL_RESPONSE>[{...}]</TOOL_RESPONSE>`. The model may then call more tools, correct a call or answer. Offline inference does not run a live tool. It reads a pre-written response from a JSON file whose `tool_name` must match an available tool. The interactive container runs tools live over a bidirectional WebSocket [nvidia-card-voicechat].

NVIDIA's own tool-use numbers are these. On spoken BFCL-v3 (AU Harness) the average is 56.1%, with 42.5% on parallel calls and 27.5% on parallel-multiple calls. On Full-Duplex-Bench v3, tool selection reaches 82.5%, argument accuracy 42.2% and pass at 1 33% [nvidia-card-voicechat]. The paper's abstract says argument accuracy and end-to-end tool execution remain areas for improvement [nvidia-paper-voicechat].

### Coding

NVIDIA gives no coding guidance.

### Long context and retrieval

The card gives no context size. It names no retrieval feature [nvidia-card-voicechat].

### Structured output

Tool calls use the JSON format above. The card gives no other structured-output setting.

### Images, audio, other inputs

Input is 16 kHz audio (WAV or WebAudio) and a text prompt. The model is English only. Training used about 550,000 hours of audio from real and synthetic speech, together with Nemotron text data and persona data. When you use a recording, add enough silence at the end so that the agent has time to answer [nvidia-card-voicechat].

### Voice: turn-taking, interruption and speech style

**Turn-taking.** There is no turn detector, and no interruption or silence setting. The model listens while it speaks and does its own turn-taking. The prompt asks it not to interrupt the user [nvidia-card-voicechat].

**Interruption.** NVIDIA's own Full-Duplex-Bench 1.0 run reports a takeover rate of 1.0 when the user interrupts, with a latency of 480 ms and a GPT-4o rating of 4.33. Artificial Analysis scores the interruption-handling part of its test at 29.0%. The two results differ a lot. The pages do not say whether the test set-ups differ [nvidia-card-voicechat] [aa-s2s].

**Pauses and turn-taking numbers.** NVIDIA reports pause-handling takeover rates of 0.153 (synthetic) and 0.255 (Candor), where lower is better, and a smooth turn-taking takeover rate of 0.82 with a latency of 448 ms. It says turn-taking latency is about 450 ms. The test hardware was an H100 [nvidia-card-voicechat]. Artificial Analysis scores the pause-handling part of its test at 18.2% [aa-s2s].

**Speech while a tool runs.** The on-hold message per tool lets the agent keep talking while the call and response complete [nvidia-card-voicechat].

**Running it.** The card gives two paths. Offline inference loads the Hugging Face checkpoint in a conda environment on an NVIDIA GPU. Interactive streaming uses NVIDIA's inference container (Triton and vLLM) and a WebSocket interface. The listed GPUs are A100, H100, H200, B100, B200 and RTX 6000, on Linux. The card lists no voice choice or voice cloning [nvidia-card-voicechat].

### Sampling and API parameters

There is no hosted API. The card documents no sampling setting. Deployment details are in NVIDIA's GitHub repository, branch `nemotron-labs-voicechat`, which was not read [nvidia-card-voicechat].

### Migrating from the previous generation

There is no earlier VoiceChat model. NVIDIA's earlier open full-duplex model is [PersonaPlex](personaplex-7b-v1.md). It has voice and role prompts but no tool calling, and it is 7 billion parameters on the Moshi architecture. The new model uses a hybrid Mamba and Transformer backbone, 16 kHz input and 22.05 kHz output [nvidia-card-voicechat].

## Behaviour observed in practice

Artificial Analysis measured the model on its Speech to Speech page (read 2026-10-03), listed as NVIDIA Nemotron Voicechat [aa-s2s]:

- Speech reasoning (Big Bench Audio): 27.0%.
- Conversational dynamics: 52.9%. The parts are pause handling 18.2, turn-taking 71.4, interruption handling 29.0 and backchannel handling 92.9.

These results are lower than NVIDIA's own on the same family of tests (Full-Duplex-Bench). The earlier PersonaPlex scored 91.0% on conversational dynamics on the same page. No practitioner report was read.

## Benchmarks

Independent: the two results above. Maker: Full-Duplex-Bench 1.0, AU Harness BFCL-v3 and Full-Duplex-Bench v3 as above. NVIDIA also says it is second among open full-duplex models on VoiceBench and on Full-Duplex-Bench 1.0. The paper reports a VoiceBench normalized average of 55.1, 93% successful resumption after backchannels on Full-Duplex-Bench 1.5, and 82.5% tool-selection F1 on version 3 [nvidia-card-voicechat] [nvidia-paper-voicechat].
