# PersonaPlex-7B-v1

PersonaPlex-7B-v1 is NVIDIA's open full-duplex speech-to-speech model with control of role and voice. It is a fine-tune of Kyutai's Moshiko weights, with the Moshi architecture and the Mimi codec. Before a conversation starts, you give it two prompts: a text prompt for the role and a voice prompt for the voice. NVIDIA published the weights and code on 2026-01-15. The weights are gated on Hugging Face and need acceptance of NVIDIA's Open Model License. The paper is dated 2026-01-14. Maker-wide facts for NVIDIA are in the [README of this folder](README.md) [nvidia-card-personaplex] [nvidia-gh-personaplex] [nvidia-paper-personaplex].

## How to instruct it

### Setting up the prompt

The text prompt sets the persona: role, background and scenario. NVIDIA says the model was trained on three kinds of prompt, so prompts close to these work best [nvidia-gh-personaplex]:

- **Assistant.** One fixed prompt: a wise and friendly teacher who answers questions or gives advice in a clear and engaging way. NVIDIA uses it for the user-interruption tests of Full-Duplex-Bench.
- **Customer service.** Varied prompts of one pattern: who the person works for, the type of business, the agent's name, and an "Information" block with facts such as prices, hours and the current account state. The examples are a waste-collection service, a restaurant and a drone-rental firm.
- **Casual conversation.** The prompt starts with a short line that says the agent enjoys good conversation. It may add a topic, an emotional register and personal background such as a job, a city or a dislike. NVIDIA uses the short line alone for the pause, backchannel and smooth turn-taking tests.

The model generalises to prompts outside these kinds, and NVIDIA says some abilities emerge there. It gives no list of what works. The card calls the model ready for commercial use, under the licence [nvidia-gh-personaplex] [nvidia-card-personaplex].

### Reasoning and effort

The model has no reasoning mode or effort control. Independent tests show weak speech reasoning. See Behaviour below [aa-s2s].

### Output: format, length, tone

The output is audio plus the agent's text. A voice prompt sets the voice and the speaking style. The text prompt sets the persona. No other control of length or tone is documented [nvidia-card-personaplex].

### Tools and agents

The model has no tool calling. NVIDIA's later model [Nemotron VoiceChat 11B](nemotron-voicechat-11b.md) adds it, and lists this model's training data among its own [nvidia-card-voicechat].

### Coding

NVIDIA gives no coding guidance.

### Long context and retrieval

The card gives no context size. Training used conversations of up to 10 minutes [nvidia-card-personaplex].

### Structured output

Not applicable.

### Images, audio, other inputs

Input is audio at 24 kHz and a text prompt. The model speaks and understands English only. Training used the Fisher English corpus (7,303 conversations of up to 10 minutes, under 10,000 hours) plus synthetic conversations written with open text models and speech synthesis [nvidia-card-personaplex] [nvidia-paper-personaplex].

### Voice: turn-taking, interruption and speech style

**Voice prompts.** The repository packages 18 voice embeddings. Eight are natural: NATF0 to NATF3 (female) and NATM0 to NATM3 (male). Ten are varied: VARF0 to VARF4 and VARM0 to VARM4. NVIDIA says the natural set sounds more conversational and the varied set offers more range. The voice is fixed for the conversation [nvidia-gh-personaplex].

**Turn-taking.** The model has no turn detector and no interruption setting. It listens and speaks in two parallel streams. It handles interruptions, barge-ins, overlaps and fast turns by itself. Its behaviour depends on the weights and on the text prompt [nvidia-card-personaplex].

**Latency.** NVIDIA reports 0.170 seconds from the end of user speech to the start of the reply, and 0.240 seconds for the agent to stop when the user interrupts. The test was Full-Duplex-Bench on an A100 80 GB [nvidia-card-personaplex].

**Running it.** The README steps are: install the Opus development library and the `moshi` package from the repository, accept the model licence on Hugging Face and set an access token, and start `python -m moshi.server` with a temporary SSL certificate. The web interface runs on port 8998. The `--cpu-offload` flag moves layers to the CPU when GPU memory is short. `python -m moshi.offline` runs a recorded input file and writes an output file of the same length. Blackwell GPUs need a special PyTorch build [nvidia-gh-personaplex].

### Sampling and API parameters

There is no hosted API. The offline script takes a seed. The pages read document no other sampling setting [nvidia-gh-personaplex].

### Migrating from the previous generation

There is no earlier PersonaPlex model. It follows [Moshi](../kyutai/moshi.md), which has no prompts and one voice per build. Kyutai's Hugging Face listing also holds a gated repository named `personaplex-rl-seamless` that names this model as its base. The files were not readable [hf-kyutai-list].

## What the system card reports

The card holds NVIDIA's standard sections on use, training data, hardware and ethics. It says developers should check that the model meets the needs of their industry and use. It points to separate subcards for bias, explainability, safety and privacy. Those subcards were not read. The card gives no refusal or misuse test result [nvidia-card-personaplex].

## Behaviour observed in practice

Artificial Analysis measured the model on its Speech to Speech page (read 2026-10-03), listed as NVIDIA PersonaPlex [aa-s2s]:

- Conversational dynamics: 91.0%. The parts are pause handling 90.5, turn-taking 92.4, interruption handling 93.5 and backchannel handling 87.8.
- Speech reasoning (Big Bench Audio): 19.1%.

The base model, Moshi, scored 61.0% and 4.4% on the same two tests. On this page the fine-tune scores much higher than its base on conversational dynamics, and its speech-reasoning score stays low [aa-s2s]. No practitioner report was read.

## Benchmarks

Independent: the two Artificial Analysis results above. Maker (Full-Duplex-Bench on an A100 80 GB): smooth turn-taking takeover rate 0.908 with latency 0.170 seconds; user-interruption takeover rate 0.950, GPT-4o rating 4.29 and latency 0.240 seconds; speaker similarity 0.650 (WavLM). The pause-handling takeover rates are 0.358 on the synthetic set and 0.431 on the Candor set, where lower is better. The backchannel takeover rate is 0.273. NVIDIA says the model beats other open and commercial systems on these tests [nvidia-card-personaplex].
