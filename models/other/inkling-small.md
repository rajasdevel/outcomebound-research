# Inkling-Small

Inkling-Small is the smaller open-weight model of Thinking Machines Lab's Inkling class: 276B total and 12B active parameters on
42 layers, the same input types (text, image, audio) and output (text) as [Inkling](inkling.md), released as generally available
on 2026-07-30 under Apache-2.0 after a preview announced with Inkling on 2026-07-15. The class has no earlier generation. It is
for the same uses as Inkling at lower cost and latency. Everything on instruction, tools and sampling is in the Inkling file; this
file says what differs.

## How to instruct it

### Setting up the prompt

Thinking Machines gives no separate prompting guidance for Inkling-Small; the card repeats Inkling's intended uses (agents, coding
assistants, chatbots, retrieval-augmented generation) and its multilingual claim [hf-inkling-small]. The prompt construction
described in [Inkling's file](inkling.md#setting-up-the-prompt) is the only documented route, with the caveat that the Tinker pages
that document it name only Inkling in their text and code; Tinker's model table gives Inkling-Small the same model type.

### Reasoning and effort

Tinker's effort page lists presets from 0.0 to 0.99 and is written for Inkling: its text and code name only that model
[tinker-thinking-effort]. The Inkling-Small card names no levels and reports no effort setting for its benchmarks [hf-inkling-small].
Artificial Analysis lists a reasoning variant and counted 140M output tokens for its index, the same count as Inkling's, and calls the
model somewhat verbose [aa-inkling-small]. Whether the float scale, the default of 0.9 and the preset names carry over unchanged was
not confirmed on a page.

### Output: format, length, tone

Same position as Inkling: no controls published. Artificial Analysis measured 190.8 output tokens per second and 2.12 s to first token
[aa-inkling-small].

### Tools and agents

No tool-use guidance specific to this model. The card's agent results are vendor runs: SWE-bench Verified 80.2 (bash-only harness),
SWE-bench Pro public split 55.9 (harness not stated), Terminal-Bench 2.1 64.7 (best harness; the maker says a few web-contaminated
solutions were scored 0) [hf-inkling-small]. These sit slightly above the larger model's maker-run numbers (77.6, 54.3 and 63.8),
which the maker's own table shows and the card does not explain.

### Coding

See Tools and agents. No independent SWE-Bench Pro V2 entry exists for Inkling-Small; Scale's table lists only the larger model
[scale-swe-pro-v2].

### Long context and retrieval

The card says up to 1M tokens, the same as Inkling [tml-model-card-small]. Tinker lists a 64K and a 256K context option for both models
[tinker-pricing]. No long-context measurement is published for this model.

### Structured output

Nothing published, as for Inkling.

### Images, audio, other inputs

Inputs match Inkling's except for audio length: the card says ideally under 2 minutes, where Inkling's says under 20
[hf-inkling-small] [tml-model-card-small]. Image results on the card (maker-run): MMMU Pro 74.0, CharXiv RQ 77.4 (81.3 with Python);
audio: VoiceBench 90.1, MMAU 77.0 [hf-inkling-small]. Tinker lists both models as supporting audio and vision [tinker-pricing].

### Sampling and API parameters

No sampling recommendation from the maker. Hardware: BF16 needs at least 600 GB of accelerator memory (four B300 or eight H200);
NVFP4 at least 180 GB (one B300 or two H200) [tml-model-card-small]. Prices: Tinker's serverless inference beta lists 0.30 in, 0.06
cached and 1.20 out per million tokens for a 256K NVFP4 endpoint, the same input and output Artificial Analysis shows; Tinker's
fine-tuning table lists sampling at 64K as 1.16 prefill and 2.88 sample before a limited-time 50% discount [tinker-pricing]
[aa-inkling-small].

### Migrating from the previous generation

None: the class has one generation. Moving from Inkling to Inkling-Small changes the audio-length guidance, the active-parameter count
(12B against 41B), and the price. On the maker's table Small is higher on most reasoning and coding rows (GPQA Diamond, HLE, HMMT,
CritPt, ARC-AGI, SWE-bench Verified, SWE-bench Pro, Terminal-Bench 2.1), lower on AIME 2026, and much lower on factuality (SimpleQA
Verified 20.6 against 43.9; AA-Omniscience index -9.0 against 2.1) [hf-inkling-small]. At the preview, a report gave Small GPQA Diamond
88.3 against Inkling's 87.2 and relayed that the lab credits changes to pre-training data and the training process; the generally
available card gives 89.5 [the-decoder-inkling] [hf-inkling-small].

## What the system card reports

A model card only [tml-model-card-small]. The wording matches Inkling's: a conclusion that Inkling-Small gives no material uplift beyond
what open weights already offer, a residual risk of occasional compliance with role-play and indirectly framed harmful requests, and a
recommendation to add layered defences with a moderation model. Numbers on the card: StrongREJECT 98.4, FORTRESS adversarial 71.6 and benign 96.9
(Inkling: 98.6, 78.0 and 95.9) [hf-inkling-small]. The card lists hallucination, instruction-following lapses and degraded long multi-turn
quality as limits. No prompt-injection, reward-hacking, sycophancy or sandbagging number is reported. See [Inkling](inkling.md) for the
named evaluation areas.

## Behaviour observed in practice

- **Verbosity and speed (M).** Artificial Analysis: rank 26 of 118 on the index at 26, 190.8 tokens per second, 2.12 s to first token,
  cost per index task about $0.09 [aa-inkling-small].
- **Reliability (A).** A launch write-up cites a 63% hallucination rate for "the model" on a knowledge benchmark; it was written about Inkling, and no
  figure for Small was found [the-decoder-inkling].
- **Parameter count.** The card says 276B total; Artificial Analysis says 266B [aa-inkling-small] [hf-inkling-small].

## Benchmarks

Independent: Artificial Analysis Intelligence Index v4.3.2, 26 with a reasoning variant, 140M output tokens, rank 26 of 118
[aa-inkling-small]. Thinking Machines' own table lists index v4.1 scores of 40 for Small and 41 for Inkling; v4.1 and v4.3.2 are
different tests [hf-inkling-small]. No Scale V2, Terminal-Bench 4.0, Coding Agent Index or METR entry was found
[scale-swe-pro-v2] [metr-horizons] [tbench-4-leaderboard] [aa-coding-agents]. Maker-run: SWE-bench Verified 80.2, SWE-bench Pro public 55.9, Terminal-Bench 2.1
64.7, GPQA Diamond 89.5, AIME 2026 95.5, HMMT Feb 2026 90.2 [hf-inkling-small].

## Open questions

- Whether Inkling's effort scale and default apply to Small.
- Why the smaller model scores above the larger on most maker-run reasoning and coding items; the only explanation found is a relayed
  remark about pre-training data and process.
- Independent coding, long-context and tool-use measurements.
- Which price applies on third-party hosts; only Tinker's two price tables were read.
