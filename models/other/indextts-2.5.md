# IndexTTS-2.5

IndexTTS-2.5 is an open-weight speech synthesis model of Bilibili's IndexTeam, class IndexTTS, generation 2.5. It clones a voice from one clip and sets emotion apart from the voice: you give the emotion as a vector of eight numbers, as a second reference clip, or as a description in text. It is a voice actor model with emotion as its main control. Bilibili released it on 2026-08-10 as the successor of [IndexTTS-2](indextts-2.md). It adds Japanese, Spanish and Arabic, a speed control, faster inference and better control of pronunciation. Maker-specific facts are in this file.

## How to instruct it

### Setting up the prompt

- **Four ways to give emotion.** The same call takes: (1) no emotion input, so the model infers it from the voice clip and text; (2) a separate emotion reference clip (`emo_audio_prompt`) with a strength `emo_alpha` from 0.0 to 1.0, default 1.0; (3) an emotion vector of eight numbers in the order happy, angry, sad, afraid, disgusted, melancholic, surprised, calm; (4) text emotion, where the model turns the script, or a separate description (`emo_text`), into a vector (`use_emo_text`) [gh-index].
- **Text emotion.** For the text route, the README recommends an `emo_alpha` of about 0.6 or lower for more natural speech. On version 2.5 the route needs the model to be built with `use_qwen_emo=True`; without it the call raises an error. Version 2 needs no flag [gh-index].
- **A description separate from the script.** The README's example gives a frightened line to speak. It gives the emotion as a description of a different line. So the script and the emotion are kept apart [gh-index].
- **Randomness.** `use_random` adds sampling randomness. The README says this lowers voice cloning fidelity [gh-index].
- **Speed.** `duration_factor` from 0.5 to 2.0 scales the duration: above 1.0 slows speech, below 1.0 speeds it up. Version 2.5 only [gh-index].
- **Pronunciation.** Version 2.5 takes a word and its reading in the form of angle brackets with a bar, with Pinyin tone numbers, CMU phonemes or Kana [hf-index25].

A web UI, a Python API and a vLLM serving recipe are documented. BF16 inference lowers memory with small quality loss; DeepSpeed may or may not help, depending on hardware [gh-index].

### Images, audio, other inputs

Text, a speaker clip, and optionally an emotion clip, an emotion vector or an emotion description. The auxiliary models (a speech encoder, a codec and a speaker model) download on first run [hf-index25].

### Voice: turn-taking, interruption and speech style

Turn-taking does not apply.

**How to direct delivery.** Emotion is the direction axis. Direction is one of the four routes above. Emotion is eight fixed classes in the vector route and free text in the description route. Speed is a number. The model has no instruction for accent, role or non-verbal sounds on the pages read [gh-index].

**Strength.** The maker publishes no emotion-control score for version 2.5 on the pages read. For version 2, a third-party table by Boson, run with no tags, puts IndexTTS-2 at 39.29 percent on emotions against a baseline row [boson-blog-tts3c].

**What fails.** Random sampling lowers cloning fidelity. A high `emo_alpha` with text emotion reads less natural, according to the README's own advice [gh-index].

**Voice design and cloning.** Cloning from one clip. No voice design.

**Multi-speaker dialogue.** Not documented.

**Long-form consistency.** Not documented.

**Pronunciation and normalisation.** Pinyin, CMU phonemes and Kana control through the word-and-reading form [hf-index25].

### Sampling and API parameters

Python: `spk_audio_prompt`, `text`, `lang`, `emo_audio_prompt`, `emo_alpha`, `emo_vector`, `use_emo_text`, `emo_text`, `use_random`, `duration_factor`, `use_bf16` [gh-index].

### Migrating from the previous generation

IndexTTS-2.5 keeps the emotion-and-timbre separation of IndexTTS-2 and adds three languages, `duration_factor` speed control, a faster model and better Pinyin, CMU and Kana control. Version 2.5 loads from `indextts.infer_v2_5`, and the text-emotion route needs a construction flag that version 2 does not. Both versions load their own checkpoint folder [gh-index].
