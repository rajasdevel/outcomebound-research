# IndexTTS-2

IndexTTS-2 is an open-weight speech synthesis model of Bilibili's IndexTeam, class IndexTTS, generation 2, released on 2025-09-08. It clones a voice and takes emotion as a separate input: a vector of eight numbers, a second reference clip or a description in text. It is a voice actor model. The maker describes it as the first autoregressive model with precise control of duration, but the README says that function is not enabled in this release. [IndexTTS-2.5](indextts-2.5.md) replaced it. Maker-specific facts are in this file.

## How to instruct it

### Setting up the prompt

- **Emotion routes.** The same four routes as in 2.5: none, a separate emotion clip with `emo_alpha`, an eight-number vector, and text emotion with an optional separate `emo_text` description [gh-index].
- **Chinese and English only** on the Hugging Face card. Pronunciation control is by Pinyin mixed into Chinese text [gh-index] [hf-index2].
- **Text emotion.** The README recommends `emo_alpha` of about 0.6 or lower. Version 2 needs no extra construction flag for text emotion [gh-index].

### Reasoning and effort

None.

### Output: format, length, tone

Not stated beyond the emotion routes. There is no `duration_factor` in version 2 [gh-index].

### Tools and agents

Not applicable.

### Coding

The Python class is `indextts.infer_v2.IndexTTS2`, with the version 2 checkpoint folder. The README warns that running the module directly starts a benchmark loop against a fixed folder name, so the Python API is the advised route [gh-index].

### Long context and retrieval

Not applicable.

### Structured output

Not applicable.

### Images, audio, other inputs

Text, a speaker clip, and optionally an emotion clip, vector or description.

### Voice: turn-taking, interruption and speech style

Turn-taking does not apply.

**How to direct delivery.** Emotion by clip, vector or text description, as for 2.5. No speed parameter, no accent or role instruction and no sound tags are documented in the README for version 2. The paper describes a duration mode that fixes the number of generated tokens, and a soft instruction from text descriptions through a fine-tuned Qwen3 model [gh-index] [arxiv-index2].

**Strength.** Boson's table, which ran no tags, gives IndexTTS-2 a 39.29 percent win rate on emotions and 31.12 percent overall against a baseline row [boson-blog-tts3c]. The maker's paper reports its own tests [arxiv-index2].

**What fails.** Random sampling lowers cloning fidelity [gh-index].

**Voice design, multi-speaker dialogue, long-form consistency.** None documented.

**Pronunciation.** Pinyin mixed into Chinese text [gh-index].

### Sampling and API parameters

Python: `spk_audio_prompt`, `text`, `emo_audio_prompt`, `emo_alpha`, `emo_vector`, `use_emo_text`, `emo_text`, `use_random`, `use_fp16`, `use_deepspeed` [gh-index].

### Migrating from the previous generation

The README news entries for IndexTTS-1.5 (2025-05-14) and IndexTTS 1.0 (2025-03-25) name no emotion input. They are older than two generations and have no file here [gh-index].

## What the system card reports

Bilibili publishes a paper (arXiv 2506.21619) and a licence, and no system card [arxiv-index2].

## Behaviour observed in practice

- **Competing maker's table (L).** Boson's EmergentTTS-Eval table places IndexTTS-2 last of six on overall win rate, 31.12 percent [boson-blog-tts3c].
- No practitioner report was read.

## Benchmarks

Third-party vendor (Boson): emotions 39.29 percent, overall 31.12 percent. Maker: see the paper [boson-blog-tts3c] [arxiv-index2].

## Open questions

- Output sample rate and GPU needs for version 2.
- An independent measure of emotion control.
