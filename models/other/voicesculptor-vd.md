# VoiceSculptor-VD

VoiceSculptor-VD is an open-weight voice design model of the ASLP-lab group, with about 4B parameters, built on the Llasa-3B speech model. It makes a Chinese voice from a written description of at most 200 characters. It is a voice actor model for design: the description sets persona, age, pace, intonation and timbre. It handles Chinese only in this version. The group released it in January 2026 under Apache-2.0. Maker-specific facts are in this file.

## How to instruct it

### Setting up the prompt

- **A description, in Chinese.** The model takes a voice description of at most 200 characters. English descriptions are not supported in this version [gh-vs-guide].
- **Five principles from the maker's guide.** A description is specific and uses perceptible words. It covers several dimensions. It describes the sound and not an opinion of it. It does not ask for a named person's voice. It does not repeat or pad words. The guide says its text draws on Alibaba's Qwen3-TTS voice design guide [gh-vs-guide].
- **Dimensions.** Persona or use (news, advertising voice-over, audiobook, animated character, documentary), gender, age band, personality traits (lively, calm, gentle, intellectual, cute, serious), speaking rate and rhythm, intonation style (rising, neutral, passionate, relaxed) and timbre (deep and magnetic, crisp and bright, husky and warm, youthful). The checklist asks for at least three dimensions and a clear use [gh-vs-guide].
- **Examples in our words.** A man who recites modern poetry in a low, resonant voice, with marked pauses and forceful, emotional delivery. A woman who reads the news in standard Mandarin, with a bright, fairly high voice, an even professional pace and a neutral tone [gh-vs-guide].

### Coding

Clone the repository, create a Python 3.10 environment, install the requirements, download the model with Git LFS and run `infer.py`. The maker's to-do list names a Gradio app, vLLM support, a technical report and training code as not yet released [hf-vs].

### Voice: turn-taking, interruption and speech style

Turn-taking does not apply.

**How to direct delivery.** Through the voice description only, in Chinese, up to 200 characters [gh-vs-guide].

**Strength.** On InstructTTSEval for Chinese, the maker reports attribute perception 75.7, description-speech consistency 64.7 and response precision 61.5. The average is 67.6. In the same table, MiMo-Audio-7B-Instruct averages 64.5 and Gemini 2.5 Flash averages 85.4. InstructTTSEval is a published benchmark of instruction following in speech synthesis [hf-vs] [arxiv-instructtts].

**What fails.** The guide lists vague, subjective, single-dimension, padded and imitation prompts as errors. English prompts are unsupported [gh-vs-guide].

**Voice design and cloning.** Design only.

**Multi-speaker dialogue, long-form consistency, pronunciation.** Not documented.

- **Other makers' tables (L).** The Alibaba and OpenBMB READMEs list VoiceSculptor with the same Chinese scores as above. Both put Qwen3-TTS-VD and VoxCPM2 higher, at 85.2 on Chinese attribute perception [qwen3tts-gh] [voxcpm-gh].
- No practitioner report was read.

## Benchmarks

Maker: InstructTTSEval-ZH APS 75.7, DSD 64.7, RP 61.5, average 67.6 [hf-vs]. No independent result was found.
