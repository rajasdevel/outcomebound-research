# MiMo-V2.6-Flash

MiMo-V2.6-Flash is the smaller model of Xiaomi's MiMo-V2.6 pair, released on 2026-09-21 under the MIT licence: a mixture-of-experts model with 309B total and 15B active
parameters, 1M-token context, native text, image, video and audio input and text output, with thinking on by default. Xiaomi positions it for frequent calls and large-scale
professional tasks, at about a third of the Pro's input price. It follows the V2.5 generation (MiMo-V2.5 and MiMo-V2.5-Pro), which Xiaomi's API deprecates on
2026-10-21; Xiaomi's own table compares it with MiMo-V2.5-Pro. The API rules and guides the two models share are in [the
maker README](README.md) and are not repeated here; the [Pro file](mimo-v2.6-pro.md) holds the fuller account of what the Pro results say.

## How to instruct it

### Setting up the prompt

No prompt guidance from Xiaomi for either model. The Flash card has the same structure as the Pro's and describes the V2.6 series as a whole [hf-mimo-flash]: a
fully asynchronous GRPO run (batches of 1,568 prompts with 16 rollouts each), groupwise reward synthesis that writes task-specific rubrics from contrasting rollouts, online
ranking of passing trajectories, and a multi-teacher on-policy distillation stage that reuses teacher histories [hf-mimo-flash].

### Reasoning and effort

Same control as the Pro: `thinking.type` `enabled` or `disabled`, on by default, with sampling fixed at 1.0 and 0.95 while thinking, and `reasoning_content` required back in multi-turn tool use
[mimo-docs-thinking] [mimo-docs-thinking-zh]. Where Flash differs is cost: Artificial Analysis counted 240M output tokens for its index, against 140M for the Pro, rated the model rank 37 on
verbosity and measured 46.4 output tokens per second with 5.69 s to first token, against 37.4 and 3.78 for the Pro (live figures, read 2026-10-03) [aa-mimo-flash] [aa-mimo-pro].
The smaller, cheaper model therefore spends more output tokens per task in that test; Artificial Analysis does not split them into thinking and answer.

### Output: format, length, tone

Output limit 128K tokens including thinking, as for the Pro [mimo-page-flash]. No format or tone controls.

### Tools and agents

Function calling, streaming, web search, structured output and context caching are listed [mimo-page-flash]. Maker-run (Xiaomi's own, harness not stated): DeepSWE v1.1 67.9, Toolathlon-Verified 73.6,
AutomationBench v1.0.6 52.3, Agents' Last Exam 27.6, Terminal-Bench 4.0 28.8, OSWorld-Verified 80.8, JobBench 61.2 [hf-mimo-flash] [hf-mimo-pro]. Serving flags and parsers are the same (`mimo` for
reasoning and tools) [hf-mimo-flash].

### Coding

DeepSWE v1.1 67.9 (Pro 71.9), ProgramBench 26.0, MiMo Code Bench 61.2, Terminal-Bench 2.1 87.6 (Pro 89.9), MiMo VisualCoding 71.5 [hf-mimo-flash] [hf-mimo-pro]. Xiaomi's table puts the Flash within a few points of the Pro on these
and well above MiMo-V2.5-Pro on most.

### Long context and retrieval

1,048,576 tokens (the config's maximum position count) with 39 sliding-window and 9 global-attention layers, a five-layer drafter that predicts seven tokens per step for
speculative decoding [hf-mimo-config] [hf-mimo-flash]. Xiaomi's report says the Flash was pre-trained on 48T tokens (26T text, 22T multimodal) against the Pro's 30T, with
context extended from 32K to 256K in pre-training and to 1M at the end of mid-training [mimo-tech-report]. No long-context benchmark is
published.

### Structured output

Same JSON mode as the Pro (`json_object`, syntax only) [mimo-docs-structured].

### Images, audio, other inputs

Xiaomi lists text, image, video and audio input for the Flash [mimo-page-flash]; Artificial Analysis lists text and image only [aa-mimo-flash]. Limits are those of the pair (image URLs or base64 up to 50 MB, no local upload)
[mimo-docs-image].

### Sampling and API parameters

Recommended `temperature=1.0`, `top_p=0.95` [hf-mimo-flash]. Price: $0.14 per million cache-miss input tokens, $0.0028 cache-hit and $0.28 output, as Xiaomi's page and Artificial Analysis list
it [mimo-page-flash] [aa-mimo-flash]. Rate limit 100 requests and 10M tokens per minute [mimo-page-flash].

### Migrating from the previous generation

Xiaomi's table gives MiMo-V2.5-Pro as the previous reference, not the Flash. On that table the Flash is well above it: DeepSWE v1.1 19.0 to 67.9, Terminal-Bench 4.0 1.5 to 28.8, Terminal-Bench 2.1 65.2 to 87.6,
Toolathlon-Verified 49.1 to 73.6, CyberGym 40.0 to 95.1 [hf-mimo-pro] [hf-mimo-flash]. The V2.5 models are deprecated on 2026-10-21 and the docs recommend V2.6 [mimo-docs-models] [litellm-mimo].

## What the system card reports

Xiaomi publishes no system card for the Flash; neither the Hugging Face model card nor the series technical report has a safety, refusal, injection or sycophancy
evaluation [hf-mimo-flash] [mimo-tech-report]. The report's reward-hacking measures (summarised in the [Pro file](mimo-v2.6-pro.md#what-the-system-card-reports)) cover
both models, and it reports a confirmed-hack share below 2% throughout the Flash's RL run [mimo-tech-report]. Reported capability that matters for deployment: cyber
results from Xiaomi's runs, CyberGym 95.1, MiMo Cyber Bench 77.2, ExploitGym 6.0, ExploitBench 25.3, SEC Bench Pro 47.5, which are close to the Pro's on the first two and well below on the exploit items
[hf-mimo-flash] [hf-mimo-pro]. The weights are MIT-licensed; no usage policy or classifier is described.

## Behaviour observed in practice

- **Index (M).** Artificial Analysis v4.3.2: 38, rank 9 of 118, 240M output tokens, $0.06 per index task, 98% cache discount [aa-mimo-flash].
- **Speed (M).** 46.4 tokens per second, rank 53 of 118, and 5.69 s to first token on Xiaomi's API; Artificial Analysis rates both at the slow end for its size [aa-mimo-flash].
- **Hosting (A).** LiteLLM's write-up gives the cache-read price for the Pro only, and says V2.6 kept the V2.5 rates; the Flash cache price is on Xiaomi's page [litellm-mimo] [mimo-page-flash]. Alibaba Model Studio's MiMo page documents only the previous `mimo-v2.5-pro`, without
  multimodal input [aliyun-mimo].

## Benchmarks

Independent: Artificial Analysis Intelligence Index v4.3.2, 38 (reasoning, 240M output tokens) [aa-mimo-flash]. No Scale SWE-Bench Pro V2 row, Terminal-Bench 4.0 row, Coding Agent Index entry or METR entry
[scale-swe-pro-v2] [metr-horizons] [tbench-4-leaderboard] [aa-coding-agents]. Maker-run (Xiaomi's table): Terminal-Bench 4.0 28.8, Terminal-Bench 2.1 87.6, DeepSWE v1.1 67.9, OSWorld-Verified 80.8, AutomationBench 52.3,
Toolathlon-Verified 73.6, CyberGym 95.1 [hf-mimo-flash].
