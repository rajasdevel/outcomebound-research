# Muse Wonder Full

Muse Wonder Full is the higher-capability variant of Meta's Muse Wonder 1.0, released with
[Muse Wonder](muse-wonder-1.0.md) on 2026-10-12. Meta calls it its most advanced model. It is a separate model, not an
effort level: Meta says that `max` effort on `muse-wonder-1.0` does not select it. It runs only inside Muse Code, Meta's
terminal coding agent, on the Power Usage and Maximum Usage subscriptions; it has no API and no per-token price. L
[meta-api-models] [meta-wonder-page]

## How to instruct it

Muse Wonder Full is reached only through Muse Code, so the harness writes the system prompt, the tool definitions and
the request. The advice for Muse Wonder applies where Muse Code exposes it; see the
[Muse Wonder file](muse-wonder-1.0.md#how-to-instruct-it). The Muse Code rules for instruction files and memory are in
the [maker README](README.md#prompting-guides).

### Setting up the prompt

Muse Code reads `AGENTS.md`, `CLAUDE.md`, `.agents/AGENTS.md` and `.claude/CLAUDE.md` from the workspace root down to
the nearest `.git` boundary, after the workspace is trusted (details in the maker README). Meta publishes no prompting
advice specific to Muse Wonder Full. L [meta-muse-code-config]

### Reasoning and effort

Meta's reasoning page says that Muse Wonder Full supports `max` in Muse Code. Muse Code's `--reasoning-effort` flag and
`/effort` command take `none`, `minimal`, `low`, `medium`, `high` (the default), `xhigh`, `max` and `ultra`; `ultra` is
a client setting that maps to the provider's highest level and can make Muse Code delegate more; the Meta provider does
not accept `none`. Meta ran most of its benchmarks at `max`, and SWE-Marathon at `xhigh`. L [meta-api-reasoning]
[meta-muse-code-config] [meta-wonder-card]

### Output: format, length, tone

No output limit or verbosity control is published for this variant. Artificial Analysis counted 110 million output
tokens to run its index at `max`. M [aa-wonder-full]

### Tools and agents

Tools are Muse Code's own. Muse Code can cap a run with `--max-model-steps` and emit JSONL events with `--json`. L
[meta-muse-code-config]

### Coding

This is the variant's main use. Artificial Analysis measured Muse Code with Muse Wonder Full at 34.9 minutes, 194.9
turns and 14.5 million tokens per task, with a 96% cache hit rate. M [aa-coding-muse-code]

### Long context and retrieval

Meta gives the context as 1M tokens without an exact count. MemoryBench (internal, 64K to 100K-token conversations)
is 85.5 in Meta's table. L [meta-wonder-page] [meta-wonder-card]

### Structured output

Not applicable outside Muse Code; no structured-output interface is documented for this variant.

### Images, audio, other inputs

Meta's model card lists text, image, video and audio input and text output. How Muse Code passes each kind of file to
the model is not documented for this variant. L [meta-wonder-card]

### Sampling and API parameters

None are exposed: the model has no API.

### Migrating from the previous generation

There is no earlier generation. To move from Muse Wonder to Muse Wonder Full, select it in Muse Code (`/models` or
`--model`) on a plan that includes it. Subscriptions default to Contributor mode, which lets Meta train on the content
sent; it can be turned off in Muse Code's settings. L [meta-muse-code-config] [meta-muse-code-subscriptions]

## What the system card reports

Meta's model card covers Muse Wonder and Muse Wonder Full. Its risk results are for Muse Wonder Full, under the Meta
Superintelligence Scaling Framework. L [meta-wonder-card]

- **Risk levels.** Without mitigations, Meta does not rule out the high-risk threshold for chemical and biological
  risk, so it applies safety post-training and system-level classifiers for that domain. Cyber and loss of control are
  moderate or lower before mitigation. With mitigations and system safeguards, all domains are moderate or lower, which
  Meta says supports deployment.
- **Cyber capability.** CyberGym 88.4% and ExploitBench 58.9%. For ExploitGym, Meta published a correction on
  2026-10-23: after it fixed its harness to put the intended vulnerability in the prompt, the model captured 20 intended
  flags (the first report gave 92 flags in total and 21 intended). Meta says the change does not alter its risk level.
- **Cyber misuse robustness** (attack success, lower is better): CyberBench 0.8 single-turn and 0.8 multi-turn;
  PolyGuard cyber subset 1.1 and 2.3; RedCode 9.0 and 8.0.
- **Chemical and biological capability** (dual-use proxies): SecureBio MBCT 59.6%, HPCT 66.5%, VCT 55.9%; LAB-Bench
  ProtocolQA 89.0%; SeqQA with tools 95.6%; ABC Bench liquid handling 100.0%; Meta BDT 79.4%. ABC Bench fragment design
  and screening evasion show no score because of a high refusal rate; Meta dropped refusals before scoring.
- **Refusal on harmful biology and chemistry prompts** (higher is better): BioTIER 98.7% English, 98.7% multilingual
  and 98.2% adversarial; Meta's chemistry set 100.0%, 100.0% and 99.8%.
- **Loss of control.** MASK honesty 87.3%; agentic misalignment 0% harmful actions.
- **What is missing.** The card gives no over-refusal, sycophancy, prompt-injection, reward-hacking or
  evaluation-awareness result. The launch post says a full report with more safety evaluations will follow.

The card recommends a broader system with use-specific guardrails and human confirmation for irreversible actions,
and says the model is not intended for people under 18. L [meta-wonder-card] [meta-wonder-post]

## Behaviour observed in practice

Artificial Analysis has no speed or price data for this variant, because it has no public API. On its coding-agent
index, Muse Code with Muse Wonder Full takes more turns per task than OpenCode with GLM-5.3 (194.9 against 111.5) and
less time (34.9 against 56.2 minutes). M [aa-wonder-full] [aa-coding-muse-code]

No practitioner report was read for this file.

## Benchmarks

Independent:

- Artificial Analysis Intelligence Index v5.0: 50 at `max`; Terminal-Bench 4.0 inside it 57.1%. M [aa-wonder-full]
- Artificial Analysis Coding Agent Index v2.0, in Muse Code at `max`: 59 (FrontierCode v1.1 49%, Terminal-Bench 4.0
  59%, SWE-Atlas-QnA-AA 69%), the top Muse Code entry. M [aa-coding-muse-code]
- SWE-Bench Pro (Scale), METR and the tbench.ai 4.0 board: no entry for this variant. M [scale-swe-pro-v2]
  [metr-horizons] [tbench-4-leaderboard]

The maker's (Meta's table, `max` unless stated): DeepSWE v1.1 79.0 (Datacurve's run, per Meta), SWE-Marathon 57.5 at
`xhigh`, OSWorld V2.1 78.4 partial and 39.4 binary, ProgramBench 59.0, MemoryBench 85.5, Personal Superintelligence
Index 59.1, and an Artificial Analysis index of 56 that Meta's card describes as v4.3. Meta's SWE-Marathon row is not a
controlled comparison: the GPT-6 Astra and Claude Fable 5.1 results use Codex and Claude Code. L [meta-wonder-page]
[meta-wonder-card]
