# Dragon HD

Dragon HD is the first of the two HD voice base models of Azure Speech in this library. It gives 30+ fine-tuned voices with fixed personas, and the base model reads the text and picks emotion and pace on its own. Microsoft's pages disagree on whether you can also direct it: one section shows bracket styles and `express-as` for it, and the element table and the comparison table say style control is by temperature and advanced parameters only. It counts as a voice actor model here only with that doubt, and the files for the other Microsoft models say more about direction. Family-wide rules are in the [Microsoft README](README.md). The newer model is [Dragon HD Omni](dragon-hd-omni.md).

## How to instruct it

### Setting up the prompt

- **The voice name selects the model.** The form is `en-US-Ava:DragonHDLatestNeural`. `LatestNeural` follows the newest base model [ms-hd].
- **The base model infers delivery.** Microsoft says HD voices understand the content, detect emotion in the text and adjust tone to match. They also reproduce pauses and filler words found in conversational text and add slight variation to each output [ms-hd].
- **Style markers, with a conflict.** The expressive-style section of the HD page and the SSML voice page show `[excited]`-style markers and `mstts:express-as` on a `DragonHDLatestNeural` voice, with 53 keywords such as amazed, calm, excited, sad, sarcastic, slow, fast, shouting and whispering. The element table of the same page says `mstts:express-as` is not supported for Dragon HD, and the comparison table says its style control is temperature and advanced parameters only. A reader who needs styles on Dragon HD should test the voice and fall back to Omni [ms-hd] [ms-ssml-voice].
- **Paralinguistic tags.** Laughter, coughing, throat_clearing, breathing, sighing and yawning, in every language [ms-hd].

### Reasoning and effort

None.

### Output: format, length, tone

Opus, mp3, pcm and truesilk at 8, 16, 24 and 48 kHz, in real time only. Latency below 300 ms for HD voices [ms-hd].

### Tools and agents

Not a tool-calling model.

### Coding

The model is reached through the Speech SDK, the Speech CLI or REST. The `parameters` attribute of the voice element sets `temperature` and `enhancePronunciation` [ms-hd].

### Long context and retrieval

No per-request limit is published in the pages read [ms-hd].

### Structured output

Not applicable.

### Images, audio, other inputs

Text or SSML only [ms-hd].

### Voice: turn-taking, interruption and speech style

The model is not a conversation model. It has no turn detection and no barge-in. Turn-taking does not apply. A multi-talker voice handles turns inside one synthesis request, as below.

**How to direct delivery.** The base model infers it. The extra levers are the style markers (disputed for this model), the paralinguistic tags and `temperature`, which runs from 0 to 1 with a default of 1.0. A lower value gives steadier, more predictable output [ms-hd].

**Multi-talker dialogue.** A multi-talker voice such as `en-US-MultiTalker-Ava-Andrew:DragonHDLatestNeural` takes an `mstts:dialog` element. Inside it, one `mstts:turn` element per turn names the speaker, here `ava` or `andrew`. Microsoft says multi-talker voices keep context, emotional consistency and speech patterns across turns, which single-talker models do not do [ms-ssml-voice].

```xml
<voice name="en-US-MultiTalker-Ava-Andrew:DragonHDLatestNeural">
  <mstts:dialog>
    <mstts:turn speaker="ava">Did the shipment arrive?</mstts:turn>
    <mstts:turn speaker="andrew">It came this morning.</mstts:turn>
  </mstts:dialog>
</voice>
```

**Pronunciation and text normalisation.** Dragon HD accepts `phoneme`, `break`, `lexicon` (alias only), `say-as` and `sub`. The `enhancePronunciation` parameter, default false, applies extra handling to proper names, acronyms and words with several readings. Microsoft says SSML pronunciation elements stay the way to get deterministic results [ms-hd].

```xml
<voice name="en-US-Ava:DragonHDLatestNeural" parameters="enhancePronunciation=true">
  Kubernetes runs the service.
</voice>
```

**Voices.** 30+ fine-tuned voices, with fixed personas. Some voices are in preview, for example one tuned for podcasts. Personal voice cloning is a separate gated Azure Speech feature [ms-hd].

**Long-form.** No claim was found.

### Sampling and API parameters

`temperature`, 0 to 1, default 1.0, and `enhancePronunciation` [ms-hd].

### Migrating from the previous generation

Moving to Omni adds 700+ voices, `express-as`, automatic language detection and word boundary events, and loses `phoneme` and `break`. Microsoft's page recommends Dragon HD for fixed personas in specific languages and for customer service [ms-hd] [ms-tc-omni].

Microsoft's pages do not say which base model that is, so the score is not attached to the card [aa-hd25].
