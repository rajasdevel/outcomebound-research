# Soniox TTS Real-Time v2

Soniox TTS Real-Time v2 is the current model of the Soniox TTS Real-Time class. It reads bracketed audio tags for emotion, tone, human sounds, volume, pace and pauses, and reads written emphasis. Soniox made it generally available on 2026-08-11. The tag list is open, so this is an instruction-style tag model. The maker has no earlier model in scope, because v1 was removed. Family-wide rules are in the [Soniox README](README.md).

## How to instruct it

### Setting up the prompt

- **No system prompt.** The input is `text` with optional tags, plus `model`, `language`, `voice`, `audio_format`, `speed` and related fields. Every real-time stream opens with one configuration message [so-rt] [so-tone].
- **Audio tags.** Bracketed cues such as `[excited]` and `[whispering]` placed before the text they affect. Tags are written in English whatever the language of the text [so-tone].
- **Model status.** `tts-rt-v2` is generally available from 2026-08-11. `tts-rt-v1` was removed on 2026-08-31, and requests to it now go to v2 without an API change [so-models].

### Reasoning and effort

None.

### Output: format, length, tone

- **Formats.** See the card [so-formats].
- **Speed.** `speed` from 0.7 to 1.3, default 1.0. Soniox says it rescales the whole output and can flatten a voice's natural rhythm, so it advises picking a voice with the right pace and using tags and punctuation for local pacing [so-speed].
- **Length.** A stream is capped at 2 minutes of audio, and the output is truncated at the cap [so-limits-rt].

### Tools and agents

Not applicable.

### Coding

Official SDKs for Python, Node.js, Web and React, and an examples repository [so-index].

### Long context and retrieval

A stream carries at most 2 minutes of generated audio. The docs advise starting a new stream to continue [so-limits-rt].

### Structured output

Not applicable.

### Images, audio, other inputs

Text only. A cloned voice comes from a reference clip. The clone copies speed, inflection, accent, breathing, noise and mouth clicks, so the docs advise a consistent clip [so-clone].

### Voice: turn-taking, interruption and speech style

Soniox TTS is not a conversation model. It has no turn detection and no barge-in in the pages read. A client stops its own playback and can cancel a stream (the docs have a page on stream termination) [so-index].

**How to direct delivery.**

- **Audio tags.** Place a tag before the words it should affect. The words after it inherit the delivery. The docs group the tags like this [so-tone]:
  - Emotion: happy, sad, angry, excited, nervous, fearful, surprised, annoyed, relieved, disappointed, curious, delighted, calm.
  - Tone and manner: warm, stern, serious, playful, sarcastic, flirty, deadpan, sincerely, reassuringly, dramatically, mockingly.
  - Human sounds: laughs, chuckles, giggles, sobs, sniffles, whimpers, sighs, exhales, gasps, grunts, groans, clears throat, coughs, yawns.
  - Volume and pace: whispering, softly, loudly, shouting, getting louder, getting quieter, trailing off, muttering, slowly, quickly, rushed, drawn out, hesitantly.
  - Not supported: environmental sound effects such as a dog barking or a phone ringing.
  - Pitch and voice quality: high-pitched, low voice, monotone, breathy, raspy, trembling voice, shaky.
  - Pauses: `[pause]` and `[long pause]`.
- **The set is open, with a warning.** The docs say the listed tags are not exhaustive and that other tags may work, and they advise testing any other tag. An unrecognised tag may be spoken aloud [so-tone].
- **Strength and limits.** Short single-purpose tags such as laughs and shouting are reliable. Compound directions are not. Two stacked tags combine well. Five stacked tags pull in different directions. A voice has to support the direction, so a soft narrative voice asked to shout goes only so far. Tags do not override the text: an excited tag on a flat sentence sounds forced [so-tone].
- **Illustration, written for this library and not taken from the maker.** `[low voice] Close the door. [hesitantly] There is something you should see. [pause] Please.` This shows how tags chain; it is not a sample from the docs. It was not run against the model.
- **Text formatting.** Capitals mean loud or strong stress. Single asterisks stress a word. Stretched vowels give a drawl. A hyphenated stutter and lowercase text give a muted read. An ellipsis is a trailing pause, a dash is an abrupt cut, and `?!` is an incredulous tone. A few repeats read as intent. Dozens degrade delivery [so-tone].
- **Spoken interjections.** Words such as hmm, um, uh, mhm, ugh, oof and phew are written as ordinary words and not as tags [so-tone].
- **Speed.** A separate `speed` parameter, not a tag [so-speed].

**Voice choice and cloning.** Built-in voices vary in gender, age, energy and accent. A voice keeps its identity across languages. A cloned voice is scoped to one project and must be recomputed for each new model that appears after its creation. Cloning does not appear as a way to carry emotion in the pages read [so-voices] [so-clone].

**Multi-speaker dialogue and long-form consistency.** One connection can host up to 5 streams, and each stream can use its own voice and language. The pages read describe no dialogue request and no continuity feature across streams [so-limits-rt] [so-index].

**Pronunciation and language mixing.** Text in several languages in one utterance is pronounced naturally, and the `language` field sets the overall delivery and a light accent bias. The model is also advertised as accurate on alphanumerics such as phone numbers and emails. The pages read describe no pronunciation tag or dictionary [so-mixing] [so-models].

**Turn-taking.** Not applicable to a synthesis model.

### Sampling and API parameters

`model`, `language`, `voice`, `audio_format`, `sample_rate`, `bitrate`, `speed` (0.7 to 1.3), `reduce_silence`, `stream_id` and timestamp options [so-speed] [so-formats] [so-index].

### Migrating from the previous generation

From `tts-rt-v1` [so-models]:

- The model name is the only change in the request. Soniox says v2 is fully compatible with v1.
- v2 adds audio tags for emotion, delivery and vocal reactions, high-fidelity voice cloning, language switching inside a sentence and less silence between sentences.
- Voices cloned before v2 need a recompute to work with it [so-clone].
- v1 requests are routed to v2 from 2026-08-31.

## Behaviour observed in practice

- **Rank (M).** Artificial Analysis gives a quality Elo of 1178.92 [aa-tts-board].
- **Throughput (M).** About 18 characters a second in the same data, the lowest of the models in this group. The page does not say how it measured a real-time model [aa-tts-board].
- No practitioner report was read.

## Benchmarks

Independent: Artificial Analysis quality Elo 1178.92 [aa-tts-board]. No maker benchmark was read.
