# Raon-SpeechChat-9B

Raon-SpeechChat-9B is KRAFTON's open full-duplex speech model. It extends Raon-Speech-9B with full-duplex decoding, so it can listen and speak at the same time. The card names natural turn-taking, backchannels such as "uh-huh" and barge-in handling. The Hugging Face repository was created on 2026-04-01 and the technical report is dated 2026-04-08. The weights are under CC BY-NC 4.0, which bars commercial use. Maker-wide facts are in the [KRAFTON README](README.md) [raon-card-chat] [raon-paper] [hf-krafton-list].

## How to instruct it

### Setting up the prompt

The model takes a system prompt. The card lists 17 built-in personas, customisable system prompts, context injection and a persona catalogue. KRAFTON gives no longer guidance on prompt wording in the pages read. The training data format has a `system` field for text prompts, a `language` field for prompt selection and a `speak_first` flag per channel [raon-card-chat] [raon-gh].

### Reasoning and effort

The model has no reasoning mode or effort control. Artificial Analysis measured 57.5% on speech reasoning. See Behaviour below [aa-s2s].

### Output: format, length, tone

Output is speech and text. A dedicated backchannel token (`<|audio_output_backchannel|>`) makes short feedback sounds. A backchannel penalty changes how often they occur. The card gives no length or tone controls [raon-card-chat].

### Tools and agents

The card lists no tool calling.

### Coding

KRAFTON gives no coding guidance.

### Long context and retrieval

The card gives no context size.

### Structured output

Not applicable.

### Images, audio, other inputs

Input is speech and a text prompt. Optional speaker reference audio conditions the voice through ECAPA-TDNN embeddings. The card builds the model on Qwen3 (36 layers), the audio encoder of a Voxtral Mini realtime model, the Mimi codec (32 quantizers) and a talker module. The SpeechChat card says English. The base Raon-Speech model covers English and Korean. The README says the SpeechChat training set holds about 116,000 hours of time-aligned dialogue [raon-card-chat] [raon-gh].

### Voice: turn-taking, interruption and speech style

**Turn-taking.** The model has no turn detector and no VAD setting. It decodes listening and speaking together, and an explicit interaction-state model and a text look-ahead drive its choices, per the README [raon-gh].

**Speak-first or listen-first.** Runtime token forcing sets whether the model waits for the user or starts to speak at once [raon-card-chat].

**Backchannels.** A dedicated token and a penalty control how often the model gives short feedback [raon-card-chat].

**Interruption.** The card lists barge-in handling as a feature. No separate setting was found [raon-card-chat].

**Running it.** The model loads with `AutoModel.from_pretrained(..., trust_remote_code=True)`. The README says the realtime duplex demo needs the `raon` package, because its runtime code imports `raon.*` modules. The self-hosted Docker demo needs an NVIDIA GPU with CUDA 12 and 16 GB or more of memory, and downloads about 25 GB on the first run [raon-card-chat] [raon-gh].

**Echo and audio.** The pages read give no sample rate or echo guidance for the realtime audio.

### Sampling and API parameters

There is no hosted API. The pages read document no sampling setting for the duplex model [raon-card-chat].

### Migrating from the previous generation

There is no earlier SpeechChat model. The base Raon-Speech-9B handles speech recognition, synthesis, spoken and text questions as offline tasks and is not full-duplex. KRAFTON lists a larger `A.X-K2-Raon-Speech-21B-A3B` (2026-07-27). Its card describes turn-based chat and no full-duplex mode [raon-gh] [hf-krafton-list] [raon-card-ax21b].

## Behaviour observed in practice

Artificial Analysis measured the model on its Speech to Speech page (read 2026-10-03), listed as Krafton Raon SpeechChat [aa-s2s]:

- Speech reasoning (Big Bench Audio): 57.5%.
- Conversational dynamics: 86.2%. The parts are pause handling 74.5, turn-taking 86.6, interruption handling 92.0 and backchannel handling 91.8.
- Time to first audio: 0.04 seconds on average. The page does not say how this is measured for a model that can speak while it listens. It is therefore not directly comparable with the figures of the turn-based models.

The open models on the page show a spread: Raon scores higher than Moshi (61.0%) and Nemotron VoiceChat (52.9%) on conversational dynamics, and below PersonaPlex (91.0%) [aa-s2s]. No practitioner report was read.

## Benchmarks

Independent: the Artificial Analysis results above. Maker: the card shows its benchmark results as an image only.
