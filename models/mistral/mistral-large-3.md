# Mistral Large 3

Mistral Large 3 is an open-weight mixture-of-experts model (Apache-2.0) with 675 billion parameters, 41 billion of them
active per token, released on 2025-12-02. It is the Large class's generation 3 and is a general-purpose instruct model
with image input, not a reasoning model. It is the oldest of the three Mistral models here and the only one without a
reasoning switch. Rules shared by Mistral's models are on the [Mistral page](README.md); this
file says what is specific to Large 3.

## How to instruct it

Mistral's guidance for Large 3 is a short "recommended settings" list in the model card, plus the shared pages described on the
[Mistral page](README.md#prompting-guides). There is no coding-agent or agent-design guide.

### Setting up the prompt

- **System prompt.** The card advises defining a clear environment and use case, and saying how tools should be used in agentic
  systems [hf-large-3]. The repository's `SYSTEM_PROMPT.txt` casts the model as the assistant behind Le Chat, takes `{today}`
  and `{yesterday}` placeholders, tells it to use tools for uncertain or current information, to ask for clarification on
  ambiguous requests, to answer in the user's language, and states a knowledge cut-off of 2023-10-01 [large-system-prompt].
- **General advice.** Role line, few-shot examples as made-up turns, hierarchical sections written for a reader with no context,
  objective wording [mistral-prompting-docs].
- **Style, tags, long documents.** The prompting page calls Markdown or XML-style tags ideal for marking sections
  [mistral-prompting-docs]. No guidance on where to place long documents.
- **Intended and restricted use.** Mistral's technical documentation names long-document and long-context understanding,
  multimodal reasoning over documents, graphs and images, instruction following, coding, tool use, enterprise workflows
  and assistants, and says the model is not meant for critical decisions with significant real-world impact without
  prior validation and human oversight [mistral-td-large-3].
- **Languages.** Mistral's launch post claims more than 40 languages; the card lists eleven, English through Arabic
  [mistral-3-post, hf-large-3].

### Reasoning and effort

- None. The card says the model is not a dedicated reasoning model, and the API has no `reasoning_effort` for it
  [hf-large-3, mistral-reasoning-docs]. Mistral's December 2025 post said a reasoning version was coming; the models page read on
  2026-10-03 lists none [mistral-3-post, mistral-models-overview].
- No setting adds reasoning depth, and Mistral says nothing about step-by-step prompting for this model. Its reasoning page
  lists `mistral-small-latest`, `mistral-medium-3-5` and the hosted `zai-glm-5-3` as the models that take
  `reasoning_effort`, and the card says dedicated reasoning models can outperform Large 3 on strict reasoning
  [mistral-reasoning-docs, hf-large-3].

### Output: format, length, tone

- No verbosity or format control; the model page lists structured outputs, function calling, prefix completion and document
  question answering, and no predicted outputs [mistral-large-docs].
- Output speed on Artificial Analysis was 79.2 tokens a second, 1.06 s to the first token; it wrote 9.8 million output tokens to run
  the index, about 6,000 a task [aa-large-3, aa-compare-large-small].

### Tools and agents

- **Advice from the card.** The tool set is to be well defined and as small as the use case allows, to avoid overloading the model
  with many tools; say in the system prompt how to use them [hf-large-3].
- **Mechanics.** Function calling, `tool_choice`, `parallel_tool_calls` and `tool_call_id` rules are on the [Mistral
  page](README.md#family-wide-behaviour). vLLM needs `--enable-auto-tool-choice --tool-call-parser mistral` [hf-large-3].
- **Not documented.** Persistence, long-horizon behaviour and context management; Artificial Analysis's agentic components are
  near zero (below).

### Coding

- No coding score from Mistral. Artificial Analysis: Terminal-Bench 4.0 0%, SciCode 37%, index 9. No Coding Agent Index, Scale or METR
  figure [aa-compare-large-small, scale-swe-pro-v2, metr-horizons].
- Mistral names Medium 3.5, not Large 3, as the replacement for its retired coding models [mistral-deprecations].

### Long context and retrieval

- 256k tokens; Artificial Analysis gives 256k on its comparison page and 260k in its model-page summary; Mistral's
  technical documentation gives 256k tokens as the maximum size of text input and of text output, so no separate output
  cap is published [mistral-large-docs, aa-large-3, mistral-td-large-3].
- Cached input tokens are billed at 10% of the input price per Mistral's API reference, $0.05 per million tokens here
  (Artificial Analysis shows the same) [mistral-chat-api, aa-compare-large-small].
- Artificial Analysis's long-context reasoning test scored it 36%, against 50% for Small 4 and 69% for Medium 3.5
  [aa-compare-large-small].
- Self-hosting at the full 262,144-token length uses `--max-model-len 262144` on an 8-GPU H200 node [hf-large-3].

### Structured output

- The model page lists structured outputs; `json_schema` and `json_object` formats and the custom-schema recommendation are on the
  [Mistral page](README.md#family-wide-behaviour). The card advertises native function calling and JSON output
  [mistral-large-docs, hf-large-3].

### Images, audio, other inputs

- Image and text in, text out, through a 2.5-billion-parameter vision encoder. Mistral recommends aspect ratios close to 1:1 and
  says to crop images that are very thin or wide. The card says Large 3 lags behind vision-first models on multimodal tasks. The
  docs' vision page lists Large 3 (`mistral-large-2512`) [hf-large-3, mistral-vision-docs]. Mistral's technical
  documentation gives "8 images" as the maximum image input, and the card's speculative-decoding example caps prompts at
  10 images [mistral-td-large-3, hf-large-3]. No audio or video input.

### Sampling and API parameters

- **Temperature.** Below 0.1 for daily-driver and production use; higher values may be tried for creative work. This is much lower
  than the 0.0 to 0.7 range the API reference recommends, and the card tells developers to experiment [hf-large-3, mistral-chat-api].
- **`n`.** Mistral's sampling page says Large 3 (`mistral-large-2512`) does not support multiple completions [mistral-sampling-docs].
- **Aliases.** `mistral-large-latest` points to the newest General Availability Large; the pinned id is `mistral-large-2512`
  [mistral-lifecycle, mistral-large-docs].
- Price $0.50 input and $1.50 output per million tokens; cached input is billed at 10% of input and batch at 50% off
  [mistral-large-docs, mistral-chat-api, mistral-pricing].

### Migrating from the previous generation

- Large 2.0 retired on 2025-03-30, and Mistral's table gives Large 3 as its alternative. Large 2.1 retired on 2026-05-31, and the table
  gives Medium 3.5 as its alternative, not Large 3 [mistral-deprecations].
- Mistral calls Large 3 its first mixture-of-experts release since the Mixtral series, which changes serving needs: the card
  says one node of eight H200 or B200 GPUs in FP8, and Mistral's technical documentation says 16 H200 for standard
  inference and at least eight for FP8 [mistral-3-post, hf-large-3, mistral-td-large-3].
- The card asks for vLLM 1.12.0 or later and `mistral_common` 1.8.6 or later [hf-large-3].

## What the system card reports

Mistral publishes no system card or safety report for Large 3. The Hugging Face model card gives settings, serving commands, a
licence, known limitations (not a dedicated reasoning model, behind vision-first models, hard to deploy with limited
resources) and charts without text numbers; the docs page gives capabilities and price [hf-large-3, mistral-large-docs].
Its AI-Act technical documentation (dated 2025-12-02) gives limits, uses, hardware and a general account of training
data, and says data is deduplicated and safety-filtered against Mistral's usage policy; it reports no evaluation results
[mistral-td-large-3]. Nothing from the lab covers refusals, over-refusal, reward hacking, sycophancy, deception, sandbagging, prompt injection or cyber and
biology safeguards. Product-level safeguards are Mistral's separate moderation model and the `guardrails` request block, which an
application must configure. The one independent signal is Artificial Analysis's AA-Omniscience index of -40, on a scale that
penalises wrong answers [aa-compare-large-small, mistral-guardrailing-docs].

## Behaviour observed in practice

- Speed and cost on Artificial Analysis's index: 79.2 tokens a second (above the median of similar open non-reasoning
  models, per Artificial Analysis), 1.06 s to the first token, $0.03 per index task, about 6,000 output tokens per task
  (class M) [aa-large-3, aa-compare-large-small].
- Below the median among open-weight non-reasoning models on Artificial Analysis: index 9 against a median of 12, rank 29 of 46
  (class M) [aa-large-3].
- Agentic components near zero (Terminal-Bench 4.0 0%, AutomationBench 1%, CritPt 0%) and long-context reasoning at 36% (class M)
  [aa-compare-large-small].
- Mistral says Large 3 debuted second among open non-reasoning models on LMArena and sixth among all open models (a launch
  claim; not re-checked) [mistral-3-post].
- No independent hands-on report was found.

## Benchmarks

Independent (Artificial Analysis, class M, index v4.3.2, non-reasoning): Intelligence Index 9; 9.8 million output tokens; $0.03 per task;
rank 29 of 46 open non-reasoning models [aa-large-3]. Components: AA-Briefcase 224, GDPval-AA v2.1 424, AutomationBench-AA 1%,
Terminal-Bench 4.0 0%, SciCode 37%, Humanity's Last Exam 4%, GDP.pdf 1%, CritPt 0%, AA-Omniscience -40, AA-LCR 36%
[aa-compare-large-small]. Scale's SWE-Bench Pro (public V2) board, METR's time horizon and the tbench.ai board hold no entry for it
[scale-swe-pro-v2, metr-horizons, tbench-4-leaderboard].

Maker-reported: an LMArena rank at launch, as above; the card's benchmark charts carry no numbers in text [mistral-3-post, hf-large-3].
