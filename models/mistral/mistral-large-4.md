# Mistral Large 4

Mistral Large 4 is a mixture-of-experts model with about 1 trillion parameters and image input. It is generation 4 of
the Mistral Large class. It combines instruction following, reasoning, coding and agent work in one set of weights, with
three effort levels. It replaces Mistral Large 3 and, as the deprecation table names it, Mistral Medium 3.5. It entered
public preview on Mistral's API on 2026-10-06, and Mistral published improved open weights on 2026-10-29 under its
Mistral Ecosystem Open-Weight License. Rules shared by Mistral's models are on the [Mistral page](README.md); this file
says what is specific to Large 4.

## How to instruct it

Mistral's guidance for Large 4 is the "Recommended Settings" list in the Hugging Face model card, one effort note on the
docs model page, and the shared pages on the [Mistral page](README.md#prompting-guides). Mistral publishes no
coding-agent or agent-design guide for it [hf-large-4, mistral-large-4-docs].

### Setting up the prompt

- **System prompt.** The card advises a system prompt that defines a clear environment and use case, and that says how to
  use the tools in an agent system. It claims strong adherence to system prompts [hf-large-4].
- **No shipped system prompt.** The repository has no `SYSTEM_PROMPT.txt`, and the chat template sets an empty default
  system message. Thus the model gets no default persona, date or knowledge cut-off when you send no system prompt
  [hf-large-4-template]. The knowledge cut-off is not published.
- **General advice.** Role line, few-shot examples as made-up turns, sections marked with Markdown or XML-style tags,
  and objective wording, as on the shared prompting page [mistral-prompting-docs].
- **Languages.** The card claims more than 160 languages, which include every official language of the European Union
  [hf-large-4].

### Reasoning and effort

- **Control.** `reasoning_effort` with `low`, `medium` and `high`; the default is `high` [hf-large-4,
  mistral-large-4-post]. The chat template sets `high` when the field is missing or null, and it raises an error for any
  other value, so `none` is not accepted [hf-large-4-template].
- **What each level is for.** The card says `high` for complex prompts and agent use, `medium` for day-to-day use and
  `low` for fast chat replies. The docs page says `high` gives the best quality and that the lower levels use less
  compute. The launch post says `low` replaces the `none` mode [hf-large-4, mistral-large-4-docs,
  mistral-large-4-post].
- **Token cost of effort.** On Artificial Analysis's coding-agent runs, `high` used about 8.45 million tokens per task
  (input and output, most of the input from cache) and `medium` about 5.76 million, at US$1.26 and US$0.78 per task [aa-coding-agents].
- **Reasoning output.** Under vLLM, `--reasoning-parser mistral` puts the reasoning in `message.reasoning`. The chat
  template turns a `reasoning` or `reasoning_content` field of an earlier assistant turn into a leading thinking chunk.
  Thus the history keeps the reasoning when the client sends it back [hf-large-4, hf-large-4-template]. The replay rule
  on the [Mistral page](README.md#family-wide-behaviour) is written for Small 4 and Medium 3.5; no Large 4 page states
  it.
- **Token limits.** The card says `max_completion_tokens` counts reasoning tokens and visible output tokens together
  [hf-large-4].

### Output: format, length, tone

- No verbosity control is documented. The model page lists structured outputs, function calling, prefix completion and
  document question answering [mistral-large-4-docs].
- Artificial Analysis rates the model as fast (161.3 output tokens a second) and somewhat verbose (110 million output
  tokens to run its index) [aa-large-4].

### Tools and agents

- **Advice from the card.** Keep the tool set well defined, and keep the number of tools to the minimum that the use case
  needs [hf-large-4].
- **Mechanics.** Native function calling. The card's examples use `tools` with `tool_choice="auto"` and send the result
  back as a `tool` message with the matching `tool_call_id`. The shared rules are on the
  [Mistral page](README.md#family-wide-behaviour). vLLM needs `--tool-call-parser mistral` and
  `--enable-auto-tool-choice`; SGLang uses `--tool-call-parser auto` [hf-large-4].
- **Agent security.** The launch post reports that the model resisted 97.1% of attacks on the B3 agent security
  benchmark, against 93.3% for the preview. This is the maker's figure [mistral-large-4-post].
- **Not documented.** Context management, persistence over long runs and subagents.

### Coding

- Mistral's launch post says the model now leads open-weight models on FrontierCode and Terminal-Bench
  [mistral-large-4-post], and the card says Large 4 powers Vibe, Mistral's coding agent. The model card
  gives a Vibe configuration for a local vLLM server with `thinking = "high"`, a context of 1,048,576 tokens, an
  auto-compact threshold of 800,000 tokens and a bash timeout of 1,200 seconds [hf-large-4].
- On Artificial Analysis's Coding Agent Index v2.0, Large 4 in Mistral Vibe scored 48.3 at `high` and 35.4 at `medium`
  [aa-coding-agents]. The maker's launch post cites the same index at 48% and says this used 47% fewer tokens per task than
  GLM-5.3 [mistral-large-4-post].

### Long context and retrieval

- 1M tokens on the docs page and the card; the checkpoint's generation config allows 1,048,576 positions
  [mistral-large-4-docs, hf-large-4-config]. No separate output cap is published.
- Cached input costs $0.07 per million tokens, which is 10% of the input price [mistral-large-4-docs].
- The vLLM serving example does not set `--max-model-len`. If GPU memory runs short, the card says to lower
  `--max-model-len` or `--max-num-seqs` [hf-large-4].

### Structured output

- `response_format` with `text`, `json_object` or `json_schema`. The card says the model enforces strict JSON schemas
  natively, and its example sets `"strict": True`. The chat template passes a schema to the model in a settings block,
  and raises an error for a `json_schema` format with no schema [hf-large-4, hf-large-4-template].

### Images, audio, other inputs

- Text and image in, text out. The docs page names a 1.6-billion-parameter vision encoder; the card says that the encoder
  handles variable image sizes and aspect ratios. This is a change from Large 3, which asked for ratios near 1:1
  [mistral-large-4-docs, hf-large-4]. The checkpoint's vision settings give a maximum image size setting of 1,540
  [hf-large-4]. The card claims strong visual grounding. No audio or video input.

### Sampling and API parameters

- **Temperature and top-p.** `temperature=1.0` and `top_p=0.95` at every effort level; the generation config ships the
  same values [hf-large-4, hf-large-4-config]. This is a large change from Large 3, whose card asked for a temperature
  below 0.1.
- **Ids and aliases.** `mistral-large-4` and `mistral-large-4-0`. On 2026-10-31 the `mistral-large-latest` alias is still
  listed on the Large 3 page, not on the Large 4 page [mistral-large-4-docs, mistral-large-3-docs].
- **Speculative decoding.** The checkpoint has an embedded DSpark draft head (three draft layers that propose blocks of
  three tokens). Mistral measured up to 1.9 times the throughput and says the target outputs do not change. Enable it with
  a vLLM `--speculative-config` of method `dspark` and three speculative tokens, or SGLang's
  `--speculative-algorithm DSPARK` [hf-large-4].

### Migrating from the previous generation

- **Large 3 and Medium 3.5 are deprecated.** Mistral's deprecation table, read on 2026-10-31, gives both a deprecation
  date of 2026-10-31 and a retirement date of 2027-04-30, with Large 4 as the alternative [mistral-models-overview].
- **Reasoning is new for the Large class.** Large 3 had no reasoning control. Medium 3.5 and Small 4 take `none` and
  `high`; Large 4 takes `low`, `medium` and `high`, so code that sends `none` must change [hf-large-4-template].
- **Sampling.** Change temperature from below 0.1 (Large 3) to 1.0, and set top-p to 0.95 [hf-large-4].
- **Context.** 256k tokens on Large 3 [mistral-large-3-docs] and Medium 3.5 ([its file](mistral-medium-3-5.md)); 1M tokens
  on Large 4 [mistral-large-4-docs].
- **Price.** $0.70 in and $2.10 out per million tokens, against $0.50 and $1.50 for Large 3 [mistral-large-4-docs; Large 3 price from
  [its file](mistral-large-3.md), read 2026-10-03].
- **Licence.** Large 3 was Apache-2.0. The Large 4 licence is a modified MIT licence. A licensee whose group operates a
  Model-as-a-Service business must sign a commercial licence with Mistral before it uses the model or its derivatives
  for any commercial purpose. The licence defines that business as giving third parties inference or post-training
  access with meaningful control over inputs, parameters or training data. It excludes end-user products whose model
  capabilities are solely embedded in specific features or harnesses, and the plain relaying of requests to models that others host. Internal use,
  and use through Mistral's official products, are outside the condition [hf-large-4-license]. This is a summary, not
  legal advice. The revenue condition of the Medium 3.5 licence is not in this licence.
- **Hardware.** The vLLM example uses eight-way tensor parallelism on one node; the NVFP4 checkpoint targets Blackwell GPUs
  and its SGLang example uses four-way tensor parallelism. NVFP4 needs `--kv-cache-dtype fp8_ds_mla` under vLLM
  [hf-large-4, hf-large-4-nvfp4]. The card recommends Mistral's API if local serving is poor.

## What the system card reports

Mistral publishes no system card for Large 4. The launch post says a full technical report is coming. The model card
gives settings, serving commands, a licence and benchmark charts [mistral-large-4-post, hf-large-4]. The launch post
gives these safety claims, all from Mistral (class L):

- **Cyber refusals.** An average refusal rate of 96.6% on the cyber prompts of JailbreakBench, StrongREJECT and AgentHarm.
  Mistral calls this the highest it measured among open models [mistral-large-4-post].
- **Cyber capability.** 51% on the Artificial Analysis Cyber Index, which Mistral reports with the claim that the model
  does defensive work without unnecessary refusals [mistral-large-4-post].
- **Observed risk.** Mistral says it monitored cyber-related traffic during the preview. It saw the model refuse
  black-box attacks against live targets, but it sees a potential uplift for real attacks. It is changing its guardrails
  and will continue to update them [mistral-large-4-post].
- **Restricted variant.** Selected enterprise partners get preview access to a cyber-specialised variant for
  penetration testing and red-teaming, after vetting and under contract, for owned or authorised systems only
  [mistral-large-4-post].
- **Agent security.** 97.1% attack resistance on the B3 benchmark, as above [mistral-large-4-post].

No document reports over-refusal outside cyber, reward hacking, sycophancy, deception, sandbagging or biology
evaluations. Artificial Analysis's coding-agent run records no refusals in 870 attempts at `high`, and a
reward-hacking flag rate of 0.3% on FrontierCode v1.1 and 1.5% on Terminal-Bench 4.0 (class M) [aa-coding-agents]. The
open weights carry no hosted guardrail: Mistral's separate moderation model and the `guardrails` request block apply on
its API only (see the [Mistral page](README.md#api-surface)).

## Behaviour observed in practice

- Artificial Analysis rates Large 4 (high) above the average intelligence of open-weight models of similar size, fast at
  161.3 output tokens a second, and somewhat verbose (class M) [aa-large-4].
- No independent hands-on report was found by 2026-10-31.

## Benchmarks

Independent (Artificial Analysis, class M):

- Intelligence Index v5.0: 26 at `high`, rank 9 of 22 in its comparison group; $2.06 per index task; 110 million output tokens
  [aa-large-4]. Artificial Analysis dates this model 2026-10-29 and lists the 2026-10-06 preview as a separate,
  deprecated entry.
- Coding Agent Index v2.0 in Mistral Vibe: 48.3 at `high` (FrontierCode v1.1 44.5, Terminal-Bench 4.0 41.4,
  SWE-Atlas-QnA 58.9) and 35.4 at `medium` [aa-coding-agents].
- Terminal-Bench 4.0 inside the Intelligence Index: 24.7 at `high`. This is a different setup from the Coding Agent
  Index run, so the two Terminal-Bench numbers are not comparable [aa-large-4].
- Scale's SWE-Bench Pro (public V2), METR's time horizons and the tbench.ai Terminal-Bench 4.0 board hold no entry for
  it on 2026-10-31 [scale-swe-pro-v2, metr-horizons, tbench-4-leaderboard].

Maker-reported (Mistral's launch post and card, class L): FrontierCode 2.0 (Cognition's private benchmark) 19.7%;
Terminal-Bench 4.0 41%, which Mistral says is 13 points above the preview with 30% fewer output tokens; Artificial
Analysis Coding Agent Index 48%; Intelligence Index v5 26; Cyber Index 51%; FinWorkBench (Finch) 73.3%; BrowseComp
84.5% [mistral-large-4-post, hf-large-4]. The post also reports blind code-preference tests by Surge. The post does not
state the effort level or harness for most of these numbers.
