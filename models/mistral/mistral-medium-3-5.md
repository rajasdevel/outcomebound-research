# Mistral Medium 3.5

Mistral Medium 3.5 is a dense 128-billion-parameter model with open weights under a modified MIT licence, released on
2026-04-28. It is the Medium class's generation 3.5 and merges instruction following, reasoning and coding into one
model with a per-request reasoning switch. It replaced Mistral Medium 3.1 and the Magistral models in Le Chat and
Devstral 2 in the Vibe coding agent. Rules shared by Mistral's models (API parameters, thinking chunks, aliases,
serving libraries) are on the [Mistral page](README.md); this file says what is specific to Medium 3.5.

## How to instruct it

Mistral's guidance for this model is one model card, one launch post, the reasoning page and the general prompting page.
There is no dedicated prompting guide and no coding-agent guide.

### Setting up the prompt

- **System prompt.** The card says the model follows system prompts closely [hf-medium-3-5]. The repository ships a
  `SYSTEM_PROMPT.txt` that casts the model as the engine behind the Le Chat assistant, with `{today}` and `{yesterday}`
  placeholders; Mistral's example code fills them in before use. The file tells the model to use tools when
  information may be stale or missing, to take care with dates, and states a knowledge cut-off of 2024-11-01 and that it
  reads images but not audio or video [medium-system-prompt, hf-medium-3-5]. Using it is optional; an application can
  write its own.
- **General advice.** Mistral's prompting page recommends a role line, few-shot examples as made-up turns, hierarchical
  sections written for a reader with no context, objective wording, and decision trees for conflicting rules
  [mistral-prompting-docs].
- **Style, tags, long documents.** The prompting page calls Markdown or XML-style tags ideal for marking sections
  [mistral-prompting-docs]. Mistral gives no guidance on where to place long documents.
- **Languages.** The card's metadata lists 24 language codes and its text says dozens, including English, French, Spanish,
  German, Italian, Portuguese, Dutch, Chinese, Japanese, Korean and Arabic [hf-medium-3-5].

### Reasoning and effort

- **The control.** `reasoning_effort` takes `none` or `high`. `none` gives an instant reply without reasoning; `high` uses
  test-time compute and is the card's recommendation for complex prompts, agentic use and agentic coding; Mistral's
  reasoning page says that with `none` the model thinks minimally and returns no thinking chunk [hf-medium-3-5,
  mistral-reasoning-docs]. Mistral does not state the default when the parameter is omitted.
- **Sampling by mode.** `high`: temperature 0.7, top-p 0.95. `none`: temperature 0.0 to 0.7 by task (the card's own example
  uses 0.1), and top-p left unset or at 1.0 [hf-medium-3-5].
- **Thinking is returned.** With `high` the content is a list of a thinking chunk and a text chunk; with `none` it is a plain
  string. Mistral says to replay the full assistant message, thinking chunk included, in later turns, and that removing
  it lowers quality [mistral-reasoning-docs]. Under vLLM `--reasoning-parser mistral` puts thinking in `message.reasoning`
  [hf-medium-3-5].
- **Cost of thinking.** Artificial Analysis counted 100 million output tokens to run its index; per task 26,000 output
  tokens, 14,000 of them reasoning; time to first token 2.23 s and 14.44 s to the first answer token
  [aa-medium-3-5, aa-compare-1-3-max-vs-medium].
- **Step-by-step prompting.** Mistral says nothing; the reasoning switch is the documented way to buy more reasoning.

### Output: format, length, tone

- No verbosity or length control is documented. Mistral lists prefix completion and predicted outputs as supported on the
  model page; the page read does not explain them [mistral-medium-docs].
- Output speed on Artificial Analysis was 163.7 tokens a second, 7th of the 65 models in its listing for this class
  [aa-medium-3-5].
- No tone guidance is published; the system prompt file covers dates, tools and capabilities, not style
  [medium-system-prompt].

### Tools and agents

- **Definitions and choice.** OpenAI-style function tools; `tool_choice` accepts `auto`, `none`, `any` and `required`;
  `parallel_tool_calls` defaults to true; each call's `id` returns as `tool_call_id` [mistral-function-calling-docs,
  mistral-chat-api]. Mistral advises a clear system prompt saying how to use the tools, and calling the model again after
  each tool result until it answers [mistral-function-calling-docs].
- **What Mistral claims.** The launch post presents long tasks, dependable multi-tool calling and machine-readable
  structured output as the model's design goals, and credits it with making Vibe's asynchronous cloud agents workable
  [mistral-vibe-post]. In Le Chat's Work mode the agent runs several tools at once and, depending on permissions, waits
  for the user's approval before steps such as sending a message, writing a document or changing data
  [mistral-vibe-post].
- **Built-in tools and agents.** The model page lists agents, conversations and built-in tools [mistral-medium-docs].
- **Serving.** vLLM needs `--tool-call-parser mistral --enable-auto-tool-choice` [hf-medium-3-5].
- **Remote and local agents.** Remote Vibe sessions run in isolated sandboxes, many in parallel, with file diffs and tool
  calls visible, and can end with a pull request and a notification; a local session can be moved to the cloud with its
  history and approvals [mistral-vibe-post].

### Coding

- **Maker claims.** 77.6% on SWE-Bench Verified, ahead of Devstral 2 and Qwen3.5 397B A17B in Mistral's comparison, and 91.4
  on tau3-Telecom; Mistral says the model beats all its Devstral models on every benchmark it ran. The scaffold and
  settings are not stated, and the comparison charts are images [hf-medium-3-5, mistral-vibe-post].
- **Independent.** Artificial Analysis's Terminal-Bench 4.0 run resolved 0% of tasks, and its index is 14. No Coding Agent
  Index, Scale SWE-Bench Pro or METR figure exists [aa-compare-1-3-max-vs-medium, scale-swe-pro-v2, metr-horizons].
- **Harness.** Medium 3.5 is the default model in Vibe. The card's example for a local vLLM server in Vibe sets the model
  to `thinking = "high"`, temperature 0.7, a compaction threshold of 168,000 tokens and a bash timeout of 1,200 seconds
  [hf-medium-3-5]. Vibe reads `AGENTS.md` and skill folders only for trusted directories, as set out on the [Mistral
  page](README.md#prompting-guides) [mistral-vibe-readme].
- **Reviewer.** One reviewer notes that the chart shows the model trailing a Claude model badly on a banking scenario while
  leading on coding and telecom (class A) [decoder-medium-3-5].

### Long context and retrieval

- Context is 256k tokens; Artificial Analysis's model-page summary says 260k and OpenRouter lists 262,144. No maximum
  output is published [mistral-medium-docs, aa-medium-3-5, openrouter-medium-3-5].
- Artificial Analysis's long-context reasoning test scored it 69% [aa-compare-1-3-max-vs-medium].
- **A known fault.** The Transformers config once carried a wrong entry that degraded long-context quality. It is fixed, and
  GGUF files and other frameworks that read that config need the fixed one [hf-medium-3-5].
- Mistral's API reference says cached input tokens are billed at 10% of the input price, which makes $0.15 per million
  tokens for this model (Artificial Analysis shows the same), and offers a `prompt_cache_key` for requests that share a
  prefix; no other cache mechanics are documented [mistral-chat-api, aa-medium-3-5, mistral-pricing].

### Structured output

- The model page lists structured outputs; `response_format` takes `json_object` or `json_schema`. Mistral recommends custom
  schemas over JSON mode where possible, says JSON mode still needs a prompt that asks for JSON and describes the format, and
  recommends iterating on the prompt either way [mistral-structured-docs, mistral-chat-api]. The card advertises native
  function calling and JSON output.

### Images, audio, other inputs

- Image and text input, text output. The vision encoder was trained from scratch for variable image sizes and aspect ratios
  [hf-medium-3-5]. No limits on image count, size or tokens are published for this model, and the docs' vision page lists
  older models. Document question answering works through OCR followed by the model [mistral-medium-docs,
  mistral-vision-docs]. No audio or video input.

### Sampling and API parameters

- See the sampling-by-mode lines above. The API reference recommends a temperature from 0.0 to 0.7 and lists `top_p`,
  `random_seed`, `stop`, penalties, `prediction` and `safe_prompt` [mistral-chat-api]. Whether `n` works for this model
  is not stated; Mistral says it does not for Large 3.

### Migrating from the previous generation

- **One model for three.** Medium 3.1, Magistral and Devstral 2 are replaced by this model, which Mistral says does better
  at instruction following, reasoning and coding than those. Medium 3.1 retired on 2026-08-31 and Devstral 2 and the
  Magistral 1.2 models on 2026-07-31, so their ids now return 404 [hf-medium-3-5, mistral-deprecations].
- **Reasoning.** What was a separate Magistral model is now `reasoning_effort="high"`, and thinking arrives as a chunk list that
  must be replayed. The API reference still lists a `prompt_mode` value of `reasoning`; whether it applies here is not stated.
- **Aliases.** `mistral-medium-latest` points to the newest General Availability model across generations, so it may already
  point here and may change again; the pinned id is `mistral-medium-3-5` [mistral-lifecycle].
- **Licence and cost.** The weights moved to a modified MIT licence with a revenue threshold (see below). API price is $1.50 input
  and $7.50 output per million tokens [mistral-medium-license, mistral-vibe-post].
- **Hardware.** A dense 128-billion-parameter model is heavier to self-host than the mixture-of-experts Small 4: the card shows
  eight-way tensor parallelism, the launch post says as few as four GPUs, and a reviewer calls even four out of reach
  for most (class A) [hf-medium-3-5, mistral-vibe-post, decoder-medium-3-5].

## What the system card reports

Mistral publishes no system card or safety report for Medium 3.5. The Hugging Face model card (the closest document) holds
recommended settings, serving commands, two benchmark figures and a licence, and no safety evaluation; the docs page holds
no benchmark or safety information [hf-medium-3-5, mistral-medium-docs]. Consequently nothing is published by the lab on
refusals and over-refusal, reward hacking or test special-casing, sycophancy, deception, sandbagging, prompt-injection
resistance, or cyber and biology safeguards. The safeguards Mistral names are product-level: remote agents run in isolated
sandboxes, Le Chat asks approval before sensitive actions, and its separate moderation model and request guardrails can block
an input (HTTP 403) when an application configures them [mistral-vibe-post, mistral-guardrailing-docs]. The licence
withholds its rights from companies with global monthly revenue above $20 million, who can ask Mistral for a commercial
licence [mistral-medium-license]. Mistral's AI governance hub lists Medium 3.5 as a version of the Medium 3 family,
classed as a general-purpose AI model and released on 2026-04-29, and links no technical documentation for it
[mistral-governance-medium-3]. The one independent signal is Artificial Analysis's AA-Omniscience index of -37, on a
scale that penalises wrong answers [aa-compare-1-3-max-vs-medium].

## Behaviour observed in practice

- Speed and cost on Artificial Analysis's index: 163.7 tokens a second, 2.23 s to the first token, $0.50 per index
  task, 26,000 output tokens a task (class M, Artificial Analysis) [aa-medium-3-5, aa-compare-1-3-max-vs-medium].
- Low scores on Artificial Analysis's agentic components: Terminal-Bench 4.0 0%, AutomationBench 6%, CritPt 0% (class M)
  [aa-compare-1-3-max-vs-medium].
- Reviews found were derived from Mistral's launch material. One, written from the launch announcement, notes that Mistral
  published no MMLU, GPQA, AIME, HumanEval or MATH numbers; none reports tool-call failures, latency or long-context
  measurements [devto-medium-3-5, decoder-medium-3-5].
- Self-hosting reports: none independent were found beyond the card's own fault notice.

## Benchmarks

Independent (Artificial Analysis, class M, index v4.3.2, reasoning mode):

- Components: AA-Briefcase 519, GDPval-AA v2.1 764, AutomationBench-AA 6%, Terminal-Bench 4.0 0%, SciCode 40%, Humanity's
  Last Exam 14%, GDP.pdf 3%, CritPt 0%, AA-Omniscience -37, AA-LCR 69% [aa-compare-1-3-max-vs-medium].
- Scale's SWE-Bench Pro (public V2) board, METR's time horizon and the tbench.ai board hold no entry for it
  [scale-swe-pro-v2, metr-horizons, tbench-4-leaderboard].

Maker-reported: SWE-Bench Verified 77.6% and tau3-Telecom 91.4 (vendor runs; harness and settings not stated)
[hf-medium-3-5].
