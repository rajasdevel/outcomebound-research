# Mistral Small 4

Mistral Small 4 is an open-weight mixture-of-experts model (Apache-2.0) with 119 billion parameters, about 6.5 billion of
them active per token, released on 2026-03-16. It is the Small class's generation 4 and merges Mistral's instruct, reasoning
(Magistral) and Devstral lines into one multimodal model with a per-request reasoning switch. It replaced Mistral Small 3.2
and the Magistral Small models. Rules shared by Mistral's models are on the [Mistral page](README.md); this file says what
is specific to Small 4.

## How to instruct it

Mistral's guidance is its model card, launch post, a vLLM recipe, the reasoning page and the general prompting page. It
publishes no dedicated prompting or coding-agent guide for Small 4.

### Setting up the prompt

- **System prompt.** The card says the model adheres strongly to system prompts. The repository's `SYSTEM_PROMPT.txt` names the
  model, casts it as the assistant behind Le Chat, takes `{today}` and `{yesterday}` placeholders, says to use tools for
  uncertain or time-sensitive requests, to ask for clarification when a request lacks context, to answer in the user's
  language, and states a knowledge cut-off of 2024-11-01 and that it reads images but not audio or video
  [hf-small-4, small-system-prompt]. Using the file is optional.
- **Intended and restricted use.** Mistral's technical documentation for downstream providers lists instruct, coding and
  reasoning tasks, retrieval-augmented generation and function calling in eleven named languages, and says the model is
  not meant for critical decisions with significant real-world impact without prior validation and human oversight
  [mistral-td-small-4].
- **General advice.** A role line, few-shot examples as made-up turns, hierarchical sections written for a reader with no
  context, objective wording and decision trees for conflicting rules [mistral-prompting-docs].
- **Style, tags, long documents.** The prompting page calls Markdown or XML-style tags ideal for marking sections
  [mistral-prompting-docs]. Mistral gives no guidance on where to place long documents.
- **Languages.** The card says it covers dozens, including English, French, Spanish, German, Italian, Portuguese, Dutch,
  Chinese, Japanese, Korean and Arabic [hf-small-4].

### Reasoning and effort

- **The control.** `reasoning_effort` per request, `none` or `high` only; the vLLM recipe says no other value is accepted.
  `none` is described as equivalent to the chat style of Mistral Small 3.2 (a 24-billion-parameter instruct model); `high` as deep
  step by step reasoning with the verbosity of the earlier Magistral models. Mistral recommends `high` for complex
  problems [hf-small-4, vllm-small-4-recipe]. The default when omitted is not stated.
- **Sampling.** Temperature 0.7 with `high`, and 0.0 to 0.7 with `none` by task complexity. The card gives no top-p
  for this model [hf-small-4].
- **Thinking.** With `high` the content is a thinking chunk followed by a text chunk, and Mistral says to replay the full
  message into the history. `mistral-small-latest` is one of the ids Mistral's reasoning page lists for the parameter. Under vLLM
  `--reasoning-parser mistral` is needed [mistral-reasoning-docs, hf-small-4].
- **Efficiency claims.** Mistral says that in reasoning mode the model matches or exceeds GPT-OSS 120B on three benchmarks
  (AA-LCR, LiveCodeBench and AIME 2025, per its chart names) while writing shorter outputs: a score of 0.72 on AA-LCR with about 1,600 characters, where Qwen models need 3.5 to 4 times
  more, and 20% less output than GPT-OSS 120B on LiveCodeBench [hf-small-4, mistral-small-post]. Artificial Analysis counted
  54 million output tokens to run its index, and 14,000 output tokens a task [aa-small-4, aa-compare-large-small].
- No source discusses step-by-step prompting; the switch is the documented route.

### Output: format, length, tone

- No verbosity or format control is documented. Predicted outputs and prefix completion are listed on the model page, without
  explanation in the page read [mistral-small-docs].
- Output speed on Artificial Analysis was 176.7 tokens a second with 0.71 s to the first token and 12.03 s to the first
  answer token [aa-small-4, aa-compare-large-small].

### Tools and agents

- Function calling is native; the card calls the model strongly agentic. `tool_choice`, `parallel_tool_calls` and the `tool_call_id`
  rules are on the [Mistral page](README.md#family-wide-behaviour). vLLM needs `--tool-call-parser mistral
  --enable-auto-tool-choice` and, per the vLLM recipe, vLLM 0.20.0 or later for tool and reasoning parsing; Mistral provides a
  patched image for older versions [hf-small-4, vllm-small-4-recipe].
- Mistral gives no tool-count advice for this model (Large 3's card says to keep tools few) and no long-horizon or
  context-management guidance. Agents, conversations and built-in tools are listed on the model page [mistral-small-docs].
- Mistral's launch post lists SWE automation and codebase exploration among intended uses [mistral-small-post].

### Coding

- Mistral's only coding claim is that the model beats GPT-OSS 120B on LiveCodeBench while writing about 20% less; there is no
  score in text and no SWE-Bench figure. Artificial Analysis's Terminal-Bench 4.0 run resolved 0% of tasks and its index
  is 11 [hf-small-4, aa-compare-large-small].
- The card says the model merges the Devstral coding line into itself, but Mistral's retirement table points Devstral Small 1.1
  to Small 4 and Devstral 2 to Medium 3.5, so Medium 3.5 is the model Mistral names for agentic coding [hf-small-4,
  mistral-deprecations].

### Long context and retrieval

- 256k tokens, reached by YaRN scaling from an 8k base. On two H200 GPUs a full 256k context can run out of memory,
  and the vLLM recipe suggests `--max-model-len 131072` or the NVFP4 build [vllm-small-4-recipe]. Mistral's technical
  documentation gives 256k tokens as the maximum size of text input and of text output [mistral-td-small-4].
- Cached input tokens are billed at 10% of the input price per Mistral's API reference, $0.015 per million tokens here
  (Artificial Analysis shows the same) [mistral-chat-api, aa-compare-large-small].
- Artificial Analysis's long-context reasoning test scored it 50% [aa-compare-large-small]; Mistral's 0.72 on its own AA-LCR run
  is a vendor figure on a different scale [hf-small-4].
- No output cap separate from the context window is published.

### Structured output

- Structured outputs, JSON mode and custom schemas work as on the [Mistral page](README.md#family-wide-behaviour); the card
  advertises native function calling and JSON output [hf-small-4, mistral-small-docs].

### Images, audio, other inputs

- Image and text in, text out. Mistral's card says it analyses images and extracts insights. Mistral gives no image-count
  or size limit; its technical documentation counts image input against the 256k-token window, and the vLLM recipe
  describes the encoder as Pixtral-style at 1540 by 1540 pixels with 14-pixel patches [hf-small-4, mistral-td-small-4,
  vllm-small-4-recipe]. Large 3's advice to keep aspect ratios near 1:1 is stated for that model only. The docs'
  vision page predates Small 4 and lists Small 3.2 [mistral-vision-docs]. No audio or video input.

### Sampling and API parameters

- See above for temperature by mode. `reasoning_effort` accepts only `none` and `high`. Model-page capabilities include batching
  at half price; the API id is `mistral-small-2603` and `mistral-small-latest` points to the newest General Availability Small
  [mistral-small-docs, mistral-lifecycle, mistral-batch-docs].
- Self-hosting extras: an EAGLE draft head for speculative decoding and an NVFP4 4-bit build [hf-small-4].

### Migrating from the previous generation

- **From Small 3.2 and Magistral Small.** Both retired on 2026-07-31, so their ids return 404. `reasoning_effort="none"` gives the Small 3.2
  chat style and `"high"` gives Magistral-style reasoning in one model [mistral-deprecations, hf-small-4].
- **Architecture.** A 119-billion-parameter mixture of experts with 128 experts and 4 active replaces a 24-billion dense model, so memory
  needs rise (two H200, B200 or MI300X GPUs per the vLLM recipe; four H100, two H200 or one B200 at minimum per
  Mistral's technical documentation, which recommends 16 H200 split between prefill and decode) while compute per token
  is lower [vllm-small-4-recipe, mistral-td-small-4].
  Mistral claims 40% less completion time in a latency-optimised setup and three times the requests per second in a
  throughput-optimised setup against Small 3 [hf-small-4].
- **Thinking format.** Thinking arrives as chunks that must be replayed [mistral-reasoning-docs].
- **Price.** $0.15 input and $0.60 output per million tokens [mistral-small-docs].

## What the system card reports

Mistral publishes no system card or safety report for Small 4. Its model card gives settings, serving commands, efficiency
claims and a licence, and no safety evaluation; the docs page gives capabilities and price [hf-small-4, mistral-small-docs].
Its AI-Act technical documentation (dated 2026-03-16, shared with the Leanstral model) gives limits, uses, hardware and a
general account of training data, which mixes public, licensed, synthetic and Mistral user data with an opt-out, and
says data is deduplicated and safety-filtered against Mistral's usage policy; it reports no evaluation results
[mistral-td-small-4]. Nothing from the lab covers refusals, over-refusal, reward hacking, sycophancy, deception, sandbagging, prompt injection or cyber and
biology safeguards. Product-level safeguards are Mistral's separate moderation model and the `guardrails` request block, which an
application must configure. The one independent signal is Artificial Analysis's AA-Omniscience index of -30, on a scale that
penalises wrong answers [aa-compare-large-small, mistral-guardrailing-docs].

## Behaviour observed in practice

- Speed and cost on Artificial Analysis's index: 176.7 tokens a second, 0.71 s to the first token, $0.02 per index task,
  14,000 output tokens a task of which 9,000 are reasoning; Artificial Analysis calls its 54 million index tokens very
  concise (class M) [aa-small-4, aa-compare-large-small].
- Low scores on Artificial Analysis's agentic components: Terminal-Bench 4.0 0%, AutomationBench 1%, CritPt 0%; ahead of Large 3 on five of ten components and behind on two
  (class M) [aa-compare-large-small].
- Memory pressure at full context on two H200 GPUs (vLLM recipe; class L) [vllm-small-4-recipe].
- No independent hands-on report was found beyond hosting guides that repeat the card.

## Benchmarks

Independent (Artificial Analysis, class M, index v4.3.2, reasoning mode): Intelligence Index 11, 54 million output tokens, $0.02
per task [aa-small-4]. Components: AA-Briefcase 237, GDPval-AA v2.1 366, AutomationBench-AA 1%, Terminal-Bench 4.0 0%, SciCode
39%, Humanity's Last Exam 10%, GDP.pdf 0%, CritPt 0%, AA-Omniscience -30, AA-LCR 50% [aa-compare-large-small]. Scale's SWE-Bench Pro
(public V2) board, METR's time horizon and the tbench.ai board hold no entry for it [scale-swe-pro-v2, metr-horizons,
tbench-4-leaderboard].

Maker-reported (vendor runs): AA-LCR 0.72 with about 1,600 characters of output; matches or exceeds GPT-OSS 120B on three
benchmarks with shorter outputs; beats it on LiveCodeBench with 20% less output; no numbers for the last two [hf-small-4].
