# Higgs TTS 3

Higgs TTS 3 is an open-weight speech synthesis model of Boson AI, class Higgs TTS, generation 3. Boson released it on 2026-06-04, with about 4B parameters, 102 languages and zero-shot cloning. It is a voice actor model: 43 inline control tags set emotion, style, speed, pitch, pauses and vocalised sound effects inside the text. It follows Higgs TTS 2, the earlier open model, which has no control tags. The Higgs Realtime model of the same maker is a different class and has its own [file](higgs-realtime.md). Maker-wide facts are in the [Boson README](README.md).

## How to instruct it

### Setting up the prompt

- **The text is the prompt.** The model has no system prompt and takes no free-form instruction. Direction comes from tags inside `input`. Every tag has the form `<|category:value|>` [boson-tts-tags] [hf-higgs3-prompting].
- **Closed tag set.** The maker lists 43 tags and says that only those are recognised; an unlisted tag lowers quality or is read aloud [hf-higgs3-prompting]. The groups are:
  - 21 emotions: affection, amusement, anger, arousal, awe, bitterness, confusion, contemplation, contentment, determination, disgust, elation, enthusiasm, fear, helplessness, longing, pride, relief, sadness, shame and surprise.
  - 3 styles: singing, shouting and whispering.
  - 9 sound effects: cough, laughter, crying, screaming, burping, humming, sigh, sniff and sneeze. The maker says these are voiced by the speaker and are not mixed-in sound files.
  - 10 prosody tags: four speeds (very slow, slow, fast, very fast, about 0.65, 0.85, 1.2 and 1.4 times), low and high pitch (about minus 3 and plus 2.5 semitones), pause (about 400 to 700 ms), long pause (about 700 to 1,500 ms), and high and low expressiveness [boson-tts-tags].
- **Placement.** Emotion, style, speed, pitch and expressiveness tags colour a whole sentence, so the maker says to put them at the start of the sentence or turn. Pauses and sound effects are positional and go where the event should fall [boson-tts-tags] [hf-higgs3-prompting].
- **Sound effects need a written sound.** The tag comes first. The matching written sound follows it with no space. Examples: a laughter tag followed by Haha, or a cough tag followed by Ahem. The written sound gives the model its acoustic cue [boson-tts-tags] [hf-higgs3-prompting].
- **Stacking.** A sentence can carry one emotion tag and one sound-effect tag together [hf-higgs3-prompting].
- **Examples in our words.** An enthusiasm tag at the head of a welcome line, and a pause tag before the second sentence, give a bright opening with a beat in the middle. A sadness tag then a crying tag then I... I'm sorry is the maker's own crying example [boson-tts-tags].
- **Strength.** The maker's guide says the slowest speed tag slows the model only to about 5 s, and gives no unit of comparison. For slower delivery, the guide says to put long-pause tags between phrases. The speed tags are approximate: about 0.65 to 1.4 times [hf-higgs3-prompting] [boson-tts-tags].

### Reasoning and effort

None. The model has no reasoning or effort control. It is a speech synthesis model.

### Output: format, length, tone

- **Formats.** The hosted API returns mp3 (the default), opus, pcm, wav, aac or flac. Streaming needs `pcm`. A request can also return word timestamps for English, Chinese and Spanish, in a JSON envelope with base64 audio [boson-api-speech] [boson-tts-overview].
- **Length.** The API accepts 5,000 characters, and Boson recommends about 300 per request. Long text therefore goes out as sentences or short paragraphs, one request each (inferred from that advice) [boson-api-speech].
- **Tone.** Tags set tone, as described above. The reference clip also carries tone and accent. The maker says to use a clip with the target accent, such as British English. Language and accent follow the text and the clip [boson-tts-languages].
- **Text normalisation.** On by default (`enable_tn`). It turns numbers, dates, times, currency, units, URLs, email addresses, phone numbers, abbreviations and symbols into spoken words, and leaves tags alone. Setting it to false reads the text as written. It auto-detects 14 languages; set `tn_language` for others and for short or mixed text. It does not run when timestamps are requested [boson-tts-overview] [boson-api-speech].

### Tools and agents

Not applicable. The model does not call tools. Boson points to Higgs Realtime for conversational agents [boson-tts-overview].

### Coding

Boson gives no coding guidance. The self-hosted servers expose the same `/v1/audio/speech` route as the hosted API, so a client written for one can target the other [hf-higgs3] [boson-api-speech].

### Long context and retrieval

Not applicable. The weights were trained with sequences of 8,192 tokens, which sets the practical length of one generation. Boson says longer text is not yet reliable [hf-higgs3] [boson-api-speech].

### Structured output

Not applicable.

### Images, audio, other inputs

The model takes text, and optionally a reference clip with its transcript for cloning. Passing the transcript in `ref_text` often improves quality. A reference voice can be registered once and reused by id. The API does not accept a preset `voice` together with `ref_audio` in one request [boson-tts-voices] [boson-api-speech].

### Voice: turn-taking, interruption and speech style

Turn-taking does not apply. Higgs TTS 3 renders text to speech and does not manage a conversation [boson-tts-overview].

**How to direct delivery.** The tag set described under "Setting up the prompt" is the direction mechanism. The tags are discrete tokens, not free text. The tags do not take prose. You pick one emotion tag for each sentence, and a style or prosody tag next to it [boson-tts-tags].

**Voice design.** The model has no description-to-voice feature. Voice comes from six preset voices or from a cloned reference clip. Boson describes each preset in one line, for example a calm, narrative female voice or an energetic male voice with a slightly dramatic tone [boson-tts-voices].

**Multi-speaker dialogue.** The pages read give no dialogue syntax for the open model. A dialogue is therefore one request per speaker turn, each with its own voice (inferred) [boson-api-speech].

**Long-form consistency.** The pages read give no guidance. The practical limit is the 300-character recommendation per request. The same reference clip and voice id on every request keep the voice stable (inferred).

**Pronunciation and normalisation.** Text normalisation is on by default and is the only pronunciation control documented. No phoneme or lexicon feature is documented [boson-tts-overview].

**Latency.** Boson's card says streaming on a self-hosted SGLang-Omni server reaches sub-second time to first audio, and gives a throughput table measured on one H100. The hosted API states no latency figure [hf-higgs3].

**Hosted or self-hosted.** The hosted API is compatible in shape with the self-hosted servers. The hosted account needs the free trial credit claimed before the first call [boson-tts-overview].

### Sampling and API parameters

Hosted API fields: `input`, `model`, `voice`, `response_format`, `stream`, `ref_audio`, `ref_text`, `enable_tn`, `tn_language`, `timestamps` and a speed adjustment that streaming does not support [boson-api-speech]. The self-hosted example passes `temperature` 0.8, `top_k` 50 and `max_new_tokens` 1024 [hf-higgs3].

### Migrating from the previous generation

Higgs TTS 2 (Hugging Face `bosonai/higgs-tts-2-3b-base`, released 2025-07-01) is a 3B base model that Boson renamed from Higgs Audio v2. Its card shows no control tags. It steers by text meaning, a reference clip, `[SPEAKER*]` tags for dialogue and a `scene` message that describes the recording setting and the gender of each speaker. The card gives no delivery direction such as emotion or style. A Higgs TTS 2 integration that relied on those must switch to the tag syntax above. Boson's table reports word error rates for the two models. On the 32-language MiniMax-Multilingual set, Higgs TTS 2 scores 49.86 and Higgs TTS 3 scores 2.74. On 13 languages of CV3, they score 21.19 and 4.41 [hf-higgs2] [gh-higgs] [boson-blog-tts3]. Higgs TTS 2 is not given a file here because it has no direction by tag or instruction.

## What the system card reports

Boson publishes no system card for Higgs TTS 3. The weights page holds a licence and use limits. It bans cloning without consent, impersonation, fraud, election deception and biometric surveillance. It says AI audio must be disclosed where the law requires it [hf-higgs3].

## Behaviour observed in practice

- **Rank (M).** Artificial Analysis lists the model, as Higgs Audio V3 TTS, at Elo 1036.42 (page headline; the leaderboard data in the same page gives 1037.9). It is eighth of the open-weight models in that data in its speech arena [aa-higgs3].
- **Reproduction (L).** Boson says the SGLang-Omni team reproduced its results [boson-blog-tts3].
- No practitioner report was read.

## Benchmarks

Independent: Artificial Analysis Speech Arena Elo 1036.42 (the page data gives 1037.9) [aa-higgs3]. Maker (Boson's own runs): on EmergentTTS-Eval the overall win rate is 53.65 percent, and for emotions 53.75 percent. Boson ran the comparison models and used no tags. On SeedTTS the word error rate is 1.11 [boson-blog-tts3]. Boson does not report a test of how well the tags change delivery.
