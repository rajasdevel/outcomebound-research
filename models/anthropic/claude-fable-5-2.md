# Claude Fable 5.2

Claude Fable 5.2 is the successor to [Claude Fable 5.1](claude-fable-5-1.md) for demanding reasoning and
long-running agent work. Anthropic released it to all Claude API customers on 2026-11-09. Claude Mythos 5.2
uses the same underlying model with different safeguards and access limited to verified organizations. (L)
[release, overview, announcement]

## How to instruct it

### Setting up the prompt

The [maker README](README.md) covers shared prompt structure. For Fable 5.2, Anthropic advises stating
what completion requires, which actions require approval, and which constraints apply to the whole task.
It recommends a clear rule for when to continue past a routine obstacle. The model sometimes stops early
on multistep tasks, especially at `low` or `medium`. (L) [prompt]

### Reasoning and effort

Adaptive thinking is always active. Omit `thinking` or select `adaptive`. Manual thinking budgets
and `thinking: {"type":"disabled"}` return HTTP 400. Anthropic recommends starting an API evaluation
at `high`, the default, and testing `medium` for cost and speed or `xhigh` for difficult long-running work.
It reserves `max` for tasks where time and token cost matter little. At `high` and above, the model
deliberates before most replies. Anthropic found that asking it to answer without deliberation had little
effect at `medium` and above. The Claude apps and Claude Code default to `medium`. (L)
[new, effort, prompt, announcement]

### Output: format, length, tone

Anthropic recommends asking for the length, tone and report structure directly. It found that changing
effort had little effect on the length of replies. Assistant prefill is unsupported. During tool runs,
progress can arrive in `thinking` blocks, which have empty text with the default `display: "omitted"`.
The prompting guide describes `display: "summarized"` and the beta `display: "updates"` mode for clients
that render progress. (L) [migration, prompt]

### Tools and agents

`tool_choice` accepts `auto` and `none`. Forced choices `any` and `tool` return HTTP 400, including
on token counting. Computer use takes `computer_toolset_20260801`. Bedrock also accepts the older
`computer_20251124` tool. With the beta advisor tool, an executor on Fable 5.2 accepts only Fable 5.2 or
Mythos 5.2 as its advisor. Anthropic recommends specifying what a delegate should do, when it is worth
starting one, and which work stays with the main agent. (L) [new, migration, prompt]

### Coding

Anthropic advises making code ownership and edit scope explicit. In its tests, a prompt that assigned
broad ownership led to edits beyond the immediate change, and the final report sometimes omitted small
changes. The guide also advises testing harness prompts without a displayed token budget. Removing a large
budget in its coding tests at `high` and `xhigh` reduced cost with similar performance. (L) [prompt]

### Long context and retrieval

The Claude API offers a 1,000,000-token context window and up to 128,000 output tokens per synchronous
request. Anthropic lists a 512-token prompt caching minimum. The API binds returned thinking blocks to
their preceding request content and to the producing account or a linked account. On the Claude API and
Google-managed Google Cloud, Fable 5.2 can read thinking blocks produced by several earlier Claude models.
A switch from Fable 5.2 to a model outside the 5.2 pair drops its thinking blocks and the request still
succeeds. (L) [overview, new, migration]

### Structured output

Anthropic documents JSON outputs and strict tool schemas for Fable 5.2. Both are unavailable for this model
in organizations with customer-managed encryption keys. The migration guide advises validating tool inputs
in the client where that restriction applies. (L) [new, migration]

### Images, audio, other inputs

The model accepts text and images and returns text. (L) [overview]

### Sampling and API parameters

Anthropic advises omitting `temperature`, `top_p` and `top_k`. API version `2026-10-21` rejects
those fields even when they carry a default value. (L) [overview, migration, api-version]

### Migrating from the previous generation

Use `claude-fable-5-2` on the Claude API and `global.anthropic.claude-fable-5-2` on Bedrock's
`bedrock-runtime` route. By default, every account receives HTTP 400 if a request returns a Fable 5.2
thinking block after changing the preceding `system`, `tools` or messages. On Fable 5.1, the default
error applied to accounts created on or after 2026-08-31. Anthropic advises keeping history append-only,
sending assistant blocks back unchanged and using supported mid-conversation instructions or server-side
compaction. Its migration guide gives a temporary beta setting, `prefix_mismatch_behavior: "drop_block"`,
that continues without the affected blocks and reports them in `input_transformations`. Check model
switches, computer tool declarations and advisor compatibility before moving production traffic. (L)
[release, overview, migration]

## What the system card reports

Anthropic publishes a joint system card for the two configurations and describes their safeguards separately.
Anthropic found that Fable 5.2's safeguards and harmlessness were broadly comparable to Fable 5.1's.
It attributes a higher prompt-injection success rate in its agentic evaluations to more frequent
fallback. It found Fable 5.2 among its most robust models when it answered directly. (L) [system]

For Fable 5.2, the API reports a classifier refusal as HTTP 200 with `stop_reason: "refusal"` and a
`stop_details` object. The launch report says early tests across claude.ai, Claude Code and Cowork had
about 55 percent fewer classifier blocks than Fable 5.1. That result describes the tested product traffic.
(L) [system, announcement, new]

## Behaviour observed in practice

Artificial Analysis publishes Claude Code runs with named effort levels and default fallback, and
Terminal-Bench publishes a Claude Code run at `max`. These measurements apply to their stated harnesses
and settings. (M) [aa-agent, terminal]

## Benchmarks

Terminal-Bench 4.0 reports 65.76 percent at `max` in Claude Code over 330 trials. Artificial Analysis
reports its Intelligence Index v5.0.1 with default fallback. Its Coding Agent Index page data gives a
three-benchmark composite for Claude Code with default fallback. Fable 5.2 scores 58.47 out of 100 at
`xhigh` and 55.74 at `max`. The page labels its current index v2.1, while the embedded model rows
label the terminal component Terminal-Bench v4. (M) [terminal, aa, aa-agent]

Anthropic reports FrontierCode 2.0 at `xhigh` at 49.1 percent in its launch comparison. (L) [announcement]
