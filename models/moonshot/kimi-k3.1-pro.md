## How to instruct it

### Setting up the prompt

Moonshot's examples put the task in `messages`. The [family guide](README.md) holds the general prompt advice. L [quickstart].

### Reasoning and effort

Thinking is always on. Top-level `reasoning_effort` accepts `low`, `high` or `max`, with `max` the default. The complete assistant message, including reasoning and tool calls, goes back unchanged on continuation. L [effort].

### Output: format, length, tone

Streaming separates reasoning from final content. Partial Mode continues a supplied assistant prefix. No model-specific verbosity setting was verified. L [quickstart].

### Tools and agents

`tool_choice` supports `auto`, `none` and `required`. Tool results need their matching call ids, and the client retains the assistant's full message. L [parameters] [quickstart].

### Coding

Moonshot's Terminal-Bench 4.0 result used Claude Code at max effort. Its comparison rows combine published sources rather than one matched rerun. These results do not establish the best harness for a new workload. L [launch].

### Long context and retrieval

The pricing guide gives 1,048,576 tokens of context for K3-series models and separate cache-write billing, with a default five-minute retention. Vercel lists output up to 1,048,576 tokens, including reasoning, within shared prompt-and-response context. The direct API output ceiling remains unverified. L [pricing] [gateway].

### Structured output

Moonshot documents `json_object` and `json_schema`. Strict schemas follow its supported subset; parse the final `content`, not `reasoning_content`. L [format].

### Images, audio, other inputs

The quickstart shows base64 image parts and uploaded video ids. No audio input or output was established. L [quickstart].

### Sampling and API parameters

Moonshot applies K3's constraints to both K3.1 variants: temperature 1.0, top-p 0.95, one completion and zero penalties are fixed. Other values fail. The K2-only `thinking` object is removed. Switching effort invalidates prefix-cache hits. L [parameters].

### Migrating from the previous generation

The new model id retains the K3 parameter rules. K2.x clients also change the thinking control and preserve complete assistant messages. The [Highspeed variant](kimi-k3.1-pro-highspeed.md) has its own route prices. L [parameters] [models].

## What the system card reports

No separate system card was verified. Moonshot's launch blog reports removal of cyber-related mid-training data and RL tasks. On its internal xdev-bench-hard test, pass@3 fell from 90.5% without those measures to 81.0% in the final model. Runs had no hard timeout or output-token limit. This comparison measures capability in that setup, not refusal rates or deployment safety. L [launch].

## Behaviour observed in practice

No local model run or independent practitioner workflow was verified in this update. The maker's Highspeed equivalence claim is not an independent comparison. L [launch].

## Benchmarks

Artificial Analysis reports 46 on Intelligence Index v5.0; effort is not stated. This version differs from the v4.3.2 scores in older model files. M [aa]. The maker reports 65.7% on Terminal-Bench 4.0 with the settings above. L [launch]. No result is transferred to Highspeed. The card records the other required benchmark checks as unverified.
