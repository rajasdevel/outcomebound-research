# Step-Audio-EditX

Step-Audio-EditX is an open-weight 3B model of StepFun that edits the emotion, speaking style and paralinguistic sounds of speech, and also clones a voice zero-shot. It was trained with reinforcement learning on top of a large audio language model. It is a voice actor model that works by editing: you give a clip and ask for a change such as fearful, whisper or faster, and you can repeat the edit to strengthen it. StepFun released it on 2025-11-12 and added more tags on 2026-01-23. The hosted StepAudio 2.5 and StepAudio 3 realtime models of the same maker are separate, in this folder's [README](README.md).

## How to instruct it

### Setting up the prompt

- **Edit type and edit value.** The command-line tool takes `--edit-type` and `--edit-info`. Types: `clone` (zero-shot cloning with new text), `emotion`, `style`, `paralinguistic`, `denoise`, `vad` and `speed`. Each edit takes a source clip (`--prompt-audio`) and its transcript (`--prompt-text`) [hf-editx].
- **Emotion values.** Fourteen: happy, angry, sad, fear, surprised, confusion, empathy, embarrass, excited, depressed, admiration, coldness, disgusted and humour [hf-editx].
- **Speaking style values.** Thirty-two, including serious, arrogant, child, older, girl, pure, sister, sweet, exaggerated, ethereal, whisper, generous, recite, act_coy, warm, shy, comfort, authority, chat, radio, soulful, gentle, story, vivid, program, news, advertising, roar, murmur, shout, deeply and loudly [hf-editx].
- **Speed values.** faster, slower, more faster and more slower [hf-editx].
- **Paralinguistic tags in the text.** A tag goes where the sound should occur: sigh, inhale, laugh, chuckle, exhale, clears throat, snort, giggle, cough, breath, uhm, a confirmation sound, four surprise sounds, a dissatisfaction sound and five question sounds. The `paralinguistic` mode takes the tagged text [hf-editx].
- **Iterate.** An edit can run for several iterations, and each iteration writes its own file. For the whisper style the README says the iteration count should be above 1 to get better results [hf-editx].
- **Language and dialect tags.** A bracket tag before the text, such as Sichuanese, Cantonese, Japanese or Korean, selects the dialect or language [hf-editx].
- **Length.** The README advises audio under 30 seconds per inference [hf-editx].

### Reasoning and effort

None.

### Output: format, length, tone

- **Output.** One wave file per edit iteration.
- **Tone.** Edit type and value, repeated if needed.
- **Pronunciation.** For polyphonic Chinese characters, write the pinyin with a tone number in place of the character, for example guo4 in place of the character [hf-editx].

### Coding

The repository has command-line scripts, a Gradio demo, a Dockerfile and a 4-bit AWQ build for smaller GPUs. Since 2026-01-23 it also has vLLM training and inference support and GRPO training code. The SFT and PPO training code was not yet released at the time of the README [hf-editx].

### Long context and retrieval

Not applicable. The README advises clips under about 30 seconds [hf-editx].

### Structured output

Not applicable.

### Images, audio, other inputs

Text and audio. The edit tasks need a source clip and its transcript. Denoise and voice-activity edits need only the clip [hf-editx].

### Voice: turn-taking, interruption and speech style

Turn-taking does not apply.

**How to direct delivery.** Direction is an edit type and a value from the lists above, repeated to push the effect further. Direction by edit is iterative: each pass changes the clip a little more. The values are closed lists, not free text [hf-editx].

**Strength.** StepFun published a technical report and an edit benchmark (the Step-Audio-Edit-Benchmark, 2025-11-23). The pages read give no per-value score. The README has a table of edits applied to voices of four closed systems. For MiniMax-2.6-hd voices, average emotion accuracy over Chinese and English rises from 63.3 before editing to 74.9 after three iterations, and speaking-style accuracy rises from 44.2 to 65.8. The README says the effect grows with each iteration and that whisper needs more than one [hf-editx] [arxiv-editx].

**What fails.** Whisper needs more than one iteration. Clips over about 30 seconds are outside the advised range [hf-editx].

**Voice design and cloning.** Zero-shot cloning for Mandarin, English, Sichuanese and Cantonese. No voice design [hf-editx].

**Multi-speaker dialogue.** Not documented.

**Long-form consistency.** Not documented; the clip limit is about 30 seconds.

**Pronunciation and normalisation.** Pinyin replaces polyphonic characters [hf-editx].

### Sampling and API parameters

Command-line flags: `--model-path`, `--tokenizer-path`, `--prompt-text`, `--prompt-audio`, `--generated-text`, `--edit-type`, `--edit-info` and `--output-dir`. The pages read name no sampling flags [hf-editx].

### Migrating from the previous generation

StepFun's earlier open speech models, such as Step-Audio-TTS-3B (2025-02), were not read for this file. They are older than two generations of this class. The 2025-11-19 update of this model added polyphone control and better emotion, style and paralinguistic editing. The 2025-11-28 update added Japanese and Korean. The 2026-01-23 update added more tags [hf-editx].

## Behaviour observed in practice

- **Rank (M).** Artificial Analysis gives the March 2026 listing Elo 1092.01 on its page headline (1095.18 in the leaderboard data of the same page). It is third of the open-weight models in that data [aa-editx].
- **Competing maker's benchmark.** BreezeBlue's voice direction benchmark does not list this model [bb-blog2s].
- No practitioner report was read.

## Benchmarks

Independent: Artificial Analysis Elo 1092.01 (page headline; 1095.18 in the page data) [aa-editx]. Maker: the README's editing table (emotion accuracy 63.3 to 74.9 over three iterations on MiniMax-2.6-hd voices, averaged over two languages); the Step-Audio-Edit-Benchmark and the technical report figures were not read [hf-editx] [arxiv-editx].
