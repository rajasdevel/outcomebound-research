# StepAudio 2.5 Realtime

StepAudio 2.5 Realtime is StepFun's end-to-end speech-to-speech model of the 2.5 generation. It takes streaming audio or text and gives back streaming speech with a matching transcript, with no separate speech recognition or synthesis step. StepFun says it hears tone, hesitation and laughter as well as words. A reference site dates the release 2026-05-24 and the technical report was submitted on 2026-05-22. It is billed by token. The newer [StepAudio 3 Realtime](stepaudio-3-realtime-preview.md) is a free preview. Maker-wide facts are in the [StepFun README](README.md) [step-25-realtime] [step-paper-25] [llmreference-step25].

## How to instruct it

### Setting up the prompt

`instructions` on `session.update` sets the persona, speaking style and limits for the session. StepFun's page says session instructions can shape audio behaviour, such as short replies or a warm tone, and can keep a consistent voice through a conversation. Its API reference gives examples such as "be very concise", "speak quickly" and "inject emotion into your voice", and says the model is not guaranteed to follow them [step-25-realtime] [step-realtime-api]. The sample call in the page uses a customer-support agent that acknowledges the customer's feeling first, then helps, and keeps replies short. The page says to set `voice` explicitly in the first `session.update` [step-25-realtime].

### Reasoning and effort

The model has no documented reasoning switch or effort level [step-25-realtime].

### Output: format, length, tone

Output is audio and its transcript. The API fixes `modalities` to text and audio. `volume_ratio` (default 1) sets output volume [step-realtime-api].

### Tools and agents

`session.tools` takes function tools [step-realtime-api]. The model page names no tool guidance for this model.

### Coding

StepFun gives no coding guidance.

### Long context and retrieval

StepFun states no context size. The API keeps the conversation history. The client can add or delete items [step-realtime-api].

### Structured output

StepFun documents no structured-output setting for the realtime model.

### Images, audio, other inputs

Input is audio or text. Audio is PCM16, 24 kHz, mono in both directions. The model page says the language is English. The API page and the audio overview say real-time conversation supports Chinese and English only. The pages differ, and no source settles it [step-25-realtime] [step-realtime-api] [step-audio-models].

### Voice: turn-taking, interruption and speech style

**Turn detection.** Server VAD is off by default. `turn_detection.type` set to `server_vad` turns it on. `prefix_padding_ms` defaults to 500, `silence_duration_ms` to 100 and `energy_awakeness_threshold` (0 to 5000) to 2500. Without VAD the client commits the buffer and sends `response.create` [step-realtime-api].

**Interruption.** StepFun says that server-side VAD finds when the user starts and stops, so the model can answer on time and the user can cut in during a reply. The server sends `input_audio_buffer.speech_started` when speech starts. `response.cancel` cancels a response [step-25-realtime] [step-realtime-api].

**Voices.** There are seven system voices (the same IDs as the StepAudio 3 preview). The API reference also accepts cloned voices made with the StepAudio 2.5 TTS model, but the model page says only the seven listed IDs are valid for this model. StepFun says the voice is set before the model speaks. A value outside the list gives a 400 error, and the voice cannot change once the model has produced audio [step-25-realtime] [step-realtime-api].

**Use cases.** StepFun names customer-support voice agents, live hands-free assistants and phone or IVR systems that callers can interrupt [step-25-realtime].

### Sampling and API parameters

The reference documents no sampling parameter. The endpoint is `wss://api.stepfun.ai/v1/realtime?model=stepaudio-2.5-realtime`, with a bearer token. Billing is by token: US$1.50 per million input tokens, US$0.30 cached input and US$10.00 output [step-realtime-api] [step-pricing].

### Migrating from the previous generation

This is the earlier generation of the class in this library. StepFun's pricing page also lists older speech models, such as `step-audio-2` and `step-1o-audio`, which have no file here. Moving to the 3 preview changes the model name, removes the token price for now and adds full-duplex behaviour [step-pricing].
