# MiniMax M3.1 Flash

MiniMax M3.1 Flash is the generally available model of MiniMax's Flash line (class MiniMax M Flash, generation 3.1),
released on 2026-10-19. It is a mixture-of-experts model of about 428 billion parameters (23 billion active) with text,
image and video input, a 1M-token context and thinking that cannot be turned off. It replaces MiniMax M3.1 Flash
Preview, which MiniMax has retired; requests that name the preview are now served by this model. Unlike the preview, it
has a pay-as-you-go price and open weights. It builds on [MiniMax M3](MiniMax-M3.md). Rules that hold across MiniMax
models are in the [MiniMax README](README.md); this file says what is specific to this model. L [minimax-m31-blog]
[minimax-m31-hf] [minimax-m-plan]

## How to instruct it

MiniMax publishes no prompting guide for this model. What exists: the text-generation page (thinking depth), the API
references, the tool-use guide, a MiniMax Code page built from what MiniMax calls its integration guide, and setup pages
for Claude Code and Codex. Labels: L is what MiniMax says, M a measurement, A a reseller or press observation.

### Setting up the prompt

- **What to supply.** MiniMax's page says to give the repository, reproduction steps and acceptance criteria for
  coding; source data and dates for research; and the original images or video for visual analysis. It says to test
  code, check spreadsheet formulas and sources and inspect visual results before relying on them (L).
  [minimax-m31-page]
- **System prompt.** The `system` field is supported on the Anthropic-compatible endpoint. MiniMax gives no advice on
  structure, examples or where to put long documents (L). [minimax-anthropic-api]

### Reasoning and effort

- **The control.** `effort` takes `low`, `medium`, `high`, `xhigh` or `max`; omitted, it is `max`. The field is
  `output_config.effort` (Anthropic-compatible), `reasoning_effort` (Chat Completions) or `reasoning.effort`
  (Responses). Higher levels think more and give more output tokens at higher latency (L). [minimax-text-generation]
- **Thinking cannot be turned off.** `thinking: {"type": "disabled"}` or an effort of `none` returns HTTP 400 (error
  2013). To cut latency and tokens, MiniMax says to lower the effort. MiniMax recommends `max` as the default (L).
  [minimax-text-generation, minimax-openai-api, minimax-m31-page]
- **Thinking on demand.** The tool-use guide says that for simple tool calls the model may call the tool with no
  thinking, so a turn can have no `thinking` block or `reasoning_content` field; check for the field before reading it
  (L). [minimax-m3-tool-guide]
- **Visibility.** Thinking comes back as a `thinking` block (Anthropic), always in `reasoning_content` (Chat
  Completions; `reasoning_split: false` is not supported) or as a reasoning output item (Responses) (L).
  [minimax-text-generation, minimax-openai-api]
- **What each level is for.** MiniMax gives no per-level guidance or measurement.

### Output: format, length, tone

Thinking tokens count toward `max_tokens` or `max_completion_tokens`; too small a limit ends the reply with
`finish_reason: "length"` or `stop_reason: "max_tokens"` and no text. `stop_sequences` is ignored on the
Anthropic-compatible endpoint. MiniMax says output reaches more than 200 tokens a second in everyday use with a median
above 170; Artificial Analysis measured 118.9 (L, M). [minimax-openai-api, minimax-anthropic-api, minimax-m31-blog]
[aa-m31-flash]

### Tools and agents

The family rule holds: return the whole assistant message each turn (the `response.content` list on the Anthropic
protocol; the full message with `tool_calls` and `reasoning_content` on the OpenAI protocol). The model reasons between
tool calls (interleaved thinking). MiniMax's Codex catalog marks the model as supporting parallel tool calls. M Plan
works in MiniMax Code and, with an M Plan key, in Claude Code, Codex, Cursor, OpenCode, Pi, Hermes Agent and OpenClaw
(L). [minimax-m3-tool-guide, minimax-m-plan-codex, minimax-m-plan]

### Coding

MiniMax's own results: DeepSWE v1.1 73.7% (mini-SWE-agent, 512K context) and Terminal-Bench 4.0 38.1 (Codex). MiniMax's
Claude Code page sets every model alias to `MiniMax-M3.1-Flash[1m]`, the effort to `max` and the automatic-compaction
window to 524,288 tokens; its Codex page sets a 524,288-token window and warns not to add `none` as a reasoning level,
because Codex would then send it and get HTTP 400 (L). [minimax-m31-hf, minimax-m-plan-claude-code,
minimax-m-plan-codex]

### Long context and retrieval

1,000,000 tokens per MiniMax's pages (OpenRouter lists 1,048,576). In a 200-task ProgramBench comparison with this
model, MiniMax found similar performance with a 512K and a 1M client window, 18.5% fewer tokens per task (111.42 million
against 136.76 million) and 19.9% lower estimated charges at 512K; it suggests 512K for everyday coding and 1M where the
task must keep much code or document detail (L, MiniMax's own run). MiniMax says the model uses sparse attention in every
layer; M3 kept three full-attention layers (L). [minimax-text-generation, minimax-m-plan-codex, minimax-m31-hf]
A [openrouter-models]

### Structured output

No JSON mode or strict-tool setting is documented for this model, as for the rest of the family.

### Images, audio, other inputs

Text, image and video input; text output. Images up to 10 MB; video up to 50 MB inline or 512 MB through the Files API
(`mm_file://`), at 0.2 to 5 frames a second (default 1); a `detail` field steers image tokens. No audio input. Artificial
Analysis lists text and image input only, and MiniMax's Codex catalog declares text and image (L, M).
[minimax-openai-api, minimax-m-plan-codex] [aa-m31-flash]

### Sampling and API parameters

[as-of 2026-10-31] MiniMax's references now say `temperature` and `top_p` are not supported for this model: any value
has no effect, and the model always uses 1 and 0.95 (`top_p`, if sent, must be within (0, 1]). The `priority` service
tier is not supported for this model. `top_k` and `stop_sequences` are ignored on the Anthropic endpoint. For
self-hosting, the Hugging Face card recommends temperature 1.0 and top_p 0.95 and sets effort in the chat template (L).
[minimax-anthropic-api, minimax-openai-api, minimax-m31-hf]

### Migrating from the previous generation

From M3: thinking is always on (M3 can turn it off, and on the Anthropic endpoint M3 does not think unless asked); five
effort levels exist where M3 has none; the price is half M3's lowest band ($0.15 and $0.60 against $0.30 and $1.20) with
no context band; the priority tier is gone. MiniMax says the agent-task cost is 70% lower than the previous generation,
and that this is not a unit-price comparison. From the preview: change the id or keep it, since the old name is now
served by this model; requests that disable thinking still fail (L). [minimax-m31-page, minimax-pricing,
minimax-anthropic-api, minimax-m-plan]

## What the system card reports

MiniMax publishes no system card, safety report or model card with safety results. The Hugging Face card gives the
architecture, the benchmark table and notes on how each benchmark was run. MiniMax presents cyber capability as a
strength (CyberGym 82.2; code auditing, penetration testing, malware analysis and reverse engineering by its internal
experts' account) and says to let qualified people make final security decisions; no misuse, refusal or
prompt-injection evaluation is published (L). [minimax-m31-hf, minimax-m31-blog, minimax-m31-page]

The licence (MiniMax Community License) allows free non-commercial use. Commercial use needs a "Built with MiniMax
M3.1-Flash" notice and either a one-time notice to MiniMax or, above US$20 million of yearly revenue, prior written
authorization; changed or fine-tuned versions used commercially count as commercial use. Its appendix prohibits
unlawful content, any military purpose, harm to minors, harmful false information and discrimination. This is a
summary, not legal advice (L). [minimax-m31-license]

## Behaviour observed in practice

- **Verbosity.** Artificial Analysis counted 160 million output tokens to run its index (median 99 million for open
  models of its size), at $0.49 per index task (M). [aa-m31-flash]
- **Hallucination.** Artificial Analysis gives an AA-Omniscience hallucination rate of 93.7%, against 91.4% for M3 on
  the same page data. This library recorded 18.4% for M3 from Artificial Analysis on 2026-10-03, so the metric or its
  version has probably changed; do not compare the two readings (M). [aa-m31-flash]
- **Before launch.** MiniMax says an anonymous model named Space Bunny, which processed more than 200 trillion tokens,
  was an early version of this model (L). [minimax-m31-blog]
