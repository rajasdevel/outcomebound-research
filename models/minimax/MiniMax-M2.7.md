# MiniMax M2.7

MiniMax M2.7 is the previous generation of MiniMax's M class (generation 2.7), released on 2026-03-18. It is a text-only
model with a 204,800-token context (about 229B parameters by the Hugging Face file sizes, 10B active by Artificial
Analysis) whose thinking is always on. MiniMax describes it as its first model to take part in its own development and
aims it at software engineering, agent harnesses and office-document work. Its weights, released 2026-04-09, are under a
non-commercial licence. [MiniMax M3](MiniMax-M3.md) replaced it on 2026-06-01. Rules that hold across MiniMax models are
in the [MiniMax README](README.md); this file says what is specific to M2.7.

## How to instruct it

MiniMax publishes no prompting guide for M2.7. The guidance that covers it is the M2 agent post, the M2-series tool-calling
guide on GitHub, the Hugging Face card and the release post; the [README](README.md#prompting-guides) summarises the shared
parts. Labels: L is what MiniMax says, M what was measured, A an observation.

### Setting up the prompt

- **Recommended settings and system prompt.** The Hugging Face card recommends temperature 1.0, top_p 0.95 and top_k 40 and
  shows a default system prompt: "You are a helpful assistant. Your name is MiniMax-M2.7 and is built by MiniMax." The API
  default for top_p is 0.9, and the Anthropic-compatible endpoint ignores `top_k` (L). [minimax-m27-hf-readme,
  minimax-anthropic-api]
- **Skills and many tools.** MiniMax says M2.7 kept 97% skill adherence across more than 40 skills of over 2,000 tokens each
  in its own MM Claw set, and builds on dynamic tool search and native agent teams in which each role keeps a stable identity
  and challenges teammates (L, MiniMax's evaluation). [minimax-m27-news]
- **Office documents.** MiniMax says M2.7 handles multi-round, high-fidelity edits of Word, Excel and PowerPoint files and can
  work from templates and skills (L). [minimax-m27-news]
- **Character and conversation.** M2.7 was tuned for character consistency and emotional intelligence; MiniMax's demo places the
  model in an interactive web scene (L). [minimax-m27-news]
- **Instruction files.** The earlier M2.1 post claimed support for Claude.md, agent.md, cursor rules, Skill.md and slash
  commands; nothing newer was found for M2.7. OctoBench, which MiniMax co-authored, found skill-file constraints a persistent
  bottleneck for the models it tested, M2.1 included (see the [README](README.md#family-wide-behaviour)); M2.7 was not run.
- **Structure, examples, long-document placement.** No guidance published.

### Reasoning and effort

Thinking is always on and has no level: `thinking: {"type": "disabled"}` is accepted but ignored, and no effort field exists
for M2.x (L). The model reasons between tool calls, so the history must keep every thinking block; MiniMax's M2 post says
this is where much reported underperformance came from. On the OpenAI-compatible endpoint thinking appears inside `content`
in `<think>` tags unless `reasoning_split` is true, and the tags must be kept in later turns. Thinking counts toward
`max_tokens`; too small a limit returns no text. MiniMax gives no advice on "think step by step" prompts. [minimax-anthropic-api,
minimax-openai-api, minimax-agent-generalization]

### Output: format, length, tone

No verbosity, formatting or prefill controls are documented. `stop_sequences` is ignored on the Anthropic-compatible
endpoint. Speed: about 60 output tokens a second on the standard id and about 100 on `MiniMax-M2.7-highspeed`, which is the
same model at twice the price (L). [minimax-text-generation, minimax-pricing]

### Tools and agents

- **Format.** M2-series tool calls use an XML-style syntax. MiniMax strongly recommends the tool-call parsers built into vLLM and
  SGLang and gives a manual parsing recipe for other engines. On the API, `tools` and `tool_choice` are standard. [minimax-m27-tool-guide,
  minimax-anthropic-api]
- **Continuity.** Return the full assistant message each turn (all `thinking`, `text` and `tool_use` blocks on the Anthropic
  protocol; the whole message with `tool_calls` and `<think>` text on the OpenAI protocol). [minimax-openai-api]
- **Long-horizon claims (L).** MiniMax says an internal M2.7 ran more than 100 rounds of analysing failures, editing a scaffold,
  evaluating and keeping or reverting changes, for a 30% gain; found useful sampling-parameter combinations and loop detection;
  averaged a 66.6% medal rate on 22 MLE-Bench Lite competitions over three 24-hour trials; and handled live-incident debugging tasks,
  with incident recovery "under three minutes" on several occasions. Toolathlon 46.3. [minimax-m27-news, minimax-m27-hf-readme]
- **Agent teams.** Native multi-agent roles with protocol adherence, shown in a prototype-building demo (L). [minimax-m27-news]

### Coding

- **Measured by MiniMax (harness and thinking settings not stated on the pages read).** SWE-Pro 56.22 (split not stated), SWE
  Multilingual 76.5, Multi SWE Bench 52.7, VIBE-Pro 55.6, Terminal Bench 2 57.0, NL2Repo 39.8 (L). [minimax-m27-news]
- **Measured by MiniMax again at the M3 release.** The benchmark table on the M3 Hugging Face card lists M2.7 at SWE-Bench
  Verified 79.9, SWE-Bench Pro 56.2, Terminal-Bench 2.1 51.1 (Terminus 2, 8 CPU and 16 GB sandbox, 2 h timeout, 128K
  output), NL2Repo 35.0, SWE Atlas-QnA 11.3, BrowseComp 76.3 and MCP Atlas 49.4 (L). [minimax-m3-hf-readme]
- **Measured independently.** Artificial Analysis: Terminal-Bench 2.1 55.4 and Terminal-Bench 4.0 0.0 (M). M2.7 has no row on Scale's
  SWE-Bench Pro V2 page, the tbench.ai board, Artificial Analysis's Coding Agent Index or METR's page. [aa-minimax-m2-7,
  scale-swe-pro-v2, tbench-4]
- **Special-casing and reward hacking.** None published.

### Long context and retrieval

204,800 tokens of context. The OpenAI-compatible reference sets the `max_completion_tokens` maximum for M2.x models at 204,800,
equal to the context window, with 65,536 recommended; OpenRouter lists 176,947. Artificial Analysis's AA-LCR is 78.3% (M). Caching is automatic (512
tokens or more) or explicit with `cache_control`; cache reads cost US$0.06 and cache writes US$0.375 per million tokens. No
placement advice is published beyond static content first. [minimax-chat-openai-ref, aa-minimax-m2-7, minimax-pricing,
minimax-prompt-caching]

### Structured output

No JSON mode, response-format or strict-tool setting appears in MiniMax's references; function-call schemas are the documented
route. [minimax-anthropic-api, minimax-chat-openai-ref]

### Images, audio, other inputs

Text and tool blocks only; image, video and audio are not supported. Use M3 for images and video. [minimax-anthropic-api]

### Sampling and API parameters

Temperature 0 to 2, recommended 1.0; top_p default 0.9 on the API, 0.95 recommended on the Hugging Face card with top_k 40;
penalties and `logit_bias` are ignored; `n` is 1; `service_tier: priority` costs 1.5 times. [minimax-openai-api, minimax-m27-hf-readme]

### Migrating from the previous generation

From M2.5 or M2.1: the ids, prices (US$0.30 in, US$1.20 out) and thinking rules match, and cache reads cost US$0.06 against
US$0.03 for M2.5. M2.7 adds agent-team, skill and office-document strengths in MiniMax's account; MiniMax gives no migration
advice. Moving on to M3 is covered in the [M3 file](MiniMax-M3.md#migrating-from-the-previous-generation): thinking becomes
optional and defaults differ by endpoint. [minimax-pricing, minimax-m27-news]

## What the system card reports

MiniMax publishes no system card or safety report for M2.7. The release post and Hugging Face card report capabilities and
internal uses: SWE-Pro 56.22, Terminal Bench 2 57.0, VIBE-Pro 55.6, GDPval-AA 1495 Elo (behind three closed models among the 45
it lists), Toolathlon 46.3, MM Claw 62.7, MLE-Bench Lite medal rate 66.6%. The post's central claim is self-evolution: M2.7
built its own research harness, updated its own memory and skills, and iterated its scaffold; MiniMax says future work will move
toward full autonomy across data, training and evaluation. It reports no refusal or over-refusal rates, sycophancy, deception or
sandbagging tests, reward-hacking findings, prompt-injection or agentic-safety results, cyber or biology evaluations or
classifiers, and no human-oversight measures for the self-evolution loop. The licence is non-commercial: personal use
(including self-hosted coding and agent work) and non-profit, academic and research use are free, while commercial use needs
MiniMax's prior written authorization and a "Built with MiniMax M2.7" notice; an appendix lists prohibited uses, including
military use. [minimax-m27-news, minimax-m27-hf-readme,
minimax-m27-license]

## Behaviour observed in practice

- **Independent run (M, Artificial Analysis).** Intelligence Index 22.8; AA-Omniscience hallucination rate 35.6% (accuracy 26.8%);
  IFBench 75.7; GPQA Diamond 87.4; Humanity's Last Exam 29.6; SciCode 50.1; GDPval-AA 1013. [aa-minimax-m2-7]
- **Status (M).** Artificial Analysis marks the model deprecated, points to M3 as its replacement and keeps benchmarking speed only
  for the default 10,000-input-token workload; MiniMax still lists and prices it. [aa-minimax-m2-7, minimax-pricing]
- **Release gap.** Weights followed the API by three weeks (2026-03-18 to 2026-04-09). [minimax-m27-hf-readme]
- **Earlier models' instruction following (M).** OctoBench measured M2 and M2.1, not M2.7; see the README. [octobench]
