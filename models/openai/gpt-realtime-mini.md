# GPT-Realtime Mini

GPT-Realtime Mini (`gpt-realtime-mini`) is OpenAI's earlier small speech-to-speech model in the Realtime API, released on 2025-10-06. It is generation 1 of the GPT Realtime Mini class. It has no reasoning control, a 32,000-token window and a 4,096-token output limit. OpenAI deprecated it on 2026-07-20, names GPT-Realtime-2.1 Mini as the replacement, and removes it from the API on 2027-01-20 [openai-changelog] [openai-model-gpt-realtime-mini] [openai-deprecations]. The [OpenAI README](README.md) holds the Realtime API guide.

## How to instruct it

### Setting up the prompt

- OpenAI's prompting guide has no section for the Mini models. Its section for GPT-Realtime-1.5, which says that the original `gpt-realtime` guidance applies, is the closest, and it gives these general tips: iterate often, prefer bullets to paragraphs, guide with examples (the model follows sample phrases closely), be precise, pin the output language if it switches, add a Variety rule against repetition, capitalise key rules for emphasis, and write rules in words and not in code such as "IF x > 3" [openai-guide-voice-prompting].
- The guide's prompt skeleton for this generation: Role and Objective, Personality and Tone, Context, Reference Pronunciations, Tools, Instructions and Rules, Conversation Flow, and Safety and Escalation [openai-guide-voice-prompting].
- OpenAI's developer note of 2025-09-12 on `gpt-realtime` says that an old model could treat a rule such as "Always say X when Y" as vague guidance, and the new one may follow it in cases the writer did not expect. The note advises rewriting prompts and assuming that instructions will be followed [openai-blog-realtime-api].
- OpenAI's December 2025 note for the `2025-12-15` snapshot reports gains of 18.6 points in instruction following and 12.9 points in tool calling over the earlier snapshot, in its own speech-to-speech evaluations [openai-blog-audio-updates].

### Reasoning and effort

The model has no reasoning control and no reasoning tokens [openai-model-gpt-realtime-mini].

### Output: format, length, tone

- The guide's examples give a length per turn (2 to 3 sentences), a pacing rule and a Variety rule. The `speed` parameter changes playback speed only [openai-guide-voice-prompting].
- OpenAI's guide also describes a rule against unwanted background music, humming or sound-like artefacts in speech output [openai-guide-voice-prompting].

### Tools and agents

- Function calling and prompt caching are the listed features. The guide's tool advice for this generation: say when to use and when not to use each tool, put a short line such as "I'm checking that now" before a tool call to hide latency, remove confirmation loops only where the action is safe, wrap long tool output in a small JSON envelope so the model repeats it exactly, and use a responder-and-thinker split, where a stronger text model plans and the voice model rephrases its answer for speech [openai-guide-voice-prompting].
- The guide also describes state-machine and dynamic conversation flows, where `session.update` replaces the prompt and tool list at each state [openai-guide-voice-prompting].

### Coding

OpenAI gives no coding guidance for this model.

### Long context and retrieval

- 32,000-token window with 4,096 output tokens, so about 28,000 input tokens fit before truncation (OpenAI's cost guide gives 28,224 for this size). OpenAI's 2025 note says that, for the original `gpt-realtime`, instructions plus tools may take up to 16,384 tokens [openai-model-gpt-realtime-mini] [openai-guide-voice-cost] [openai-blog-realtime-api].

### Structured output

No structured-output feature is listed [openai-model-gpt-realtime-mini].

### Images, audio, other inputs

- Text, audio and image in; text and audio out. Audio formats: PCM 16-bit mono at 24 kHz, G.711 mu-law, G.711 A-law [openai-model-gpt-realtime-mini] [openai-ref-client-secrets].

### Voice: turn-taking, interruption and speech style

- **Turn detection.** `server_vad` and `semantic_vad`, as for the later models [openai-guide-vad].
- **Idle timeout.** OpenAI's 2025 note describes `idle_timeout_ms` on `server_vad`, which makes the model ask "are you still there" after a quiet period [openai-blog-realtime-api].
- **Unclear audio.** The guide reports that changing "inaudible" to "unintelligible" in the prompt improved handling of noisy input [openai-guide-voice-prompting].
- **Voices.** Ten built-in voices; custom voices for eligible customers since the December 2025 snapshots [openai-guide-conversations] [openai-blog-audio-updates].
- **Voice quality.** The December 2025 snapshot has an upgraded decoder for more natural voices and better voice consistency with custom voices [openai-blog-audio-updates].

### Sampling and API parameters

- **Rate limits [as-of 2026-10-09].** Build lists 400 requests and 200,000 tokens per minute; Grow lists 20,000 requests and 15 million tokens per minute. The page also lists Launch. Actual organization limits can differ. L ([model page](https://developers.openai.com/api/docs/models/gpt-realtime-mini#rate-limits), read 2026-10-09).
- The knowledge cutoff is 2023-10-01 [openai-model-gpt-realtime-mini].
- Snapshots: `gpt-realtime-mini-2025-12-15` (the default) and `gpt-realtime-mini-2025-10-06`, which shut down on 2026-07-23 [openai-model-gpt-realtime-mini] [openai-deprecations].

### Migrating from the previous generation

This is the first generation of the Mini class. The move to GPT-Realtime-2.1 Mini adds reasoning effort and a 128,000-token window, keeps the same rates, and calls for a review of tool names, examples and hard rules [openai-guide-voice-prompting] [openai-model-gpt-realtime-2.1-mini].

## Behaviour observed in practice

- **Independent measurement (M).** Artificial Analysis lists an entry that it labels October 2025: Speech to Speech Index 56.8, Big Bench Audio 63.6%, tau-Voice 15.1%, Conversational Dynamics 95.7%, time to first audio 0.8 s. The page does not say which snapshot the entry is [aa-speech-to-speech]. Scale's AudioMultiChallenge lists the `2025-12-15` snapshot at 13.94% with audio output and 16.59% with text output [scale-audiomc].
- **Maker (L).** OpenAI cited a customer who found latency near instant for bilingual translation and intent routing on the new snapshot. This is a vendor-chosen example [openai-blog-audio-updates].
- **Practitioner (A).** In OpenAI's 2.1 launch thread, two developers who compared this model with GPT-Realtime-2.1 Mini in telephone flows in July and August 2026 found that this model called a function tool where 2.1 Mini did not, and that it behaved more predictably in a structured multi-step script [community-realtime-21].
