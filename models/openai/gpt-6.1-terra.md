# GPT-6.1 Terra

OpenAI released GPT-6.1 Terra on 2026-10-26. It positions this GPT Terra generation for visual reasoning, computer use and writing. OpenAI recommends testing it against GPT-5.6 Terra on representative workflows when migrating. L [changelog] [guide].

## How to instruct it

### Setting up the prompt

The GPT-6 family guide describes instructions, examples and workflow boundaries; its model-specific section recommends clear task context. See the [OpenAI family guide](README.md). L [guide].

### Reasoning and effort

The model supports `none`, `low`, `medium`, `high`, `xhigh` and `max`; `medium` is the default. OpenAI recommends starting at medium and raising effort when the improvement justifies the time and tokens. L [model] [guide].

### Output: format, length, tone

OpenAI positions the model for clear writing. The model supports structured output; the checked sources do not establish model-specific verbosity effects. L [model] [selection].

### Tools and agents

Tool calling requires Responses. The model page lists web and file search, image generation, code interpreter, hosted shell, apply patch, skills, computer use, MCP and tool search. It does not establish independent evaluation of tool reliability. L [model].

### Coding

OpenAI suggests scoped code fixes and keeps Sol and Astra as choices for more complex coding. Its Terminal-Bench 4.0 result is a maker measurement with no harness named in the launch text. L [selection] [launch].

### Long context and retrieval

The context window is 1,050,000 tokens with up to 128,000 output tokens. More than 272,000 input tokens reprices the whole request at twice input and cache rates and 1.5 times output. OpenAI lists 30-minute and 12-hour cache writes; these are total write prices, not additional surcharges. L [model] [caching].

### Structured output

The model page lists structured outputs and function calling as supported. Tool calls require Responses. L [model].

### Images, audio, other inputs

Text and image inputs and text output are supported. The model page does not list audio or video input or output. L [model].

### Sampling and API parameters

The GPT-6 migration guide says to remove `temperature`, `top_p` and log-probability settings when reasoning effort is not `none`; the exact parameter differs between Responses and Chat Completions. L [guide].

### Migrating from the previous generation

For migration from GPT-5.6 Terra, OpenAI recommends a comparison at the same reasoning effort on representative images and workflows. Move tool calls from Chat Completions to Responses. Standard direct API prices are $1 input, $0.05 cached input and $5 output per million tokens; GPT-5.6 Terra's model page lists $2, $0.20 and $12 respectively. L [guide] [model] [pricing].

## What the system card reports

OpenAI treats the model as Critical for cybersecurity and High for biological and chemical capability, with the safeguards stack used for GPT-6.1 Sol and Astra. In its internal matched Codex simulation it reported 22 severity-3-or-higher flags in 48,690 tasks (0.045%). These are maker evaluations, not a guarantee for a user's traffic. L [system].

## Behaviour observed in practice

No independent practitioner observation was verified in this pass. The model is listed for ChatGPT Work, Codex and the OpenAI API; CLI use requires Codex 0.159.0 or later. L [work-codex].

## Benchmarks

OpenAI reports 50.3% on Terminal-Bench 4.0 at max effort; its launch text does not name the harness. OpenAI also reports stronger visual and computer-use results than GPT-5.6 Terra on its tested tasks. These are maker results, not independent replications. L [launch].

## Open questions

- Independent coding, visual and latency measurements and task-specific outcomes remain unverified.
- Azure Foundry and Amazon Bedrock availability, prices, regions and actual account access were not established by the checked pages. An unavailable or incomplete listing is not proof of nonavailability. L [azure-catalog] [azure-regions] [aws-models].
- OpenRouter lists Terra at $1 input and $5 output per million tokens, and a separate batch listing at $0.50 and $2.50. Account access and billing were not tested. L [openrouter].
