# GPT-4o Transcribe

GPT-4o Transcribe (`gpt-4o-transcribe`) is OpenAI's earlier speech-to-text model, based on GPT-4o. OpenAI added it to the Audio API on 2025-03-20 as an improvement on the original Whisper models. It is generation 1 of the GPT Transcribe class here (the numbering is this library's), and GPT-Transcribe followed it. OpenAI deprecated it on 2026-08-26 and removes it from the API on 2027-02-26. It is priced in audio tokens, with an estimated $0.006 per minute [openai-changelog] [openai-model-gpt-4o-transcribe] [openai-deprecations] [openai-pricing]. The [OpenAI README](README.md) holds the API guide for all voice models.

## How to instruct it

### Setting up the prompt

- The model accepts a `prompt` for names, acronyms, formatting and vocabulary. Useful uses: product names and technical terms, context from the previous chunk of a long recording, punctuation, capitalisation and filler words, and a preferred writing system [openai-guide-speech-to-text].
- It takes a single `language` hint. The newer models take `languages` [openai-guide-speech-to-text].

### Reasoning and effort

No reasoning control.

### Output: format, length, tone

Text output from `v1/audio/transcriptions`, with streaming events. The model returns no speaker labels (use `gpt-4o-transcribe-diarize`) and no word timestamps (use `whisper-1`) [openai-guide-transcription].

### Tools and agents

Not applicable.

### Coding

Not applicable.

### Long context and retrieval

The model page lists a 16,000-token window and 2,000 output tokens. Files may be up to 25 MB. Artificial Analysis chunked long audio to about 9 minutes for this model [openai-model-gpt-4o-transcribe] [openai-guide-speech-to-text] [aa-stt-non-streaming].

### Structured output

Not applicable.

### Images, audio, other inputs

Audio and text in, text out. The model page lists two endpoints: Transcription (`v1/audio/transcriptions`) and Realtime (`v1/realtime`), where it can transcribe the input audio of a session. It lists the dedicated route `v1/realtime/transcription_sessions` as not supported [openai-model-gpt-4o-transcribe].

### Sampling and API parameters

- Price: $2.50 per million audio input tokens and $10 per million output tokens [openai-model-gpt-4o-transcribe].
- Rate limits: tier 1, 500 requests and 10,000 tokens a minute; tier 5, 10,000 requests and 6 million tokens [openai-model-gpt-4o-transcribe].
- Microsoft Foundry lists the `2025-03-20` snapshot as a preview model [ms-foundry-models].

### Migrating from the previous generation

This is the first generation. To move to GPT-Transcribe or GPT-Live-Transcribe, see the [GPT-Transcribe file](gpt-transcribe.md) and the [GPT-Live-Transcribe file](gpt-live-transcribe.md) [openai-deprecations].

## Behaviour observed in practice

- **Independent measurement (M).** Artificial Analysis's non-streaming benchmark gives an AA-WER of 3.96%, a median speed factor of 36.0 and a price of $6.00 per 1,000 minutes. GPT-Transcribe scores 3.31% and GPT-4o Mini Transcribe 4.47% on the same page [aa-stt-non-streaming].
- **Practitioner reports (A).** None gathered.
