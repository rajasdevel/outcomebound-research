# Chat Latest

`chat-latest` is a rolling API alias for the Instant model used in ChatGPT. OpenAI updated it on
2026-10-07 and says it will update the underlying snapshot regularly. The update does not establish
a numbered generation or the alias's first release date. L [openai-chat-latest] [openai-changelog].

## How to instruct it

### Setting up the prompt

OpenAI's general prompt guide uses `instructions` or developer messages for application rules and
user messages for the request. It recommends clear sections, delimiters and examples. These are
general API techniques; no guide specific to this alias was found. L [openai-prompt-engineering].
The [maker README](README.md) covers the shared API surface.

### Reasoning and effort

The model page does not state a reasoning control or accepted effort levels. Its Instant label
alone does not establish support for `reasoning.effort` or a GPT-6 effort setting. L
[openai-chat-latest].

### Output: format, length, tone

The general prompt guide puts tone and goals in application instructions. The model-specific page
states no verbosity control or prefill behavior. L [openai-prompt-engineering] [openai-chat-latest].

### Tools and agents

The Responses model page supports functions, web and file search, image generation, code
interpreter and MCP. It does not support hosted shell, apply patch, skills, computer use or tool
search. It supports streaming. L [openai-chat-latest]. No long-horizon or delegation measurement
was verified for this snapshot.

### Coding

No coding guide or coding-agent measurement for this alias's October snapshot was verified.
OpenAI recommends GPT-6 models for production API work; a ChatGPT alias update is not evidence of
coding-agent quality. L [openai-changelog].

### Long context and retrieval

The page reports a 400,000-token window, but separately limits input to 272,000 tokens and output
to 128,000 tokens. File search is supported; retrieval accuracy for this snapshot was not verified.
L [openai-chat-latest].

### Structured output

Structured Outputs and function calling are supported. The general schema guide distinguishes
strict output schemas from strict function arguments and describes refusals and incomplete output
as cases the application handles separately. Schema adherence does not verify the answer's facts
or authorize an action. L [openai-chat-latest] [openai-structured-outputs]; last sentence is inference.

### Images, audio, other inputs

The alias reads text and images and returns text. It has no audio or video input or output.
L [openai-chat-latest].

### Sampling and API parameters

The page supports Responses and Chat Completions but not Batch or fine-tuning. It publishes no
alias-specific sampling rules. The general prompt guide notes that `instructions` from a previous
Responses request do not carry through `previous_response_id`; each request supplies the required
instructions again. L [openai-chat-latest] [openai-prompt-engineering].

### Migrating from the previous generation

There is no numbered predecessor for this rolling alias. OpenAI's general guide recommends fixed
snapshots and evaluations for production, but this alias's page lists only `chat-latest`. No dated
id with which to pin its October snapshot was identified. A regression suite and the date of an
observation help distinguish behavior across alias updates; this is an inference from the documented
update policy. L [openai-chat-latest] [openai-changelog] [openai-prompt-engineering].
