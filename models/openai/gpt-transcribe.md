# GPT-Transcribe

GPT-Transcribe (`gpt-transcribe`) is OpenAI's speech-to-text model for finished recordings. It can also stream the text of a file as it works, and it can transcribe committed turns of a Realtime session over WebSocket. OpenAI released it on 2026-07-28 with GPT-Live-Transcribe, and it is the model that OpenAI's file-transcription guide recommends. It is generation 2 of the GPT Transcribe class here, after GPT-4o-Transcribe (the generation numbering is this library's). It costs $0.0045 per minute of audio and it returns the languages that it detects [openai-changelog] [openai-guide-speech-to-text] [openai-model-gpt-transcribe]. The [OpenAI README](README.md) holds the API guide for all voice models.

## How to instruct it

### Setting up the prompt

Three inputs give context, and OpenAI says to use them only for context that is relevant to the audio [openai-guide-speech-to-text] [openai-guide-transcription]:

- `prompt`: free-form context about the recording.
- `keywords`: literal terms such as product names, medications and acronyms. They are hints. Include only relevant terms and check that they do not make unspoken terms appear.
- `languages`: expected input languages, as ISO 639-1 codes, selected ISO 639-3 codes or regional `zh` codes. It replaces the singular `language`. Do not send both.

The API rejects a whole request for an unsupported language code, a keyword with a forbidden character (`<`, `>`, carriage return or line feed) or a prompt over the length limit. In a Realtime session or a dedicated transcription session the model uses earlier transcribed turns as context automatically [openai-guide-transcription-rt].

### Reasoning and effort

No reasoning control.

### Output: format, length, tone

- The response is JSON with the transcript and the detected languages. When the model cannot predict a language reliably, `languages` is an empty array [openai-guide-speech-to-text].
- With `stream=true` the API returns `transcript.text.delta` events and a final `transcript.text.done` event that includes the detected languages. This works for a finished file and needs no Realtime session [openai-guide-speech-to-text].
- OpenAI points to a different model for speaker labels (`gpt-4o-transcribe-diarize`), for word timestamps and `srt` or `vtt` subtitles (`whisper-1`), and for translation into English (`whisper-1`). These two models shut down on 2027-02-26, and OpenAI's deprecation page names `gpt-live-transcribe` or `gpt-transcribe` as the replacement [openai-guide-transcription] [openai-deprecations].

### Long context and retrieval

Files may be up to 25 MB. For larger recordings, use a compressed format or split the file, and avoid cutting in the middle of a sentence [openai-guide-speech-to-text].

### Structured output

Not applicable.

### Images, audio, other inputs

Input formats: `mp3`, `mp4`, `mpeg`, `mpga`, `m4a`, `wav` and `webm`. In a Realtime session the model transcribes committed audio turns, and it works there over WebSocket only [openai-guide-speech-to-text] [openai-guide-transcription-rt].

### Sampling and API parameters

- Endpoints: `v1/audio/transcriptions` and `v1/realtime/transcription_sessions` [openai-model-gpt-transcribe].
- **Rate limits [as-of 2026-10-09].** Build lists 5,000 requests and 2 million tokens per minute; Grow lists 30,000 requests and 150 million tokens per minute. The page also lists Launch. Actual organization limits can differ. L ([model page](https://developers.openai.com/api/docs/models/gpt-transcribe#rate-limits), read 2026-10-09).
- Data: the audio transcription endpoint keeps no application state, uses no data for training and is eligible for Zero Data Retention; US and EU data residency apply [openai-guide-your-data].

### Migrating from the previous generation

From `gpt-4o-transcribe` and `gpt-4o-mini-transcribe` (removed 2027-02-26): OpenAI names `gpt-transcribe` or `gpt-live-transcribe` as the replacement, depending on whether the audio is a file or a live stream. The newer model takes `languages` where the older one takes a single `language`, and it adds `keywords` [openai-deprecations] [openai-guide-transcription].

## Behaviour observed in practice

- **Independent measurement (M).** Artificial Analysis's non-streaming benchmark gives an AA-WER of 3.31% (AA-AgentTalk 2.22%, VoxPopuli-Cleaned 2.72%, Earnings22-Cleaned 6.10%), a median speed factor of 41.4 and a price of $4.50 per 1,000 minutes. That is the lowest word error rate among the OpenAI models on the page: GPT-4o Transcribe scores 3.96% and GPT-4o Mini Transcribe 4.47% [aa-stt-non-streaming].
- **Cloud (L).** Microsoft Foundry lists it as an offline transcription model for files, not a Realtime model, with a 25 MB request limit [ms-foundry-models].
- **Practitioner reports (A).** None gathered.
