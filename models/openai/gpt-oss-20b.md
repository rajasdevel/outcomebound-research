# gpt-oss-20b

gpt-oss-20b is the smaller of the two open-weight reasoning models OpenAI released on 2025-08-05 under the
Apache 2.0 licence: 20.9 billion parameters in a mixture-of-experts text model, 3.6 billion active per token,
with MXFP4 weights that run within 16 GB of memory. OpenAI aims it at lower latency and at local or
specialised use. It uses the same harmony format, the same reasoning-level control and the same model card as
gpt-oss-120b, and the [gpt-oss-120b file](gpt-oss-120b.md) holds the full account; this file records the
numbers and cautions that are specific to the smaller model. The [OpenAI README](README.md) covers the
maker.

## How to instruct it

### Setting up the prompt

- Everything about the harmony format, roles, channels, the fixed identity line and the developer message
  in the 120b file applies. The format is required; hosts and runtimes apply it
  [hf-gpt-oss-20b] [openai-harmony].
- OpenAI's guardrail tests are weaker for the 20b than for the 120b. Holding a developer instruction against
  a user who tries to override it: protecting a phrase 0.661 against 0.912 for o4-mini; prompt-injection
  hijacking defence 0.639 against 0.917; system-prompt extraction 0.881 against 0.993. The card says this may
  leave developers less able to stop a jailbreak through the system message than OpenAI is with o4-mini
  [arxiv-gpt-oss].
- OpenAI's card says the 20b lags on knowledge-heavy tasks such as GPQA because of its size, and the
  independent agent study below measured it as the weakest agent in its set [cmu-steer-dont-solve]
  [arxiv-gpt-oss].

### Reasoning and effort

- The level is set with `Reasoning: low`, `medium` or `high` in the system message; the default is medium
  [openai-harmony].
- The card's numbers (low, medium, high): AIME 2025 without tools 37.1, 72.1, 91.7; GPQA Diamond without tools
  56.8, 66.0, 71.5; Humanity's Last Exam without tools 4.2, 7.0, 10.9; MMLU 80.4, 84.0, 85.3; Codeforces Elo
  without tools 1366, 1998, 2230. OpenAI says the 20b used over 20,000 chain-of-thought tokens per AIME
  problem on average, and attributes the models' math strength to their effective use of very long chains of
  thought [arxiv-gpt-oss].
- Artificial Analysis scores it 10.0 on its Intelligence Index at low and 9.0 at high, so higher effort did not
  raise its score there [aa-model-gpt-oss-20b].
- Chain-of-thought handling is as for the 120b: OpenAI says it is not for end users, is dropped after a final
  answer and is kept between tool calls [openai-gpt-oss-raw-cot].

### Output: format, length, tone

- As the 120b: answers in the `final` channel; preambles in `commentary`; `<|return|>` becomes `<|end|>` in
  stored history [openai-harmony]. Artificial Analysis counted 70 million output tokens on its Index run and
  lists 180 output tokens a second [aa-model-gpt-oss-20b].

### Tools and agents

- Browsing, Python and developer functions as for the 120b [openai-harmony]. The card's agentic numbers (low,
  medium, high): Tau-Bench Retail 35.0, 47.3, 54.8; Tau-Bench Airline 32.0, 42.6, 38.0, so the airline score
  falls from medium to high; Codeforces Elo with a terminal tool 1251, 2064, 2516 [arxiv-gpt-oss].
- OpenAI's guide says the previous reasoning goes back to the model during a run of tool calls
  [openai-gpt-oss-raw-cot].

### Coding

- OpenAI's card: SWE-bench Verified 37.4 (low), 53.2 (medium), 60.7 (high); Aider Polyglot 16.6, 26.6, 34.2
  [arxiv-gpt-oss].
- Independent: in the Carnegie Mellon critic study's mini-SWE-agent harness (150 steps) the 20b resolved 3.0%
  of SWE-bench Verified with no critic and 14.8% with a small trained critic, the weakest agent in the study's
  set; the study ran both gpt-oss models at medium reasoning. OpenAI's own figure at medium is 53.2, which
  shows how far the harness and budget move the result [cmu-steer-dont-solve] [arxiv-gpt-oss].
- Artificial Analysis shows 0% for Terminal-Bench 4.0 inside its Intelligence Index [aa-model-gpt-oss-20b].

### Long context and retrieval

- 131,072-token context by YaRN extension; Amazon Bedrock lists 128,000 tokens; no maximum output length is
  published [arxiv-gpt-oss] [aws-gpt-oss-params].
- Artificial Analysis's AA-LCR long-context reasoning: 34.7% at high, well below the 120b's 52.0%
  [aa-model-gpt-oss-20b].

### Structured output

- The card says the models support Structured Outputs. In harmony, a schema in the developer message steers
  but does not guarantee the output; a guarantee needs constrained decoding in the runtime
  [openai-harmony] [arxiv-gpt-oss].

### Images, audio, other inputs

- Text in, text out only [hf-gpt-oss-20b].

### Sampling and API parameters

- No maker sampling recommendation; OpenAI's vLLM example uses temperature 1 [openai-gpt-oss-vllm].
- For local use, the Hugging Face card points to Ollama and LM Studio for consumer hardware. Model IDs:
  `openai/gpt-oss-20b` (Hugging Face), `openai.gpt-oss-20b-1:0` (Bedrock), `gpt-oss-20b` (Foundry preview,
  Foundry resources only) [hf-gpt-oss-20b] [aws-gpt-oss-params] [ms-foundry-models].

### Migrating from the previous generation

There is no earlier open-weight model in this class. See the 120b file for the move from an OpenAI hosted
reasoning model. For the smaller model the card measures more hallucination (SimpleQA accuracy 6.7% and
hallucination rate 91.4%; PersonQA accuracy 15.5%) and a weaker instruction hierarchy than the 120b
[arxiv-gpt-oss].

## What the system card reports

OpenAI published a model card, not a system card, for the pair [arxiv-gpt-oss]. The Preparedness work
(including adversarial fine-tuning) was run on the 120b, and OpenAI states conclusions for the default model
below High capability in all three tracked categories; the 20b numbers below are OpenAI's.

- **Refusals and over-refusal.** Within 1 to 2 points of o4-mini on standard disallowed-content tests; on the
  harder production-style set it beats o4-mini on most categories but trails it on illicit/violent
  (0.744 against 0.845) and sexual/illicit (0.852 against 0.857).
- **Jailbreaks.** StrongReject scores 0.960, 0.979, 0.982 and 0.970 across four categories, about parity with
  o4-mini.
- **Instruction hierarchy.** Weaker than o4-mini and weaker than the 120b (numbers above).
- **Hallucination and bias.** SimpleQA accuracy 0.067, hallucination rate 0.914; PersonQA accuracy 0.155,
  hallucination rate 0.532; BBQ accuracy 0.79 on ambiguous and 0.89 on disambiguated questions.
- **Health.** HealthBench 40.4, 41.8, 42.5 (low, medium, high); Hard 9.0, 12.9, 10.8; OpenAI says it performs
  slightly better than o1 despite its size.
- **Chain of thought.** No direct optimisation pressure; it may contain hallucinated content, and OpenAI says
  developers should not show it to users directly.

## Behaviour observed in practice

- **Independent measurement (M).** Artificial Analysis rates it 9 on its Intelligence Index at high, with a
  hallucination rate of 94.1% on AA-Omniscience; its providers page lists speeds up to 927 tokens a second
  (Groq) and the lowest blended price at $0.04 per million tokens (CoreWeave and DeepInfra)
  [aa-model-gpt-oss-20b] [aa-providers-gpt-oss-20b].
- **Agent study (M).** Carnegie Mellon's study found it the weakest agent tested, gaining from critic guidance
  but starting from 3.0% [cmu-steer-dont-solve].
- **Hosting (L).** Groq lists $0.075 in, $0.037 cached input and $0.30 out per million tokens
  [groq-gpt-oss-20b].
- **Practitioner reports (A).** None first-hand were gathered.
