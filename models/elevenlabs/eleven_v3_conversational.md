# Eleven v3 Conversational

Eleven v3 Conversational is the low-latency version of Eleven v3. It belongs to the Eleven Realtime class, generation 3. ElevenLabs built it for live, back-and-forth dialogue in ElevenAgents. The changelog added it to agent configuration in the entry of 2026-02-09, and expressive mode is on by default when it is selected. The docs now call it the previous generation, and Eleven v4 Turbo took its place [el-models] [el-changelog-v3conv] [el-agents-expressive]. Family-wide rules are in the [ElevenLabs README](README.md).

## How to instruct it

### Setting up the prompt

The text comes from the agent's language model. The delivery is steered through the agent's system prompt. The expressive-mode page gives these rules [el-agents-expressive]:

- Tone rules go in natural language, from broad guidance to specific triggers. The model reads them in context, so a tag is not needed every time.
- The language model can emit tags for specific moments. The page lists `[laughs]`, `[whispers]`, `[sighs]`, `[slow]` and `[excited]`. A tag affects about the next four or five words.
- Delivery should match the situation. The page's example is a calm, empathetic reply to a frustrated caller.
- The page advises tone rules in the system prompt for consistency across calls, tests in every target language, and a review of conversation analytics to refine the rules.

The agent API has `suggested_audio_tags` (up to 20 tags, each with an optional note on when to use it) and an `expressive_mode` switch that adds an expressive-tags prompt. The API reference says `expressive_mode` is on by default and is switched off for non-v3 models [el-changelog-v3conv] [el-changelog-0216] [el-api-agents].

### Reasoning and effort

None. ElevenLabs describes no reasoning or effort control for a speech synthesis model. The language model of the agent has its own reasoning controls [el-agents-llm].

### Output: format, length, tone

- **Formats.** ElevenAgents defaults to PCM 16 kHz and accepts PCM 8 to 48 kHz and mu-law 8 kHz. The WebSocket takes the `output_format` list of the other speech models [el-api-agents] [el-ws-ttd].
- **Length.** The models page gives no character limit for this model [el-models].
- **Tone.** The model adapts to the tone and intent of each turn and keeps context across turns. Agent `stability` defaults to 0.5, `similarity_boost` to 0.8 and `speed` to 1 (range 0.7 to 1.2) [el-agents-expressive] [el-api-agents] [el-agents-speed].

### Tools and agents

- **Where it runs.** ElevenAgents, where it is a speech model choice, and the Text to Dialogue WebSocket, where the API reference makes it the default model [el-api-agents] [el-api-ttd-ws].
- **Price.** The expressive-mode page says it costs the same as other speech models in agents, from US$0.08 a minute. API price is US$0.04 per 1,000 characters [el-agents-expressive] [el-pricing-api].
- **Limits.** It does not keep professional voice clones well, and the page tells users who need a clone's identity to use Flash v2. Expressiveness varies by voice and language [el-agents-expressive].

### Coding

In the agent configuration, `conversation_config.tts.model_id` takes `eleven_v3_conversational` [el-agents-expressive] [el-api-agents].

### Long context and retrieval

Not applicable to the model. The agent platform keeps the conversation history.

### Structured output

Not applicable.

### Images, audio, other inputs

Text only. The docs give 70+ languages, up from about 32 on the Flash models, with better expressiveness in languages where nuance lagged, such as Japanese [el-agents-expressive].

### Voice: turn-taking, interruption and speech style

- **Latency.** About 280 ms, without application and network time [el-models].
- **Turn-taking.** The new turn-taking system of expressive mode uses live signals from Scribe v2 Realtime, such as emotional cues and speech patterns. Its example: "yeah" can be a full answer or a lead-in, and prosody helps tell which. Turn eagerness tunes it: `patient` for emotionally sensitive talk, `eager` for fast talk [el-agents-expressive] [el-agents-flow].
- **Other turn settings.** Turn timeout (1 to 30 seconds, default 7), soft timeout filler, `speculative_turn`, `spelling_patience` and `turn_model` (`turn_v2` or `turn_v3`) [el-agents-flow] [el-api-agents].
- **Interruption.** Users can interrupt by default. Tools can block interruptions during execution or for the whole turn. The `skip_turn` tool lets the agent stay silent on request [el-agents-tool-int] [el-agents-skip].
- **Speech style.** Tags, system-prompt tone rules and speed. The page advises matching tone to context [el-agents-expressive].
- **WebSocket use.** The API reference allows exactly one registered voice. `new_turn`, `flush` and `keep_alive` work as for the other Text to Dialogue models. The docs describe no cancel message [el-api-ttd-ws] [el-ws-ttd].

### Sampling and API parameters

Agent TTS fields: `model_id`, `voice_id`, `expressive_mode`, `suggested_audio_tags`, `stability`, `similarity_boost`, `speed`, `text_normalisation_type`, `pronunciation_dictionary_locators`, `enable_phoneme_tags` and `agent_output_audio_format` [el-api-agents].

### Migrating from the previous generation

No earlier model in this class has a file here. The agent TTS models before it were Flash and Multilingual v2. Against Flash [el-agents-expressive] [el-models]:

- Higher emotional range and 70+ languages, against about 32. The page says it is more context-aware.
- Higher latency: about 280 ms against about 75 ms on the maker's figures.
- Expressive mode is on by default.
- Professional clones lose their character.
- The same agent price per minute.

## What the system card reports

ElevenLabs publishes no system card for Eleven v3 Conversational in the pages read. The platform safeguards are in the [README](README.md) [el-safety].

## Behaviour observed in practice

- **Rank (M).** Artificial Analysis lists it as v3 Conversational with an Elo of 1199.99 on the model page and 1202.99 on the leaderboard. Eleven v3 has 1171.45 and Eleven v4 has 1321.44 [aa-tts-v3conv] [aa-tts-v3] [aa-tts-v4].
- **Speed (M).** Median throughput is 65.5 characters a second [aa-tts-board].
- **Price check (M).** Artificial Analysis lists US$50 per 1M characters. The pricing page gives US$40 [aa-tts-board] [el-pricing-api].
- **Maker claim.** The maker says it has a higher emotional range than Flash and Multilingual v2. It gives no data [el-agents-expressive].

## Benchmarks

Independent: Artificial Analysis Speech Arena Elo of 1199.99 and a median of 65.5 characters a second [aa-tts-v3conv] [aa-tts-board]. Maker: about 280 ms latency [el-models].
