# Eleven Flash v2.5

Eleven Flash v2.5 is the fast, low-cost speech synthesis model of the Eleven Flash class, generation 2.5. ElevenLabs released it on 2024-12-18 together with Flash v2 (launch post; the changelog entry is dated 2024-12-19) [el-blog-flash]. It speaks 32 languages with a model inference time of about 75 ms, and it takes up to 40,000 characters in a request. It replaced Turbo v2.5, which the docs now call deprecated. The maker names it for agents, games and bulk speech [el-changelog-flash] [el-models]. Family-wide rules are in the [ElevenLabs README](README.md).

## How to instruct it

### Setting up the prompt

- **The text is the prompt.** The model reads emotion from the words around the speech. The guide says descriptive text such as "she said excitedly", and exclamation marks, change the emotion. The model reads such text aloud, so it must be cut from the audio by hand if it is not wanted [el-tts-overview] [el-tts-practices].
- **No audio tags.** Square-bracket tags are described for v3, v4 and v4 Turbo. The pages read do not describe them for Flash [el-tags-help] [el-v4-page].
- **Pauses.** The guide gives `<break time="x.xs" />` for up to 3 seconds. Many breaks in one request can make the voice speed up or add artefacts. Dashes and ellipses are weaker options. Voices trained with fillers such as "uh" may handle pauses in their own way [el-tts-practices].
- **Pronunciation.** Phoneme tags work only on Flash v2. For models without phoneme tags, the guide offers respelling (capitals, dashes, apostrophes) or an alias entry in a pronunciation dictionary. The dictionary search is case sensitive and the first match wins. A WebSocket request with phoneme tags needs `enable_ssml_parsing=true` [el-tts-practices] [el-ws-tts] [el-agents-pron].
- **Numbers and symbols.** This is the weak point. The models page says Flash v2.5 does not normalise numbers by default, to keep latency low, so phone numbers, dates and currencies can sound wrong. The best-practices page gives "$1,000,000" as an example that this model reads as "one thousand thousand dollars". Its fixes are Multilingual v2, a language model told to write numbers and symbols as spoken words, preprocessing with code, or (Enterprise only for v2.5) `apply_text_normalization` set to `on` [el-models] [el-tts-practices].

### Reasoning and effort

None. ElevenLabs describes no reasoning or effort control for a speech synthesis model.

### Output: format, length, tone

- **Formats.** The same list as the other speech models. The default is `mp3_44100_128` [el-api-tts].
- **Length.** 40,000 characters a request, about 40 minutes of audio [el-models].
- **Tone.** Voice settings and wording. The API reference lists `stability` (lower gives a broader range), `similarity_boost`, `style`, `speed` and `use_speaker_boost`. A `style` above 0 and speaker boost both add compute and can add latency. `speed` runs from 0.7 to 1.2, and extreme values can reduce quality [el-api-tts] [el-tts-practices].

### Tools and agents

- **In agents.** `eleven_flash_v2_5` is an agent speech model. A new agent starts on Flash v2. Adding a language moves the agent to the v2.5 model, and English keeps using v2 [el-api-agents] [el-agents-lang].
- **Advice.** The choose-a-model page names Flash v2.5 for the lowest latency, and says to use the 2.5 model for any language but English [el-choose].
- **Agent normalisation.** The agent setting `text_normalisation_type` is `system_prompt` or `elevenlabs`. See the README [el-agents-prompting].

### Coding

The docs give the HTTP stream endpoint for ready text, and the WebSocket for a language model that feeds the speech model. The multi-context WebSocket suits voice agents [el-latency-opt] [el-ws-multi].

### Long context and retrieval

The docs advise splitting long text and passing `previous_text` and `next_text`, or up to three request ids no older than two hours, so that prosody carries across parts. Request stitching does not work with Zero Retention Mode [el-tts-overview] [el-stitching] [el-api-tts].

### Structured output

Not applicable. The WebSocket can return `alignment` data with word-level timing [el-ws-tts].

### Images, audio, other inputs

Text only. Voice types affect speed: default voices, designed voices and instant clones are faster than professional clones, and the maker says it is working on professional-clone latency for Flash v2.5 [el-latency-opt] [el-latency-concept].

### Voice: turn-taking, interruption and speech style

- **Latency.** About 75 ms of model inference, without network and application time. With the WebSocket, time to first byte is 100 to 150 ms in North America, Europe and South East Asia, and 150 to 200 ms in South Asia and North East Asia. The `x-region` header names the serving cluster [el-models] [el-latency-opt].
- **Streaming in.** The WebSocket buffers text until it reaches a threshold. `auto_mode` starts speech by itself. With `chunk_length_schedule` set (the guide's example is 120, 160, 250, 290 characters), the model waits for that much text, so short input can stall. The guide advises `flush: true` with the last text of a turn. Closing the socket flushes the rest [el-ws-tts] [el-latency-opt].
- **Keeping the socket open.** It closes after 20 seconds without input. A single space keeps it open. An empty string closes it [el-ws-tts].
- **Barge-in.** The multi-context WebSocket gives up to five contexts on one connection. On an interruption, the guide closes the current context and opens a new one. A context times out after 20 seconds (a socket setting allows up to 180). An empty text message resets the clock. The `is_final_audio_for_turn` marker is emitted after every buffered byte of a turn, for MP3 and Opus too [el-ws-multi] [el-changelog-0921].
- **Turn-taking in an agent.** The platform decides turns. See the README for turn timeout, eagerness, soft timeout and interruption settings [el-agents-flow].
- **Speech style.** The voice sample sets the pace, so the guide asks for longer, continuous samples. The guide offers `speed` for control and a narrative writing style to guide pace and tone [el-tts-practices].

### Sampling and API parameters

`voice_settings`, `seed`, `language_code` (ISO 639-1; ignored if unsupported), `apply_text_normalization` (`auto`, `on`, `off`; the API default is `auto`), `pronunciation_dictionary_locators` (up to three) and `enable_logging=false` for Enterprise. `optimize_streaming_latency` is deprecated and does nothing in agents [el-api-tts] [el-api-agents].

### Migrating from the previous generation

The previous generation in this class is Flash v2, and the model it replaced is Turbo v2.5 [el-models] [el-blog-flash]:

- From Flash v2: the model adds 31 languages to English, and the limit grows from 30,000 to 40,000 characters. Phoneme tags no longer work.
- From Turbo v2.5: the docs call the two functionally equal, with lower latency on Flash on average.
- The maker says Flash has slightly lower quality and emotional depth than Turbo.

## What the system card reports

ElevenLabs publishes no system card for Eleven Flash v2.5 in the pages read. The platform safeguards are in the [README](README.md) [el-safety].

## Behaviour observed in practice

- **Rank (M).** Artificial Analysis gives Elo 1076.29 on the model page and 1078.14 on the leaderboard. Multilingual v2 has 1091.99 and Eleven v4 has 1321.44 [aa-tts-flash25] [aa-tts-ml2] [aa-tts-v4].
- **Speed (M).** Median throughput is 488.1 characters a second, far above the expressive models [aa-tts-board].
- **Price check (M).** Artificial Analysis lists US$50 per 1M characters. The pricing page gives US$40 [aa-tts-board] [el-pricing-api].
- **Maker claim.** In blind tests by its labelers, Flash outscored comparable ultra-low-latency models. No data is given [el-blog-flash].
- **Practitioner view (A).** One author says Flash v2.5 now wins only on price [pr-raxxo].

## Benchmarks

Independent: Artificial Analysis Speech Arena Elo of 1076.29 and a median of 488.1 characters a second [aa-tts-flash25] [aa-tts-board]. Maker: about 75 ms inference latency [el-models].

## Open questions

- Whether number normalisation is on or off by default. The models page says off, the best-practices page says on, and a changelog line says it was enabled for Flash [el-models] [el-tts-practices] [el-changelog-0908].
- Independent latency, with network time included.
- Whether Flash v2.5 supports tags in any form.
