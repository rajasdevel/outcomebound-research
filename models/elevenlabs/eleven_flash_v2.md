# Eleven Flash v2

Eleven Flash v2 is the English-only build of Flash. It belongs to the Eleven Flash class, generation 2, and ElevenLabs released it on 2024-12-18 with Flash v2.5 (launch post; the changelog entry is dated 2024-12-19) [el-blog-flash]. It has a model inference time of about 75 ms and takes up to 30,000 characters in a request. It is the default speech model of a new ElevenLabs agent. It replaced Turbo v2 [el-changelog-flash] [el-models] [el-api-agents] [el-agents-lang]. Family-wide rules are in the [ElevenLabs README](README.md). This file says what differs from [Eleven Flash v2.5](eleven_flash_v2_5.md).

## How to instruct it

### Setting up the prompt

- **The text is the prompt.** Emotion comes from the words around the speech, and the model reads descriptive text aloud [el-tts-overview].
- **Phoneme tags work here.** Flash v2 is the only model for which the guide says SSML `phoneme` tags are supported. The guide prefers CMU Arpabet for predictable results, and also allows IPA. A tag covers one word, so a first and last name needs two tags. The guide asks for stress marks on words of several syllables. On a WebSocket, set `enable_ssml_parsing=true` [el-tts-practices] [el-ws-tts].
- **Pronunciation dictionaries.** In agents, dictionary phoneme tags work with `eleven_flash_v2`, `eleven_v3` and `eleven_v4`. Other models need alias entries. The page says IPA and CMU notation in other languages needs v3 or v4, and English is the only language of Flash v2 [el-agents-pron].
- **Pauses.** `<break time="x.xs" />` up to 3 seconds. Many breaks can cause instability [el-tts-practices].
- **Numbers and symbols.** The guide's normalisation advice for small fast models applies. The models page names Flash v2.5 on this point, and the pages read do not say whether the same holds for v2. The guide's advice is to test phone numbers, dates and currencies, or to have the language model write them as words [el-models] [el-tts-practices].

### Reasoning and effort

None. ElevenLabs describes no reasoning or effort control for a speech synthesis model.

### Output: format, length, tone

- **Formats.** The same list as the other speech models. The default is `mp3_44100_128` [el-api-tts].
- **Length.** 30,000 characters a request, about 30 minutes of audio [el-models].
- **Tone.** Voice settings as on Flash v2.5. In agents, the default `speed` is 1 and the range is 0.7 to 1.2 [el-api-tts] [el-agents-speed].

### Tools and agents

- **Default agent model.** `eleven_flash_v2` is the default value of the agent speech model. The language guide says a new agent starts on Flash v2, and that English always uses v2 when other languages are added [el-api-agents] [el-agents-lang].
- **Advice.** The choose-a-model page names the Flash models for the lowest latency [el-choose].
- **Professional clones.** For a professional clone's identity in agents, the expressive-mode page points to Flash v2 rather than v3 Conversational [el-agents-expressive].

### Coding

As for Flash v2.5: HTTP stream for ready text, WebSocket and multi-context WebSocket for live use [el-latency-opt] [el-ws-multi].

### Long context and retrieval

The docs advise splitting long text and passing `previous_text` and `next_text`, or request ids. Request stitching does not work with Zero Retention Mode [el-stitching] [el-api-tts].

### Structured output

Not applicable. The WebSocket can return `alignment` timing data [el-ws-tts].

### Images, audio, other inputs

Text only, in English. The multilingual advice does not apply [el-models].

### Voice: turn-taking, interruption and speech style

Behaviour on the WebSocket, with `auto_mode`, `chunk_length_schedule`, `flush`, the 20-second timeout and multi-context barge-in, is the same as for [Eleven Flash v2.5](eleven_flash_v2_5.md) [el-ws-tts] [el-ws-multi].

- **Latency.** About 75 ms of model inference, without network and application time. The WebSocket time-to-first-byte figures the docs give for Flash models are 100 to 200 ms by region [el-models] [el-latency-opt].
- **Agents.** Turn timeout, eagerness, soft timeout and interruption settings belong to the platform. See the README [el-agents-flow].

### Sampling and API parameters

As for [Eleven Flash v2.5](eleven_flash_v2_5.md). `language_code` has no use for an English-only model [el-api-tts].

### Migrating from the previous generation

Flash v2 is the older generation in the class. To move to Flash v2.5 [el-models] [el-agents-lang]:

- Languages grow from English to 32. The limit grows to 40,000 characters.
- Phoneme tags stop working. Alias entries or respelling take their place.
- In agents, adding a language already moves the agent to v2.5.

The model it replaced is Turbo v2, which the docs call functionally equal with higher average latency [el-models].

## What the system card reports

ElevenLabs publishes no system card for Eleven Flash v2 in the pages read. The platform safeguards are in the [README](README.md) [el-safety].

## Behaviour observed in practice

No independent measurement was found. Artificial Analysis lists no entry for Flash v2 on its text-to-speech pages (read 2026-10-03) [aa-tts-board]. The maker gives about 75 ms of model inference and no other figure [el-models].

## Benchmarks

None independent. Maker: about 75 ms inference latency, without network and application time [el-models].

## Open questions

- Whether number normalisation on Flash v2 behaves like Flash v2.5.
- Independent quality and latency figures.
- The first-byte time for Flash v2 on the WebSocket. The docs give one set of figures for "Flash models".
