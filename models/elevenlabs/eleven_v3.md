# Eleven v3

Eleven v3 is a speech synthesis model of the Eleven Expressive class, generation 3. ElevenLabs showed it as an alpha research preview on 2025-06-03 (launch post; the changelog entry is dated 2025-06-08), opened it to the API on 2025-08-20 and took it out of alpha on 2026-02-02 [el-blog-v3]. It adds audio tags and multi-speaker dialogue to speech in 70+ languages. The docs now call it the previous generation, and Eleven v4 replaced it as the recommended expressive model [el-changelog-v3-alpha] [el-changelog-v3-api] [el-changelog-v3-ga] [el-models]. Family-wide rules are in the [ElevenLabs README](README.md). Most text rules are in the [Eleven v4 file](eleven_v4.md), and this file says what differs for v3.

## How to instruct it

### Setting up the prompt

- **The text is the prompt.** There is no system prompt. The v4 guide says that its techniques for voice choice, audio tags, punctuation and several speakers also apply to v3 [el-tts-practices].
- **Audio tags.** The launch post writes them in lowercase square brackets inside the script. The help pages give three groups: emotions (`[sad]`, `[angry]`, `[happily]`), delivery direction (`[whispers]`, `[shouts]`) and human reactions (`[laughs]`, `[clears throat]`, `[sighs]`). The same tags work on v3 and v4. The launch post gave a short example and showed tags for accents [el-v3-help] [el-tags-help] [el-blog-v3].
- **More prompt work.** At the alpha launch the maker said v3 needs more prompt engineering than earlier models, and that output is excellent when it works but less reliable. The February 2026 changelog says v3 is more stable and accurate and has lower latency since then [el-blog-v3] [el-changelog-v3-ga].
- **Pauses.** SSML break tags do not work on v3. The guide points to audio tags and ellipses instead [el-tts-practices].
- **Pronunciation.** The general guide says phoneme tags work only on Flash v2. The agent API says that for v3 models, phoneme tags are parsed into inline IPA, and it turns that on by default. The guides do not give v3 a method like the IPA of v4 [el-tts-practices] [el-api-agents] [el-changelog-0720].
- **Several speakers.** Text to Dialogue takes text and a `voice_id` for each turn. Tags go inside the turn they affect. Punctuation shows interruptions and trailing sentences [el-ttd-overview].
- **Voice choice.** At alpha the maker advised an instant or a designed voice, because professional clones were not fully tuned for v3. The v4 guide repeats this and points professional-clone users to v4 [el-blog-v3] [el-tts-practices].

### Reasoning and effort

None. ElevenLabs describes no reasoning or effort control for a speech synthesis model.

### Output: format, length, tone

- **Formats.** The same list as the other speech models. The default is `mp3_44100_128` [el-api-tts].
- **Length.** 5,000 characters a request, about 5 minutes. For Text to Dialogue the page advises 2,000 characters or fewer [el-models] [el-ttd-overview].
- **Tone.** Tags and wording set it. Voice settings: stability and similarity. Lower stability gives a wider emotional range [el-api-tts] [el-v4-page].
- **Endpoints.** The Text to Speech endpoint takes `eleven_v3`. Text to Dialogue defaults to it [el-v3-help] [el-api-ttd].

### Tools and agents

The agent API lists `eleven_v3_conversational`, `eleven_v4` and `eleven_v4_turbo` as speech models. It does not list `eleven_v3`. One agent page names `eleven_v3` for dictionary phoneme tags. Agent support is unconfirmed [el-api-agents] [el-agents-pron].

### Coding

The ElevenLabs CLI made `eleven_v3` its default speech model in version 1.2.0 (changelog entry of 2026-09-07) [el-changelog-0907].

### Long context and retrieval

The maker advises splitting long text into parts. The request-stitching guide says the feature is not available for `eleven_v3`. The Text to Dialogue endpoints take preceding and following text and request ids, and the docs say some models do not support them. They do not say whether v3 does [el-stitching] [el-api-ttd].

### Structured output

Not applicable.

### Images, audio, other inputs

Text only. Instant clones, designed voices and library voices work. Professional clones work, but the maker says they are not fully tuned for v3 and can give lower clone quality than earlier models [el-blog-v3] [el-tts-practices].

### Voice: turn-taking, interruption and speech style

Eleven v3 is not a conversation model. It has no turn detection and no barge-in.

- **Real time.** The alpha post said v3 was not suited to real-time use and named Flash and Turbo for that. Eleven v3 Conversational is the real-time version [el-blog-v3] [el-agents-expressive].
- **Streaming.** The Text to Speech WebSocket does not take v3. The Text to Dialogue WebSocket takes models that start with `eleven_v3` or `eleven_v4`. The API reference says up to 10 voices for `eleven_v3`. Turns end with `new_turn` or a voice change. The server waits for about 40 characters and 8 words, and a connection closes after 20 seconds without a message unless you send `keep_alive` [el-ws-tts] [el-ws-ttd] [el-api-ttd-ws].
- **Speech style.** Tags give whispers, sighs, laughter and accents. Ellipses give pauses and trailing speech. Dialogue can show interruptions through punctuation [el-ttd-overview] [el-tts-practices].
- **Barge-in.** The docs describe no cancel message for the WebSocket. Stopping playback is left to the client (inferred from the missing message).

### Sampling and API parameters

As for v4 [el-api-tts]: `voice_settings` (`stability` 0.5, `similarity_boost` 0.75, `style`, `speed`, `use_speaker_boost`), `seed`, `language_code`, `apply_text_normalization`, `use_pvc_as_ivc`, `pronunciation_dictionary_locators` (up to three) and `enable_logging=false` for Enterprise Zero Retention Mode. Text to Dialogue has `stability` and `similarity` settings [el-api-ttd]. Which voice settings act on v3 is not stated.

### Migrating from the previous generation

The previous model of the line is Eleven Multilingual v2, which is a separate class in this library. What changes [el-models] [el-tts-practices] [el-latency-concept]:

- Tags replace SSML breaks. Languages grow from 29 to 70+. The request limit falls from 10,000 to 5,000 characters.
- Latency is higher. The maker says the larger model and richer codec cost time, and that Flash speed and v3 quality do not come together.
- Request stitching and the Text to Speech WebSocket are not available.
- The list price is the same, US$0.08 per 1,000 characters [el-pricing-api].
- Professional clones are not fully tuned.

## What the system card reports

ElevenLabs publishes no system card for Eleven v3 in the pages read. The alpha post called the model a research preview. The platform safeguards are in the [README](README.md) [el-blog-v3] [el-safety].

## Behaviour observed in practice

- **Rank (M).** Artificial Analysis gives Elo 1171.45 on the model page and 1173.8 on its leaderboard table. Eleven v4 has 1321.44 and Multilingual v2 has 1091.99 [aa-tts-v3] [aa-tts-v4] [aa-tts-ml2].
- **Speed (M).** Median throughput is 31.6 characters a second, the lowest of the ElevenLabs models on that board [aa-tts-board].

## Benchmarks

Independent: Artificial Analysis Speech Arena Elo of 1171.45 and a median of 31.6 characters a second [aa-tts-v3] [aa-tts-board]. No maker benchmark was found.
