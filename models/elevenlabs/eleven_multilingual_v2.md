# Eleven Multilingual v2

Eleven Multilingual v2 is a speech synthesis model of the Eleven Multilingual class, generation 2. ElevenLabs published its launch post on 2023-08-22, the date Artificial Analysis also gives [el-blog-ml2]. It speaks 29 languages, takes 10,000 characters in a request and is the default model of the Text to Speech endpoint. The docs call it a previous generation and say it is the most stable model on long-form speech. It costs more per character than Flash and has higher latency [aa-tts-ml2] [el-models] [el-api-tts] [el-changelog-0512]. Family-wide rules are in the [ElevenLabs README](README.md).

## How to instruct it

### Setting up the prompt

- **The text is the prompt.** Emotion comes from narrative context and dialogue tags. The guide says explicit tags give more predictable results than context alone, and that the model reads those cue words aloud, so cut them in an editor if unwanted [el-tts-practices].
- **No audio tags.** Square-bracket tags are described for v3 and v4 [el-tags-help].
- **Pauses.** `<break time="x.xs" />` for up to 3 seconds. Many breaks can cause speed-ups or artefacts. Dashes and ellipses work less consistently [el-tts-practices].
- **Pronunciation.** Multilingual v2 does not support phoneme tags. The guide offers respelling or an alias entry in a pronunciation dictionary [el-tts-practices].
- **Numbers and symbols.** The guide says this larger model reads "$1,000,000" as "one million dollars", and recommends it for phone numbers and other cases where normalisation matters. For low-latency use, normalise in the language model prompt instead [el-tts-practices] [el-models].
- **Language.** `language_code` is not supported on this model. The overview advises a voice whose accent fits the target language and region [el-api-tts] [el-tts-overview].

### Reasoning and effort

None. ElevenLabs describes no reasoning or effort control for a speech synthesis model.

### Output: format, length, tone

- **Formats.** The same list as the other speech models. The default is `mp3_44100_128` [el-api-tts].
- **Length.** 10,000 characters a request, about 10 minutes of audio [el-models].
- **Tone.** Voice settings: `stability`, `similarity_boost`, `style`, `speed` and `use_speaker_boost`. Style and speaker boost add compute. `speed` runs from 0.7 to 1.2 [el-api-tts] [el-tts-practices].
- **Consistency.** The maker names long-form generations as the strength of this model [el-models].

### Tools and agents

`eleven_multilingual_v2` is an agent speech model. The models page lists it for agents. The choose-a-model page names the Flash models and v4 Turbo for agents [el-api-agents] [el-models] [el-choose].

### Coding

HTTP, stream, WebSocket and multi-context WebSocket endpoints take this model. Because it is the default model of the Text to Speech endpoint, a call without `model_id` uses it [el-api-tts] [el-ws-tts].

### Long context and retrieval

The docs advise splitting text longer than 10,000 characters, and passing `previous_text` and `next_text`, or up to three request ids no older than two hours. The request-stitching guide shows the effect on prosody across parts [el-stitching] [el-api-tts].

### Structured output

Not applicable. The WebSocket can return `alignment` timing [el-ws-tts].

### Images, audio, other inputs

Text only. The model keeps a voice's character and accent across its 29 languages. Professional clones work, but the maker notes that they add per-request overhead compared with instant clones [el-models] [el-latency-concept].

### Voice: turn-taking, interruption and speech style

- **Latency.** The docs give no figure. They say latency is higher than on Flash models [el-models].
- **Streaming and barge-in.** The Text to Speech WebSocket and the multi-context WebSocket take this model. The behaviour is the same as for [Eleven Flash v2.5](eleven_flash_v2_5.md): `chunk_length_schedule`, `auto_mode`, `flush`, a 20-second timeout and up to five contexts for barge-in [el-ws-tts] [el-ws-multi].
- **Speech style.** The voice sample sets the pace. The guide offers `speed`, narrative style and punctuation [el-tts-practices].
- **Turn-taking.** None in the model. In agents, the platform decides [el-agents-flow].

### Sampling and API parameters

`voice_settings`, `seed`, `apply_text_normalization`, `pronunciation_dictionary_locators` (up to three) and `enable_logging=false` for Enterprise. `language_code` is not supported [el-api-tts].

### Migrating from the previous generation

Multilingual v1 and Monolingual v1 came before this model. The changelog set their removal for 2026-07-09, and made Multilingual v2 the default of the Text to Speech endpoint on 2025-05-12 [el-changelog-0608] [el-changelog-0512]. To move up to a newer model [el-models] [el-tts-practices]:

- To Eleven v3 or v4: tags replace SSML breaks, languages grow to 70+ or 90+ and the limit changes (5,000 for v3, 10,000 for v4).
- To Flash v2.5: latency drops and the price per character halves, at lower quality and weaker number handling.

## What the system card reports

ElevenLabs publishes no system card for Eleven Multilingual v2 in the pages read. The platform safeguards are in the [README](README.md) [el-safety].

## Behaviour observed in practice

- **Rank (M).** Artificial Analysis gives Elo 1091.99 on the model page and 1096.95 on the leaderboard. Eleven v3 has 1171.45 and Eleven v4 has 1321.44 [aa-tts-ml2] [aa-tts-v3] [aa-tts-v4].
- **Speed (M).** Median throughput is 97.2 characters a second [aa-tts-board].
- **Price check (M).** Artificial Analysis lists US$100 per 1M characters. The pricing page gives US$80 [aa-tts-ml2] [el-pricing-api].
- **Practitioner view (A).** One author notes that many production pipelines still run on this model [pr-raxxo].

## Benchmarks

Independent: Artificial Analysis Speech Arena Elo of 1091.99 and a median of 97.2 characters a second [aa-tts-ml2] [aa-tts-board]. No maker benchmark was found.
