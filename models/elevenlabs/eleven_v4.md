# Eleven v4

Eleven v4 is the speech synthesis model of the Eleven Expressive class, generation 4. ElevenLabs released it on 2026-09-28. It turns text into speech in 90+ languages. It takes audio tags for delivery, IPA for pronunciation and several speakers in one script. The docs recommend it over Eleven v3 for quality. Eleven v4 Turbo is its low-latency variant [el-changelog-v4] [el-v4-page]. Family-wide rules are in the [ElevenLabs README](README.md).

## How to instruct it

### Setting up the prompt

- **The text is the prompt.** The model has no system prompt and no role. It reads the script, the tags and the punctuation. The voice you pick matters as much as the words [el-tts-practices].
- **Voice choice.** A delivery that exists in the voice's training audio is easier to reproduce. The guide says v4 follows tags better than earlier models, even on a voice that never whispered or shouted. It adds that the result can be less reliable, and it advises testing with the chosen voice [el-tts-practices].
- **Audio tags.** A tag is a short instruction in square brackets, placed where the delivery changes. The guide lists voice tags (`[laughs]`, `[whispers]`, `[sighs]`, `[sarcastic]`, `[curious]`, `[excited]`, `[crying]`), sound-effect tags (`[applause]`, `[gunshot]`, `[explosion]`) and experimental tags (`[strong X accent]`, `[sings]`). Tags are natural-language instructions, not a fixed list. Direction tags can be longer, such as a quiet, measured narration or a gradually building energy [el-tts-practices] [el-ttd-overview].
- **Explicit tags.** The model makes both voice styles and sound effects, so a tag can be read as a sound cue. The guide advises tags that describe the voice quality wanted (its example is a low, gravelly voice) and says to test them [el-tts-practices].
- **Tags and the voice.** The guide says a meditative voice should not shout and a hyped voice does not whisper well. It allows combined tags for a complex delivery and invites tests of descriptive tags beyond its list. It says the model does not follow every tag yet [el-tts-practices] [el-v4-page].
- **Punctuation.** Ellipses add pauses and weight. Capital letters add emphasis. Normal punctuation sets rhythm. The guide says the structure of the text strongly shapes the output [el-tts-practices].
- **Several speakers.** The Text to Dialogue API takes a list of inputs, each with a text and a `voice_id`. A request can hold up to 10 distinct voices. Tags go inside the text of the turn they affect. The guide's examples show talk that cuts in with dashes and tags such as an interruption or an overlap [el-ttd-overview] [el-api-ttd] [el-tts-practices].
- **Pronunciation.** v4 reads IPA between forward slashes inside the sentence, as in the guide's chemistry example. The guide asks for primary and secondary stress marks, and for IPA only on the words that need it. Results can vary by voice. For an exact result, the guide advises testing and generating more than once [el-tts-practices]. Pronunciation dictionaries also take phoneme tags for v4 in agents [el-agents-pron].
- **Not supported.** SSML break tags, SSML in general, and the Style and Speed sliders. Pauses come from tags and ellipses [el-v4-page] [el-tts-practices].

### Reasoning and effort

None. ElevenLabs describes no reasoning or effort control for a speech synthesis model.

### Output: format, length, tone

- **Formats.** MP3, PCM, WAV, Opus, mu-law and A-law. The default is `mp3_44100_128`. MP3 at 192 kbps needs the Creator plan or above. PCM and WAV at 44.1 kHz need Pro or above [el-api-tts].
- **Length.** 10,000 characters a request, about 10 minutes of audio. For Text to Dialogue, the page advises 2,000 characters or fewer in all inputs, and says longer requests can stop early in streaming or return an error [el-models] [el-ttd-overview] [el-api-ttd].
- **Tone.** Tags, wording and punctuation set it. The two voice settings are stability and similarity. Lower stability gives a more varied and expressive delivery. Higher stability stays closer to a fixed baseline. Higher similarity holds closer to the reference voice and can cost some naturalness [el-v4-page].
- **Output is not repeatable.** A `seed` gives a best effort at the same result. The maker says that regenerating fixes about half of the quality faults [el-tts-overview] [el-api-tts].

### Tools and agents

The model calls no tools. In ElevenAgents it is a choice of speech model (`eleven_v4`). The models page lists `eleven_v4_turbo`, both Flash models and Multilingual v2 for agents, and the choose-a-model page lists v4 Turbo and the Flash models. Neither lists `eleven_v4`, although the agent API accepts it [el-models] [el-choose] [el-api-agents]. Agent settings such as `expressive_mode` and `suggested_audio_tags` are described for v3 models. Whether they act on v4 is not stated [el-api-agents].

### Coding

ElevenLabs gives SDK examples with `model_id="eleven_v4"` (Python) and `modelId: "eleven_v4"` (TypeScript) [el-tts-practices]. The CLI command `elevenlabs say` made `eleven_v3` its default model in version 1.2.0 (changelog entry of 2026-09-07), so a script that wants v4 names the model [el-changelog-0907]. A hosted MCP server lets an MCP client generate speech [el-tts-overview].

### Long context and retrieval

The maker advises splitting long text into parts. The Text to Dialogue endpoints accept preceding and following text and request ids for continuity. `previous_text` and `future_text` take 100 characters at most, and each request id list takes three ids at most. The guide on request stitching says the feature is not available for `eleven_v3` and gives no statement for v4. The launch post says request stitching is much more reliable on v4, and names Studio and the Reader app as the places that gain [el-changelog-v4] [el-api-ttd] [el-stitching] [el-blog-v4]. A news site says the launch material describes "context stitching" for long projects [pr-testingcatalog].

### Structured output

Not applicable. Some endpoints return timing data with the audio, such as the `sync_alignment` option on the Text to Dialogue WebSocket [el-ws-ttd].

### Images, audio, other inputs

The model takes text only. Voices come from the library, from cloning and from Voice Design.

- **Cloning.** Instant and professional voice clones both work with v4. The page says v4 copies timbre, cadence and delivery more closely than earlier models, and so a v4 clone can sound unlike its v3 version. The page asks for clean source audio and a single speaking style, because v4 copies flaws too. It says this advice may change. The page says an instant clone needs one to two minutes. The launch post says 10 seconds can be enough [el-v4-page] [el-blog-v4].
- **Professional clones.** The page says support is still rolling out. To train an existing professional clone on v4, the owner starts a v4 fine-tune from the My Voices page. An instant clone needs no separate training step [el-v4-page].
- **Accent.** If the text language equals the sample language, the accent stays. If the language differs, v4 speaks natively in the new language and drops the sample accent. The maker calls this deliberate, says it is still being tuned, and says a toggle is only a research idea. A tag may nudge an accent, with varying results [el-v4-page].
- **Voice Design.** Designed voices work with v4 and can be less performative than with earlier models [el-v4-page] [el-voices].

### Voice: turn-taking, interruption and speech style

Eleven v4 is not a conversation model. It has no turn detection and no barge-in. The surrounding system supplies them.

- **Speech style.** Tags and text set it. The guide's examples set pace with direction tags (a quick, light pace; a measured pace; a brief pause), pauses with ellipses and delivery with tags such as `[sighs]` [el-tts-practices].
- **Fillers.** The guide describes no filler control for v4. An older note says a voice trained with fillers such as "uh" can pause differently, and advises tests with the chosen voice [el-tts-practices].
- **Interruptions in the script.** The dialogue examples show a speaker cut off with a dash and a tag. They do not describe a live control [el-tts-practices].
- **Turns in a stream.** On the Text to Dialogue WebSocket, `new_turn` or a change of `voice_id` ends a turn. The server waits for about 40 characters and 8 words before it sends audio, unless the client sends `flush`. A connection closes after 20 seconds without a message unless the client sends `keep_alive`. `eleven_v4` takes up to 10 registered voices [el-ws-ttd] [el-ws-compare].
- **Barge-in in your own pipeline.** The docs describe no cancel message for this WebSocket, so stopping playback is left to the client (inferred from the missing message). The multi-context WebSocket is made for barge-in, but it belongs to the Text to Speech WebSocket family, which does not accept v3 or v4 [el-ws-multi] [el-ws-compare].
- **Live agents.** ElevenLabs points to `eleven_v4_turbo`, which it built to work with its agent platform, transcription and turn-taking models as one stack [el-blog-v4-agents].

### Sampling and API parameters

- `voice_settings`: `stability` (default 0.5), `similarity_boost` (0.75), `use_speaker_boost` (true), `style` (0) and `speed` (1). v4 uses stability and similarity. Whether `style` and `speed` do anything on v4 is not stated [el-api-tts] [el-v4-page].
- Text to Dialogue `settings`: `stability` (0.5) and `similarity` (0.75) [el-api-ttd].
- `seed`: an integer from 0 to 4294967295. `language_code`: ISO 639-1, ignored if the model does not support it. `apply_text_normalization`: `auto`, `on` or `off`. `use_pvc_as_ivc`: use the instant version of a professional clone, which can cut latency and add expressiveness. `pronunciation_dictionary_locators`: up to three. `enable_logging=false`: Zero Retention Mode, for Enterprise only [el-api-tts].

### Migrating from the previous generation

The previous generation is Eleven v3. What changes [el-v4-page] [el-models] [el-tts-practices]:

- A new architecture. Languages grow from 70+ to 90+. The request limit grows from 5,000 to 10,000 characters.
- Clones follow the source voice more closely, so they can sound different. The maker advises comparing both models on one's own voices.
- Cross-language speech drops the sample accent.
- IPA between slashes is the pronunciation method. Break tags do not work on v3 or v4, and SSML does not work on v4.
- Professional clones are supported on v4 (v3 is not fully tuned for them).
- The Text to Dialogue WebSocket takes v4 (up to 10 voices) and v4 Turbo (one voice).
- The list price is the same, US$0.08 per 1,000 characters, with a promotion to 2026-10-12 [el-pricing-api].
- The maker says v4 will keep changing after launch and says to test a use case again from time to time [el-v4-page].
- A practitioner warns that a tag which v3 ignored may now take effect, and advises a search of scripts for leftover tags before a batch run (evidence class A) [pr-raxxo].

## What the system card reports

ElevenLabs publishes no system card for Eleven v4 in the pages read. The platform safeguards (consent checks and verification for cloning, blocked high-risk voices, an AI Speech Classifier) are in the [README](README.md) [el-safety]. A news site says every cloned voice needs verified owner consent [pr-testingcatalog]. The docs say the model follows tags better than earlier models but not perfectly [el-v4-page].

## Behaviour observed in practice

- **Rank (M).** Artificial Analysis states that Eleven v4 has the highest quality in its text-to-speech comparison, with an Elo of 1321.44 on the day this file was read [aa-tts-v4].
- **Speed (M).** Median throughput of 73.5 characters a second, against 31.6 for Eleven v3 on the same board [aa-tts-board].
- **Launch-day view (A).** A practitioner reports that v4 entered the same leaderboard first and about 150 Elo points above v3. The author had not yet run a listening test and says to render one paragraph with your own clone on both models and compare on headphones [pr-raxxo].
- **Raw output keeps flaws.** The maker says its showcase clips are unprocessed, and that clipping, plosives or volume jumps in them are likely in the voice's training audio [el-v4-page].
- No other independent report was found.

## Benchmarks

Independent: the Artificial Analysis Speech Arena Elo of 1321.44 (blind pairwise votes) and a median of 73.5 characters a second [aa-tts-v4] [aa-tts-board]. Maker: about 75% listener preference over four competing models in a blind test, with ties counted as half, run in September 2026 by ElevenLabs [el-blog-v4-agents]. The code and agent benchmarks of this library do not apply to a speech model.

## Open questions

- Whether professional clones work on v4 for every account. The page says the rollout was in progress.
- Whether an existing instant clone must be made again for v4. The docs say an instant clone needs no training step and an existing professional clone needs a v4 fine-tune. A news site says older instant and professional clones need retraining [el-v4-page] [pr-testingcatalog].
- Whether `style`, `speed` and `expressive_mode` act on v4.
- Whether request stitching through the API works on v4. The launch post says it is more reliable on v4 in Studio and the Reader app, and the stitching guide does not name v4 [el-blog-v4] [el-stitching].
- Credit cost of v4 on the website. The pages read give only the API price.
- Independent latency for v4. The maker gives none for this model.
