# Eleven Realtime v1 Mini

Eleven Realtime v1 Mini is the faster and cheaper of the two Eleven Realtime models, ElevenLabs' first speech-in, speech-out models for voice agents, launched on 2026-10-20. It is the default Realtime model in ElevenAgents. The maker points it at assistants, tutors and interactive characters, where the conversation itself is the product, and says it is enough for most uses. It is in gradual rollout; this library records it as preview for that reason, although the maker does not use the word [el-blog-rt] [el-rt-models] [el-changelog-1019].

## How to instruct it

### Setting up the prompt

- **What the model is.** One model id selects a whole voice agent: speech recognition, voice activity detection and turn-taking, a language model and speech synthesis, chosen and tuned by ElevenLabs as one system. ElevenLabs calls the class Speech to Speech, but it is a cascade of distinct models, not a fused model. Which component models it uses is not public [el-models-1031] [el-rt-openai] [el-blog-rt].
- **In ElevenAgents.** Set the agent's Voice mode to Realtime, or set `conversation_config.realtime_model`. The system prompt, first message, voice, languages, temperature, tools, knowledge base and conversation-flow settings work as in Custom mode, so the [agents prompting guide](README.md#prompting-guides) applies. ElevenLabs then manages the LLM, reasoning effort, thinking budget, parallel tool calls, cascade timeout, TTS model, expressive mode and ASR provider, and ignores the stored values; set `realtime_model` to `null` to return to them [el-rt-models].
- **Keep Custom mode** for a custom LLM, Amazon Bedrock or Speech Engine, a specific LLM or TTS model, workflow nodes that override a managed setting, transfers to or from Custom-mode agents, or a text-only agent [el-rt-models].
- **On the Realtime API.** The session takes `instructions` (the system prompt), `model`, `output_modalities`, `audio`, `tools`, `tool_choice` (default `auto`), `temperature` (default 0.7) and `max_response_output_tokens` (default 4096). The `model` string selects the agent's behaviour directly, with no `agent_id`. The session sent when the client secret is minted is the authoritative first session [el-rt-secret] [el-rt-openai].

### Reasoning and effort

Not documented. ElevenLabs says Max reasons before it responds; it says nothing of Mini. In ElevenAgents, reasoning effort and thinking budget are managed settings. The Realtime API session has an undocumented `reasoning` map [el-rt-models] [el-rt-secret].

### Output: format, length, tone

Speech in the chosen voice. On the Realtime API, `output_modalities` takes `audio` in the maker's examples. `max_response_output_tokens` caps a reply [el-rt-secret] [el-rt-openai]. ElevenLabs manages the TTS model and expressive mode, so the audio-tag guidance for Eleven v3 and v4 does not carry over unless the maker says so; the pages read do not [el-rt-models].

### Tools and agents

- **Realtime API.** `tools` takes `function` tools (name, description, JSON parameters) and `mcp` tools (server label and URL, allowed tools, authorization, `require_approval` `never` or `always`); `tool_choice` is `auto` by default, and `parallel_tool_calls` is accepted [el-rt-secret].
- **ElevenAgents.** The agent's tools and knowledge base work as in Custom mode; parallel tool calls are a managed setting. If the Realtime model does not answer in time or errors, the agent falls back to its backup LLMs, and the model sets the wait [el-rt-models].
- **Transfers.** A Realtime agent can transfer only to and from other Realtime agents; Mini to Max and back works [el-rt-models].
- **Which tier.** The maker recommends Max for frequent or complex tool calls. On Artificial Analysis's Speech Agent Arena, Mini completed 60.3% of tool-use tasks against 87.1% for Max [el-blog-rt] [aa-s2s-arena].
- **Compliance.** Mini is not available under Zero Retention Mode or HIPAA; use Max there [el-rt-models].

### Coding

The Realtime API follows OpenAI's Realtime wire protocol: the same client and server events over WebSocket. A backend mints a short-lived client secret with `POST /v1/convai/realtime/client_secrets` (ElevenLabs SDK `conversational_ai.realtime.create_client_secret`), and the browser passes it to OpenAI's `@openai/agents-realtime` SDK with the transport pointed at `wss://api.elevenlabs.io/v1/convai/realtime`. The SDK wires audio only for WebRTC, so over WebSocket the client captures and plays PCM16 at 24 kHz itself. WebRTC is not supported, and the docs for server-side OpenAI Realtime SDKs are not published yet. The Realtime API runs apart from ElevenAgents, without its channels, knowledge base or guardrails [el-rt-openai] [el-rt-secret] [el-blog-rt] [el-rt-page].

### Long context and retrieval

The context window is not published. In ElevenAgents the knowledge base works as in Custom mode [el-rt-models].

### Structured output

A function tool takes a name, a description and a `parameters` object. The pages read describe no structured-output mode for replies [el-rt-secret].

### Images, audio, other inputs

Audio in. The pages read describe no image input. ElevenLabs advises Custom mode for a text-only agent [el-rt-models].

### Voice: turn-taking, interruption and speech style

- **Turn detection.** On the Realtime API, `turn_detection.type` is `semantic_vad` (default) or `server_vad`, with `eagerness` `low`, `medium` (default) or `high`. `create_response` and `interrupt_response` default to `true`. `threshold`, `prefix_padding_ms`, `silence_duration_ms` and `turn_timeout` (default -1) are also accepted. `pacing` is `realtime` (default) or `bursty`, for a client that streams ahead of wall time [el-rt-secret].
- **In ElevenAgents.** Turn eagerness, timeouts and interruptions are set as for any agent; see the [README](README.md#prompting-guides) [el-rt-models].
- **Interruption.** On by default (`interrupt_response`). The maker says the models handle turn-taking and interruption naturally [el-rt-secret] [el-models-1031].
- **Language.** `audio.input.transcription.language` sets the language of transcription, speech and reply; the default is `en` [el-rt-secret].
- **Voice.** `audio.output.voice` (default `brian`), any library voice [el-rt-secret] [el-blog-rt].
- **Visibility.** Because the system is a cascade, each step produces text: what the agent heard and what it decided to say. The maker says this lets ElevenAgents apply guardrails and PII redaction to a Realtime agent [el-blog-rt].

### Sampling and API parameters

`temperature` (default 0.7 on the Realtime API). In ElevenAgents the dashboard hides temperature in Realtime mode; the CLI or API changes it [el-rt-secret] [el-rt-models].

### Migrating from the previous generation

There is no previous generation. From a Custom-mode agent, switch Voice mode; the stored LLM, TTS and ASR settings come back when the agent returns to Custom. From OpenAI's Realtime API, change the endpoint and the model name; a WebRTC client must move to WebSocket first [el-rt-models] [el-blog-rt] [el-rt-openai]. Switching between Mini and Max is a model selection, not an integration change [el-models-1031].

## What the system card reports

ElevenLabs publishes no system card or model card for the Realtime models, and says the specifics of the component models are not public. The pages read give the compliance limits only: see the card's access row [el-rt-openai] [el-rt-models].

## Behaviour observed in practice

- **Speed against reasoning (M).** Artificial Analysis measures Mini at 0.62 s to first audio and 75.9% on Big Bench Audio, against 0.57 s and 98.8% for Max. Mini is not faster than Max on this measure, although the maker calls it the lowest-latency Realtime model [aa-s2s-1031] [el-rt-models].
- **Conversational dynamics (M).** Mini scores 95.8% on Full Duplex Bench, a little above Max (94.1%), with higher backchannel handling (86.7 against 79.6) [aa-s2s-1031].
- No practitioner report was read.

- When the gradual rollout ends.
- Whether the token rates count text tokens only, and whether a cached-input rate applies.
