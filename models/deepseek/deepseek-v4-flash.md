# DeepSeek V4-Flash (0731)

DeepSeek V4-Flash is the small model of DeepSeek's V4 series: a 284B-parameter mixture-of-experts model with 13B parameters active per token, a 1M-token window and text input only. This file covers the 0731 release of 2026-07-31, which DeepSeek made by post-training the 2026-04-24 Preview again on the same architecture and size. It belongs to the class DeepSeek Flash, generation 4, the generation before [V4.1-Flash](deepseek-flash.md). DeepSeek retired it from its API on 2026-09-10, when V4.1-Flash replaced it, but the weights stay public under the MIT licence, so it stays in scope for local use. What DeepSeek's models share (API, formats, switches, safety evidence) is on the [DeepSeek page](README.md); this file says what is specific to V4-Flash.

## How to instruct it

DeepSeek publishes no prompt-writing guide for V4-Flash. This section reports what the model card, its prompt-format reference, the Preview technical report and the API pages say. The API pages were read on 2026-10-03 and describe the current ids; DeepSeek's change log says the calling method stayed unchanged when 0731 shipped, so they are the closest record of how this model was driven [deepseek-changelog].

### Setting up the prompt

- **System prompt.** The model takes a normal system message. In its own prompt format the system text sits at the start of the sequence; tool definitions are added to it as a schema block, and the high and max effort levels each add a text prefix before the system message [hf-v4-flash-0731-encoding].
- **No Jinja template.** The weights ship no chat template. The `encoding` folder's Python scripts are the reference for turning OpenAI-style messages into the model's input string and for parsing its output; the parser expects well-formed output only [hf-v4-flash-0731] [hf-v4-flash-0731-encoding].
- **Roles.** `system`, `user`, `assistant` and `tool`. A `developer` role exists in the format but DeepSeek says it is used only in an internal search pipeline and the official API does not accept it [hf-v4-flash-0731-encoding].
- **Instruction style, placement, examples.** DeepSeek gives no advice on roles, personas, tags, Markdown, examples or document placement. Its caching guide implies keeping stable material first and varying text last, because only whole stored prefixes hit the cache [deepseek-context-caching].
- **Instruction load.** No test of how many simultaneous instructions V4-Flash follows was found.

### Reasoning and effort

- **The control.** Thinking is a switch plus an effort level. The model card says `reasoning_effort` has three levels, `low`, `high` and `max`. In the prompt format the level is a text prefix placed before the system message: `low` is the encoding's default and adds none, and `high` and `max` each add a multi-sentence instruction. DeepSeek's API guide gives `high` as the API default, but this model is no longer served there. Thinking can also be off (the "chat" mode, which closes the reasoning block at once) [hf-v4-flash-0731] [hf-v4-flash-0731-encoding].
- **What the levels are.** The Preview report says each mode was trained with its own length penalty and context window in reinforcement learning, and that max beat high on the hardest tasks [deepseek-v4-report] (class L). In the encoding reference, the high prefix asks for thorough decomposition, checks against edge cases and a written record of rejected hypotheses; the max prefix asks for decomposition to root causes and verification from several angles before stopping [hf-v4-flash-0731-encoding].
- **Output budget.** For high and max the model card recommends an output limit of 384K tokens [hf-v4-flash-0731].
- **Interleaved thinking.** With tools in the request the format keeps all earlier reasoning, including across new user messages; without tools it removes reasoning from turns before the last user message (`drop_thinking`, default on). The report advises non-thinking mode for agent frameworks that simulate tools through user messages, because those never enter the tool path [hf-v4-flash-0731-encoding] [deepseek-v4-report].
- **Visibility.** Reasoning is returned as raw text in `reasoning_content`. The Anthropic format ignored `thinking.budget_tokens` and honoured only the effort level; the Responses format gives no reasoning summary [deepseek-anthropic-api] [deepseek-responses].
- **Step-by-step prompting.** No advice for this model.

### Output: format, length, tone

- **Length.** No verbosity control: the Responses format accepts `text.verbosity` and ignores it. Output length is set by `max_tokens` and up to 16 `stop` sequences [deepseek-responses] [deepseek-chat-api].
- **Prefill.** Assistant-prefix completion was a beta feature on the `/beta` base URL: end the list with an assistant message that has `prefix: true` [deepseek-chat-api].
- **Style.** DeepSeek publishes nothing on tone or formatting defaults for 0731. Artificial Analysis counted 240M output tokens across its index run, against a median of 140M [aa-v4-flash-0731].

### Tools and agents

- **Format.** Tool calls are written in an XML-like block with a `DSML` markup token: one `tool_calls` block holds `invoke` elements, each with `parameter` elements that carry a `string` attribute (`true` for raw strings, `false` for JSON values). DeepSeek's report says this reduced escaping failures. Tool results go back inside `tool_result` tags in a user turn, ordered like the calls [hf-v4-flash-0731-encoding] [deepseek-v4-report]. The tag spelling differs in V4.1 (see migration).
- **Definitions.** Function tools with JSON Schema. On Chat Completions `tool_choice` accepts `none`, `auto`, `required` or a named function, but the last two are rejected in thinking mode. Strict schemas were a beta feature on the `/beta` URL [deepseek-chat-api] [deepseek-tool-calls].
- **Reasoning must travel with the history.** With tools present, earlier `reasoning_content` goes back in the request; omission returns 400 [deepseek-thinking-mode].
- **Codex.** DeepSeek's 0731 notice says the model supports the Responses format natively and was adapted for Codex [deepseek-changelog] [deepseek-codex].
- **Agent harness.** DeepSeek's 0731 results used its own harness in "minimal" mode, which it had not yet released [hf-v4-flash-0731].
- **Preview versus 0731.** DeepSeek's table shows the Preview Flash trailing the Preview Pro on agent tasks, and 0731 passing both (Benchmarks, below) [hf-v4-flash-0731].
- **Computer use.** Not offered: no image input.

### Coding

- **Maker table.** In DeepSeek Harness minimal mode at max effort, temperature 1.0 and top-p 0.95: Terminal-Bench 2.1 82.7 (Claude Opus 4.8 85.0, GLM-5.2 81.0), DeepSWE 54.4 (58.0; 46.2), NL2Repo 54.2 (69.7; 48.9), CyberGym 76.7 (83.1; not reported) [hf-v4-flash-0731] (class L). The card says 0731 beats the Preview Pro on all listed tests.
- **Independent.** Artificial Analysis lists a coding-agent run for the model, but its scores did not render as text; no independent agentic-coding number was read [aa-v4-flash-0731].
- **Harnesses.** DeepSeek's integration pages cover Claude Code and Codex; neither gives a per-harness table for 0731.

### Long context and retrieval

- **Limits.** 1M tokens of context, up to 384K tokens of output per DeepSeek's pages for the V4 ids [deepseek-pricing].
- **Architecture.** The report says at 1M tokens V4-Flash needs 10% of the per-token compute and 7% of the KV cache of V3.2 [deepseek-v4-report].
- **Retrieval quality.** Retrieval in the Preview tests stayed stable within 128K and degraded visibly beyond it; the retrieval figures that DeepSeek gives are for V4-Pro, not Flash [deepseek-v4-report]. Artificial Analysis's long-context reasoning component (AA-LCR) was not read for this model.
- **Caching.** Prefix caching on disk is automatic on the API; for local serving the vLLM recipe uses an FP8 KV cache [deepseek-context-caching] [hf-v4-flash-0731].

### Structured output

- **JSON mode.** DeepSeek's guide says `response_format: {type: json_object}` needs the word "json" and an example of the format in the prompt, and a `max_tokens` high enough to avoid truncation; it warns that the API may sometimes return empty content [deepseek-json].
- **No schema-constrained format.** Schemas applied to tool calls only (strict mode, beta) [deepseek-tool-calls].

### Images, audio, other inputs

Text only. DeepSeek issued a separate experimental vision model on 2026-08-21 (V4-Flash-Vision-Exp) and then built vision into V4.1-Flash; V4-Flash-0731 itself takes no images, audio or video [deepseek-changelog] [aa-v4-flash-0731].

### Sampling and API parameters

- For local deployment DeepSeek recommends temperature 1.0, with top-p 0.95 for agentic use and 1.0 otherwise [hf-v4-flash-0731].
- On the API in thinking mode, `temperature` and the penalties were accepted and ignored and `top_p` was raised to at least 0.95; without thinking `temperature` ran 0 to 2 [deepseek-thinking-mode] [deepseek-chat-api].
- Serving: the card shows vLLM and SGLang flags for DSpark speculative decoding (seven speculative tokens in the vLLM example) and the weights carry the draft module [hf-v4-flash-0731].

### Migrating from the previous generation

- **From the Preview.** Same name, architecture and size; only post-training changed. DeepSeek's table: Terminal-Bench 2.1 61.8 to 82.7, DeepSWE 7.3 to 54.4, NL2Repo 39.4 to 54.2, CyberGym 38.7 to 76.7, Toolathlon-Verified 49.7 to 70.3 [hf-v4-flash-0731]. Anything measured on the Preview describes an earlier model.
- **From `deepseek-chat` and `deepseek-reasoner`.** Until their retirement after 2026-07-24 these names pointed to the Preview's non-thinking and thinking modes [deepseek-news-260424].
- **To V4.1-Flash.** DeepSeek retired this model on 2026-09-10 and routes the legacy id `deepseek-v4-flash` to V4.1-Flash for now, billed at Flash prices. V4.1-Flash reads images, uses a new architecture and changes the DSML tag spelling; see the [V4.1-Flash file](deepseek-flash.md) [deepseek-changelog] [deepseek-pricing].

## What the system card reports

DeepSeek publishes no system card for V4-Flash. The model card has a nine-row benchmark table, run settings, serving notes and the licence. The technical report describes the Preview and has no safety or alignment section: nothing on refusals, reward hacking, sycophancy, deception, prompt-injection resistance, or biology and cyber policies [hf-v4-flash-0731] [deepseek-v4-report]. The only cyber-related number is the CyberGym capability score. For independent safety findings on the V4 line see the [DeepSeek page](README.md#family-wide-behaviour); they were measured on other builds.

## Behaviour observed in practice

- **Speed and cost (class M).** Artificial Analysis measured about 207 output tokens a second and 1.11 s to the first token over DeepSeek's API, $0.22 per index task, and 240M output tokens for the index run [aa-v4-flash-0731].
- **Standing.** The same page ranks it 11 of 118 models on the index and marks it deprecated for benchmarking, naming V4.1-Flash as its replacement [aa-v4-flash-0731].
- No practitioner review of the 0731 build was read.
