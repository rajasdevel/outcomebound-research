# Research index

Facts about large language models, coding-agent harnesses, model providers and the engineering
practices around them, each dated and sourced, for people and for agents. The base is neutral: it
describes the outside world for any use of these models. Applications build a judgement on the base
for one use. Dated research is context, not a rule: a design or a guide may cite a document by path,
section and evidence id, and the decision stays with whoever cites it.

How to read it:

1. Find the document in the tables below by its scope, and read only that one. For a model, the
   table in [models/README.md](models/README.md) lists every model with its file.
2. Read its `last_checked` and `volatility` first. VOLATILE facts (prices, defaults, betas, open
   bugs) are worth re-checking at the source before you rely on them; the
   [conventions](CONVENTIONS.md) give each class's window.
3. Each claim carries an evidence class (M L P A S F O) and a bracketed id into [`_evidence/`](_evidence/),
   or a URL with the day it was read. The classes and the other rules are in [CONVENTIONS.md](CONVENTIONS.md).

Each model has a card (JSON) next to its file in `models/<maker>/`; the card format, the model-file
template and the maker README template are in [models/FORMAT.md](models/FORMAT.md), and the provider
template and kinds are in [providers/README.md](providers/README.md). These four pages carry no row
below: [models/README.md](models/README.md), [models/FORMAT.md](models/FORMAT.md),
[providers/README.md](providers/README.md) and [applications/README.md](applications/README.md).
